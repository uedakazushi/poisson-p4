# 六変数関数体上の monic 次元判定：独立監査

2026年11月3日。frozen producer を別 directory で再実行し、秒数以外の全 report/evidence が一致した。
Cloud M2 の有限被約例・有限非被約例の unit cofactor、双曲線の非unitと change matrix を含む。
全134式が元の五変数断面入力と文字通り一致し、q32 の係数−1の消去が全座標の順列だけを使い、
座標や方程式を切り捨てていないことを独立に確認した。

monic 補題の両方向を受理する。正次元幾何的整成分 B 上で monic f(c) が kbar(c) 上の単元なら、
分母を払って f*g=h(c)≠0となる。h の定数根の因子 c−a は B[c] の素元である。
これらを一つずつ f 側または g 側へ割り当てると、f=u∏(c−a_j) となる。
この論理に B の UFD 性は不要であり、monicity は u=1 を強制する。
全係数 q_i が kbar に属することになり、B がそれらで生成される正次元代数であることと矛盾する。
逆に零次元の有限代数では f の乗法行列式が c の非零 monic 多項式であり、随伴行列が逆元を与える。
この向きは nilpotent を含む有限代数も扱う。

Sp4×Gm×五変数断面の dominance と正確な群作用は、**全 affine fiber の次元**という不変な
性質をこの断面へ移す。固定した二つの q 座標の有限射性を断面へ移す追加仮定は不要である。
したがって QQ(s1,…,s5,c) 上の保存された一つの unit 問題は、全一般 affine dimension≤0 と同値である。
未知数は q32 を消去した44個、c の次数45は係数体内の次数であり、元134式の未知数次数は二次以下。
