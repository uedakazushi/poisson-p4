# 固定 base の全交点代数：一変数八次式と T の線形回収

2026-11-03。受理済み `Q_FIRSTJET_FIXED_BASE_RESIDUAL_CURVE_20261103_v63`
の二つの (2,2) 式に対する新しい有限表示である。追加の β 点、高次数不変式評価、
GB は用いない。一般の係数体上の全交点代数を扱い、選ばれた実像成分の正確な
次数や種数、NEW25 の未知 divisor を決める結果ではない。

## 1. 係数体と短い多項式

前稿の x,y,a,k1,k2,m,c,d,f,u,v,B0,K1 を使う。特に u−v=m。
既存の rank6 証明により、ordered 固有値を取った後の x,y,a,k1,k2,m は
代数的独立である。以下は

```
K0=QQ(x,y,a,k2,m),   K=K0(K1),   K1=k1/2−A0
```

上で考える。A0 は k1 に依存せず、K1 は K0 上の超越元である。
この一般係数体では x,y,x²−y²,m,c,f,u,v は非零。特殊な全 base 点や m=0
まで単元であると主張しない。

```
A=R²−2dR−f,
b=−xvR²+fxu−K1 R,
q=vR²+fu,
L=yR(B0R+2afu−2avR²)+A b,
M=ymR q.
```

元の二式は

```
Q1=−cyR T²+bT+yuvR,
Q2=cA T²+(B0R+2afu−2avR²)T−v²R²+fu²+2duvR.
```

## 2. 消去恒等式と八次式

直接、全係数で

```
yR Q2+A Q1=L T+M
```

が成り立つ。従って L が単元なら T=−M/L。
次の因数化された短い式を定義する。

```
P8=uvL²−m q b L−cy²m²R²q².
```

u−v=m を使うと R に関する次数は正確に8で、最高係数は x²v⁴、定数項は
x²f⁴u⁴。展開した九つの係数は証明書に保存するが、β に関する高次数展開は
行わない。a1=−cyR、E=LT+M とすれば

```
yR P8=L²Q1−a1 E²−(bL−2a1M)E.
```

これは零点だけでなく全イデアルの恒等式である。また T=−M/L の代入後は
L²Q1=yR P8、yRL²Q2=−AyR P8 となる。

## 3. 一般係数体で L が実際に単元となる証明

P8 の定数項は非零なので、その任意の根 R は零でない。P8=L=0 なら
P8 の定義から q=0 となる。q=0 の根は K0 上代数的である。

一方 L=L0−K1 R A で L0 は K0[R] に属する。K1 が K0 上超越的なので、
q の根で L=0 なら A=0 が必要である。しかし A と q の resultant は

```
Res_R(A,q)=f²(u+v)²+4d²fuv.
```

これは実際の c,d,f,u,v の式へ戻した m の四次多項式で、最高係数は
(x²+y²)²/(4x²y²)≠0。従って一般係数体で A と q に共通根はない。
よって gcd(P8,L)=1。さらに P8=q=0 なら uvL²=0 だから同様に矛盾し、
q も八次代数の単元である。R, m, y も単元なので T=−ymRq/L は単元となる。

ここで resultant の恒等式も、q=vA+2dvR+f(u+v) から直接検証する。
単元性の証明に標本や数値 resultant を使っていない。

## 4. 全スキーム代数の表示

以上から厳密に

```
K[R^{±1},T^{±1}]/(Q1,Q2)  ≅  K[R]/(P8),
T ↦ −ymR(vR²+fu)/L
```

となる。逆方向は R の共通座標で与えられ、上の全イデアル恒等式で確認できる。
右辺での L の逆は、基底 1,R,…,R⁷ に関する multiplication-by-L の8×8行列の
adjugate を非零 determinant で割る有限 recipe として構成できる。

従って全一般交点代数は8次元で、一変数で生成される。被約性、既約性、八つの
幾何点、選択された実成分が全8次元を占めることは主張しない。実成分の m 次数は
引き続き高々8であり、NEW25 の base 上の multisection 次数とも区別する。

特殊 base や m で L が消える場合を捨てて全域の定理にするものでもない。
今回の一般係数体での単元性は、証明済みの超越性と resultant 非零を使う。
残余曲線の genus、Prym との同定、有理性も未解決のままである。
