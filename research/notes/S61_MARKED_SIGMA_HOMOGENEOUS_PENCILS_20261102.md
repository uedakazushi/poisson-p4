# 指定平方の特殊一次項に存在する斉次アフィン直線の全分類

指定平方の零 nuisance において b1=1, b5=a, b14=c, b6=h とし、他の旗係数を零とする。底の重み付き射影平面は [a:c:h]∈P(2,2,3) である。旗方向のアフィン直線 q=q*+s e25 が、中心を保つ対角 Gm の不変集合となる場合を分類する。q の添字は 45 個の重み二座標内での零始まりである。[射影 core と有限源](S61_MARKED_SIGMA_PROJECTIVE_CORE_20261102.md)

不変直線の e25 成分はスカラー作用で非零重みを持つため、その成分が零である唯一の代表 q* は Gm 固定である。逆も成り立つ。従って q* の候補は正規化した射影 chart で t と同じ重み 3 を持つ次の 12 座標だけである。

    q2,q4,q5,q13,q15,q18,q22,q23,q24,q39,q41,q44.

全 135 式に代入する。s² 係数は恒等零、s 係数は q* の線形方程式、残る定数係数は q* の高々二次式である。12 個の未知数とその拡大列に対して行基本変形を行い、実際の pivot 小行列式の零点を場合分けする。各非零小行列式の開では線形一般解を全定数式へ代入し、分母を払ってから同じ小行列式を逆にする。保存した Gröbner 基底は代数閉体での解を判定する。

| core chart | 非零小行列式 | 結果 |
|---|---|---|
| a=1 | −576h(c−5) | 単位 ideal |
| a=1, h=0 | 1152(c−5)(c−1) | c=3 で一点 |
| a=1, h=0, c=1 | 18432 | 拡大列が pivot |
| a=1, c=5 | 144h(h²+32) | 拡大列が pivot |
| a=1, c=5, h=0 | −36864 | 拡大列が pivot |
| a=1, c=5, h²=−32 | 576√−2（片側） | 単位 ideal |
| a=0, c=1 | 288h | 単位 ideal |
| a=0, c=1, h=0 | 288 | 一つの自由係数 |
| a=c=0, h=1 | 144 | 拡大列が pivot |

正規化 a=1 または c=1 は平方根を選ぶ有限被覆、最後の h=1 は立方根を選ぶ有限被覆で行う。h²=−32 の両共役は一つの二次数体計算で被覆する。小行列式は約分後の解から推定せず、元方程式の指定行・列から計算するので、約分で消えた極を見落とさない。

従って射影 core 上でこの種の直線が存在するのは正確に次の二点である。

* [1:3:0] では q=s e25−(5/2)e39 が実直線である。
* [0:1:0] では q=s e25+(3/4)e2+z e13+(1/2)e15+(1/4)e44 が任意の s,z について解であり、この固定 β のアフィン fiber は実アフィン平面を含む。

各直線を射影化するとその旗点が実アフィン部分の閉包に入り、そこでは t は周囲で冪零でない。従って h=0 の直線全体を「各 core の零 nuisance 周囲で t 冪零」という方法で被覆することはできない。この二つの射影 core の全源像は次元 15 以下なので、十分一般の β に対する非有限性の例にはならない。他の射影 core で除外したのは、上に指定した不変直線に限る。異なる一次項、Gm 不変でない直線、高次の弧の有無は別問題である。
