# K92：一行全多項式加算と同じ重みでの次段階source gate

承認された一回の操作 `row1 <- row1+2row2` を、保存済みsource係数から全11入口について厳密に行う。行potentialと行LCMが同じで、sourceはG18/aとG39/aだから、指数ずらしや未知分母はない。各入口の整数共通分母を使い、得られた多項式を正のQQcontentと原始整数係数へ正規化する。全source係数について独立した有理係数の比較でも加算恒等式を確認する。多項式の乗算や572個のsource演算は行わない。

新しい行に対し同じ固定重み `(1,2244,68)` の正確な支持・最大重み・割当dualを再計算する。全入口のdeficitとその度数を読み取り、新しい先頭定数行列だけの小さいQQ rank profileを保存する。新しいdeterminant series係数は計算しない。

次に最小正gapをδ、先頭rankをrとする。QQ定数変換で `R B(0) Q=diag(I_r,0)` とし、B(t)の正次数は全てδ以上だから、変換後Schurの先頭候補は `S_delta=(R B_delta Q)_residual` となる。交差項の補正は2δ以降にしか現れない。したがってdet(S_delta)が非零なら、元の行列式の次数は厳密に(11-r)δである。

ここではB_deltaに寄与する保存済み入口係数、QQ定数変換、共通分母、有限な小行列の計算量だけをsource gateとして固定する。S_delta自体もその行列式も評価しない。次の計算は別途承認された固定小行列に限る。全域FULLU57、残余2×9全階数、チャート補集合について新しい結論はない。
