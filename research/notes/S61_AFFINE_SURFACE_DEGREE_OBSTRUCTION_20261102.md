# 一般アフィン曲面の射影次数の下界10と、次数10で強制される境界

2026年11月2日。\(K=\mathbb C(W_{16})\) とし、元 S61 の一般アフィンファイバーに \(K\) 上整な曲面 \(Y\) が存在すると仮定する。通常の \(q\) 次数による射影閉包 \(\bar Y\subset\mathbb P^{45}_K\) の次数は5の倍数であり、少なくとも10である。次数が10なら超平面 \(t=0\) による交叉**サイクル**は \(2[W]\) で、\(W\) は \(K\) 上次数5の既約曲線である。幾何学的には、標準曲線 \(C_\beta\) の次数5の一閉点に対応する五つの支持平面上に、それぞれ一本の共役な非平方二平面型の射影直線が現れる。ここで非平方とは各直線の一般点を指す。これらの直線や曲面の存在は仮定のままである。

## 1. 真の無限遠曲線の一般点で残る型

一般 \(\beta\) で、非二元 \(R0\) と非零最小モジュラー型からは真の無限遠に曲線は残らない。以下は過去の個別除去をこの次元判定に必要な範囲で整理したものであり、有限個の点が残る場合まで除去を要しない。

* 非二元 \(R0\) の純 \(xzw\) と純双根軌道は、それぞれ既約17次元の joint incidence をもつ。固定 \(Q\) の軌道次元7、全 \(\beta\) 核次元10であり、その上の稠密開で固定ファイバーの \(t=0\) が証明済みである。従って例外の joint 次元は高々16で、一般 \(\beta\) 上では高々有限となる。残る七混合軌道のうち T3 は \(\beta\) 像が真で、T1,T2,T4,T6 と二曲面 T5,T7 はいずれも一般 \(\beta\) 上の全軌道除去が証明済み。[全型の次元](S61_AFFINE_BOUNDARY_DIMENSION_20261102.md)、[純型の開](S61_NONBINARY_FORMAL_RING_20261101.md)、[双根型の開](S61_NONBINARY_DOUBLE_ROOT_OPEN_20261101.md)、[四混合曲線](S61_R0_MIXED_CURVE_EXHAUSTION_20261101.md)、[T5](S61_R0_T5_ZERO_L_EXHAUSTION_20261101.md)、[T7](S61_R0_MIXED_SURFACE_T7_EXHAUSTION_20261101.md)
* 最小型の二つの主曲線は有限 semisimple 頂点の全域が処理済みで、Jordan と rank-one の特殊化も別に検査されている。18有理グラフは六 semi・二 triple・六 pure cubic・四 mixed の全有限部分が除去済み。四自由基線も除去済みであり、残る孤立軸や特殊頂点で一意な点は一般 \(\beta\) に曲線を与えない。rank-one 頂点の M0 の \(\mathbb A^1\) 全有限部分も除去済みである。この表の射影端点は既存の零モジュラー表示に戻るので、非零最小型曲線としては数えない。[頂点の全表](S61_MINIMAL_VERTEX_EXHAUSTION_20261101.md)、[全有限主曲線](S61_MINIMAL_MAIN_REMOVAL_20261101.md)、[Jordan](S61_MINIMAL_MAIN_JORDAN_REMOVAL_20261101.md)、[rank-one](S61_MINIMAL_RANKONE_A1_REMOVAL_20261101.md)、[semi](S61_MINIMAL_SEMISIMPLE_TAILS_REMOVAL_20261101.md)、[triple](S61_MINIMAL_TRIPLE_TAILS_REMOVAL_20261101.md)、[pure cubic](S61_MINIMAL_PURE_CUBIC_TAILS_REMOVAL_20261101.md)、[mixed](S61_MINIMAL_MIXED_TAILS_REMOVAL_20261101.md)、[M0 基線](S61_MINIMAL_M0_BASELINE_REMOVAL_20261101.md)、[M1 基線](S61_MINIMAL_M1_BASELINE_REMOVAL_20261101.md)

従って真の境界に含まれる曲線の一般点は、非平方二平面型または平方旗型である。これは他の型の未飽和無限遠曲線が存在しないという主張より弱く、\(t\ne0\) 部分の閉包だけについて使う。

## 2. 一次横断の必要条件

射影無限遠点で、接ベクトルに \(dt=1\) を許すには、\(t\) の Jacobian 列が \(q\) の Jacobian 列の張る空間に入る必要がある。元134式の最初の70行だけを取り、二次項 \(q^2\) の微分を \(J_0\)、\(b^2q\) 項の値を \(w\) とする。求める一次条件は \(w\in\operatorname{im}J_0\)。\(J_0\) は各代表ごとに定数であり、コードはその全左障害を有理多項式として計算する。射影座標で一列を固定しても、動径方向は \(J_0\) の核なので像は同じである。

非平方代表 \(u_{30}=1\) では \(u_{12}=u_{13}=0,\ \operatorname{rank}J_0=16\)。全左障害の共通零点は \(5u_{35}+u_{50}=5u_{14}-u_{49}=0\) であり、その \(\beta\) 像は次元15以下。従って一般 \(\beta\) の非平方点には一次横断接ベクトルがない。旗代表 \(u_{38}=-1\) では \(u_4=0,\ \operatorname{rank}J_0=15\)。全左障害は、点集合として \(u_5=5u_{14}-4u_{49}=0\) に等しい。両場合とも各線形条件の平方を前の線形条件を課した商で残余の定数線形結合として検査し、逆に線形条件上の全残余消滅を確認した。[同時零の \(\beta\) 像](S61_BINARY_DEEPER_REDUCTION_20261101.md)

旗の条件 \(u_4=u_5=0\) は支持面 \(\Pi\in C=C_\beta\) にほかならない。\(C\) 上で先の線形汎関数 \(\alpha:V=\operatorname{ann}\Pi\to\mathcal O_C\) は全射、\(\ker\alpha=L=\det V=\mathcal O_C(-1)\)。標準旗の座標から二平面標準座標へ symplectic 交換すると、二次形式の重因子 \(x\) における \(\alpha(x)\) は \(-5u_{14}+4u_{49}\) となる。したがって曲線一般点で一次横断を許す唯一の候補は \(\Sigma=\mathbb P_C(L^2)\) である。この曲線の \(q\) 表示は \([\ell^2\wedge^2\Pi]\)。その tautological 線は \(L^2\otimes\det U=\mathcal O_C(-3)\) で、\(\Pi\) はテンソルの像から復元されるので \(\deg\Sigma=15\)。この必要条件は \(\Sigma\) が真の境界に残ることを意味しない。[因子線と支持面束](S61_AFFINE_SURFACE_BOUND_20261102.md)

## 3. 曲面次数

\(K\) 上の各境界曲線の次数が5の倍数であることは、真の境界の全閉点の剰余次数に対する指数5の定理から、その曲線を一般超平面で切って従う。次数5の曲面があれば \(\bar Y\cdot(t=0)\) は次数5の一つの \(K\)-曲線を重複度1で含む。重複度1ではその一般点の一次元局所整域を \(t\) で割った長さが1だから、局所環は正則で \(t\) は一様化元である。標数零なので一般の幾何点で \(\bar Y\) と境界曲線は滑らかであり、曲面の接ベクトルに \(dt\ne0\) のものがある。これは周囲の全式の接ベクトルにもなる。第二節よりその曲線は \(\Sigma\) でなければならず、次数15に矛盾する。次数10の曲面でも同じ理由で重複度1の境界成分は許されず、交叉サイクルは \(2[W]\)、\(\deg W=5\) に限られる。[境界の指数](S61_GENERIC_BOUNDARY_INDEX_20261102.md)

## 4. 次数5の境界曲線はどの直線を与えるか

二平面型のコンパクト化 \(\mathbb P_C(\operatorname{Sym}^2V)\) に入る境界曲線を考える。ここには、平方旗で支持面が \(C\) 上にある場合も含む。幾何的既約曲線が次数 \(d>0\) で \(C\) を支配すると、正規化上の二次形式の tautological 線 \(M\subset\operatorname{Sym}^2 V\) の引戻しは \(\deg M\le-5d\) である。実際、\([2]^*V\) には次数 \(-10\) の線二本による filtration があり、その対称二乗の線商はすべて次数 \(-20\)。曲線をこの有限被覆へ引き戻し、線 \(M\) が非零に写る線商を取れば所望の不等式を得る。\(q\) の tautological 線にはさらに \(\det U\) の引戻しが掛かるため、像の曲線の次数は少なくとも \(10d\)。この計算は元テンソルから支持面と二次形式を一意に復元できる開で行い、正規化に延長する。[束の半安定性と有限被覆上の filtration](S61_AFFINE_SURFACE_BOUND_20261102.md)

従って次数5の \(K\)-曲線がこの族にあれば、支持面は \(C\) の閉点である。その剰余次数は5の倍数で、曲線の全幾何成分の次数の和が5だから、支持面は次数5の一閉点であり、五つの共役な各面に一本ずつ次数1の曲線がある。各面の平方形式は Veronese 二次曲線を作るので、これら五本の直線の一般点はすべて非平方である。

最後に、支持面が \(C\) 外にある旗曲線を除く。先の指数定理での判定より、この旗の因子線 \(v\) は次数5で \(\mathbb P^3\) に埋め込まれた \(E_\tau\) に属する。もし \(v\) が動けば \(q=\omega(v,-)^2\wedge^2\Pi\) の射影次数は少なくとも \(2\deg v^*\mathcal O_{E_\tau}(1)\ge10\) である。\(v\) が固定であれば、その剰余次数を以下で計算できる。

頂点曲線 \(E_\tau\) 上で \(\beta_v(v,-)=\alpha_v\omega(v,-)\) とし \(\eta=-5\alpha_v/3\) とおくと、\(\eta\) は \(\mathcal O_{E_\tau}(1)\) の節である。\(v^\perp/v\) の自然な symplectic 形式で行列式線束を自明化し、\(q_v(w)=\beta_w(w,v)\) をこの階数2束上の二次形式とする。これは引数 \(w\) の \(v\) による持ち上げの差に依存せず、\(v\) に線形であるから、\(\operatorname{disc}(q_v)\) は \(\mathcal O_{E_\tau}(2)\) の節となる。標準頂点 \(v=\partial_y\) では
\[
 \eta=u_{49},\qquad q_v=u_{13}z^2+(2u_{14}-u_{49})zw-u_5w^2.
\]
故に従来の旗 core \(r=(u_5u_{13}-u_{14}u_{49}+u_{14}^2)/u_{49}^2\) は \(1+4r=\operatorname{disc}(q_v)/\eta^2\) を満たし、支持面の残る選択に依存しない。

固定 \(v\) で頂点条件二つ、\(q_v\) の三係数、\(\eta\) は独立な六線形評価である。従って universal vertex incidence の中で \(\eta=\operatorname{disc}(q_v)=0\) は余次元2、その \(\beta\) 像次元は15以下。一般 \(E_\tau\) 上では二節 \([\operatorname{disc}(q_v):\eta^2]\) は共通零点を持たず、\(\mathcal O_{E_\tau}(2)\) の次数が10なので \(\mathbb P^1\) への次数10の射を与える。任意の固定有限値 \(j\in\mathbb C\) について、\(\operatorname{disc}(q_v)=j\eta^2\) の普遍 incidence は既約被約である。固定 \(v\) で独立な四評価の空間における方程式は \(b^2-4ac-j\eta^2=0\) で、階数3以上の二次錐である。残る十変数は自由で、\(v\) を動かした全体は \(\mathbb P^3\) 上で局所的にこの既約な fiber の積となる。一般 \(K\) ではそのファイバーは有限整スキームであり標数零で分離的な一閉点、次数は上の10である。

支持面が \(C\) 外の真の旗は通常旗の記号で \(b_0\ne0,b_1=0\)。\(\eta=0\) の場合は zero12 全層が除去済みである。\(\eta\ne0\) の場合、残り得る \(r\) は既証明の有限な定数表に入る。よって固定された \(v\) は少なくとも次数10の閉点であり、次数5の旗曲線を作れない。以上により第三節の \(W\) の型が尽くされる。[zero12 全除去](S61_FLAG_ZERO12_RELATIVE_WEIGHT_REMOVAL_20261102.md)、[有限 core 表](S61_FLAG_ORDINARY_CORE_SUPPORT_20261102.md)
