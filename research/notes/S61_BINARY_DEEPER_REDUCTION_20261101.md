# 十八次元二平面型族の中央ブロック rank≤7 の帰着

2026年11月1日。core を (a,b,c,d,e,f)=(u4,u14,u35,u36,u49,u50) とし、
K=5c+f、L=5b−e と書く。
全 rank-drop 表の十八次元表示 K=0 の中で、中央12×9ブロック B の階数が7以下となる部分を全て求める。
これは全 Jacobian のさらに低い階数を、そのまま全て尽くす主張ではない。

## 1. 正確な四つの被約部分

常に u12=u13=0で、他の八一次座標を自由に保つ。
K=0 と B の8次 minor からなる ideal の根基は、次の四素 ideal の共通部分である。

1. (K,L)。core 次元4。
2. (K,Q*)、Q*=600b²−255be−63e²+100af。core 次元4。
3. (K,25bd+25de+8f²,5ad−4bf+2ef,10b²+5be−5e²+4af)。core 次元3。
4. (K,50bd−25de−4f²,5ad+6bf,30b²−15be+2af)。core 次元3。

QQ 上で元 ideal が上の共通部分 J に含まれ、J の各保存生成元の平方が元 ideal に含まれることを確認した。
各 ideal の素性と次元も確認している。従って単なる共通零点の標本比較ではなく、根基の等号である。

第3、第4の部分は、それぞれ稠密開で

    c=−f/5,
    a=−5(2b−e)(b+e)/(4f), d=−8f²/(25(b+e)),

および

    c=−f/5,
    a=−15b(2b−e)/(2f), d=4f²/(25(2b−e))

と表せる。
分母の零集合との交叉はどちらも core 次元2であることを確認した。
従って三次元有理開集合が全幾何学的成分を占め、これらは複素数体上でも既約である。
第1は線形空間、第2は階数4の二次形式の零集合と自由 d 座標なので、同じく幾何学的既約である。

## 2. 三部分の β 像は次元高々15

第1、第3、第4について、source の β 微分を全自由係数上で計算した。
射影 Q=xw∂y∧∂z の五次元安定化 Lie 代数に対し、十個の sp4 生成元のうち
保存番号2,4,5,6,7が固定の補空間を与えることを、非零10次行列式で確認した。
source 制約の群微分は安定化代数上で零なので、この五方向だけで全群微分の階数を判定できる。

第1の線形 source の次元は12。
制約方向への群微分の全4次 minor五個は恒等的に零である。
従って群を加えても β 像の次元は高々12+3=15。

第3、第4の source 次元は11。
上記の有理パラメータ表示に代入し分母を払った後、制約方向への群微分の全5次 minor六個が
それぞれ恒等的に零であることを検証した。
従って β 像の次元は高々11+4=15である。
稠密有理 chart での微分上界は既約 source 全体の像閉包の次元を制御するので、
分母零点を別の未知像として残していない。

よって十分一般の β では、第1、第3、第4の部分に属する点は現れない。
K=0 かつ B の階数≤7という条件の下で、一般 β 上に残り得るのは第2の (K,Q*) だけである。
第2は十七次元の優越族であり、その指定開部分の自由階数65は
[別証明書](S61_BINARY_DEEPER_FORMAL_20261101.md)で確認済みである。

## 3. 全低階数 locus との区別

上三角残余行列には C ブロックもある。
B の階数が8でも C の階数降下により全 Jacobian の階数が下がる場合がある。
例えば K=0、a=0、25b−14e=0 の十六次元表示は別に扱う必要があり、本証明書で除いていない。
この表示は R0 正常形 k=−14/3 の混合尾と二平面型の接続に対応する可能性があり、
実際の枝を確認する前に有限自由階数65を仮定してはならない。

また、第2の十七次元族の非空開部分が除去済みでも、その補集合は十六次元で β を優越し得る。
従って本結果は残余を具体的に狭めるものであり、全一般二平面型の飽和除去やアフィン有限性の結論ではない。
