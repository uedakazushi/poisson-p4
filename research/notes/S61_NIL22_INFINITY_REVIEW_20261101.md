# 非零モジュラー (2,2) 型無限遠排除の独立点検

2026年11月1日。対象は [nil22 排除](S61_NIL22_INFINITY_20261101.md)。
本点検は歴史的な17枝の被約固定トレース分類を明示的な依存定理として残す。
今回の一般一次部分からの排除に必要な正常化、階数、次元の合成を点検した。

独立コードは主要コードの `beta_matrix` と `leading_equations_matrix` を import せず、
元の134式の単項式から q²β 係数を集め直す。八閉コア、二直線、開正常形の
全11係数行列を再構成し、一様な非零小行列式、U0 の rank10 標本、
二直線の全例外値の小行列式、合わせて39個を exact QQ または QQ(√3) 上で確認した。
主要証明書と全係数が一致し、実行時間は約七秒である。

開 A≠0 では二つの独立な symplectic shear が b と d を消し、トーラスが A を一にする。
残る ν に依存しない12次 minor があるので、この正常化は特別な ν を捨てない。
閉枝のトーラス重みは非零の枝パラメータを任意の固定値へ移し、磁気三係数を
可逆に変える。零端点を二直線 L0、L1 に戻す手順も完全である。
中心化群交換の全係数恒等式により、対になる枝を一つずつ調べればよい。
これらの正常化恒等式の実装を読み、全パラメータを保持していることを確認した。

次元評価で重要な二点も確認した。まず非零 rank 二平方零モジュラー行列の軌道は
六次元、固定トレース解空間は高々四次元なので、全 Q の affine 次元は高々十。
Q のスカラー倍を行った後にトレースを戻す対角変換が各対象飽和を保つため、
非零錐の射影化で次元を一減らしてよい。

次に rank 九が残る U0/V1 の飽和は既約で rank10 の点を含む。
rank≤9 locus はその真の閉部分なので affine 次元は高々九、射影次元は高々八。
nil22-L0 の d=0,1 では固定トレースで三つの磁気係数だけが残り、
軌道六次元を加えても同じ上界になる。その他は rank≥10 である。
従って β との incidence 次元は、それぞれ
8+(16−9)=15 または 9+(16−10)=15 以下となる。
有限個の構成可能な像の閉包を避ける一般 β に対する排除が従う。

以上の証明を受け入れる。Δ≠0 の全点での排除、別のモジュラー Jordan 型、
飽和後の全無限遠、アフィン一般ファイバーの尽くしは主張していない。
ここでいう nil22 の枝名 L0、L1 は零モジュラー成分 L0 とは別物である。
