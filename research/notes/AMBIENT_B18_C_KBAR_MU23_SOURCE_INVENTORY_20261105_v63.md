# 元 K の最小 R0 生成数二か三かを決める SOURCE

Kbar/rKbar は U,S,q2 の三つの QQ 基底をもつ。z_i U,z_i S は旧 Told の m 一次に入るので、この商では q2 方向だけをもつ。また z_i q2 は旧 m 三次、すなわち g 方向に入り、g=rq2 だから商で零である。従って元 K の最小 R0 生成数は、この十四の q2 係数の少なくとも一つが非零なら二、全て零なら三である。ell-Nakayama によりこの bar 判定は元 K に適用できるが、D 上の七生成と区別する。

rU の一次部分は w+A v、rS は lambdaS v で、lambdaS は既知の非零数である。z_i X の一次 NF を aw*w+av*v とすると、`Y=z_i X-aw*rU-((av-aw*A)/lambdaS)*rS` は旧 m 二次に入る。その元五座標を次数で分けて F1+F2 とし、accepted actual37 線形関係の真の all-order lift に F1=M1*u0 を解くと、q2 係数は `pi_q2(F2)-pi_q2(M2*u0)` である。三次以上の補正は旧 m³ に入り、この判定には現れない。

重要なのは M2 を単なる homogeneous GB へ置き換えないことである。本 SOURCE は旧 operator5×825 の first168 d3 と last657 source の区別を保ち、actual selected37 first source とその constant lift37×37 を元の elimination receipt から再構築する。十四係数は同じ三十七個の未知 `t_j=pi_q2(M2*R_j)` の affine functional として保持する。これは実作用値を計算したという意味ではない。

pi_q2 自体は accepted forty initial generators と exact HF2=2 により全180入力を正確に還元して固定する。その後、raw P_g 二次、旧 Schur 一次 carry、実 g-cofactor_r² cache がどの t_j の組合せへ必要かを profile する。未保存の M2 や高次 cofactor を零としない。Delta の経路に必要だった M3/H は、この二か三かの判定には不要である。
