# 等階数特殊化における有限底torsionと飽和境界

2026年11月1日。以下は完備局所加群についての一般補題であり、個別のPoisson点の数値検算を
含まない。torsion-free特殊化補題を、特殊加群に有限長torsionがある場合へ拡張する。

## 1. 特殊化補題

kを体、A=k[[b1,…,bd]]、R=A[[u1,…,um]]とし、Mを有限R加群とする。
M0=M/(b)Mと置く。次を仮定する。

1. rank_R M=rank_{k[[u]]} M0=r。
2. M0のk[[u]]-torsion部分は有限長である。

このときMのR-torsion部分Tは**A上有限加群**である。
Tが零、A上flat、または自由であることは結論しない。

### 証明

d=0は仮定そのものである。d≥1とし、b=b1、R1=R/(b)、M1=M/bMと置く。
有限表示行列のminorから各中間特殊化の階数もrである。
実際、最終特殊化で非零の最大minorは中間でも非零であり、一般階数を越えるminorは恒等的に零である。

Q=M/TはR-torsion-freeなのでbはQの非零因子であり、完全列

    0→T/bT→M1→Q/bQ→0

を得る。Rを高さ一素ideal(b)で局所化するとDVRになり、Qはそこで自由階数rである。
従ってQ/bQのR1上の階数はrで、T/bTのR1階数は零である。
この部分加群はM1のR1-torsion部分T1に含まれる。

残るd−1変数についての帰納法からT1はA/(b)上有限である。
従ってその部分加群T/bTもA/(b)上有限であり、T/(b1,…,bd)Tは有限k次元となる。
Tは有限R加群として完備である。
特殊加群が有限長なので、あるNについて(u)^N T⊂(b)Tとなり、(b,u)-進と(b)-進位相は同値になる。
位相的NakayamaによりTはA上有限となる。証明終。

特殊M0がtorsion-freeなら、同じ議論と通常のNakayamaを帰納的に用いてT=0を得る。
これは以前のtorsion-free特殊化補題を含む。

## 2. 有限底torsionが制御する飽和支持

SをR上有限な完備局所可換環とし、Sのideal TがA上有限であるとする。
t∈Sに対して、あるh≥1でt^hS⊂Tと仮定する。
このときt可逆部分の閉包の支持はA上有限な閉集合に含まれ、そのt=0境界の次元はd−1以下である。

### 証明

Tは有限A加群なのでEnd_A(T)も有限A加群である。
作用写像によって

    S/ann_S(T) ↪ End_A(T)

となり、Noether性からS/ann(T)はA上有限である。
従ってSupp_S(T)はA上有限、次元はd以下である。

tを反転するとt^hが単元なのでT[1/t]=S[1/t]となる。
従ってt可逆部分の閉包はSupp_S(T)に含まれる。
ここで**T[1/t]自体がA上有限とは主張しない**。例えばtが底変数bの場合には偽になる。
使用しているのは反転前のannihilatorによる有限な支持である。

飽和ideal(0:t^∞)で定まる支持の各既約成分ではtは恒等的には零でない。
その成分のt=0部分は次元を少なくとも一つ落とすので、境界次元はd−1以下となる。
従ってS内のd次元の実在するt=0 section Spec A全体がこの境界に含まれることはない。

## 3. 二つの実在部分がある場合の使用法

相対全環Sから実在する商Dへの全射があり、DがA-flat、t^hD=0とする。
N=ker(S→D)ならN/(b)Nは特殊全環から特殊Dへの核N0と一致する。
これはDのA-flatnessによるTor_1^A(D,k)=0を用いる。

さらにSのR一般部でt^h=0、rank_R N=rank N0、N0のtorsionが有限長なら、§1から
NのR-torsion部分TはA有限である。t^hはDでもR一般部でも零なのでt^h∈Tとなり、
TはSのidealであるからt^hS⊂Tを得る。従って§2を適用できる。

これは相対環Sの指定点でtが冪零であることを自動的に証明するものではない。
有限底torsionの支持上に新しい相対成分が存在する可能性は残る。
結論は、そのt=0境界がd次元sectionを全部は覆えないという次元制御である。

## 4. algebraic族への降下で必要な条件

Noether環ではcolon鎖(I:t^n)は有限段で安定し、flat base changeとcolonは可換である。
従って完成やsmooth base changeとt飽和は可換になる。

ある切断Hに制限した相対環だけから、元ambientの飽和支持を判定してはいけない。
群Gの同変性があり、G×H→Wがsmoothで、相対スキームとGの積がambientのこのbase changeに
同型である場合には、相対飽和支持の非包含をambientへ戻せる。

指定section Hの完成において境界次元がdim H未満なら、実際のalgebraic sectionも
ambient飽和支持に丸ごとは含まれない。
そのG飽和閉包Zが既約でdim Z=dim Wであれば、Zと飽和支持の交叉はdim W−1以下である。
従ってそのW像閉包を除いた十分一般の底上ではZの全ファイバーがt飽和で除かれる。

この最後の等次元仮定を、より大きな十八次元・十七次元の層へ無条件に拡大してはいけない。
