# 平面外のアフィン残余を20変数上の434生成以下の有限加群で表す

既知五点の射影三平面に沿う四斉次座標を z=(t,x₁,x₂,x₃)、法線42座標を n とする。元135式の同次数二次斉次化の商を A、その法線イデアルを N=(n)A とする。既証明の25平面を切る20個の法線座標 y を取ると、N は B=K[y₁,…,y₂₀] 上有限で、次数1,2,3の生成元がそれぞれ42、292、100個以下あれば足りる。ここで K は一次ジェットの関数体とする。同じ証明は以下の小行列式が非零な底の開集合上で有効である。

## 法線だけを残す還元

既知の25平面に沿う法線を w₁,…,w₂₂、残る方向を y とし、(w,y) を法線の全座標とする。表示行列の正方小行列が非零な22行を選び、他の20個の標準方向を加えて可逆な法線枠を取った。この枠で y=0 とすると既証明の25平面に一致する。

先行する二つの全射によって z n² は純 n³ の線形結合に等しく、z² n は z n² の線形結合に等しい。従って後者も純 n³ に還元できる。次数 d≥3 の任意の z と n の混合単項式で、少なくとも一個 n があれば、この置換を繰り返して全ての z を消せる。すなわち N_d は純 n^d の単項式の像で張られる。[偏極行列の非零小行列式](S61_AFFINE_NORMAL_PROJECTION_20261102.md)

y=0 に制限すると、w³ は全て既知五点上で消える。従って w³ はその三次消滅式の全空間を張る元134二次式の一次倍の線形結合である。この等式を全座標へ持ち上げると、商 A で w³∈(y)A₂ が従う。係数の分母は同じ実3271次小行列式により制御できる。実装は w₁³ について、32003の剰余で一次乗数の全係数を求め、中央の3276個の係数を元式と直接照合した。一様性は単一標本の剰余から帰結を推測するのでなく、元の3271次小行列式が張る有理開における全三次空間の一致による。[25平面の三次式](S61_AFFINE_TWENTYFIVE_PLANE_20261102.md)

上の式に任意の法線 n を掛ければ w³ n∈(y)N₃ である。従って純 n⁴ は、y が因子にある場合も w⁴ の場合も (y)N₃ に属する。さらに n の単項式を掛けると d≥4 で N_d=(y)N_{d−1} となる。

## 三次数の生成数

次数1では42個の n を取る。次数2の純法線のうち y を含むものは (y)N₁ に属するので、残るのは253個の wᵢwⱼ である。168個の zₖnⱼ に対し、平面制限を消した129行の混合部分は一次独立である。元129次小行列式の非零剰余を保存した。法線枠を変えてもこの階数は等しい。従って関係式により129個を解き、残り39個と上記253個で次数2を生成できる。

次数3では純法線単項式だけを考えれば十分で、y を含むものは (y)N₂ に属する。w³∈(y)A₂ により、剰余 N₃/(y)N₂ は20個の y と (A/N)₂ の基底の積で張られる。(A/N)₂ は四つの平面座標の十個の二次単項式を五独立な平面二次式で割った五次元空間である。このため次数3の追加生成元は100個以下である。以上から N は B^434 の次数シフト付き商となる。次数別の数値は生成数の上界であり、最小生成数を計算する必要はない。

## t の作用とアフィン商

t−1 は A/N の非零因子である。実際、非負次数の斉次環の有限和に t−1 を掛けたとき、その最低次数成分は必ず元の最低次数成分の負になる。従って N と (t−1)A の交叉は (t−1)N である。よって N/(t−1)N は A/(t−1) の中の実際の法線イデアルに一致する。

t=1 の平面上の点の各局所環では N=0 であり、平面外では一つの法線が単元となり N=A である。これらは互いに交わらない開かつ閉な部分を与える。従って N/(t−1)N は平面外のアフィン座標代数そのものである。特にアフィン五点が全てを尽くすことの必要十分条件は、この20変数上有限の商加群が零となることである。射影的には対応する残余の P¹⁹ への線形射影は有限となる。

一般 β への移行には、元の二つの偏極全射、中央25平面上の三次全射、混合部分の129次小行列式を同じ開で取る。いずれも固定された β* で非零で、普遍三平面の枠はそこで正則である。従って本加群表示そのものは一般 β で正確である。一方、20変数上の有限性だけから β への有限性は出ない。残る計算対象は t が作用する N の商の支持である。
