# 三 core 全開で積対の三一次式は独立

2026-11-03 / v62。指定開は [六二次式の全階数](S61_BINARY_NONSQUARE_QUADRATIC_COVER_20261103_v62.md) と同じ U={aFBC≠0} である。元135式から構成した六二次式を q0,…,q5 と書く。

既存の可逆な行変換（行列式80a）により、二次 ideal は

    (q0,q1,q3,q5, Wℓ, Zℓ),
    Z=3v0−v1+v6, W=v3

となる。今回は U の**全点**で ℓ,Z,W が一次独立であることを追加した。

## 五つの係数条件

ℓ の係数を (L0,L1,L2,L3,L4,L6,L7) とする。Z と W 自身は定数係数で独立なので、ℓ がその張る空間に入る条件は正確に

    L2=L4=L7=L0+3L1=L6+L1=0.

元の六二次式から `−(de+8)q1+8q2+dq3=Wℓ` を完全除算で再構成し、既存の ℓ と全係数を照合した。この五多項式と `z*a*F*B*C−1` が生成する QQ[a,e,d,z] の ideal は単位 ideal になる。producer は Gröbner 余りの確認に加え、六生成元に対する明示的な Bezout 列ベクトル L を計算し、`gens I*L=1` を exact に検査する。

従って U の全複素点で ℓ,Z,W は一次独立である。この三式を最初の三 light 座標とする有限 chart 被覆が得られる。

## 残る四二次式の独立性

定一次式 Z=W=0 を課し、v3=0、v6=v1−3v0 として残る五変数へ移す。q0,q1,q3,q5 の4×15係数行列に四つの pivot を順に取れる。各 pivot の分子・分母は a,F,B,C と有理定数の積であることを完全除算で確認した。従って、この四式の制限の階数も U の全点で4である。

これにより、四式の定数係数線形結合が (Z,W) の二次部分へ入るという種類の退化は存在しない。ただし、ℓ=0 上の四式が**全点で**完全交叉になることや、六二次式の一次倍42本の階数が全点で41となることまでは示していない。

## 後続計算に関する注意

指定した通常点 (a,e,d)=(1,2,3) では、q0,q1,q3,q5 と ℓ の商は次元2・次数16で、Hilbert 級数は

    (1+4T+6T²+4T³+T⁴)/(1−T)²

となる。一方、さらに Z=W=0 を課した商は次元1・次数4となる。従って Z,W はこの完全交叉に対する有限切断ではない。この特別な二切断で四変数四二次式の有限性を証明し、全 cubic-product 階数を得ようとする経路は使えない。この点別計算を全 core の完全交叉定理として用いない。
