# rank Kβ≥2 上の被約交叉の一意性と指定 Q を通る成分

2026年11月3日。対象は既知の被約成分 CA,CB と既存の18次元被約交叉成分 N⊂S61である。
元の射影 Poisson 空間では N は27次元となる。

## 定理

U={β∈Z:rank Kβ≥2} とする。この開の逆像上で

    (CA∩CB)_red = N

である。特に指定 v24 Q(a=1) を通る CA∩CB の既約成分は N ただ一つである。
他の交叉成分があれば rank Kβ≤1 の上にある。

これは scheme-theoretic intersection ideal の等式ではない。
rank2 臨界点では旗が二重一点を成し得るので、全交叉の厚みを消してよいという主張ではない。

## 1. 全 rank≥2 基底旗は幾何学的に一つ

既存の full flag 定理により、固定六平面で τ≠0 または Δ=4CF−D²≠0 なら、
**全射影** 旗ファイバーは被約一点である。
残る τ=Δ=0 を調べる。Kβ の非零になり得る二行は

    [A,0,2C,D],    [B,0,D,2F].

H=[[2C,D],[D,2F]] と置く。
H=0 なら rank Kβ≤1であり、U に入らない。
H は非零 rank1だから、SL2(z,w) の Levi 作用で

    h2=C*z²+A*x*z+B*x*w,    C≠0

へ移せる。この chart で rank Kβ=2 は B≠0 と同値である。
symplectic shear

    x'=x, y'=y−(A/(2C))*w, z'=z+(A/(2C))*x, w'=w

は A を零にする。次に symplectic torus

    x'=a*x, y'=a^−1*y, z'=b*z, w'=b^−1*w

は C を C/(a*b²)、B を B*b/a²へ移す。
b^5=C²/B、a=C/b²を選べば両方とも1となる。
C 上で必要な非零五乗根が存在するので、臨界 rank2 全体は一つの Sp4 軌道である。

その代表 (τ,A,B,C,D,F)=(0,0,1,1,0,0) では、実際の全旗方程式の chart GB は

    (r,q,w²)

となり、chart 外の唯一の核の線 e_w は追加の収縮条件を満たさない。
従ってファイバーは幾何学的には一つの旗である。
これで U の全点についての一意性が得られた。
P ker Kβ をそのまま旗ファイバーと扱ったものではない。

## 2. 同じ旗を持つ固定線交叉は N

CA,CB の全射 proper な閉旗解消を EA,EB とする。
同じ点 P∈CA∩CB で β(P)∈U なら、EA と EB への持ち上げ旗は、
前節により幾何学的に同じ線 L でなければならない。

この L を固定線へ戻した全 q ファイバーは、既に保存した閉 affine10平面 TA,TB である。
その交叉の全方程式は

    rA=0,
    rB=25τ²/4,
    h3A−h3B=(5τ/2)*x*h2 mod x³

で、九次元 affine 平面を与える。
その共通旗入射 EN の proper 像が N である。
従って上の P は N に入る。逆包含は既知なので、全閉点で被約交叉が一致する。
有限型 C スキームの被約閉部分は閉点で決まるため、定理の被約等式が従う。

指定 Q は rank Kβ=2なのでこの開に入る。
もし別の交叉既約成分が Q を通れば、その開との非空な交わりは N に含まれ、
閉包も N に含まれてしまう。従ってそれは別の極大既約成分ではなく、N に一致する。
