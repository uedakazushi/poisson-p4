# W=1 における実際の CA、CB、N と交叉の接空間

2026-11-03。既受理の全非零 W 完成型から、錐での埋込次元は CA、CB が38、
N が36と分かっている。今回は実際の150物理係数でその接空間を作り、
交叉を計算する。normalization の微分だけを target の接空間としない。

基点は受理済みの全 W 曲線の W=1、すなわち
`P_W=P0+W*x²∂z∧∂w`。x=1,h=y=z=w=0 で rank4 の値を持つ。

## 実際の source

CA は固定20空間、N はその C2=0 の19空間を用いる。CB は f の3係数、
H の16係数、ratio の計20変数で `g=−ratio*f` を全て掛けてから微分する。
各々に、受理済み proper 旗の9個の群方向を加える。全 point、全 Jacobian、
kernel、kernel の GL 行列、CB の二次混合項を保存する。

source kernel を κ とする。κ と任意の source 方向の mixed 二次係数は
実際の target 接方向である。任意の target 定義式を source へ戻した
mixed 係数で、κ の一次像が零なので定義式の二次項が消えるからである。
全 mixed 列は coefficient-index Lie action で作り、別の有限5×5逆座標
代入の二次 polarization によって全150係数を照合する。

真の kernel 曲線の二次係数も target 接方向である。それだけで全接空間が
得られない場合、同じ kernel 曲線一つだけの三次係数を計算する。この曲線
では target 変位が O(p²) なので、定義式の非線形部分は O(p⁴)。従って
三次係数も実際の接方向である。一般の source 三次項を無条件に接方向と
する議論ではない。CB では固定 source の ratio と f の二次項が三次に
及ぼす寄与も保持する。

作った接方向の階数が既受理の埋込次元38/38/36に達することで、これらが
全 target 接空間に等しいと結論する。全150係数の kernel 三次は物理的
座標代入と Lie 展開の両方で照合する。一般の多変数三次 source は展開しない。

## 交叉と scope

計算結果は、二次までの span が CA、CB、N で37、37、35。各々一つの
真の kernel 三次を加えると38、38、36に達する。CA と CB の接空間の和は
39次元なので、**実際の交叉の接空間は37次元**となる。

スキーム的交叉の接空間は二つの実際の接空間の共通部分である。N の全36
方向が両者に含まれることも確認する。W=1 は rank4 の値を持つため、
generic Poisson rank2 成分 R には入らず、全被約交叉 N∪R の定理から
この点の被約交叉は N に等しい。

従って交叉接空間が36より大きい場合、その差は正確に冪零根基の cotangent
への像の次元を与え、D はこの点で非被約である。ただし、この接空間計算
だけで冪零根基の台の次元、新しい埋込成分、D の全完成環や深さを決めない。
接空間が N と等しい場合にも、conductor と Nakayama による全環同定は
別途仮定を検証してから行う。

今回はその差が1であるから、W=1 の実際の D は非被約で、冪零根基の
cotangent への像は正確に1次元である。従って D=N の全環同定を目指す
この接空間の十分条件は成立しない。受理済みの全非零 W の群移送は CA、
CB、N とスキーム的 D を保つため、同じ結論を全 W≠0 へ移すこともできる。
新しい埋込成分やその次元を、この結論に追加してはいない。
