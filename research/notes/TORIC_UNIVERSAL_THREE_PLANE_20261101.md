# 一般一次部分上の既知五点を含む普遍的アフィン3平面

2026-11-01。全16個の一次部分変数を残した厳密な多項式恒等式である。
**全 S61 ファイバーがこの平面に含まれることは未証明**であり、全ファイバーの次数5という主張ではない。

## 1. 結論

一次部分を β∈W16、45個の重み2座標を q と書く。既に得られた楕円切断を
Q51(β),Q52(β) とする。対称三次テンソル c∈Sym³(V*)≅A20 を用いる
トーリック代数モデルに対して、次を全 β について構成した。

- β に線形な51×20行列 L(β)。トーリック解は L(β)c=0 を満たす。
- β に線形な45×20行列 N(β)。トーリック解の S61 座標は
  q=q̄(β)+N(β)c と書ける。
- β の二次式である中心 q̄ は、厳密な恒等式

\[
 3\bar q(\beta)=2Q_{51}(\beta)+Q_{52}(\beta)                 \tag{1}
\]

を満たす。

非空な Zariski 開集合で ker L は2次元、N のこの核への制限は単射である。
従って三つのトーリック延長はアフィン2平面

\[
 \mathcal T_\beta=\bar q(\beta)+N(\beta)\ker L(\beta)
\]

に入る。二つの楕円延長を結ぶ直線は (1) により q̄ を通る。
この直線を加えたアフィン包

\[
 \mathcal L_\beta=\bar q(\beta)+N(\beta)\ker L(\beta)
       +\mathbb C\bigl(Q_{52}(\beta)-\bar q(\beta)\bigr)   \tag{2}
\]

は一般に3次元であり、既知五点をすべて含む。
さらに、一般 β について **S61β とこの3平面との交わり** は被約な長さ5のスキームである。

(1) の q̄ を三つのトーリック点の平均だと呼ぶためには、別途 trace(c)=0 の証明が要る。
保存済みの特殊 β ではその等式も成立するが、本証明では用いない。

## 2. 二次の c 依存を定数行変換で除く

トーリック代数モデルは、primitive closed β から定まる乗法

\[
 m=m_0(\beta)+m_c,\qquad
 q_{\rm tr,ij}=\tfrac13\operatorname{tr}(m_i m_j)
\]

を用いる。既存の96結合則方程式を

\[
 E(\beta,c)=H(c,c)+B(\beta,c)+C(\beta,\beta)                \tag{3}
\]

と分ける。H の210個の二次単項式に対する係数行列の階数は45である。

トーリックなアフィン bivector は

\[
 P(y)=F(y)JF(y)^t,\qquad
 F(y)=I+m_y-y(y^tq_{\rm tr})
\]

で与えられる。その y に関する二次部分は

\[
 P_2=m_yJm_y^t-y(y^tq_{\rm tr})J-Jq_{\rm tr}yy^t.         \tag{4}
\]

(4)の60個の係数について c に関する二次最高部分を取ると、その係数行空間は H の行空間と
**厳密に一致**する。従って、45本の独立な H を選べば、定数有理60×45行列 R によって

\[
 P_2^{(c^2)}=R H_{\rm selected}
\]

となる。全係数を保存した R を使い、

\[
 P_2-R E_{\rm selected}                                 \tag{5}
\]

を取ると、c に関する次数は高々1になる。E=0 上で (4) と (5) は同じである。
これは有限体の階数観察からの推論ではなく、全36変数 β,c を残した QQ 上の係数恒等式である。

さらに H の定数左核は51次元で、そのすべてのベクトル γ に対して

\[
 \gamma E=L_\gamma(\beta)c                              \tag{6}
\]

となる。β² の定数項は全51本について恒等的に零である。
従って (5) の c=0 の値は、R の行表示の選択に依存しない。
異なる表示の差は (6) であるため、線形部分も ker L 上では選択に依存しない。

(5) の二次 jet を S61 の perspective gauge に戻すと、q=q̄+Nc を得る。
40個の任意の B0i の斉次二次係数はアフィン三次尾部に対応し、これらが重み1・2の自由座標へ
寄与しないことを基底ごとに確認した。従って三次尾部を省いた操作は q の値を変えない。
**全アフィン bivector が二次式だと主張しているわけではない。**

最後に既存の Q51,Q52 の45座標を用い、(1) を全16変数の多項式恒等式として直接確認した。

## 3. 一般の核と3平面

保存済みの β*（トーリック係数 2,3,5,7,11,13 に対応）では L の階数は18である。
コードは18×18小行列式、自由座標 c18,c19、核の20×2基底 T を保存する。
この小行列式が非零な開集合では、選んだ18行によって

\[
 T_{\rm free}=I_2,\qquad
 T_{\rm pivot}=-L_{\rm pivot}^{-1}L_{\rm free}            \tag{7}
\]

と定められる。

全51行の一般階数も18であることは、既存のトーリック次数3の有限エタール近傍から分かる。
その近傍の三つの解は L の核に入る。β* では三つの c はアフィン共線でないため、
同じことが非空な開集合で成り立つ。従って一般の核は少なくとも2次元であり、階数18の
非零小行列式と合わせて一般階数18となる。よって (7) は一般に全51行の核の基底でもある。

β* では NT の階数は2で、さらに Q52−q̄ を加えた45×3行列の階数は3である。
その3次小行列式も保存した。これらは非空な開条件である。

この表示は、42本の線形条件を一般 β 上へ持ち上げるための具体的な有理式レシピである。
大きな16変数の逆行列を展開する必要はなく、(7) の18次行列式で局所化すればよい。

## 4. 平面との交わりの一般長さは5

β* の平面は、既存の `S61_KNOWN_FIVE_POINT_SECTION_20261101` の平面と一致する。
実際、既知三次商環で c を代入し、q̄+Nc が三つすべてのトーリック点の全45座標と一致する
ことを厳密に確認した。楕円二点も (1) により入る。既知五点のアフィン包は3次元なので、
二つの平面は等しい。

以前の座標 (τ,ρ,σ)、A=24010/13 では、全134式の制限イデアルは

\[
 \tau\sigma,\quad\tau(\rho-1),\quad\rho(\rho-1),\quad
 \sigma(3\rho+2\sigma-2),\quad
 \tau^2-A\rho(1+2\sigma)                                \tag{8}
\]

で生成される。この商は被約な長さ5である。

相対有限性を得るため、(8) の二次最高部分に τ,ρ,σ を掛けた15本と、3変数の三次単項式10個
との係数行列を作った。階数は10で、非零10次小行列式を保存した。
この同じ小行列式を一般 β の制限式に適用して局所化すれば、全三次単項式が次数2以下へ
還元される。従って平面との交わりは、β* のある開近傍で基底上有限になる。

有限加群の β* ファイバーの長さは5である。そこで5個の基底要素を持ち上げると、Nakayama により
さらに小さい開近傍でその5個が加群を生成する。従って一般長さは高々5。
一方、既知の三トーリック点と二楕円点は一般に相異なり、すべて (2) に入るから、一般長さは
少なくとも5である。よって一般長さは5で、幾何学的に5点あるため一般ファイバーは被約。
さらに縮小すれば有限エタールな次数5の族になる。

この有限性は **平面との交わりについてのみ**である。全45変数ファイバーに同じ結論を
適用するには、全ファイバーの点が (2) に入ることを別に証明しなければならない。

## 5. 次の課題と探索の範囲

主な未解決点は、一般 β について平面 (2) の42本の線形条件が、全 S61 イデアルの radical に
属することを示すか、平面外の追加成分を発見することである。本計算はそのどちらも決定しない。

補助探索では、トーリック代数の相対有限性が余次元1で一様に成り立つことから trace 恒等式を
導く案も試した。F32003 の一次部分の一つの pencil について、H による二次単項式の商165次元、
三次単項式の商800次元に L の倍式を加えた行列を調べた。
端点ではそれぞれ全階数だが、pencil の observability 計算は各々24次元を残した。
したがって、この単純な十分条件では余次元1での有限性を証明できなかった。
これは非固有性や特異ファイバーの分類を証明するものではない。
新しい恒等式 (1) の証明は、この補助探索や trace の仮説に依存しない。
