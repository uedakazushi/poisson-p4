# 全初期代数と自由な埋込差から冪零性は従わない

2026-11-01。以下は全ての整数 N≥2 に対する厳密な反例族である。
S61 自体の反例ではなく、有限切断から完成環へ進む際に使えない一般的推論を特定する。

体 k に対して R=k[[u,v,h]]、A=k[[u,v]] とし、

    S_N = k[[u,v,h,z]] / (h z,z²−u^N z)

と置く。R から A への h=0 制限を bar で表す。
R⊕Az に積

    (r+bz)(s+cz) = rs + (bar(r)c+bar(s)b+u^Nbc)z

を入れると、これは可換結合的な単位的完備代数である。
h z=0 と z²=u^N z を満たすので S_N からの写像がある。
逆に任意の形式級数をこの二関係で r+bz に直せる。
z^j=u^{N(j−1)}z の右辺の u 次数は j とともに増すため、形式級数の還元も収束する。
両写像は互いに逆であり、R 加群として正確に

    S_N ≅ R ⊕ A z

である。特に h を反転した一般 R 点では z=0、一般階数は1となる。

## 全次数の初期代数

m を S_N の極大イデアルとする。上の表示から、d≥1について

    m^d = m_R^d ⊕ m_A^(d−1) z

が従う。帰納段階で新たな z² の積が生じても、u^N z は N≥2 により
必要な右辺に入る。従って全次数で

    gr_m S_N = k[u,v,h,z]/(h z,z²)

となり、N に依存しない。
局所標準基底の観点でも、二先頭 h z,z² の S-polynomial は

    z(hz)−h(z²−u^Nz) = u^N(hz)

と厳密に還元される。保存コードは a=u^N と置いたこの多項式恒等式と結合律を確認する。

初期代数から普通成分 k[u,v,h] への商の核は k[u,v]z であり、
二変数多項式環上自由階数1、生成次数1である。
従って『全初期代数が既知』『埋込差が二変数上自由』『一般階数が既知』は全て成立する。

## ord(t)=4 でも t² は非零

t=u³z と取ると、上の filtration から ord(t)=4 である。一方

    t² = u^(N+6) z

は非零で、次数は N+7 である。
h=0,z=u^N への代入による k[[u,v]] への写像で t² は u^(2N+6) に移るため、
この非零性は形式計算だけで直接分かる。同じ写像で全ての t の冪が非零となる。

被約成分は z=0 の三次元成分と、h=0,z=u^N の二次元成分である。
後者は主成分の接空間に接し、D(t) の低次元枝となる。
t は一般 R 点では零だが、この枝の一般点では非零である。

N を任意に大きくできるため、平方零の族
k[[u,v,h,z]]/(hz,z²) との違いは任意に高い有限切断まで見えなくできる。
さらに全初期代数自体は、切断を全て知っても同じである。
従って ZERO12 での E111 の自由性や初期代数の一致を完成環の t 冪零性に結び付けるには、
S61 固有の多項式恒等式、実際の torsion への作用、または低次元枝を除く追加幾何が必要である。

親担当による一般 N の概念監査も受理された。
これは本反例の証明に関する確認であり、ZERO12 の冪零性を主張するものではない。
