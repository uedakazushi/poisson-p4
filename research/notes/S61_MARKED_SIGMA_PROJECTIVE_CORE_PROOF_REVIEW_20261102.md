# 指定平方旗の重み付き射影 core の証明監査

有限群変換と b1 によるスケールの逆は、保存した元の b1,b12 で正則に復元できる。core の三座標と残る八座標を分ける二つの一変数作用がなすことを確認した。第一の作用は八座標を零へ収縮するので、周囲の非冪零 locus の閉性により零 nuisance 点での除去が全 nuisance へ及ぶ。第二の作用は三座標に重み (2,2,3) を与える。零三つ組以外の有限個の射影 core はアフィンの有限本の一次元 orbit に対応する。固定旗で 1+1+1+8=11 次元、旗の四次元軌道を加えても15次元なので、一般 β の16次元底に優越しない。零三つ組なら上界は14次元である。

h² は可逆で ample な O(6) の節なので、h=0 の台はあらゆる射影曲線に会う。この全台で除去が証明されれば未除去 core は有限になるという条件付き帰結は正しい。原点で二つの指定楕円 section を通る実アフィン直線の恒等式があることと、非零 core で全方向の任意の直線が消えることは区別されている。後者を前提には置いていない。この監査は正規化の定数や元135本の三次代入の第二実装を含まない。[主証明](S61_MARKED_SIGMA_PROJECTIVE_CORE_20261102.md)
