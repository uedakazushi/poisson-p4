# T2の一次Hilbert層：既知解像度と下側三方向のsource gate

完全最小6対1060表示を用いる。最初418列の一次項は
(PiY3 G3linear,0)で、G3の定数が零なのでformal unitの微分は現れない。
active G3linear=Pi42 d3linear I3origin。d3origin I3origin=0 と
Pi42 d3origin=0 が両unit微分を消す。I3originは固定126本の元d3列の
factorから作り、zero3 Koszulの符号付きtensorを全418列に残す。
全G2linear G3linear=0をell²=0で逐係数確認する。

残り642本はY0定数kernelの定数source組合せ。下側三方向の一次項は
保存済みfull9 X1だけからPiBottom3 Xgamma1となる。この既知行列のrankと
kernelをまず固定すれば、新しい比較係数を問う前にunknown部分を縮められる。
そのkernelではM0 Xgamma1=0かつ自由三方向も零なので、全56成分で
Xgamma1=Xp0 a1となる。実Xp a1を引くとZは二次から始まり、
(MZ)2=M0 Z2でM1が消える。上側三方向はこの補正X2のprojected functional
だけを必要とする。G3linearによるY1のambiguityを実関係として保つ。

このgateは既知G3linearのsource値と入力範囲だけを保存し、rankやX2を
まだ求めない。全X2pairがcache内とはしない。T2全長、H0長、torsion指数は未決。
