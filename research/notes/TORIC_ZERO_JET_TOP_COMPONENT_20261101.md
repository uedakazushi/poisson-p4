# 零一次部分ファイバーの唯一の10次元成分は AB

2026-11-01。前二ノートに続く被約台の部分分類である。

**結論：F0=(T01∩{β=0})red の唯一の10次元既約成分は、旧 nil22 の AB 成分である。**
9次元以下の追加既約成分はまだ排除していない。従って F0=AB という尽くしではない。

証明書は `reports/TORIC_ZERO_JET_TOP_COMPONENT_20261101.json`、コードは
`code/toric_zero_jet_top_component_20261101.py`。
旧 Q45 分類、前ノートの安定化群による必要条件、AB の実際のトーリック退化に依存する。
今回必要な Schur complement、非零小行列、全 nil22 代表の Pfaffian は別の短い計算で確認した。

## 1. R0 と最小冪零二成分の交叉を9次元以下へ改善

記号 G,h0,…,h8,H(z,w)、作用行列 MR,MA,MB は
`TORIC_ZERO_JET_DIMENSION_20261101.md` と同じ。
追加の平行移動を持つ部分は同ノートの incidence 議論で既に全体として9次元以下。
以下は平行移動が最小次元である部分だけを扱う。

### R0

必要条件は rank MR≤5。H の三根が相異なる場合は rank≥6 なので除外される。
二重根の代表 H=z²w を代入すると、行 (2,3,5,6,7)、列 (0,1,2,3,5)
の5次ブロックの行列式は4である（添字は零始まり）。
その Schur complement の非零行は正確に

    [ 2(h0−h2h3),       −2(h0−h2h3)                    ]
    [ 4h1−h3²,          −(4h1−4h2h4−h3²)/2            ]
    [ 4h4,              −h4                            ].

rank≤5 はこの残差が零であることと同値なので

    h4=0,   h0=h2h3,   4h1=h3².

固定 H で残る次元は2。二重根 H の軌道3次元を加えても5次元である。

三重根 H の層は全体で7次元だが、H=z³、下位係数 (h0,…,h4)=(1,2,3,4,5)
における MR の階数は7である。従って rank≤5 はこの既約層で真の閉条件となり、
次元は高々6。H=0 の層は5次元である。
因子直線の3次元を加えると、R0∩F0 は9次元以下となる。

### M0,M1

必要条件は rank MA,MB≤4。相異なる三根と二重根は前ノートで全域的に除外済み。
H=z³ とし、行 (3,7,9)、列 (1,0,4) の定数可逆3次ブロックを除くと、
5×3残差の二つの行が h4² の非零定数倍を小行列として持つ。
従って残差の階数が1以下なら h4=0。

この後の非零二行は、ε=1 を M0、ε=−1 を M1 として

    [ 0,        −h3(h3−ε)/3,       (3h1−h2h3+εh2)/9  ]
    [ −h3−ε,    −(3h1−2h2h3)/3,   −2(3h0−h2²)/9     ].

h3≠−ε なら第一行が零でなければならず、h3=0 または ε と、
h1,h2 の一つの線形関係を得る。h0 ともう一つの係数だけが自由なので次元2。
h3=−ε なら第一行の第二成分が −2/3 であり、残る2×2行列式は
h0 に関して係数が非零の一次式となる。ここでも h1,h2 の二係数だけが自由。
よって固定 H の全 rank≤4 locus は2次元である。
三重根 H の2次元を加えて4次元、H=0 の場合は5次元。
固定モジュラー軌道の4次元を加え、M0∩F0、M1∩F0 はともに9次元以下となる。

## 2. 残る10次元層の除外

### nil22 の11飽和

旧分類では固定 trace s=xz の各飽和は既約10次元である。
各代表一点が T01 に入らないことを示せば、その飽和と F0 の交叉は9次元以下になる。

完全分解の必要条件では s=−a²−b²、PfQ=a²b² であり、rank(s)=2 だから
a,b は x,z の線形結合でなければならない。
従って PfQ は x,z のみの平方二次式 h²であり、さらに s+2h、s−2h の
両方が一次式の平方でなければならない。
コードは旧11代表すべてにこの判定を厳密に適用した。

| 層 | 代表 Pfaffian と不適合の理由 |
|---|---|
| open | x²(−2wz+2xy−2xz+z²)/2：trace 支持外の変数を含む |
| C+ | (x+z)⁴/64：s±2h の一方が平方でない |
| C− | −(x+z)²(x²−6xz+z²)/64：平方でない |
| D± | 相異なる一次式の1乗と3乗の積：平方でない |
| U0 | z³(x−z)：平方でない |
| U1 | z²(x+2z)²/4：s±2h の一方が平方でない |
| nil22 L0 | 0：rank(s)=2 と両立しない |
| nil22 L1 | x²z²/4：s±2h の非零側が平方でない |
| A0 | −z⁴/4：s±2h が平方でない |
| A1 | z²(x−z)(x+z)/4：平方でない |
| AB | −(x−2z)²(x+2z)²/64：条件を満たす |

表の一部は中心化群により他の旧枝と同一視された飽和であり、
旧分類の11個の飽和に対応している。新しい成分数を数えているのではない。
AB の十分性は別途証明した普遍的な対数型退化による。

### 最小冪零の第三成分 M

旧代表 QM は trace=3x²、PfQ=12x³z である。
rank1 の trace の支持は x のみだから、完全分解条件なら PfQ も x⁴ の倍数で
なければならない。この代表は条件に反する。
10次元既約成分 M と F0 の交叉も従って9次元以下である。

### 零モジュラーの L0

ここでいう L0 は上の nil22 L0 とは別の、零モジュラー10次元成分である。
旧族 Q=V∧U で a=1,b=3、すなわち

    U=z∂y+3x∂w,
    V=−3x∂x+5y∂y+z∂z+w∂w

を選ぶ。P=J+Q は全134式と再構成を満たすが、全射影軌道は21次元、
射影安定化群は3次元である。証明書に22次小行列を保存した。
必要な安定化群次元4を満たさないので、この代表は T01 に入らない。
L0 と F0 の交叉も9次元以下となる。
零モジュラー C0 はもともと9次元であり、新しい制約を要しない。

## 3. 結論と次の対象

旧分類による有限個の層のうち、AB 以外と F0 の交叉はすべて9次元以下となった。
AB は F0 に含まれる10次元既約閉集合であるから、唯一の10次元既約成分となる。

未知部分が AB の内部の境界だけであるとはまだ言えない。
可能な追加の既約成分は9次元以下であり、上の小さい determinantal locus と
nil22 各層の完全分解 locus に絞られた。
「唯一の最大次元成分」と「被約ファイバー全体が既約」は別の主張として保持する。
