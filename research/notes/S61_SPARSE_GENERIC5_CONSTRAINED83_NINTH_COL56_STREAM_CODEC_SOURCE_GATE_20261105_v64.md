# Same-format streaming primitive-cell I/O gate

This SOURCE test copies only already accepted col82 cells. It creates no new matrix coefficient. For all4160 existing coefficients, the custom in-place alias-key heapsort is checked against an independent sorted order and object identity. The new writer's bytes are compared exactly with every original primitive binary, including its declared shift. Incremental readback checks every coefficient against the original resident map, canonical varints, integer signs, header reduction, term count/order, value hash and whole-file hash. Zero, negative content, signed Laurent coordinates and a1651-bit integer fixture are also compared with the old independent encoder.

The old full encode/decode arrays appear only in this SOURCE test. Future VALUE code uses a list of n references to existing map key tuples, in-place heapsort and constant scratch; no decorated key/Timsort arrays. It writes one canonical term at a time and reads one term at a time. Map7n+alias refs n+constant fits the planned10n+2048 bound. Future implementation and independent code audit remain required; passing these existing-data tests does not authorize new col56 values.
