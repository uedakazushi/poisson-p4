# 三つのcoreの四次行列：e だけに依存する共通因子はない

ここで扱うのは、既存の [B-free horizontal 証明](S61_BINARY_HYPERPLANE_BFREE_HORIZONTAL_20261102.md) が元135式から作った多項式行列 M(a,e,d) の321行238列である。行は六つの二次関係の重み2倍と二十一の三次関係の重み1倍で、標的から heavy² 列を除いている。元の係数順序、分母の払い方を変えない。結論は、この行列のすべての最大小行列式を割る非定数 h(e)∈QQ[e] は存在しない、というもの。a に依存する垂直因子、余次元2以上の欠損、全135式の周囲の環はこの結論には含まれない。

## 一つの元の小行列式の先頭項

d=3,a=1 とし、保存した元の238行を指定順で取り、全238列を自然順に並べた小行列式を P(e) とする。選択は有限体計算で得た候補であり、検証は元の全係数からやり直す。原行・列に与えた整数重み r_i,c_j は、各非零成分について deg_e M_ij ≤ r_i+c_j を満たし、総和は1132である。逆変数 x=1/e を用いると、各成分 x^(r_i+c_j) M_ij(1/x) は多項式となる。その行列式は x^1132 P(1/x) である。

この行列を x^8 を法として扱う。行ごとに有理定数を掛けて係数を整数にし、全段階で法32003の単元だけを使ったことを確認する。列の並べ替えと定数倍は最後にもとへ戻す。段階ごとに先頭の正方部分 A(0) が単元であることを確かめ、次の Schur 補行列を有理数上で正確に求める：S(x)=E(x)−C(x)A(x)^(-1)B(x)。係数 Y_j=[x^j](A^(-1)B) は A(0)Y_j=B_j−Σ_{i=1}^j A_i Y_(j−i) から順に解く。S(0)=0 を全成分で検証してから、S(x)/x に移る。正確な行列式恒等式 det M=det A det S により、S の大きさに等しい付値がここで加わり、必要精度が一つ減る。入力は七次まであれば足りる。

最後は一成分の非零定数で、その値も法32003で単元。付値は正確に190である。従って deg P=1132−190=942。各単元部分の行列式と最後の一成分を法32003で掛け、行の定数倍と列順をもとへ戻すと LC(P)≡2514 となる。これは有限体で見えた次数を有理数の次数とみなす推論ではない。有理数上で成立する係数恒等式と、先頭項の良い還元を別に検証している。

## 二つの断面

法32003、d=3 の a=1 と a=2 の両方で、元の321行を F_p[e] の行ベクトルとする。先頭位置が重なる行について、一行を他行の多項式倍で引き、必要に応じて行を交換する。非定数多項式では割らない。したがって、得た行は元の行加群の中にある。どちらでも238個の相異なる先頭位置を持つ行が得られる。定数三角部分を取り除き残りの行列式を直接求めると、二つとも次数522。この二つの行列式の多項式 gcd は1である。行列式全係数を報告に保存し、Python で gcd を別に計算する。論証に全行加群の基底性は必要ない。元行の多項式線形結合である238行で十分である。

## 有理数上での排除

非定数の既約 h(e) がすべての元の最大小行列式を割ると仮定する。R=Z_(32003) とし、h を R[e] の primitive 多項式にとる。元の全係数は R にあり、Gauss の補題により、各元の小行列式の h による商も R[a,e,d] にある。d=3,a=1 とすると h は P を割る。LC(P) が R 単元なので LC(h) も単元である。従って h の法32003還元は非定数のまま残る。全小行列式を割ることから、二つの断面の双方で、元行の任意の238個の多項式線形結合の行列式をこの還元が割る。前節の gcd=1 に矛盾する。

再実行には code/s61_binary_hyperplane_e_only_support_20261102.py に --core で BFREE_HORIZONTAL の生成行列 hyperplane-Bfree-t-targets-exact-core-20261102.in を、--output で新規 JSON パスを指定する。入力行列の SHA を BFREE_HORIZONTAL の generated_sha256 と照合する。元135式からの再生成手順は同報告にある。選択した行・列・重み・階数だけを小さな静的 certificate とし、保存された Schur 補行列や kernel は入力しない。
