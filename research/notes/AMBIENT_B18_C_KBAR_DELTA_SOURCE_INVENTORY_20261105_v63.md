# 残る r-Jordan scalar の source inventory

残る判定は三つの旧 filtered 係数 gamma1,gamma2,H の一つの coherent 結合 Delta である。ここではその値を求めず、実 source の所在を固定する。

旧 Told の完全な最小表示は5×825で、最初の168列が literal d3、続く657列が元 source cycle である。一次 rank37 の選択列は後半657を添字付けしているので、825表示へ移すときは168を加える。既存119 cubic preflight には選択37本の元768列に対する constant combination が保存され、全次数 Schur/Euler operator に結ばれる。これを新しい allorder Taylor 表と読み替えない。

G38 の実二次 source は old39 の index177、すなわちこの旧620 kernel の index563 の rank1 pivot である。minor は−250/3。canonical initial G38 との差は既知177空間に入り、その source は37一次関係の八変数倍296本と native d3の168本からなる。三次係数 H を得るには、この差の全 correction を実関係として持ち上げる必要があり、同次 G38 の高次係数を零としてはいけない。

gamma1,gamma2 は二つの実一次関係 lift の M2 に q2 dual を作用させたもの、H は canonical G38 の実 lift の M3 と M2 correction に旧 cubic g dual を作用させたものである。完全 operator と constant source roots は存在するが、三 adjoint の coherent cancellation、primitive 次数、既存 cache の充足、全予算・実行前 code/custody は未完了である。新しい higher source/IFT/gauge/value query はしない。
