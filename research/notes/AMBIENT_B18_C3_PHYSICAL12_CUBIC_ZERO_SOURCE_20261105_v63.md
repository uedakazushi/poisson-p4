# 元 C の実二次 frame と physical12・tauAB cubic subset の source 消滅

実 C は三つの cyclic target (tauA,tauB,tauA tauB) に対し、IA tauA の8列、IB tauB の8列、IAIB tauA tauB の64列、physical12 action の36列を持つ完全な116-source presentation で扱える。これは既受理 raw cokernel の実 right-exact presentation であり、C を環とはみなさない。

保存済み C2 値は全12 delta の一次係数が全9方向で0、nuA/B とbA/Bの plane一次係数が0であることを示す。新しく独立受理した pure-ell readback は、全12のdelta2,bA2のell²も0と確定した。r²/rellだけの旧観察から推測した零ではない。

第一 frame は RA_i=zi eA、RB_i=(zi+beta_i)eB、RH_i=最初の七 physical F_i*tauB で、一次部分は zi eA,zi eB,zi eH の unit21。plane二次部分はそれぞれ0,beta_i2 eB,0である。したがって一次関係を法とする二次空間は9次元の pureplane 空間。

116列の constant first-kernel は95次元。64 intrinsic product と二curve、五つの残るtauB action、十二tauAB action の二次plane像は0。十二tauA actionだけが -bB_j2 eH を与える。実三行18,60,67の固定minorは非零なので、全 quadratic initial span は (r,ell)² eH。従って実 C とC3の次数0,1,2のHilbert関数は(3,6,6)である。

次に physical F_j*tauAB の十二列を考える。一次部分は0。二次の eA/eB 成分は nu1(z)*b1(z) の purezz で、eH成分delta2は全てzを含む。未知のzz係数は z*RA/RB/RH で、zi*r/zi*ell係数は r/ell*RH で正確に消す。zz補正の三次plane carryはz因子のため0、mixed補正の carryはRH2plane=0のため0である。IBの二次項を無条件に捨ててはいない。

primitive 三次planeは delta_j3 eH のみで、delta_j3は十二本・四monomialの未知 functionals のまま残す。しかし全ては既知の (r,ell)² eH の三次倍であり、投影値は0。従って十二列の cubic initial classes は全てsourceだけで0となり、scalar第三係数の評価は不要である。
