# 深い七変数切断の三角消去と二つの座標例外の除去

2026年11月1日。`S61_BINARY_DEEPER_SEVEN_SLICE_20261101` の七変数(e,d,p,q,r,h,k)を使う。
本稿は全一次Jacobianと実在binary接空間の普遍な有理行列を与える。

## 1. 全135式の線形消去

最初の70式の定数階数16を先に消し、保存済みA/B/C上三角blockに沿って残りを選ぶ。
Aの四列(0,3,7,9)、Bの七行(0,1,2,3,5,6,10)・七列(0,1,2,3,4,5,7)、
Cの五行(0,1,2,5,8)を使う。t方向は最初の70式の互換条件で消す。

定数線形座標変換Wの後、選ばれた33次minorは正確に

    −729 (2e−1)^4 (10e−1) (15e+8)^3
       ·[90de²−93de+4d+600e−400] / 7629394531250000000

である。各式は元134式と追加G6から再構成している。
12列の核Tと33列の右逆Uを有理関数として保存し、JT=0、J_selected U=1を恒等的に検証する。
Tのt成分は全て零である。
従って表示の分母はeの低次因子と既存R因子だけに限定され、無関係なdの二次因子を導入しない。

## 2. 実在三次元族と法線九変数

二平面の局所頂点をv=(A,1,0,C)、w=(−C,0,1,D)で表す。
primitive一次項の二条件を微分すると、

    [ 2, −(6e+1)/5, 3(1−2e)(15e+8)/500 ]
    [ d,             4,                 (3e−2)/5 ]

を得る。その核の外積ベクトルと、二次式xwのx²,w²への変分が、実在binary三次元族の接空間を張る。
Tの自由座標で、この三方向の射影minorは2(24e−7)/125となる。
保存行列はJ family=0、T·family_coordinates=familyも恒等的に検証する。
従って24e−7≠0上では指定された三変数を底方向として切り、九つの法線変数で高次計算できる。

## 3. 新しい二つの座標例外

新しい分母15e+8と接射影24e−7は、元core座標ではそれぞれ

    H_A=40b+7e,   H_B=35b−31e

である。各source {u12=u13=K=Q*=H_i=0,c≠0} は、b,a,fを消去できる既約十一変数族である。
固定Q0の五次元安定化群がsourceを保存することを全変数で確認する。

正規化c=L=1,d=12と、他の八座標(3,7,8,9,10,13,14,17)を使い、
それぞれe=−8/15、7/24でβ優越minorを検証する。
各点でQQ二次階数24、非斉次横断長さ65、同じβ上の一般binary点による下界65が成立する。
相対source上の同じsmooth3次元族との階数比較から相対自由65となり、t²=0である。
Sp4とのsmooth base changeによりambient非空除去開へ降下する。

sourceのSp4飽和閉包は十六次元であり、その除去開の補集合は十五次元以下である。
従って十分一般のβでは二つの座標例外の全点が飽和除去される。
残る2e−1、10e−1、Rの因子は、先のT2接続・pivot因子の定理で既に処理されている。

この結果により、一般β上で残る深部を一つの三角消去chartと九法線変数で扱える。
