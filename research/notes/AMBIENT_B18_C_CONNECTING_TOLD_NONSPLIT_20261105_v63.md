# 元 Told の UCT は R0 非分裂：二次 q2 が障害を検出する

実 Told の gr1 基底を u=rh3,v=z5h4,w=rh4、gr2 基底を
q1=z5rh4,q2=r²h4 とする。これらは既受理の正確な HF5321 と十一基底で独立。
ITold の gr1 像は v の一次元だけである。

M7 の厳密関係より rh0=alpha0*v、rh1=alpha1*v、
rh2=u/4+alpha2*v が gr1 で成り立つ。alpha は未計算のまま保持する。
既存二次 source G38 により r*u=−(11767/3652)q1、r*v=q1、r*w=q2。
従って五 head の r² 像の q2 係数は文字通り (0,0,0,0,1) である。
h0,h1 を含む全 head をここで検証し、未知の高次項で置き換えない。

真正 target の cyclic top g に chi(g)=1 を取る。実 chi=(0,0,0,0,d)、
d=−36/1681 なので、任意の preimage x の定数 h4 係数は1/d。
r²(m Told) は m³Told に入るため、r²x の gr2 の q2 係数は常に
1/d=−1681/36で非零。ところが r²g=0 なので、R0 線形 section は存在しない。

この障害は ITold に入り、七次元商 M7 では消える。従って M7→G の分裂と
矛盾せず、元の UCT Told11→G4 へその分裂を持ち上げられないことを説明する。
ITold→Kbar の extension の型、元 H0 や nil 三乗は別の問題である。
