# B18 原点を通る実際の R 曲線と N の接空間

2026-11-03。基点は `P0=e_y∧(x²,0,0,hx,h²+z²)`。これは既存の被約交叉
成分 R19 の中の曲線であり、新しい Poisson 成分を与えない。

## 1. 全次数の多項式曲線

受理済みの proper スペクトル模型で
`r=0,b=d=1,e=0,c=25t²,G2=h²+z²` と取る。相対二次式
`r²+cd−25t²=0` は恒等的に成立し、像は

`P(t)=e_y∧(x²−13thx+25t²xz,12tx²,0,hx−13txz,h²+z²+2txw)`

となる。全150個の物理係数をスペクトル模型の基底と直接照合し、25個の
発散係数および350個の生 Jacobi 係数が C[t] 上で零と確認する。単なる
無限小 Poisson 変形ではなく、全曲線が実際の R に属する。

その t 微分の非零物理座標は零始まりで
`(16,65,112,128)=(13,−12,−13,2)`。既知の19個の群軌道接方向と合わせた
階数は20であり、具体的な20次小行列を保存した。

基点のスペクトル二次式の c 微分は1で、proper source は滑らかである。
受理済みの全境界旗の一意性は、この a=b=1 の chain 点でも全幾何 fiber
を一つの旗に限定する。群19方向と本曲線の20方向は source の全接空間を
単射に写すから、全 fiber は長さ1である。proper 有限化と Nakayama に
より R 自身もこの点で滑らかな20次元錐となる。従って共通 G19 形式積を
除いた R の完備局所環は一変数正則環、すなわち DVR である。

## 2. 実際の N 接空間内の位置

既受理の N の全奇係数イデアルは `(ν,s6,WV,V²)` であり、最小生成元数は
9。従って実際の N の接空間は、同じ物理的 source の偶28方向、既受理の
奇一次7方向、零一次ジェットの奇二次2方向から得られる。これは正規化の
微分だけを N の接空間とする議論ではない。

同伴コードは偶28次小行列 `2304/5`、この全37方向の単位小行列を検証し、
物理的 R 曲線の微分を全150座標で再構成する。その式は

`P'(0)=13 E_Y16 −12 E_Y65 −13 E_Y112`

である。ここで E_Yi は保存した N の偶座標正規化における i 座標方向。
特に `T_R⊂T_N`、`dim(T_N+T_R)=37`。さらにこの曲線の一次方向は N の
階数27の source 微分にも既に属するが、群軌道19方向には属さない。

## 3. この計算から推論しないこと

二つの被約枝の接空間の和が、被約な和集合の接空間に一致するとは限らない。
従ってこの包含だけでは `T_(N∪R)` の次元や D の冪零元の一次可視性を
決めない。R と N のスキーム的接触長、B18 原点での全交叉環も本計算では
決めない。DVR との実際の fiber product を用いた別の代数的議論は可能だが、
本接空間計算による外挿とは区別する。
