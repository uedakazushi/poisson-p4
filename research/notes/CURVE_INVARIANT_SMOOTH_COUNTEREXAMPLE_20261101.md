# 滑らかな canonical curve 上でも保存則は成立しない

2026-11-01。**Δ≠0 に限定しても、全Poisson構造について c₄,c₆,j が基点移動で
一定になるという主張は偽である。** これは前ノートの Δ=0 の反例を強める。
従って提案された微分条件は、一般には飽和イデアル I_S61:Δ^∞ の根基にも属さない。
既知三つの支配成分上で証明した保存則はそのまま維持される。

## 1. 大域的二次Poisson構造

同次座標 (x₀:…:x₄) で

    B01=−2x₂²,
    (B12,B13,B14,B23,B24,B34)
      =(2x₁x₂,8x₁x₃,12x₁x₄,3x₂x₃,5x₂x₄,7x₃x₄),
    B02=B03=B04=0

とし、下三角を反対称で補う。射影Jacobiの全係数は厳密に零である。
別の構成として、アフィン log-canonical 行列の六係数を (2,8,12,3,5,7) とし、
多項式自己同型 y₀=z₀+z₁²、yᵢ=zᵢ (i>0) で押し出しても同じアフィン双ベクトルを得る。
その三次部分は −2y₁² Σᵢ₌₁³yᵢ ∂y₀∧∂yᵢ で、上記の B01 が与える射影三次部分である。
従ってアフィン三次式が現れても、これは正真正銘の大域的二次射影双ベクトルである。

toric 部分の biresidue 行列を10倍すると

    [ 0  5  −3  −5   3 ]
    [−5  0   7  −5   3 ]
    [ 3 −7   0  12  −8 ]
    [ 5  5 −12   0   2 ]
    [−3 −3   8  −2   0 ].

smoothable edge は01だけで、対頂点の次数は (2,0,0)。この装飾図式は既存の
MPS T02 と一致する。ここでは新しい成分を主張・計数しない。
また canonical curve の滑らかさだけでは、P が三つの既知支配成分に属するとはいえない。

## 2. QQ(t) 上の不変量

アフィン基点を p(t)=(t,1,1,1) として primitive 一次部分を取る。
Fisher の tensor 縮約を QQ[t] 上で行い、分母を戻すと

    A(t)=81001t⁴−127912t³+17808t²+25088t+4096,
    C(t)=22286501t⁶−52843368t⁵+27815466t⁴+10808768t³
          −5397504t²−2408448t−262144,
    c₄=16A(t)/(t−1)⁴,     c₆=64C(t)/(t−1)⁶.

判別式は

    Δ=172800 t⁴ D(t)/(t−1)¹⁰,
    D(t)=476989800t⁶−1273270250t⁵+1011748407t⁴−106742464t³
          −108811264t²−3293184t+3407872.

これらは補間・標本からの推測ではなく、多項式環で確認した恒等式である。
c₄,c₆ と j=c₄³/Δ の微分はいずれも非零。特に

    dc₄/dt=−576(5447t³−9670t²+3080t+1152)/(t−1)⁵.

二つの独立な有理点評価も保存した：

| t | c₄ | c₆ | Δ |
|---:|---:|---:|---:|
| 2 | 6371584 | 15372597248 | 12934592726630400 |
| 3 | 3347089 | 5894745263 | 6364426689994275/4 |

j の値はそれぞれ 3946956213086464/197366222025 と
149989816182953863876/6364426689994275 で、相異なる。
両点で Δ≠0 だから、Fisher の非特異性判定により canonical curve は滑らかな楕円曲線である。

追加の既存共変量による確認では、両点とも `covariant_frame` の階数は4、
`scalar_invariants` の I₄,I₁₄ は非零である。従って既存の五変数模型で用いる
Δ·det R·I₄·I₁₄≠0 という標準開条件だけでは、この反例を除けない。
この短い追加確認は保存された24成分の β に既存の二関数を適用したもので、
主証明書の不変量計算の検証範囲を拡張したとの主張ではない。

## 3. 全S61との照合と結論の範囲

二つの有理点では、全Bに実際の射影 frame と perspective を適用して61座標を求め、
150復元係数、134方程式、射影Jacobiを全て正確に確認した。
ここで全134式の検算は二点で行い、不変量の t に関する公式と大域的Jacobiは恒等的に
確認している。この二つの検証範囲を混同しない。

同じ大域的Pの基点を動かした曲線上で Δ は恒等的に零でなく、j も非定数だから、
Δ≠0 部分での全基点方向の保存則は成立しない。
従って8本の c₄,c₆ 微分条件も4本の j 微分条件も、無条件に全S61へ追加できない。
一方、この例の一次部分の像が W16 に優越するとは主張していない。
より小さい一般一次部分の開集合上での保存則は、この反例だけでは決まらない。
