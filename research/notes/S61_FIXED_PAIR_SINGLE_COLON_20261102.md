# 固定二座標の射影切断は t² による一度のコロンで零次元になる

十分一般の一次ジェット β を固定する。c=(c₁,c₂) は任意とする。元135式を q 次数二で斉次化し、u6=c₁t, u42=c₂t を加えた斉次 ideal を I_c と書く。このとき

    dim Proj k[t,q]/(I_c:t²) ≤ 0.

空の場合も含む。したがって t=1 の固定二座標ファイバーは、一つの零次元射影候補スキームの t≠0 部分と正確に一致する。I_c:t² に有限個の無限遠点が残る可能性はある。以下はこの候補の点数や次数の上界14を与えるものではない。

## 固定された二つの評価

t=0 での二形式を l₁(Q)=Qₓz(eₓ), l₂(Q)=Q_yw(e_y) とする。元 q 座標でそれぞれ u6,u42 に等しい。非平方二平面型と旗の軌道における l₁=l₂=0 の余次元は共に2以上である。これは支持平面の Plücker 条件と二次形式の二評価を全場合で数えた結果である。[二座標の中心](S61_AFFINE_TWO_COORDINATE_PROJECTION_20261102.md)

二次元を取り得る残りの無限遠型は T5,T7 である。これら二型についても同じ固定中心の軌道内余次元は2以上である。各代表は Q=∂y∧(G_w∂z−G_z∂w) で、G=x²z+xw² または x²z+w³ とする。座標の順を位置 (x,z)、運動量 (y,w) として Sp4 の大きなセルで

    g = [I 0; T I]·[A 0; 0 A⁻ᵗ]·[I S; 0 I],     S=Sᵗ, T=Tᵗ

と書く。A は可逆二次行列である。producer は det(A)g,det(A)g⁻¹ を十変数の QQ 多項式として構成し、互いの積が det(A)² I であることを確認する。二つの評価の分子は各々この行列で原 Q を動かして求めた。T5 で202項と218項、T7で174項と194項であり、どちらの組でも QQ 多項式 gcd は定数倍を除いて det(A)³ に等しい。よって大きなセル内に共通の因子はない。

補集合 det A=0 は、固定 Lagrangian 平面の像が固定の反対平面に交わる Schubert 因子の逆像である。この因子は既約で、Sp4→LG は既約な放物型群を fiber に持つ局所自明な束なので逆像も既約である。通常順序で v=(1,1,1,0) とし、g=I+vvᵗJ とすると det A=0 かつ T5,T7 ともに l₂(gQ)=−2 となる。この因子全体も中心に入らない。軌道写像の fiber は安定化群の移動だから、Sp4 上の余次元下界は軌道上の下界にもなる。

さらに、任意の非零な最高二次テンソル Q のうち元70本の最高 Jacobi 式を満たすものに対し、l₁(gQ) は Sp4 上で恒等零ではない。実際、l₁ は一つの Lagrangian 平面を核とする分解可能二形式と、その平面外の一ベクトルによる評価である。固定された核平面の安定化群の GL₂ 部分は商の非零ベクトルに推移的に作用し、対称 shear は代表の平面内成分を任意に変えられる。二形式の非零スカラー倍は消滅に影響しない。従って全ての g で零なら、全ての v について Q(v) は全ての Lagrangian Plücker 二形式を消す。これらの線形包は primitive 超平面なので Q(v)=f(v)J である。非退化 J に対する写像 w↦w∧J は四次元で同型であり、[fJ,fJ]=0 は f(J df)∧J=0 を与える。二次斉次多項式 f は零になる。[70最高式と実 Jacobi の同値](S61_UNIVERSAL_WEIGHT6_20261031.md)

## 十分一般の β における全曲線の一般点

幾何学的一般 β 上の各型と独立に g∈Sp4 を動かす。各 q において固定中心を満たす g の次元が 10−r 以下なら、d 次元族から作る incidence の次元は 10+d−r 以下である。従って一般の g の fiber の次元は d−r 以下となる。gβ も一般であり、元135式の同変性と有限型性から、有限個のこの判定を十分一般の固定 β で同時に使える。[型の全次元表](S61_AFFINE_BOUNDARY_DIMENSION_20261102.md)

* B と Fβ は三次元であり、固定中心との交叉は高々曲線である。各々の通常局所模型を持つ開の補集合は高々二次元。非平方軌道と旗軌道で r≥2 なので、この補集合との交叉は有限となる。B の平方部分にも旗の軌道で同じ評価が使える。
* T5 と T7 の二次元以下の fiber では r≥2 なので交叉は有限である。
* 残りの全型は固定一般 β で高々一次元である。各点で r≥1 を上で証明したので、その交叉も有限である。正規化のパラメータから全点が一つの Sp4 軌道にあるとは仮定しない。

アフィン部分では (u6,u42) への射影が有限なので、任意の c の fiber が零次元以下である。従って Proj k[t,q]/I_c は高々一次元で、その全ての曲線の一般点は B または Fβ の通常開に入る。そこで全周囲環は既に t²=0 を満たす。c による二切断後も同じ恒等式が成り立つ。この一般点消滅はアフィン点の不存在を仮定していない。

## コロンによる有限候補と P¹ 上の一般作用

X_c=Proj k[t,q]/I_c 上の実 ideal t²O_{X_c} は、全曲線の一般点で零であるため支持が有限となる。その零化 ideal は (I_c:t²)/I_c の層化であり、冒頭の次元上界が従う。t を反転した chart ではこのコロンは元の ideal と一致する。一般の追加一次式を一つ選んで有限候補の全点を非零 chart に入れれば、その有限代数での t 作用の可逆部分が固定 c の全アフィン代数となる。候補全体の射影長さはここでは計算していない。

また、c を固定すると X_c 自体から一般の二つの追加一次式による P¹ への射影は有限である。一般の追加 hyperplane 切断は有限の例外部分を避ける。二つの三次元成分の通常開では上の二切断が正則列である。局所環は滑らかな三次元底の有限自由加群で Cohen–Macaulay であり、期待余次元が2なのでこれは切断の接触度に依存しない。被約成分上の二切断は超平面二枚分の proper な交叉で、さらに一般 hyperplane で切れば全交叉数は元の次数となる。t=0 商についても各成分で一般平坦な開に縮め、同じ incidence 論法でその補集合が有限であることを使える。従って P¹ 上の一般 fiber の長さは 65·30+5·70=2300、t=0 商の長さは 64·30+5·70=2270 である。t の一般階数は30、二乗の一般階数は零となる。torsion として P¹ の特殊点に残るアフィン解を、この一般階数だけで除くことはできない。[二成分の次数と一般長](S61_PROJECTIVE_TOP_CYCLE_20261102.md)
