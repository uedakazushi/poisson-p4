# native C28 の要求された三十四係数（準備段階）

この immutable worker は P7/C28 SOURCE の独立 peer と root の一回実行許可を必要とする。SOURCE の37 bit committed、112 temporary、全保持14403、whole RAW 予算を変えない。元 canonical33 cache の kappa9 と二 monic を、保存済み・独立確認済み exact G8 polynomial へ代入する。元 source105や canonical gauge の新しい解を求めない。

出力は rA²ell における八 G8 の四mask32係数と二 scalar monic だけである。現在の代数元の他成分は多項式評価の内部状態であり追加の応答出力にしない。全34 source 正上界を検証する。N三次、個別 Xp二次、Xc三次、比較 upper617、HF、T2全長、H0、nil三乗を計算しない。

各binary操作の入力は37 bit以下、積のinteger temporaryは74 bit、加算のtemporaryは75 bit以下で、112以内である。guard失敗時は入力hash・cursor・現在項・accumulator・power cache・完了prefixを保存し、同じjobの自動再試行やcap増加をしない。準備時点では値未計算である。
