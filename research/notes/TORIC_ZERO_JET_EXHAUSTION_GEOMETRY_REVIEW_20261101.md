# T01 の零一次部分ファイバー：全点尽くしの幾何学的点検

2026年11月1日。統合担当とは別の agent による証明の点検。
対象は [最終定理](TORIC_ZERO_JET_EXHAUSTION_20261101.md) である。
この点検では新しい作用行列の全係数を再計算していない。
一様な block minor の独立再計算は統合担当が別途行う。

## 点検した内容

旧 v07 の被約零モジュラー分類を依存定理として残すと、零トレースの
全点は R0、C0、L0 で覆われる。C0 の可換二平面と L0 の平方零行列の
proper incidence は射影的な補助変数を用いるため、境界点を落とさない。
これらの全点被覆と正常形は既に
[独立点検](S61_ZERO_MODULAR_INFINITY_REVIEW_20261101.md)で確認した。
今回は一般一次ジェットに対する incidence 次元評価を使わず、
全点正常形自体に strict 安定化条件を適用している。

零トレースかつ Pfaffian 零なら、J+Q の射影退化因子は x0 の五乗である。
従って strict 自己同型はその唯一の超平面を保つ。無限小自己同型を
v+A y と書くと、定数、一次、二次の条件はそれぞれ
A∈sp4、∂vQ=0、A・Q=0 となる。従って strict Lie 代数次元は
10−rank(A↦A・Q)+dim ker(v↦∂vQ) である。
この条件は非零定数による Q のスカラー倍で変わらない。
従って射影正常形の係数を一にする操作は正当であり、
そのスカラー倍を実現する自己同型の存在を仮定する必要はない。

L0 の非対角型について、最終証明書の三つの block rank 下界を使うと、
t≠−1 では sp4 作用 rank≥8、t=−1 では rank≥7 となる。
平行移動核は t=1/2 または 2 で高々一次元、それ以外では零である。
従って全 t≠0 と全磁気項 F に対して strict 次元は高々三。
例外型は作用 rank≥9、平行移動核零なので高々一。
必要な四次元 strict 部分代数は存在せず、全て除外できる。

C0 の R0 外に残る二軌道のうち Jordan 型は L0 の t=1、F=0 に入る。
Cartan 型は作用 rank 八、平行移動核零から strict 次元二であり除外される。
これは密な軌道だけの議論ではなく、上記 proper incidence と
Jordan の場合分けが与える全点被覆を用いた議論である。

R0 内の全点判定は
[独立点検](TORIC_ZERO_JET_R0_REVIEW_20261101.md)で確認済みである。
非零トレースおよび最小二族については、別担当の独立点検に依存する。
AB の普遍的対数型退化による逆包含と合わせ、
依存定理を明記した最終的な被約台の等式は論理的に閉じている。

## 結論と範囲

最終ノートの幾何学的場合分け、proper incidence の適用、
strict 次元の合成とスカラーの扱いに問題は認めなかった。
従って記載された exact block 証明書と歴史的分類を前提に、
(T01∩{β=0})red=閉包 AB、既約、次元十という結論を受け入れる。
ファイバーのスキーム構造、全 S61 の一般ファイバー、未知成分の不存在は
この定理も本点検も主張していない。
