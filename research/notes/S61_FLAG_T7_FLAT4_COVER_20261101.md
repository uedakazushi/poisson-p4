# T7 の旗端点四重商：人工分母の除去と全 ordinary core 被覆

2026-11-01、v48。`S61_FLAG_T7_FLAT4_20261101` の主開条件から人工因子 Q を除く。
結論は、十分一般の β 上の

    b0*b12≠0, b1=0, (b0*b2−b3*b12+b3²)/b12²=−91/400

を満たす **全ての旗点** に、同じ β の T7 曲面を台とする自由階数4の閉商が存在し、
その商で t=0 となることである。ambient 環の一致・t 冪零性・飽和除去は主張しない。

## 三つ目の実際の座標を取り替える

H11 の自由座標を a0,...,a10 とする。P は既存の T7 critical cubic である。
既存の Laurent ν³ jet をもう一度生成し、元135式の ν 次数0から3の全540恒等式を検査する。
最初の二つの nil 基底座標 q9,q0 を保ち、三つ目を q1 から **q10** へ取り替える。

全45座標の表現および六つの対称積の表現を、多変数有理多項式環で作り直す。
分母の ε 付値を除いた後の定数項は

    3100909122761275736064000 * a0²*a8^12*a9^4*P³

となる。積係数の分母にも、これと a8,a9 の冪以外の因子はない。
従って `a0*a8*a9*P != 0` 上で正則な自由4代数が得られ、Q は不要である。
選択した実座標が nil 基底を与え、q24=3ε であるため閉商となる。
H11 を保存する shear と逆 β 補償によって第二の実在方向を加える議論は、
元の flat4 証明と同じである。端点の nil cotangent の一定次元をこの補完証明には仮定しない。

## 主開から全一般 β の core へ

既存の有限旗安定化 word は、ordinary core の全点を H11 へ移す。
二つの flow は b0,b12 をそのまま保つことを恒等検査した。
従って H11 上で a0=b0≠0、a8=b12≠0 である。

残りの a9=0 と P=0 については、既存の
`S61_R0_MIXED_SURFACE_T7_EXHAUSTION_20261101` が同じ H11 の核行列を用い、
それぞれの Sp4 を含む一次ジェット像の次元を15と証明している。
これは β だけの像次元なので、Qε の ε≠0 部分にしか使えない主張ではない。
旗端点 ε=0 においても、十分一般の β はこれらの像を避ける。

ゆえに十分一般の β 上の任意の ordinary core 点を有限 word で H11 に移した後、
正則な主開の平坦商を構成できる。word の逆作用は ε に依存せず、元の同じ β の点へ商を戻す。
これで全点被覆が従う。
