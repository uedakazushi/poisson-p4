# K=0 heavy cubic block の余次元証明の独立監査

2026-11-02。対象は `S61_BINARY_HYPERPLANE_HEAVY_CUBIC_CODIMENSION_20261102`。
主証明の source・native determinant・局所化論証を読み、主 producer を別実行し、
保存された三つの QQ 多項式の GCD を別の SymPy 実装で再計算した。
元135式の係数再構成そのものを第二実装した監査ではない。

## 1. 正確な heavy-light block

指定開は `a F B C != 0` とする（四因子は主 note の定義）。
法線重みは `(1,1,1,1,1,2,1,1)` で、`v5*vj` は通常次数二・重み三である。
従ってこの七列は、元式 `J y+H(y,y)` の通常二次の陰関数補正だけで正確に決まる。
通常三次以上の補正を省いても、この七列には影響しない。

主 producer の再実行では、元 J に対する `J Tn=0`、
`J_selected Un=delta I34`、元135式からの七列の直接構成、非零16行を確認した。
各列尺度と逆行列分母は指定開の単元である。16×7 template は無条件の入力ではなく、
全112成分の比例恒等式と、比例係数が非零有理数・`a,F,B` の積であることを検査する。
したがって template と元の heavy block の行加群は指定開で一致する。
未知の行 content を除算して開条件を増やす操作はない。

15×16 定数行結合は階数15であるが、それだけから16行全部との行空間一致を
主張する必要はない。得た15行が元の局所化した行加群に属するので、
その三つの7次 minor は元 block の階数欠損集合を覆うために十分である。

## 2. 行列式と UFD の論証

native は行・列交換の符号を保持した Bareiss 消去で、全中間除算を
QQ 多項式の exact division として検査する。三 minor は全係数で保存される。
再実行は4.064秒で成功し、実行時間と native log を除く全数学出力が主 report と一致した。
主 producer 内の二点における有理数行列式の照合も再現した。

さらに、保存された三 minor を独立に `SymPy.Poly` へ読み、QQ[a,e,d] の GCD を
再計算した。monic GCD は

\[
a^5+\frac9{50}a^4e^2-\frac9{100}a^4e-\frac1{50}a^4
=\frac{a^4}{100}(100a+18e^2-9e-2)=a^4C/100
\]

で一致した。この検査は保存多項式からの独立 GCD 計算であり、
七列の独立再生成や大きい多項式行列式の別実装を意味しない。

`QQ[a,e,d,(aFBC)^-1]` は三次元 UFD で、上の GCD は単元である。
もし元 block の最大 minor 全てを含む高さ一素 ideal があれば、選択三 minor を
含むので、その素生成元が三つの共通非単元因子になる。これは不可能である。
従って階数7未満の集合は余次元二以上、次元高々一である。
基底を複素数へ拡大しても、共通超曲面があればその有限個の共役の積が
有理数体上の共通因子を与えるので、同じ結論が成立する。

## 3. 受理範囲

三 core の nuisance-zero chart の指定開で、heavy cubic block の
階数欠損集合に超曲面成分がない、という主張を受理する。
多変数環で GCD が単元であることは ideal が単位 ideal であることを意味しない。
全点での階数7、pure cubic の全階数、重み四次、長さ65、ambient 飽和除去は
この監査の結論に含めない。入力 hash と再実行・独立 GCD の結果は同名 report に保存した。
