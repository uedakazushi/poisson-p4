# 実 M7 の R0 線形分裂と kernel J2⊕k

独立確認済みの一列計算で、cyclic top d=−36/1681、h0の単純座標a0=2/25、
head1の単純座標b1=1331/9216を得た。simple minor は1331/115200で非零。
したがって三次元 kernel は実際に J2(r)⊕k である。

さらに M7 内の S=span(h4,rh4,h0,h1) は文字通り R0 安定で、型は J2⊕k²。
target の基底を delta(h4),r delta(h4),delta(h0),delta(h1) に取ると、行列式は
d²*a0*b1=11979/2260608800。残る八個の高い係数によらず非零である。
従って delta|S は実 R0 同型で、M7=S⊕ker(delta) と分裂する。

kernel の J2 top と単純項は head2/head3 の未計算四係数p2,b2,p3,b3を
記号のまま使って表示できる。全 delta*K と r 作用を記号恒等式で確認する。
既存 ITold の四類に rh3 を加えた五類は既に実 Kbar 内で独立である。
残る二つの bar 類をこの四 parameter で示すが、全形式 K-lift を展開していない。

この分裂は honest 七次元商 M7 だけの命題である。Told では r²h4 が非零なので、
同じ span をそのまま安定な部分加群へ持ち上げない。Kbar七次元の ITold四次元による
extension の分裂や全 R0 型、元 H0 の長さ・torsion 指数、nil 三乗は決めない。
