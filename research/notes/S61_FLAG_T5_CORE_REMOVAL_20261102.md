# 通常旗の T5 接続 core の全一般一次項上での除去

2026-11-02。標数零。b0 b12≠0, b1=0 で r=(b0 b2−b3 b12+b3²)/b12²=−6/25 を満たす通常旗の全点は、十分一般の β 上で元 135 式の t 飽和後に残らない。以下では固定 β の枝の一般長 7 と、同じ枝の非零点で全 16 個の β を動かした周囲の横断長 23 を別々に求める。

## 1. 二切断後の固定 β の一次分解

中心は u5=u49=1, u13=−6/25、他の一次係数は零である。q25=−1 の chart で q19=q26=0 と置く。元 135 式から固定 β の七変数多項式環 R と重み斉次 ideal I を取り直す。重みは順に (1,1,2,2,1,2,2)。正重みのためここで使う陰関数表示は有限多項式である。この構成と t²∈I, t∉I の先行検算は [三 core の固定 β 環](S61_FLAG_REMAINING_CORE_WEIGHTED_POINTS_20261102.md) にある。

C=I:x4^∞ と E=I:(x1+2x4)^∞ の根基はそれぞれ

    Pc=(x1+2x4, x0+4x4, x5−2x6, 2x4²−x6, 2x3+x6, x2+2x6),
    Pe=(x4, 5x0−2x1, x6, x5, x3, x2)

である。両還元曲線とも滑らかで、原点完成後も整である。C は x4、E は x1 で再飽和しても変わらない。R/(C,x4) と R/(E,x1) はそれぞれ重み Hilbert 関数 (1,2,2), (1,2,4) の Artin 環である。従って二つの因子は対応する一変数多項式環上有限自由であり、階数は 5,7 となる。実際、正重みの分次生成と parameter の正則性から各因子の Hilbert 級数はそれぞれ (1+2z+2z²)/(1−z), (1+2z+4z²)/(1−z) となる。有限自由で一般環が一点の Artin 局所環なので C,E はそれぞれ Pc,Pe-primary である。

R/(C+E) の長さは 6 で、重み Hilbert 関数は (1,3,2) である。K=(C∩E)/I は有限長 78、重み 3,4,5,6 の次元は 10,28,37,3、それ以外は零。m=(x0,…,x6) とすると、K と (I+m⁷)/I の交わりは重みから零である。よって I=C∩E∩(I+m⁷)。t は両孤立一次因子で零であり、I では非零である。

第二の還元枝を同定する。標準 T5 代表とその変形は

    Gε=x²z+εxw²,
    Qε=2ε xw ∂y∧∂z − x² ∂y∧∂w

である。対角 symplectic 変換 diag(a,a⁻¹,1,1) の引戻しは Q1 を a³Q(1/a) に送る。従って ε≠0 は全て同じ射影 T5 軌道にある。β に関する条件は一般 ε で独立 4 本で、全 ε で同じ 12 次元線形空間 H12 が解に入る。中心の固定 β へ有限 symplectic 変換で戻すと q の非零成分は q21=2ε, q25=−1, q27=−8ε/25, q28=−4ε/5 であり、元 135 式を t=0 で満たす。七つの自由座標ではこの曲線は (−8ε/25,−4ε/5,0,0,0,0,0) となり、ちょうど Pe を定める。第一の因子は実旗平方零商 D5 の成分である。D5 の還元曲線は x4 の旗方向にあり、その一般長も 5 なので、全射は Pc の一般点で同型となる。[実旗の平方零閉商](S61_FLAG_BOUNDARY_SQUAREZERO_QUOTIENT_20261101.md)

## 2. 同じ T5 枝の ε=1 での全周囲横断

ここでは β を固定しない。変換前の Q1 と β=(u5=u49=1, u14=2/5) を取る。6 次元軌道上の線形核束 H12 は滑らかな既約 18 次元 incidence Z を与える。12 個の β 座標と 6 個の q 座標が Z の真の局所 parameter であることを、H12 の基底と Sp4 の有限次元軌道微分から確認する。q orbit は q25=−1 に射影正規化した後の微分である。H12 方向で q は一定なので、18 次小行列式は二つの対角ブロックの行列式の積である。座標選択と行列式は報告に保存した。

これら 18 座標を中心に固定し、134 本および追加の第 135 式を q 次数 2 に t 斉次化して代入する。残る 43 変数で一次行列は階数 40 となる。単位小行列で 40 変数を陰関数消去し、三つの法線に関して六次までの全 135 残余を求める。各次数の補正に以前の全 tail を戻し、得た非斉次残余に全単項式倍を掛けて六次で打ち切る。QQ 上の 84 列のうち階数は 61、実横断の局所 Hilbert 関数は (1,3,5,6,5,3,0)。m⁶/m⁷=0 から Nakayama により m⁶=0 であり、横断長は 23 となる。

B を Z の上記 18 parameter の形式冪級数環、S* を ε=1 における **全周囲完成環** とする。横断長により S* は B 上 23 元以下で生成される。同じ既約 Z の一般点における全周囲局所環の長さは 23 であり、そこで t²³=0 である。この既知の一般長は、H12 上の同じ T5 の相対完成環がその実在曲面を底として自由階数 23 となり、β 射影が滑らかな開で全周囲へ降下した結果を用いる。滑らかな基底変更の一般点では零次元局所因子の長さは保たれる。この一般長の使用に ε=1 の β 射影の滑らかさは要らない。[T5 の一般長と相対階数](S61_R0_T5_FORMAL_RANK23_20261101.md)

ε=1 で Z は滑らかで、その完成環は B である。S* から B への実 incidence の全射に対応する素 ideal で局所化すると、完成前の Z の一般局所環からの平坦局所写像の閉 fiber は Frac(B) である。よって一般長 23 が保たれ、rank_B S*≥23。生成上界と合わせて S* は B 上自由階数 23 となる。一般 fiber はこの一つの長さ 23 の局所因子で尽くされる。t はその極大 ideal に入り、B 自由性で t²³=0 が全 S* へ戻る。忠実平坦性と有限型性から ε=1 を含む代数的開でも t²³=0 となる。ここで 23 は周囲の自由階数であって、一変数の 23 重構造という乗法表を意味しない。

## 3. 相対族の実加群と旗 core 全体

H14={u4=u12=0} の中心での正則完備底を A とし、q19=q26=0 を課した全相対完成環を S とする。実加群 M=t²³S を取る。特殊環 S₀ の二つの minimal prime で、M そのものを局所化して調べる。

- Pc 側では、同じ二切断後の実旗閉商 D は A-flat である。D は実在する滑らかな旗曲線上の階数 4 平方零拡大で、群方向への切断微分が単位である。S→D の kernel は底特殊化と可換であり、§1 の一般長 5 の一致からその特殊化は Pc で零となる。局所化した Nakayama により相対環自体で S=D となり、t=0 である。
- Pe 側では、§2 の代数的開が §1 の実在曲線の ε=1 を含む。従ってこの開を定める元は曲線上で恒等零とならず、原点完成後の Pe でも単位になる。元式での有限 symplectic 変換・H14 への基底変更・二切断を経て、相対局所環で t²³=0 となる。

この二つの一般点での消滅により M/m_A M の支持は 1 次元局所環 S₀ の閉点に限られる。したがって有限長である。M は有限 S 加群であり、m_Sᵏ M⊂m_A M となる k を取れる。反復して二つの adic 位相が一致し、完備 Nakayama から M は A 上有限となる。ここでの有限性は M/m_A M に対する結論であり、特殊環での t²=0 のみからは従わない。

既知の対角 Gm 作用で A の底重みは全て非正、t の重みは 5 である。同変加群 M の特殊化の斉次基底を同変に持ち上げると、有限個の斉次 A 生成元となる。非零斉次元の重みには上界がある。n≥23 では tⁿ は M に属し、その重みは 5n なので、ある N で tᴺ=0 となる。この N の数値は定めていない。[完備加群の重み論法](S61_FLAG_ZERO12_RELATIVE_WEIGHT_REMOVAL_20261102.md)

二つの固定 β 群方向の q19,q26 への小行列式は 2、H14 を保つための二つの補償方向の小行列式は 2−r=56/25。相対 étale 座標で群方向を戻せるので二切断前にも tᴺ=0 となる。固定 r の正規化七変数への引戻しでは、逆作用による nuisance の重みは (3,3,1,2,2,2,1)。tᴺO の coherent support の section 逆像は閉不変で、零 nuisance を含まないため、収縮から全七変数上で消える。Sp4×この七変数源→W16 の 16 次小行列式を再計算し、写像の優越性を確認する。標数零の一般滑らかさにより一般 β の全逆像点で滑らかであり、元 135 式への忠実平坦降下と有限正常化の被覆で定理を得る。[群方向と補償](S61_FLAG_ORDINARY_WEIGHTED_FINITE_KERNEL_20261102.md) [有限正常化](S61_FLAG_BOUNDARY_NORMAL_FORMS_20261101.md)
