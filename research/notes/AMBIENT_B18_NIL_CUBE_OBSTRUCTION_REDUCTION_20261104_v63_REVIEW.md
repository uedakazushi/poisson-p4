# nil 三乗の二障害と Tor₂ source 指定の独立検討

2026-11-04。親担当による別証明の検討である。元 D0 の実 nilideal を N、
正規化比較核を K、D=k[[ell]]、P=N/K とする。既存の独立監査から
P は D-free7、NK²=0、N³⊂tors_D K、μ_D K=L−4≤13 を使う。
以下は三乗の実値を計算せず、その零性を決定しない。

β(k,p,q)=k lift(p) lift(q) の lift をそれぞれ k1,k2∈K だけ変えた差は
kk1 lift(q)+kk2 lift(p)+kk1k2 であり、全て NK² に属して零となる。
従って β:K⊗Sym²P→N³ は D 上で対称双線形に定まる。N の元を
P の lift と K の和に書くと、K を二個以上含む三次積は零であるため、
im β=KN²=:H となる。三つの lift の積を H で割れば lift 変更は
KN² に入る。従って γ:Sym³P→N³/H が定まり、これは全射である。
この二つの像が零であることと N³=0 は同値である。

D 上で七つの lift を選べることは P の自由性から従う。これを D0 環や
R0 加群の分裂に置き換えてはいない。K の D 生成元が L−4 個なら
β に必要な生成元積は高々28(L−4)、γ は高々84で、合計は
28(L−1)≤448。これは必要な積数の下界でも N³ の長さの上界でもない。
実際の lift、K の生成元、448個の積はこの証明から得たとはしない。

β=0 なら N²K=0 と N³⊂K から N⁵⊂N²K=0。
γ=0 なら N³=KN² なので N⁴=KN³=K²N²=0。
いずれの前提も現在の未検証部分であり、無条件の指数範囲は3〜7のままである。

WN²=0 より β の第一入力は K/(K∩W) を通る。P の入力を W の像だけ
変えた場合も WN² と NK² により β、または γ の H を法とした値は変わらない。
W⊂K を仮定しない。JK²=0 から JKN²=0 は従わないため、β を K/JK
の pairing と見なすことは採用しない。

J=(z7,(r,s)²) の解像度は Koszul(z7) と二変数の Hilbert–Burch 解像度の
tensor である。後者の二列を (−s,r,0),(0,−s,r) とすれば、符号
(−1)^Koszul次数を付けた tensor differential が得られる。別プログラムは
この定義から一次〜三次 differential の全係数を作り、primary の値と比較する。
完全性は二変数解像度の完全性と独立変数 z7 の正則性から従う。
Betti 初四項は (1,10,44,112)。J² の標準単項式は31個・HF(1,9,17,4)で、
別の単項式可除性検査でも全て確認する。これから strictness や Artin–Rees
指数を推論しない。

Tor₂ connecting の source 式では元の ell 切断前 V:F1→F0 を使う。
(I⊗d2)c=(V⊗I)h を全形式函数上で満たせば w=(I⊗d1)h は ker V に属す。
h の選択差は ker V⊗P1 に入り、w の差の H1 類は JH1 に入る。
c に V-boundary を足した変更は d1d2=0 により w を変えず、d3-boundary
も d2d3=0 により同様である。H1=ker V/im X の X 境界を法とする点を保持する。
従って提示された30×692および30×572の constraint は connecting map の
正しい source 指定である。実際の全次数 (c,h) の構成と image の評価は別課題で、
mod-J の核だけから補っていない。K/JK の connecting が完成しても β は解決しない。
