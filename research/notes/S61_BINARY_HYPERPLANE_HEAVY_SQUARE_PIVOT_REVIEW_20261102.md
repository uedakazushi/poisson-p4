# K=0 heavy 二乗の全開単位 pivot の独立監査

2026-11-02。対象は `S61_BINARY_HYPERPLANE_HEAVY_SQUARE_PIVOT_20261102`。
主 source と証明を読み、主 producer を別実行し、明示した多項式恒等式と
有理式の行結合を別の SymPy 展開で確認した。元135式からの二係数の再構成は
同じ主実装の再実行であり、第二の係数実装ではない。

## 1. 通常二次から heavy 二乗を読むこと

既知 `aFBC != 0` の nuisance-zero chart で、heavy 座標 `h=v5` は重み二である。
`h²` は重み四だが通常次数二なので、元式 `Jz+H(z,z)` の陰関数解の二次項
`z2=-U H(Tv,Tv)_selected` だけでその係数が正確に決まる。
通常三次以上の補正は `h²` の係数に寄与しない。

再実行では元 J に対する `JT=0` と `J_selected U=I34`、
分母 `td5=B/50`、`ud=a²FB/25000`、二回の列尺度の復元を確認した。
行77,131の係数がそれぞれ

\[
c_{77}=-3P^2/(500B^2),\qquad c_{131}=3R/(10B)
\]

となること、両式が重み四であることが再現された。主 producer は3.004秒で成功し、
実行時間・入力 hash のメタデータを除く全数学出力は保存 report と一致した。

## 2. 指定開全体の単位行結合

`P,R,S,D0,E,alpha,gamma` は主 note の明示多項式とする。
別実装で QQ[a,e,d] 上の次の四恒等式を直接展開した。

\[
SP-25aR=-D_0C,\quad 50aB=D_0E+10SR,\quad
\alpha P+\gamma R=V=50aBC,
\]
\[
\alpha^2P^2+\gamma(2\alpha P+\gamma R)R=V^2.
\]

さらに実際の二係数を代入した有理式の行結合も独立に約分し、係数が `V²` と
一致することを確認した。使用する行係数は

\[
-\frac{500B^2}{3}\alpha^2,\qquad
\frac{10B}{3}\gamma(2\alpha P+\gamma R)
\]

であり、最後に `V²` だけを反転する。`a,B,C` は既知開の単元なので、
`P,R,E,D0` のいずれも追加の非零条件にはならない。
従って二行を組み合わせた重み四関係は、指定開の全点で `h²` 係数一に正規化できる。

## 3. 残る238方向との区別

六つの重み二関係は light だけの二次式である。重み三の単項式は
light 三次か `h*light` なので、その重み一倍にも `h²` は現れない。
重み二関係の重み二倍も、light 因子を残すため `h²` 成分を持たない。
よって低重み関係の積は、重み四239単項式のうち `h²` 以外の238方向に属する。

重み四自由加群を `A h² ⊕ L` と書けば、上の単位行は `h²+ell` (`ell∈L`) である。
この行による消去後の商は `L` と同型で、全239方向の全射性は残る238方向の
全射性へ正確に還元される。この還元は全 `aFBC` 開上で有効である。
238方向の全射性そのもの、長さ65、ambient 飽和除去は本監査から主張しない。
