# K92：次の補正付きleading層を支持だけで除く

正確なD49から得たSchurの次の下界は26579である。この次数では補正C A^-1 Bを捨てられない。しかし、行列式係数の計算自体を避ける支持証明がある。

外側の双対potentialをα,βとし、内側四方向にp=(-2243,-2175,-2243,-2243)を選ぶ。支持不等式を全て確認すると、補正は形式冪級数の積Fbar Bbarへ分解できる。Fbar=t^-α C A^-1 t^-p、Bbar=t^p B t^-βであり、それぞれの定数項F0(7×4),B0(4×7)がleading補正を与える。F0に現れ得る14係数は全てCの直接係数で、非定数A逆の寄与は厳密に遅い。

既に保存されたDのleading定数行列D0の非零位置は「行1または列0,1」で覆われるのでrankD0≤3。行3は列0だけが非零であるため、kerD0内のベクトルはx0=0を満たす。一方、B0の内側行1は列0だけに支持される。よって補正F0B0をkerD0へ制限すると、像はF0の残る三方向以下に入る。dimkerD0≥4なので、D0と補正の共通kernelが非零となり、D0-F0B0は特異である。

これでSchur次数26579、元の固定正規化11行列のa^16 e^91 d^21係数は零と分かるが、全行列式の零は結論しない。全入口が零とも主張しない。次の次数下界は少なくとも26580である。

次の有用な有限目標は、F0の14個とB0の18個、合計32個のsource定数係数と65個の積で、実際のleading行列のrank・kernel・単元minorを求めることである。行列式が非零になるか試す計算ではない。ここではその全source参照・分母・高さ・保持量を固定し、32係数や積は評価しない。新しい級数、重み、K、source572演算は導入しない。
