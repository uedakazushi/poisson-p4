# Formal combined OLD second symbols

The prepared worker is limited to the coefficient of each independent ordinary
function-second symbol in the OLD part of
`D Xc2 - Gamma Xp2 a1`. It subtracts the actual 563/609 source recipes from
both c and a1, then folds identical typed and C0 labels before applying the
linear projection of the typed constructor. Literal negative C0 aliases retain
their signs, including old-minus-new g functions in the four outer pivots.

All 71 function labels, including 31 physical functions, 36 only79 functions
and four outer regular g functions, are independent formal symbols. A reported
zero sensitivity therefore does not assert a zero source jet. Nonlinear typed
products have no such sensitivity by the point-origin proof; their known
first-cross responses remain outside this worker.

The positive input bounds all 1926 possible scalar slots before signed folding.
Each multiplication and addition is separately checked at committed prior 120
bits before reuse (temporary bound 361, below the unchanged 384/1153 hard
limits). A failure preserves its uncommitted value, cursor, current source and
root maps, completed formal rows and all source pins. There is no automatic
retry or cap increase.

No actual second, cubic, native, b1, upper-relation or Hilbert value is read or
evaluated. Native individual-pivot L2*S0 terms and all remaining source terms
stay explicit in separate lanes.
