# Native70 の有限 C72 演算に対する正の係数包絡

本段階は符号付き応答値を計算せず、固定 source と既存キャッシュから正の分母・絶対値包絡だけを構成する。
基底 A18 の極大イデアルは三乗零であり、二つの monic trace の平方は既存の νA,νB である。
νA²=νAνB=νB²=0 は単項式 support から従う。C72 の極大イデアル J は J7=0。
したがって実際の regular G8 の有理式は、d² の三乗までの有限二項式逆数で評価できる。
同じ κ、同じ根のプログラムを用いるため、既存の G8 原点・九方向一次係数の絶対値を最終包絡の精密化に使う。

全70の intrinsic source は Koszul28 部分のみで、free4 は現れない。
それぞれ full C4 における S0cN=0 が先行 source packet で確認されている。
よって実際の N の二次 scalar 成分を変更しても、重み付き積 N^tS(cN) は変わらない。
ここで使う形式的延長は、実際の N0 と全九方向 N1 を保ったものに限る。
個々の pivot の一次 ell 係数 L0Se+LeS0 を捨てる根拠にはならない。

Γ4 の使用する N 出力列は 0,4,5,7 だけで、intrinsic 行0..7との32関数が必要十分である。
この新しい source gate はそれらと regular G8 の全中間係数、70の重み付き積、Γ4への射影の事前包絡を記録する。
old70 の二次 callback、first-cross、27 pivot の個別一次 carry を加えた全体 gate と独立 review、ROOT の値計算 GO は別途必要である。
本段階から actual70値、HF2、T2全長を推論しない。
