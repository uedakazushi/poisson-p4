# Cprime/ell³ の既知三次 initial 上界試験

独立に認められた完全二次階数 1、真の HF(3,3,3) を入力とする prepared worker である。別 SOURCE gate と親の GO が閉じるまで実行しない。

三次 495 自由単項式を 27 行へ送る固定写像のもとで、44 一次式×45 二次単項式、真の二次 initial 代表 P×9 一次単項式、三 target の ell³、および全 27 consistency 列を二 pass で streaming する。固定独立列・両側逆行列・全 2019 列の source hash と factorization hash を保存する。全部の compressed 列を同時保存しない。

階数 27 である場合のみ、既知 initial が m³(Cprime/ell³) を消すので長さは高々 9 となる。既存の DVR rank/torsion 下界との一致によって長さ 9、長い指数 e=2 が従う。階数不足の場合は既知三次 quotient のみを報告し、e>2 や失敗の数学的負結論を出さない。元 nilcube・genuine connecting edge の数値はこの試験の対象でない。
