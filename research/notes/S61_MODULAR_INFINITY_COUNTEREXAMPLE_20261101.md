# 滑らかな標準曲線を持つ非零モジュラー無限遠の反例

2026-11-01。コード `code/s61_modular_infinity_counterexample_20261101.py`、
証明書 `reports/S61_MODULAR_INFINITY_COUNTEREXAMPLE_20261101.json`。

この反例は、134式と G6 を個別に斉次化して得る**未飽和**無限遠について、
次の二つの提案が成り立たないことを示す。

* その先頭式を満たすなら、Q の線形モジュラー場 A が β を固定する。
* 標準曲線 Cβ が滑らかなら、非零モジュラーの Q は先頭式を満たさない。

十分一般の β における非零モジュラー型の排除まで否定する反例ではない。
また飽和された射影閉包の点であることや、アフィンファイバーから到達することは
主張しない。

## 1. 有理数係数の反例

Q の非零な上三角成分を、座標 (x,y,z,w) について

    Qxy=−z²,
    Qxw=−(x²+8xz+8z²)/2,
    Qyz=−z²/2,
    Qyw=x²+xy+2xz+2yz+3z²,
    Qzw=z(x+z)

とする。Qxz=0。これは旧 nil22 台帳の U1 正常形であり、零モジュラー L0
の名前とは区別する。

一次座標を添字順

    (u4,u5,u12,u13,u14,u25,u26,u27,u34,u35,u36,u37,u48,u49,u50,u51)

で

    (0,0,−24,784,32,24,18,0,1,−311/3,2,80/3,3,4,5,6)

と取る。Q から S61 の45個の二次座標を正規化により再構成し、上記16個を
一次座標に代入すると、元の134式と G6 の q 次数2部分、計135式は全て零となる。
61個の座標と全残差を証明書に保存する。

Q 自体が Poisson かつ J と compatible であることも、β=0 の J+Q について
全134式、150個の復元係数、直接射影 Jacobi 式を使って確認する。
これは表示した非零 β と有限 q がアフィン S61 の点であるという主張ではない。

## 2. モジュラー作用は消えない

mod(Q)_i=Σj ∂j Qij という規約では

    mod(Q)=−z∂y−x∂w.

その行列 A は非零、階数2、A²=0、A∈sp4 である。
一次データを primitive な閉二形式 β に直した後で Lie 作用を計算すると、
たとえば最初の係数が −72/5 となり、A·β≠0。

さらに十個の sp4 基底の作用行列は階数10であり、この β の Lie 安定化代数は
零である。従って、別の非零 Lie 安定化元が存在するという説明でもこの点を
排除できない。

## 3. 標準曲線は滑らか

Fisher の規約により、同じ primitive β の不変量は

    c4=47302703984349184,
    c6=−6657339632224197100699648,
    Δ=(c4³−c6²)/1728
     =35602891117000474561543155905702835990508339200 ≠0.

従って Cβ は滑らかである。滑らかな Cβ の射影安定化群が有限であるという
幾何学的事実とは矛盾しない。そもそも、この先頭方程式から A·β=0 は従わない。

## 4. 今後の扱い

非零モジュラー型は、個々の stratum と β の incidence 次元、または実際の
飽和帰結を使って扱う必要がある。A·β=0 を全先頭イデアルの根基帰結として
追加したり、Δ≠0 だけで全非零モジュラー無限遠を除いたりしてはいけない。
