# M1三重tail対の全有限部分と正規化零軌道

## 1. 二つの軌道による有限被覆

M1の規約で

```
Qxy=Qzw=x²/2, Qyz=−xz−b x², Qyw=a x²+2d xz
```

をQ(a,b,d)とする。これはG=a x²z+b x²w+d xz²に対応する。
有限shear S=T1 T2を

```
T1: w↦w−2d z,
T2: y↦y+b w, z↦z−b x
```

で定めると、全a,b,dでSはsymplecticで、pullbackはQ(a−2bd,0,0)となる。
従って有限点は次の二つで尽くされる。

- a−2bd≠0：既存の対角symplectic変換でQ1=Q(1,0,0)へ移る。
- a−2bd=0：有限shearだけでQ0=Q(0,0,0)へ移る。

後者を除外して全有限tailを証明したことにはしない。
(z,w)のsymplectic交換はg4の対へ移す。有限変換と交換の全係数恒等式を確認する。

## 2. Q1の全十変数β核と普遍三次障害

Q1の全β核Hは十次元で、保存順に

```
(0,0,0,b0,−b7,b1,b9,b2,b3,3b7,b4,b5,b6,b7,b8,b9)
```

となる。既存CUBIC_TAIL証明書は、全H上の最高Jacobian階数上界42と、
二接方向の全二次障害の消滅を証明している。
具体的には二次係数行列H2と有理lift LについてD L=H2を保存している。
今回はt列を加えた全135行を使う。全階数は43、接空間内でt=0である。

F=b0b9−9b7²、G=28b0b9−45b7²と置く。
最初70行の定数階数25を消去した全Jacobianの18次小行列は

```
462838344192 b0^5 b7^9 b9 F G / 30517578125.
```

全行列に対する有理核を確認し、t列の最初70行に残る適合条件を捨てない。
既存の第二接列vと二次lift wを使い、三次係数を元135式から再構成する。
分母を先に払い、18列のJacobianに三次列を加えた19次小行列を計算すると

```
−8464920828355805184 b0^7 b7^15 b9^4 F² G² / 48828125
```

となる。払った分母は1944000 b7^5 F G^4であり、新しい例外因子は生じない。
第一接列の純三次係数はJacobian像に入ることも確認した。

H上では同じβのまま

```
Q(1+2b9*d/(3b7), 0, d)
```

が実在する滑らかな曲線である。全135最高式への代入を恒等式で確認する。
全小行列因子が非零の開では二接変数の全関係は次数3以上で、三次初期関係は非零。
実在曲線に横断する一般線形パラメータで切ると長さは高々3となる。
同じ曲線の一般点で最高Jacobian階数42と二次障害消滅が保たれるため、
S/(t)の一般因子の長さは少なくとも3である。
この下界で全階数を使い切り、Sは一変数底上自由階数3、t=0となる。
一般因子は長さ3の一変数Artin環であり、被約曲線のideal Iは主ideal、I³=0となる。
よってこの普遍開の全点で

```
S ≅ C[[u,e]]/(e³), t=0.
```

これは三次係数が非零という一点の観察だけから高次関係を捨てた議論ではない。
同じ実在曲線に沿うS/(t)の長さ下界を併用している。

## 3. Q1上の全例外因子

Q1のprojective orbitは次元7、projective stabilizerは三次元でありHを保存する。
Sp4×Hのβ微分階数16、(β,[q])同時微分階数17を確認する。
従ってその像閉包Yは既約十七次元でW16を優越する。

b0,b7,b9,F,Gの各因子は接続stabilizerでsemi-invariantである。
F,Gは原始的な一次式を一つの変数について持つので幾何学的に既約である。
各因子の像閉包の次元は高々7+9=16である。

b7=0,b9=0,F=0のβ像はそれぞれ次元14,15,15以下。
Hの六次元定数annihilatorと因子gradientから作った七列を使い、
全β微分への恒等的左核を確認する。標本の階数だけによる上界ではない。
十分一般βはこれら三つの真の閉部分を避ける。

b0=0では主曲線の非対角公式がa_main=1,b_main=0となり、その二次部分もQ1に一致する。
これは既処理のk=−1/3主/tail接続stratumである。
JUNCTION_GENERIC_STRATAと独立レビューによる全一般β除去を適用する。

G=0にはβ微分階数16の指定点があり、その像閉包Z_Gは既約十六次元でW16を優越する。
この点では最高/全Jacobian階数42/43、全二次障害零である。
独立な局所消去で純法線三次係数5/24を得るため、横断長は高々3。
前節と同じ実在曲線のS/(t)の一般長さ下界3が一致し、三重曲線かつt=0となる。

二次障害の普遍消滅は、有理接枠の分母の零点で無条件にその枠を代入する主張ではない。
最高階数42の開上では接核・余核がベクトル束をなし、その間の二次障害写像は正則である。
既約Yの稠密開で恒等的に零なので、この一定階数開の全域で零となる。
指定点の階数42と同じ実在曲線から必要な一般下界が得られる。

局所三次非零と階数条件はZ_Gの非空開へ延長する。
その補集合は次元高々15であり、射影q空間内の閉包からのproper像を除けば、
Z_Gの全一般βファイバーが除かれる。

## 4. 正規化零軌道Q0

Q0の全β核H0も十次元であり、前節のβのu35だけを0に変更したものとなる。
全H0上のG6最高式も零である。

よって像閉包Z0は既約十六次元でW16を優越する。

Q(a,0,0)とβのu35=3a b7を同時に動かす族は、全a,b上で135最高式を満たす。

```

```

を張る。u=v0とするとu=0の横断商は長さ4、u=1の初期商は長さ3となる。

各有限jet行列の階数はZ0の一般点で指定点以上であり、上界3が延長する。
