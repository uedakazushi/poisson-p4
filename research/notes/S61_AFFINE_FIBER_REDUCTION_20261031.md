# 全S61の一般一次部分ファイバー：線形消去の障害と三次Macaulay探索

2026年10月31日。toric成分だけでなく、全134式・全45個の重み2変数を保持する。
このノートは全ファイバーの有限性・次数・尽くしを証明したものではない。

## 1. 標数零で証明したこと

重み1を\(\beta\)、重み2を\(q_1,\ldots,q_{45}\)とする。全S61の134式は、
\(\beta\)を固定するとqに関する高々二次式となる。旧toric係数
\((2,3,5,7,11,13)\)から得られる\(\beta_*\)で、その**二次斉次部分の係数行列は階数134**を持つ。

`reports/S61_FIBER_QUADRATIC_SPAN_20261031.json`に、選んだ134個の二次単項式、
134次小行列の全成分、非零の有理行列式を保存した。元の70式は重み4なので二次部分の係数が
\(\beta\)に依存せず、残り64式は重み5なのでその係数は\(\beta\)に線形である。
従ってこの小行列式は\(\beta\)の高々64次多項式で、その非零集合は非空Zariski開集合となる。

この開集合上では、134式の**非零な定数係数線形結合からアフィン一次式は得られない**。
toric20変数模型で成功した「二次項を定数行操作で消して18本の一次式を得る」手順を、
全45変数模型へそのまま適用することはできない。
多項式を係数とする結合による一次式や、根基イデアルの一次式の存在は否定していない。

再現：

```sh
.venv/bin/python code/s61_fiber_quadratic_span.py --output reports/new-quadratic-span.json
```

## 2. 三次Macaulay行列の有限体上の全計算

同じ一次部分を固定し、保存されたtoric解\(q_*\)へ平行移動して\(v=q-q_*\)とする。
全134式を\(F_i(v)\)と書くと定数項は零で、一次項と二次項を持つ。
素数32003は入力の全分母と互いに素なので、\(\mathbb F_{32003}\)へ還元できる。

\[
\{F_i\}_{i=1}^{134}\ \cup\
\{v_jF_i\}_{1\le j\le45,\ 1\le i\le134}
\tag{1}
\]

を行、全三次以下の単項式を列とする6164×17296行列を疎に構成した。
三次、二次、一次、定数の順に列を並べ、有限体上の整数演算で全行を消去した。
完了した結果は

| 項目 | 値 |
|---|---:|
| 全行列階数 | 6073 |
| 三次ピボット | 5938 |
| 二次ピボット | 135 |
| 一次・定数ピボット | 0 |
| 全行の線形関係の次元 | 91 |
| 三次部分を消す一次倍数間の関係の次元 | 92 |

である。従ってこの有限体の特殊化では、一次の多項式乗数によって、元の134式の
定数線形包にない**一つの追加二次式**が得られる。ただしこの段階では一次帰結はない。
追加式の973個の非零係数を
`reports/S61_MACAULAY_DEGREE3_COMPLETE_20261031.json` に保持した。
同レポートには元の変数との対応、中心、列順序、入力行列SHA-256、実装のハッシュもある。

**その後の進展：** [普遍的な重み6帰結](S61_UNIVERSAL_WEIGHT6_20261031.md)で、
70本の重み4先頭二次式の36次元syzygy空間から、Schoutenの35関係の外にある関係を取り出した。
これにより標数零・全一次部分で成立する追加二次式\(G_6\)を得て、\(\beta_*\)で
二次線形包が135次元となることまで証明した。第2節の有限体計算自体の証明範囲は変更しない。

```sh
.venv/bin/python code/verify_s61_macaulay_degree3.py \
  --seconds 150 --entry-limit 50000000 \
  --output reports/new-degree3-macaulay.json
```

このコマンドは同梱C++を一時ディレクトリへコンパイルし、OSやシステムライブラリを変更しない。
2026年10月31日の完了計算は約92秒、保持した行の非零成分は44,686,199個であった。
時間上限または成分数上限に達した場合は、その状態を返し、全階数を計算したとは扱わない。

先行する純Pythonの60秒試行は1979行で終了し、全行列の結論を与えなかった。
その部分結果は`reports/S61_AFFINE_FIBER_MACAULAY_20261031.json`として区別して保存した。
完了計算をこの部分結果で代替しない。

## 3. 解釈上の制限

第2節単独では一つの有限体特殊化の行列計算であり、標数零で同じ追加二次式が存在する証明ではない。
特に、toric逆問題の二次斉次行列と異なり、**全S61の二次斉次部分は\(\beta\)に依存する**。
一つの\(\beta_*\)で見つけた三次消去の係数を、そのまま普遍的一次帰結と扱ってはいけない。

全模型の斉次化には、既に別ノートで検証された無限遠のflag型部分がある。
二次式の線形独立性と、無限遠の正次元解の存在は矛盾しない。
斉次化したイデアルの次元・次数をアフィンファイバーの次元・次数に読み替えず、
斉次化変数によるsaturation、または非斉次の消去を保持する必要がある。

また、一つのアフィン特殊ファイバーが有限と分かっても、非固有な射ではその点を避ける
優越的正次元成分を排除できない。一般ファイバーの有限性には、普遍的な有限加群の生成元を
作ること、または関数体上での正当な消去等が必要である。

## 4. 次の具体的な実行単位

1. 普遍的な\(G_6\)の取得と135次元の二次線形包の証明は完了した。
   `code/s61_weight4_syzygies.py`と`reports/S61_UNIVERSAL_WEIGHT6_20261031.json`を次の入力とする。
   一次係数の関係の指数は`j*70+i`であり、元の70式に掛ける係数をそのまま再現できる。
2. 135式と一次倍数を用いる反復消去、または次数制限付きGroebner計算を行い、
   新たな低次数帰結があるかを調べる。既存の全6030一次倍数を理由なく何度も再構築しない。
3. 一般化には16個の一次部分を直接記号化する代わりに、優越性が証明された六つの
   toric係数の関数体へ引き戻す方法を使える。残存Sp4作用と必要な局所化条件を明記する。
4. 有限生成元による一般上界が得られた場合に初めて、既知の少なくとも五延長と比較する。
   それまでは全S61の一般次数や未知成分の不存在を主張しない。
