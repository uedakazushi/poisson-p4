# 二つの biform の連結 Spin4 不変式体：六つの有理座標

2026-11-04。複素数体上で G=SL2(A)×SL2(B) とし

```
L=Sym²(A)⊗B ⊕ A⊗Sym²(B),  dim L=12
```

を扱う。これは既受理の Spin4 切片の正確な表現である。
以下は独立な直接証明であり、単独 biform に関する Ma の定理を直和へ移すものではない。
文献上の優先権は主張しない。追加の β 点、高次数評価、GB は用いない。

## 1. 一般 U の正規形と exact stabilizer

U=p(x0,x1)y0+q(x0,x1)y1 と書く。p,q は二次形式で、R_U=Res(p,q)≠0 とする。
その Jacobian 二次形式 J=p_x0 q_x1−p_x1 q_x0 は

```
Disc(J)=16 R_U
```

を満たす。この全六係数恒等式を4×4 Sylvester 行列式から確認した。
従って J は非退化。c⁴=R_U を選び、SL2(A) で J を4c²x0x1へ変えられる。
二次形式の二つの根とその正規化に要る選択は有限代数的なものである。

p=ax0²+bx0x1+cx1²、q=dx0²+ex0x1+fx1² と一時的に書けば、Jacobian の
両端が零という条件は ae−bd=bf−ce=0。中間係数 af−cd は非零なので b=e=0。
従って p,q は x0²,x1² の基底で、その2×2係数行列 M の行列式は選んだ c²。
SL2(B) の元 c M⁻¹ によって

```
U=c U0,  U0=x0²y0+x1²y1
```

となる。ここで c はこの表示の scalar に戻した記号である。

U0 を固定する元を求める。SL2(A) は span(x0²,x1²) を保たなければならず、
その2×2行列は対角または反対角に限られる。反対角の場合、二次形式二平面上の
行列式は−1であり、SL2(B) では補償して U0 自体を固定できない。
対角の場合だけが残り、exact stabilizer は

```
T={(diag(t,t⁻¹),diag(t⁻²,t²)):t∈C*}.
```

従ってここには独立の swap 成分はない。

## 2. U0 の line normalizer

一方、line C*U0 を保つ元は四成分ある。
誘導二平面の行列式が対角なら1、反対角なら−1だから、U0 の倍率 ζ は
ζ²=1 または ζ²=−1。従って ζ⁴=1。
全 line normalizer N は T と

```
σ_A=[[0,1],[-1,0]],  σ_B=[[0,i],[i,0]]
```

で生成される。両行列の determinant は1、σU0=iU0、σ⁴=1、σtσ⁻¹=t⁻¹。
σ²=(−I_A,−I_B) は T の元ではない。

したがって一般の (U,V) の G 商の関数体は、cross-section cU0 と任意の V に
対する N 商の関数体に等しい。実際、正規形の存在で支配性があり、二つの
cross-section 点を結ぶ G の元は正確にこの line normalizer に属する。
これは一般軌道を完全に記述するため、標数0で quotient の関数体を同定する。
全域の regular quotient の同型は不要で、主張もしない。

## 3. V 六係数の作用

```
V=x0(v0 y0²+v1 y0y1+v2 y1²)+x1(v3 y0²+v4 y0y1+v5 y1²).
```

T の六つの重みは順に (−3,1,5,−5,−1,3)。σ の作用は全係数で

```
(c,v0,v1,v2,v3,v4,v5)
 ↦ (ic,v5,v4,v3,−v2,−v1,−v0).
```

v1≠0 上で weight1 の v1 を使って T を有理的に除く。次を置く。

```
r=v1v4,   P=v0v1³,   Q=v5/v1³,
S=v3v1⁵, T'=v2/v1⁵.
```

元の六係数はこれらと v1 から有理的に戻るので、T 不変式体は
C(c,r,P,Q,S,T')。その上で

```
σ:(c,r,P,Q,S,T') ↦ (ic,−r,Qr³,−P/r³,−T'r⁵,S/r⁵).
```

σ² は五つの V 座標を固定して c だけを−cに変える。
z=c²、Q'=Qr³、T''=−T'r⁵ と置くと、残る involution は単に

```
(z,r,P,Q',S,T'') ↦ (−z,−r,Q',P,T'',S).
```

## 4. 六つの有理不変座標と完全性

従って次の六つは N 不変である。

```
I0=c⁴,
I1=r/c²,
I2=P+Q'=v0v1³+v5v4³,
I3=(P−Q')/c²=(v0v1³−v5v4³)/c²,
I4=S+T''=v3v1⁵−v2v4⁵,
I5=(S−T'')/c²=(v3v1⁵+v2v4⁵)/c².
```

z²=I0 を添加すると逆写像は

```
r=zI1,
P=(I2+zI3)/2,  Q'=(I2−zI3)/2,
S=(I4+zI5)/2,  T''=(I4−zI5)/2.
```

全座標を回収し、唯一の残る involution は z↦−z である。
従って N 不変式体は正確に C(I0,…,I5)。六つは代数的独立であり、

```
C(L)^(SL2×SL2) ≅ C(I0,I1,I2,I3,I4,I5)
```

は超越次数6の有理関数体である。これは v1v4≠0 の一般 chart での関数体の
計算であり、v1=0 や v4=0 を全域から捨てた幾何分類ではない。
