# 旗 b12=0 の七変数 chart：b8≠0 上の真四次初期関係

2026年11月1日。対象は元134式と普遍G6を合わせた135式の同次数二次斉次化である。
[普遍低次計算](S61_FLAG_ZERO12_LOW_JETS_20261101.md)と同じ

    b0=b2=1, b1=b3=b5=b6=b12=b13=0

を使う。自由パラメータは b4,b7,b8,b9,b10,b11,b14。
**b8≠0 の全域**で、固定βの完成局所環の最大idealをmとすると

    dim gr_m(S)_d = (1,9,37,98,202),  0≤d≤4,
    t ∈ m⁴ \ m⁵

が成り立つ。したがって S/m⁵ の長さは347である。
b8=0上の四次、五次以降、t冪零性、旗境界の飽和除去は本証明書の範囲外である。

## 1. 同じ元式からの一貫した四次jet

線形消去の36次minorは非零定数 −1400832/25 である。
九つの自由接座標をv0,…,v8、45座標への形式liftをWとする。
既存低次reportのW1,W2,W3を読み、元135式からJacobianと二次項を再構成する。
元式の再代入でW1の接核恒等式、W2,W3、およびA2,A3の全係数を再検証する。
その後

    Q4 = H(W1,W3)+H(W3,W1)+H(W2,W2),
    W4 = −U Q4_pivot,  A4 = Q4+J W4

を七変数QQ多項式環で計算する。ここでHは元の二次項の双線形表示であり、
Uは固定した36式を消す逆行列である。
全pivot式の四次残差が零であることも検証する。
四次だけ別の簡約liftを混ぜる操作は行わない。

## 2. 真の四次初期空間

[追跡付きblock手順](S61_INITIAL_QUARTIC_FROM_JETS_20261101.md)を使う。
まず二次先頭項の独立八行Fを選び、全式Eを H=E−C2F へ替える。
次に、全v_jF2とH3を並べたL3の独立67行B3を選ぶ。
L3=C3B3と同じ行操作を四次尾にも適用する。

    L4 = span{v_j B3},
    R4 = T4−C3*(B3に対応するT4行).

この二つの行空間の和が初期idealの次数4部分である。
二次式の一次syzygyもこの手順に含まれる。
計算結果は

    rank L4 = 284,
    rank(R4 modulo L4) = 9,
    dim I4 = 293.

九変数の四次単項式は495個なので、商の次数4部分は202次元となる。
次数2、3は既証明の45−8=37、165−67=98である。

このchartでは、二次式の一次倍に対応する最初の72行の四次剰余は全て零となる。
追加九方向はそれだけでは得られず、残りの実際の式の四次尾が必要である。
他の層で四次関係を低次syzygyだけから得られる場合と混同しない。

## 3. b8≠0 の全域への特殊化

関数体での階数だけを使わず、実際の行と列を指定した二つのminorを保存した。

    L4 の284次minor = c_lower * b8¹⁶,
    追加剰余の9次minor = c_extra * b8¹⁷,

ここでc_lower,c_extraはreportに保存した非零有理数である。
RREF、低次行操作、observableの補正の全係数の分母は、
非零有理数とb8の冪だけであることを多項式の全単項式について検証する。
したがってこれらの行空間と射影はb8≠0上で特殊化できる。
上界は関数体上の全行関係の恒等式、下界は上の非零minorから得られる。
b4,b7,b9,b10,b11,b14には追加の開条件を置かない。

二次・真三次のrankはb8=0も含む全域で既に一定である。
本証明でb8を反転する理由は四次の選択minorと射影にあり、
b8=0が実際の四次階数降下だと主張するものではない。

## 4. tの四次先頭項

W1,W2のt座標は零であり、三次座標t3はB3の行空間に入る。
係数Ctを解いて t3=Ct B3 を全係数で確認した後、

    t4_corrected = t4−Ct*(B3に対応するT4行)

をL4とR4で割る。raw t4だけを割る方法は用いない。
得られる剰余には、パラメータに依存しない非零有理数係数がある。
その単項式、係数、および全32項の剰余をreportに保存する。
分母の監査と合わせ、b8≠0のどの点でもこの剰余は零にならない。
よってtはm⁴に入り、m⁵には入らない。
これはtを新しい方程式としてidealに追加した計算ではない。
