# K=0 超平面 chart の heavy 二乗に対する全開単位 pivot

## 1. 範囲

`S61_BINARY_HYPERPLANE_WEIGHTED_CHART_20261102` の nuisance-zero chart を用いる。
core は (a,e,d)、既知開は (aFBC\ne0) で、

\[
 F=500a+90e^2+3e-24,\quad
 B=50ad+18de^2-9de-2d+60e-40,\quad
 C=100a+18e^2-9e-2.
\]

八つの transverse 座標の重みは \((1,1,1,1,1,2,1,1)\) である。
重み二の座標を (h=v_5) と書く。
本ノートは重み四の全239単項式中、(h^2) の一方向を
全開上で除去できることだけを証明する。
残る238方向の一様な全射性、長65、ambient の除去は主張しない。

## 2. 元135式からの二つの係数

元の135式を指定 section で (Jz+H(z,z)) と書き、保存済みの
kernel (T) と選択34行に対する右逆 (U) を使用する。
実際の implicit 解の二次項は

\[
 z_2=-U H(Tv,Tv)_{\mathrm{sel}},
 \qquad A_2=H(Tv,Tv)+Jz_2.
\]

producer は元式から (J,H) を再構成し、(JT=0)、
(J_{\mathrm{sel}}U=1) を再検算する。
ここで必要な (h^2) は通常次数二なので、重み四の残余式の
この係数に (z_3,z_4) が寄与することはない。
従って巨大な全四次展開を入力にしない。

元式の0-based行77,131をそれぞれ (f_{77},f_{131}) とする。
両式の重みは四であり、次の二係数を \(\mathbb Q[a,e,d,B^{-1}]\)
上で厳密に得る。

\[
 [h^2]f_{77}=-\frac{3P^2}{500B^2},\qquad
 [h^2]f_{131}=\frac{3R}{10B},
\]
\[
 \begin{aligned}
 P&=125a^2d-450ae-200a-54e^3-27e^2+33e+6,\\
 R&=15ade-10ad+200a+18e^2+6e-12.
 \end{aligned}
\]

分母を払った実装では (T) の heavy 列分母は (B/50)、
(U) の共通分母は (a^2FB/25000) である。
この列のスケールを二回戻して上式を確認する。

## 3. 明示的な単位恒等式

\[
 S=3e-2,\quad D_0=50a+9e^2+3e-6,\quad
 E=B-S\{d(6e+1)+40\}
\]
と置く。直接展開により

\[
 SP-25aR=-D_0C,\qquad
 50aB=D_0E+10SR
\]

を得る。従って

\[
 \alpha=-SE,\quad\gamma=25aE+10SC,\quad
 \alpha P+\gamma R=50aBC=:V.
\]

この恒等式を二乗して、実際の重み四残余式の行結合

\[
 G=-\frac{500B^2}{3}\alpha^2 f_{77}
   +\frac{10B}{3}\gamma(2\alpha P+\gamma R)f_{131}
\]

を取れば、\([h^2]G=V^2\) である。
\(V^2\) は指定開全体で単位なので、\(G/V^2\) は
heavy 二乗に対する単位 pivot になる。
途中の (D_0,P,R,E) を非零とする追加開条件は一切課さない。

## 4. 重み四の線形代数への帰結

保存済みの二次関係は light 変数だけの六二次式である。
重み三の関係は light 三次または light と (h) の積からなる。
従って、重み二・三の関係に適切な単項式を掛けて得る
重み四関係には (h^2) 成分がない。

重み四単項式の自由加群を

\[
 A h^2\oplus L,\qquad \operatorname{rank}_A L=238,\quad
 A=\mathbb Q[a,e,d,(aFBC)^{-1}]
\]

と分けると、\(G/V^2\) による行消去は全 \(A\) 上で定義される。
全239方向の全射性は、この消去後の残る238列の全射性へ還元される。
特に低重み関係の積だけが (L) 全体を張る点では、
二行77,131の追加だけで全重み四関係が全射となる。
これら238方向が全開で張られるという主張はまだ含まない。
