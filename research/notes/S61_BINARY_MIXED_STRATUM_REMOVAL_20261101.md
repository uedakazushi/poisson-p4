# 二平面・混合接続C3の相対平方零性と全一般一次項上の除去

2026年11月1日。固定β点の `S61_BINARY_MIXED_FORMAL_20261101` と相対実在二重直線の
`S61_BINARY_MIXED_RELATIVE_DOUBLE_LINE_20261101` を組み合わせる。
以前の二つのノートの適用範囲はそのまま保持し、本稿で新たに相対化を証明する。

## 1. 結論と対象

`Q0=xw ∂y∧∂z` と

    H11={u12=u13=u4=0, 5u35+u50=0, 25u14−14u49=0}

のSp4飽和の閉包をZとする。これは既約十六次元で、一次項空間W16を優越する。
指定点における**一次項方向も含む全135式のambient局所環**でt²=0である。
従ってそのようなambient開集合とZの非空開部分が存在し、十分一般なβ上では
Zの全ファイバーがt飽和によって除去される。

この結果はH11の全ての特殊点でt²=0と主張するものではない。
他の二平面層、旗、全アフィンファイバーの有限性・五点の尽くしは別問題である。
また接続点の全環が自由65または自由67であるとは主張しない。

## 2. 等階数torsion-free特殊化補題

kを体、A=k[[b1,…,bd]]、R=A[[u1,…,um]]、Mを有限R加群とする。
`M0=M/(b1,…,bd)M` がk[[u]]上torsion-freeで階数rを持ち、
`rank_R M=r` なら、MはR上torsion-freeである。A上のflatnessは仮定しない。

まずd=1とする。TをMのR-torsion部分、Q=M/Tと置く。Qはtorsion-freeなのでbはQの
非零因子であり、tensorの完全列は

    0 → T/bT → M/bM → Q/bQ → 0

となる。高さ一素ideal(b)でRを局所化するとDVRになり、有限torsion-free加群Qは
自由階数rである。従ってQ/bQのR/(b)上の階数はrである。
T/bTはtorsion-free加群M/bMの階数零部分加群なので零となり、NakayamaによりT=0。

一般のdでは、Mの有限表示行列のminorを用いる。一般階数と最終特殊化階数が共にrなら、
各中間特殊化の階数もrである。実際、表示行列の一般階数を越すminorは恒等的に零で、
最終特殊化で非零の最大minorはどの中間特殊化でも非零である。
残るd−1変数についての帰納法でM/b1Mがtorsion-freeとなり、d=1の場合を適用する。

## 3. 同じ相対二平面三次元族

既証明の固定点β0は

    (u4,u5,u12,u13,u14,u25,u26,u27,u34,u35,u36,u37,u48,u49,u50,u51)
    =(0,3,0,0,42/5,7,8,9,10,11,12,13,14,15,−55,17)

である。相対二重直線のノートにある固定Darboux shear gは、Q0を保存し、β0を

    H9={u4=u5=u12=u13=0,25u14−14u49=0,
        5u35+u50=0,u51−5u26=0}, u49≠0

の点β0'へ移す。ここではH9'=g⁻¹H9を使い、β0の周りの九変数完成底をAとする。
これにより特殊ファイバーの座標と加群は、固定点証明のものと正確に同一になる。

実在する二平面族は次のように記述できる。頂点となるLagrangian平面のchartを

    v1=(a,1,0,c), v2=(−c,0,1,d)

とし、二つのprimitive制約

    β(v1)(v1,v2)=0, β(v2)(v1,v2)=0

を課す。平面のannihilatorはell1=x−ay+cz、ell2=w−cy−dzであり、

    Q=(ell1*ell2+h*ell1²+k*ell2²) v1∧v2

が二平面三次元族Cを与える。頂点の二式は二平面型の最高Jacobi条件そのものであり、
二次形式の係数h,kは自由である。

β0,a=c=d=h=k=0において、頂点の二式の(a,c,d)-Jacobianは階数2である。
従って相対頂点曲線はA上smooth1、相対CはA上smooth3となる。
固定点証明の接座標(v0,v1,v3)をuとすると、実在族の接微分の対応する3次minorが非零である。
従って相対Cの完成環は `R=A[[u0,u1,u3]]` と同一視できる。
このRの三座標はambient座標から来るので、相対全135式の完成環Sに対してもR→Sがある。

同じ頂点a=c=d=0で(h,k)=(1,1)とした

    Q1=(xw+x²+w²) ∂y∧∂z

は、Q0と同じ二次形式の射影平面ファイバーに属する。従ってQ0の滑らかな頂点成分上で
作ったCと同じ既約相対成分に属する。コードはβ0でのQ1を元135式から再構成し、
最高Jacobian階数34、全階数35、二次障害階数5、共通Hessian根基次元3を再確認する。

よってこの**同じ**相対Cの一般点で、既存の普遍二次・三次証明書を適用できる。
線形消去と二次行消去のpivotを反転した定数階数chartでの恒等式を制限するのであって、
無関係な一般βの標本から外挿しているのではない。
法線の次数0,1,2,3の次元は少なくとも1,7,23,34、一般法線長さは65以上となる。

## 4. 相対加群の有限性とtorsion-free性

Sを§3の相対全135式の完成環とし、相対実在二重直線の完成環をDとする。
固定gによる同一視を介して、既証明の全射S→Dがある。

    D ≅ A[[s,e]]/(e²),  t|D=0.

これはA上flatである。N=ker(S→D)と置くと、Torの完全列から

    N/(b1,…,b9)N ≅ N0

が正確に成り立つ。右辺は固定点証明における実在二重直線への核であり、
k[[u0,u1,u3]]上有限torsion-free、階数65である。

S/(b,u)は既証明の横断商で長さ67以下である。完全局所環での有限性判定により、Sは
R=k[[b1,…,b9,u0,u1,u3]]上有限となり、Nも有限である。
DはR有限で、次元10に対してdim R=12なのでR上torsionである。
従って `rank_R N=rank_R S`。

有限表示のminorによる特殊化不等式とrank N0=65から `rank_R N≤65`。
一方§3の相対CはRへ形式同型で、その一般法線長さは65以上なので `rank_R S≥65`。
従って両階数は65である。§2を適用し、**NはR上torsion-free**となる。
ここでSやNのR上free性は必要なく、主張もしていない。

## 5. t²の相対恒等式とambientへの降下

Frac(R)上では、既知二平面成分の法線長さ下界65がSの全階数65を尽くす。
法線ideal Iの次数0から3の次元は1,7,23,34と等しくなり、I⁴=0である。
最高階数34に対して全階数35であるためtは法線余接空間で零、すなわちt∈I²である。
従ってSのR一般部分でt²=0となる。

Dではt=0なのでt²∈Nである。NのR-torsion-free性によって一般部分での零性が戻り、
相対完成環S全体でt²=0を得る。

相対切断だけの結果をambient局所環へ無条件に移してはいけない。
ここでは七つのH9法線に対するSp4微分のminor

    −1133614671336/625 ≠ 0

があるため、`Sp4×H9→W16` は指定点でsmoothである。
全135式の同次数斉次化のSp4同変性により、ambientスキームのこのbase changeは
`Sp4×(H9上の相対全135式スキーム)` と同型となる。
projective chartのtは単元倍しか変わらない。
従ってbase changeの完成局所環でt²=0であり、smooth写像の局所的な忠実平坦性と
完成の忠実平坦性により、元のambient局所環にもt²=0が降下する。

これは特殊な九次元切断への制限だけからambient結論を引き出す論法ではない。
切断のSp4飽和のsmooth性を用いたbase changeと忠実平坦降下が不可欠である。
なお指定点でtは既証明の固定β商へ非零に写るので、ambientでも非零である。

## 6. 十六次元接続層の全一般βファイバー

固定Q0の五次元射影安定化Lie代数はH11を保存する。この恒等式と一次項法線minor
6997621428/125≠0は `S61_BINARY_MIXED_CONNECTION_20261101` に保存されている。
従ってSp4×H11の像の既約閉包Zは、Q0の軌道次元5とH11の次元11から高々16次元、
一次項像が16次元であることから正確に16次元である。

ambient局所環でのt²=0は、coherent annihilatorによって指定点を含むambient開集合上の
恒等式となる。そのZとの交わりは非空開であり、補集合の次元は15以下である。
そのβ像の閉包も15次元以下なので、これを除いた十分一般のβについてZの全ファイバーが
この開集合に入り、t飽和で除去される。

これはZの指定開だけを一般ファイバーで残す議論ではなく、補集合の**全体次元が16未満**
であることを用いた全ファイバー除去である。十八次元・十七次元の二平面層に同じ論法を
そのまま適用することはできない。
