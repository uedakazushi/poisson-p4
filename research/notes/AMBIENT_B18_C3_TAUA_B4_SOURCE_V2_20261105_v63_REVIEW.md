# 四つの τA 源の修正版射影と文字通りの零係数の独立確認

修正版 V2 を、作者のプログラムを読み込まずに検査した。初版の χ は B の r³ 項から生じる `−b2*C_r³` を欠いており、独立失敗レポートを残した。初版、訂正履歴、修正版はいずれもハッシュで固定し、変更していない。

四つの源は実際の同じ物理行 19,28,29,72 の `F_j*(τA−τB/4)` である。全 C4 での積を独立な自由多項式計算で検証すると、係数は `(νA*bA+νB*bB/4, δ, −δ/4, −bB−bA/4)` となる。最初の成分は文字通りの単位源で消え、残る三成分の全高次項を保持する。混合 H 項は r/ell 倍の RH で消すが、その B 二次平面成分は零である。zz 項の補正には z 因子が残る。B の混合補正からの β2 三次項を落とさない。

実際の β2 と二つの曲線三次式を元の源から再合成し、r³ と ell³ の関係による単項式書換えから正規形を作り直した。δ3 と七組の混合二次係数を形式変数のまま残して、八つの射影の全 144 係数を確認した。修正された χ の δ_(zi*r) 重みは `(β_i,ell²−b2 β_i,r²)/4` である。

非零重みを持つ全 60 アクセスは、既存 C2 の係数としてそれぞれ零である。raw33 の全 74 正規形に対する 16 個の Taylor 双対も確認した。したがって新しい対合ワーカーを使わず、八つの修正版射影は零と分かる。四つの三次類は依然として未知の `α_j*(A_r ell²−B_r ell²/4)` であり、類自体の零化、C3 長さ、ねじれ指数、H0、nil の結論は得ない。

独立チェッカーの最初の試行は、非零重みのアクセスだけでなく、全 16 個の混合 Taylor 葉が零だという過剰な仮定を置いて停止した。β が零の添字には非零の葉があってよく、射影には寄与しない。この自分の失敗コードと理由は ATTEMPT1 に保存し、必要なアクセスだけを検査して完了した。

主証明の `numeric_static_envelope=22000` は将来の選択的ワーカー用の値を誤って転記したもので、この独立レビューの全入力上限ではない。別添 `whole-audit-numeric-custody-correction.json` が全入力 46,791 数値葉、補助配列込み 80,000 上限を明示する。これは実際に適用される 150,000 上限内であり、数理計算の再実行や許容枠の引上げを伴わない。
