# q2 の genuine Nbar に対する零積と raw128 の補正

これは Nbar=Nil(D0)/ellNil(D0) 上の主張であり、Tnil 全体に積を定義しない。canonical minimal→honest→free44 section を使う。旧 natural origin の h4 列は `(0,1,wedges)`、wedge head の free44 原点は零で、freehead43 の原点は e43 だから、q2=i(r²h4) の free44 cycle は `r²e43+O(m³)` である。

受理済み五つの Rbar 加群生成元から、任意の genuine Nbar 元は free44 `(a36,bz7,bgA)` の原点が e43 の倍だけである代表を選べる。従って a,bz は m に入り、even b0 は m²。q2 の a,bz は m³、bgA は m²に入る。Qrad の even 成分が m に入り、CA の最初の七 conductor 関数が m、literal gA505938 が全 R0 の m³ に入ることから、q2 の b0 と odd scalar B は m⁴に入る。

全 Product44 formula を使うと q2*n の a,bz は m⁵、bgA は m⁴に入る。ここで正確な補正を省略しない。積 cycle c を raw128 に入れる写像は **iota(c)=(c,H(mc))** である。m0e43=0 なので mc∈m⁵、H が次数を高々一つ下げるので iota(c)∈m⁴になる。

この次数評価だけでは足りない。真の cycle だから d2Hmc=mc であり、任意の right section n について `Phi_n iota(c)=c-nmc+n d2Hmc=c` が厳密に成り立つ。従って old/direct section change は iota(c) を固定し、最初の44座標は文字通り c のままである。原点での完全な最小射影第一行は raw128 上で `[e42^T,0_84]`。よって order4 の H 補正がどれだけ残っても、この行の値は c42 の order4 だけであり、零である。

正確な quartic dual1650 は唯一 `(head0,r4)` に値一を持ち、Tnil の m⁵は零である。従って積は Tnil 上で零、genuine Nbar の単射により **q2*Nbar=0** である。r q2=g も同様に零積を持つ。

これで Kbar² の六つの候補積は、Rbar 加群として U²,US,S² の三つに減る。QQ rank を求める場合は r 倍も含む module closure が必要で、三独立や H0 の生成は主張しない。元 K の lift が上で N を零化するとも主張せず、元 H0 や nil 指数は未決のままである。六積の signed value は一つも計算していない。
