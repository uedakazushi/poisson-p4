# 形式的一変数曲線による実際のplane五行selector

2026-11-04。前段の実際の134×5多項式行列をそのまま使い、新しいβの標本を取らずにQQ[T]の非零minorを証明する。一回の許可された形式曲線は

```
(H,L,s0,q0,t0)=(T,T²,T³,T⁵,T⁷)
```

である。環準同型QQ[H,L,s0,q0,t0]→QQ[T]によって5minorが非零になれば、元の5変数多項式minorは非零である。すべてのT点での非零性、曲線と全openの同一視、数値β標本からの推測は用いない。

前段で証明した五汎関数の単射性により、五列でのrank5は全134式のplane制限のrank5を意味する。既知五点quotientの長さ5だけから行空間の次元を推論するのではない。これにより元134式から実際の独立五行を選べるが、全45未知数ファイバーの尽くしやcross126のrankは未解決である。

既存の692953項のQQ多項式行列をT次数ごとに厳密に足し合わせ、総項数150000以下・RAW32MiB以下のpreflightを先に保存する。passした場合だけ、一回60秒・2GB・32MiBのQQ(T)消去を行う。常に元134行をQQ(T)へ全展開するのではなく、高々五つの正規化pivot行と一つの候補行を保持する。

選択された元の5×5QQ[T]行列と、非零の行列式多項式を保存する。行列式は独立のBareiss計算の全割り算を余り零と再乗算で検証し、消去pivotの積・列符号による値とも厳密に照合する。前の五変数field段階のguard見落としpacketは変更せず、本手法を別packetとして扱う。

## 原五変数体上への結論

選んだ五行の原QQ[H,L,s0,q0,t0]行列式をDelta5とする。保存したQQ[T]多項式はDelta5の環準同型による像であるため、Delta5は非零である。前段の五汎関数は既知五点で消える次数2以下の式空間上で単射だから、全134式の実際のplane制限の行空間はrank5で、この五行が基底である。

前段のplane座標(a,b,sigma)とnormal42回路のz3は、証明済み非零3minorを通じた可逆線形座標変換である。従って同じ五行が保存したz3 frameでも基底になる。これは古い別βの固定selectorを移した主張ではなく、今回の原五変数の実際の五行に対する新しい非零minorである。

次に五列行列をA、選択五行の5×5行列をBと書けば、H=A adj(B)/Delta5はparameterのみの有限回路となり、選択行でI5である。未選択の129行からΣH_ijF_selected_jを引くと五汎関数が零で、かつ既知五点で消えるため、plane制限は恒等的に零になる。したがってその129残差は全42法線変数のidealに入る。この次段のSLP組立て、129×126 cross行列のrank、平面外残余の空性はここではまだ計算していない。
