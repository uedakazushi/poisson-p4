# 元比較 kernel K の最小 R0 生成数三

対象は同じ物理 regular 九変数の base 環 R0 上の元比較 kernel K である。D=QQ[[ell]] 上の最小生成数七や、全 D0 上の ideal 生成数とは区別する。今回の実値 primary は mu_R0(K)=3 を与える。元 K の全関数 lift の展開や、元 H0 の長さ・ell 消滅・nil 指数は求めていない。

受理済みの U,S,q2 は Kbar=K/ellK を生成し、r の rank は四、Kbar/rKbar は三次元で同じ三元を基底にもつ。zi*q2 は旧 Told の m 三次、すなわち g=rq2 方向に入るので rKbar で消える。zi*U と zi*S の十四個も、rKbar を法として q2 方向しかもたない。従って十四係数がすべて零なら最小生成数三、一つでも非零なら二である。有限性と ell-Nakayama により元 K の生成数へ戻せる。

この十四係数は true OLD5×825 の selected37 関係における head4*r² 二次係数 t_j の線形結合である。pi_q2 は全180初期還元により文字どおり index179 と確認した。定数 source は全56行で零。最後の raw55 座標を読む Schur の r 一次 carry は二十七 pivot と八十四 unit の双方で零なので、t_j は raw P_g,r² だけでよい。

literal honest C0 の640関係と元768 source の constant combination を畳み、二十一の既存 scalar root、九十八 weight に限定した。全 root は既存 source2 cache に存在し、opaque second gradient は空である。CB の非線形曲率、共通105 frame、元 gA と physical f63 の namespace を保った。新しい IFT・gauge・physical jet は使っていない。
