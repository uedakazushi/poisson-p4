# Actual canonical first-ell and effective native S1 input

This is the single first-ell30-coefficient extension authorized after
the independently checked input gate. It multiplies the existing
inverse and cached physical first-ell right-hand side, checks all30
canonical derivative equations, and applies the peered target Jacobian.
The actual two monic first-ell coefficients are zero. The actual G8
first coefficients and the native S12-by32 derivative therefore give
an exact sparse Res4 S1ell, with the original source signs retained.

There is no new physical implicit solve, gauge inverse, higher jet or
N1. This S1ell is only an input for source combinations with native
S0*cN=0: their effective first response is L0*S1ell*cN. It is not
asserted to equal each individual native X1. No T2 origin, finite length,
K-torsion exponent or H0 length is computed here.
