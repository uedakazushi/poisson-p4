# 元 Told の五 head から真正 C[ell] への実形式 connecting operator

旧最小五生成元は56列の行22,23,29,30,55に対応する。既存の単元分解から
sigma=(I−nbar*mbar)E を取る。これは既に自然写像で使った実形式 cycle であり、
旧 honest116 の wedge84 部分は零、free32 の tail がそのまま保持される。

FULL の V は元の実 chain source から復元する。Q48 の C4 成分1,2,3と、
負の U8 の同成分を並べる。全168成分の符号と、ell=0 の旧 V56 との
文字通りの source reference の一致を検証する。旧第八生成元は f63 のまま保持する。
同じ original105 の FULL_R0_F9 と ELL0_S_F9 は別の clone として固定する。

sigma の係数は ell=0 で構成した後、ell に依存しない形式級数として持ち上げる。
FULL の m,n に置換してしまうと connecting の分子を消してしまうため、そうしない。
Vbar sigma=0 が厳密に成り立つので、Vfull*lift(sigma) の全15成分を
元の形式正則環で ell で割れる。この除算を有限商への射影より先に行う。

eta=(Vfull*lift(sigma))/ell は C[ell] の元を表す。疎な実 D 線形射影 q7 を適用し、
ker E7 の自由行1,2,5,6を選び、既存の基底変換で J2(r)⊕k² の座標へ移す。
全640の元の chain 関係と128の完全 syzygy が FULL の cycle であることから、
境界の持ち上げ差は ell 倍となり、eta の差は im V になる。これにより元の
768関係および Schur/Euler 後の825関係がすべて降り、higher Tor を捨てない。

ここで得るのは具体的な source 型付き operator であり、像の数値ではない。
最高次数では A/B 分子の r³ell、r²ell² が必要になる。V4*sigma0 を含む寄与を
まだ記号のまま保持し、新しい source/IFT/gauge/jet の値計算は行わない。
真正 target の構造により五 head の二十座標は三条件を満たすが、残る十七係数は
未計算である。元 H0、K の torsion 型、nil 三乗の結論は変更しない。
