# 二平面型階数降下点の局所次元3と横断長さ上界67

2026年11月1日。[優越する階数降下族](S61_BINARY_RANK_DROP_FAMILY_20261101.md)の
指定有理点で、全135式の未飽和二次斉次化の局所次元が3であることを証明する。
対象は Q=xw∂y∧∂z、一次座標は保存順 (2,3,…,17) に対し
u12=u13=u35=u50=0 とした点である。

完成局所環の三パラメータ横断商は長さ高々67、極大イデアルの五乗は零となる。
実際の長さ、全局所環の自由性、t の冪零性、飽和後の枝はまだ決定しない。
前の一般二平面型の自由階数65を、この階数降下点へ自動的に延長しない。

## 1. 実際の三次元族と接座標

全 chart の Jacobian は階数34で、接空間は11次元、その上で t は零である。
保存された核基底を T とし、接座標を v0,…,v10 と書く。

支持 Lagrangian 平面の chart を

    v1=(a,1,0,b), v2=(−b,0,1,d)

とする。曲線の二つの方程式 β_v1(v1,v2)=β_v2(v1,v2)=0 の微分は階数2。
平面を消す一次式を ell1=x−ay+bz、ell2=w−by−dz とすると

    (ell1 ell2+h ell1²+k ell2²) v1∧v2

は固定 β の実際の二平面型三次元族を与える。
その全135最高式への包含と局所的な埋込みは
[前の局所証明](S61_BINARY_LOCAL_DIMENSION_20261101.md) §1 と同じ普遍式による。
コードはこの族を微分し、S61 正規化と射影 chart の補正を行い、
三つの独立方向が T の像に入ることを確認する。
v0,v1,v3 のこの族への制限には非零3次小行列式がある。
従ってこれらは同じ滑らかな三次元族の局所パラメータであり、局所次元の下界3が得られる。

## 2. 厳密な二次階数と三次初期形式

元の式を F(z)=Jz+H(z,z) とする。QQ 上で J の左核へ射影した H(Tv,Tv) の
係数行列を計算すると、階数は正確に14である。
ここは有限体の標本から上界を推論せず、QQ の行簡約で確認する。

素数 p=32003 において、J の選択34次小行列を逆にし、J_R U=I を検算する。
形式的陰関数消去の三次までの式は

    w2=−U H_R(Tv,Tv),
    A2=(I−JU)H(Tv,Tv),
    A3=(I−JU)2H(Tv,w2)

である。全135式の A2,A3 を構成し、連結行列 [A2|A3] を行簡約する。
二次部分の階数は p 上でも14であり、二次部分を消した三次行は54個得られる。

QQ 階数と p 上の二次階数が一致することにより、この二次消去は
p で可逆な pivot だけを使う有理係数の演算へ持ち上がり、二次部分の消滅は QQ 上でも恒等的となる。
従って得た三次行は本当の局所イデアルの初期形式の還元である。
三次行の p 上の総数を、そのまま QQ 上の全初期関係の数と同一視する必要はない。
上界の証明には、明示した関係が実際の初期イデアルに入ることだけを使う。

## 3. 八法線変数と792次 minor

三パラメータ v0,v1,v3 を零とし、残りの八変数に二次・三次初期形式を制限する。
それらの適切な単項式倍を各次数に並べた係数行列は、p 上で次の階数を持つ。

| 次数 | 単項式数 | 確認した関係の階数 | 商の次元上界 |
|---|---:|---:|---:|
| 0 | 1 | 0 | 1 |
| 1 | 8 | 0 | 8 |
| 2 | 36 | 14 | 22 |
| 3 | 120 | 86 | 34 |
| 4 | 330 | 328 | 2 |
| 5 | 792 | 792 | 0 |

五次の行列には、行列式が p 上で22292となる792次小行列を保存した。
有理入力の分母と行消去 pivot は全て p で可逆なので、この minor は QQ 上でも非零である。
従って QQ 上で全五次単項式が確認した初期関係に入り、
指定横断商 A の極大イデアル m は m5/m6=0 を満たす。
Nakayama により m5=0 となり、A は有限長で

    length A ≤ 1+8+22+34+2 = 67

を得る。S/(v0,v1,v3) が有限長だから、元の局所次元は高々3。
第1節の実際の三次元族と合わせて、指定点の局所次元は正確に3である。

## 4. 結論しないことと再現

この計算は三次までの初期関係から有限長性の上界を証明する。
実際の横断代数を決定するには、非斉次残余の四次項までを保持して調べる必要がある。
横断長さ67という等号、全環の R-自由性、t の冪零性はここでは結論しない。
一般二平面型から得た長さ下界65だけでは、特別な点の上界67との間の差を解消できない。
また、この一点の局所次元3から全一般アフィンファイバーの有限性は従わない。

```
.venv/bin/python code/s61_binary_rank_drop_local_20261101.py --output /tmp/binary-rank-drop-local.json
```

全二次・三次残余の還元、実際の三次元族の接写像、五次 minor の選択行と値、入力ハッシュを保存した。
行列の再構成に外部 CAS は必要ない。
