## 1. 座標規約と exactness

normal は凍結された順序で v0,…,v12、重みは (1^7,2^4,3^2)。
ρ=u5 は重み1の別引数として保持する。元の射影 q の45座標では q25=−1、
残る44座標と t が prepare() の45 chart 座標に対応する。
一次係数の非零値は

    u5=ρ, u12=1, u26=1, u27=h, u51=2.

β の返却配列は元の16個の重み1座標の保存順、q は元45個の重み2座標の保存順である。
q25 は全61変数の u38 に対応する。配列番号と u の添字を混同しない。

`code/s61_marked_sigma_point_lift_20261103_v62.py` は凍結 prepare() をそのまま呼び、
出力した J,T,U と全135非線形行を読む。Smith の行・列変更を再推測しない。
T normal から始め、重み d の選択行の非線形残余を計算して U で補正する。
座標重みは最大4、ρ も正重みであり、各重みの式は同じ重みの未定座標には
J を通して線形に依存する。従って重み1,…,4の四段階で陰関数解が正確に終わる。
有限 jet の打切り近似ではない。

全28選択行の消滅を毎回確認する。さらに元134式と追加G6の保存された monomial 列から、
q 次数二の t 斉次化を直接評価する。元135残余は Smith の行変換後の残余とは別に返す。
これにより、元座標での全式と t の値を独立に確認できる。

## 2. 再利用 API

```python
import sympy as s
from s61_marked_sigma_point_lift_20261103_v62 import load_model, coerce

L = load_model('reports/S61_MARKED_SIGMA_POINT_LIFT_20261103_v62_FINAL/model')
K = s.QQ.algebraic_field(s.sqrt(-s.Rational(1127,1000)), alias='h')
h = K.unit
v = [K.zero]*13
v[7] = coerce(K,s.Rational(100,161))*h
v[8] = -K.one
v[9] = coerce(K,s.Rational(10,7))*h
v[10] = K.one
p = L.lift(h,v,rho=0,domain=K)
assert p['all135_zero'] and not p['t']
```

`lift` は任意の normal 値について28選択行を正確に解く。
全135式を満たさない候補も入力可能であり、その場合は元残余を返す。
`all135_zero` を確認せずに Poisson 点と認定しない。
有理関数体 F=K.frac_field(s,k) では `h=F.convert(K.unit,K)` を使える。
`L.expression(value,F,s.Symbol('h'))` は根号に戻さず h を用いて表示する。

有限体への有理数の写像は、分子・分母を別々に写して体内で割る。
SymPy の `GF(32003).convert(Rational(1,2))` が0を返すことを今回の追加検査で認めたため、
この直接変換を使わない。元式の係数と入力有理数は `coerce` を通す。

## 3. 二つの例外での実際の点

1000h²+1127=0 の新軸で、v10=1、
v7=100h/161、v8=−1、v9=10h/7、他の normal と ρ を零にすると、
元 q の非零成分は

    q1=−1, q10=−100h/161, q12=1, q14=10/23,
    q17=100h/161, q20=10h/7, q21=−23/10, q25=−1,
    q36=1, q38=10h/7, q40=100h/161, q43=−1.

全135式が数体上で消え、t=0である。

h²+2=0 の旧平面では独立な u,v に対し v9=hu、v10=u、v12=v、
他の normal と ρ を零にすると、元 q は u,v にアフィン一次となる。
特に u=s²、v=s³k とした QQ(h)(s,k) 上の一般点で全135式が恒等零、t=0を確認した。
k に追加方程式を課していない。
二端点 (u,v)=(1,0),(0,1)、ρを保持する別の有理点、法32003の h=3083 でも検証した。

## 4. 軌道認識への具体的な簡約

新軸では c=10h/7 と置くと c²=−23/10。
元 Darboux 座標 x1,x2,x3,x4 から

    (X,Y,Z,W)=(x3−c x1, x4, x1, x2+c x4)

への変更は symplectic であり、実際の Q は

    Q=∂Y ∧ (−(10/23)XW∂Z + Z²∂W).

従って Q(G)=∂Y∧(G_W∂Z−G_Z∂W) の規約では

    G=−(5/23)XW²−Z³/3.

これは Z,W の symplectic 交換と非零対角変更・射影スカラーによって
既知の T6 正常形 XZ²+W³ に移る。Pfaffian と divergence は零である。
周囲消滅へは、この同じ入射族における横断上界との照合がなお必要であり、
ここでは座標認識と元式への復元を与えた。

旧平面にも同じ変更を c=h で使える。得られる Hamiltonian は

    G=−Z³/3+(h u/4)ZW²+(v/4)W³,  h²=−2.

12G の二元三次判別式は

    −432(2h u³+9v²).

従って非零の平面は、三根が異なる開層と非零二重根層に分かれ、三重根は u=v=0のみ。
重み chart u=s²,v=s³k では例外は k²=−2h/9である。
Hamiltonian は X³ を法としているので、G 単体の平面三次曲線の滑らかさを
Q の軌道不変量にしない。全135式の一次核・Sp4軌道・β像は別の計算で確認する。
