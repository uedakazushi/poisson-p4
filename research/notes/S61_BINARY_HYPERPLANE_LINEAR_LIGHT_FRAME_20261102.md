# 超平面 chart の一次 light frame

## 1. 結論と範囲

S61_BINARY_HYPERPLANE_WEIGHTED_CHART_20261102 の同じ
\(A=\mathbb Q[a,e,d,(aFBC)^{-1}]\) 上で、七つの light 横断変数の
線形写像を core 一次の多項式列へ取り替えられる。
旧表示の light 列の分子は core 三次であった。
この取り替えは同じ横断 scheme の正則な重み付き線形座標変換であり、
新しい core 因子を反転しない。
全点での長65、行加群の全射性、ambient 除去の追加主張ではない。

## 2. 証明書の直接検証

元135式の線形部分を \(J\)、旧 kernel/right inverse を \(T,U\) とする。
旧 normal 八列だけを \(T_{\rm old}\) と書く。
重み一の元座標は12個、元線形式の階数は四であり、
実在 binary 三次元部分を切る旧線形条件のうち一つも重み一である。
従って七つの light 方向は、これら五つの線形式の共通核である。

添付された小さい候補データは、元の12座標に値を取る七つの
core 一次多項式列を指定する。候補の発見には整数関係探索を用いたが、
証明はその探索手順に依存しない。
producer は元135式を再構成し、各列について \(Jv=0\) を
\(\mathbb Q[a,e,d]\) 上で直接検査する。

旧 heavy 列には既知単元 \(B/50\) を掛ける。
七つの新 light 列とこの heavy 列を、旧重み順序
\((1,1,1,1,1,2,1,1)\) に並べた行列を \(T_{\rm new}\) とする。
全成分は多項式であり、light 列の次数は一以下、
heavy 列の次数は三以下である。

旧定数 chart 基底 \(W\) の自由行射影を \(\pi\) と書く。
直接検査により

\[
 \pi T_{\rm old}=1_8,\qquad
 R=\pi T_{\rm new},\qquad
 T_{\rm old}R=T_{\rm new},
\]

および

\[
 \det R=51200000\,aB
\]

が成立する。\(R\) は重みを保ち、この determinant は \(A\) の単元である。
最後の等式は、新列が旧三つの切断条件も満たすことを同時に保証する。
light 部分だけの determinant は \(2560000000\,a\) である。
選択された七列の整数係数の絶対値は240以下である。

## 3. 全 implicit 模型の同一性

旧模型の自由座標を \(x\)、新模型を \(v\) として \(x=Rv\) と置く。
線形項は上の恒等式で一致する。
消去する座標の補正は旧 \(U\) をそのまま使用し、各次数で

\[
 z_r=-U[H(z_1+\cdots+z_{r-1},
                 z_1+\cdots+z_{r-1})]_{\mathrm{sel},r}
\]

と再帰的に定める。
従って次数に関する帰納法により、新しい全 implicit 解は
旧解への代入 \(x=Rv\) と一致する。
以前の重み付き一意性から解は通常四次で正確に止まるので、
これは全残余135式を含む多項式模型の同型である。
単なる接空間の同型だけを述べているのではない。

重み保存と \(R\) の可逆性から、各重みの関係空間の階数、
横断長、指定開上の全射性の問題は変わらない。
homogenizing variable \(t\) は元の解の一成分であり、
この座標変換で別の関数へ置き換えていない。

## 4. 再現性

候補データには七列の疎係数だけを保存する。
producer は元135式、旧自由射影、全 kernel 恒等式、
全行列等式、determinant、重みと次数を検査し、
候補・source・依存 report・本ノートの SHA256 を保存する。
巨大な raw jet cache や整数関係探索のログは証明の入力ではない。
