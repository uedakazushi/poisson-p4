# CA と CB の交叉の27次元成分と磁気族

2026年11月3日。副課題 L1 の26/27次元の選択を決定する。
以下の次元は PGL5 商を取る前の射影 Poisson スキームでの次元である。

**定理。** 既知の異なる28次元成分 CA,CB の交叉は、
既知の磁気族 M と区別された端点 Q を含む27次元既約成分 N を持つ。
従って交叉の Q における局所次元は正確に27であり、
26次元の M は交叉の既約成分ではない。
N が Q を通る唯一の交叉成分であるとは主張せず、交叉の scheme 構造や完成局所環も決定しない。

## 1. 二つの族を結ぶ有限射影変換

座標を (x0,x,y,z,w)、Euler 場を E とし、h(x0,x,z,w) を
x0,x だけの三次式を法とした任意の三次式とする。有効係数は16個である。
`X_h=−h_w∂z+h_z∂w`、`J=∂x∧∂y+∂z∧∂w` と置く。
追加の一変数 p に対して

    P_A=x0(x0+p x)∂x∧∂y+x0²∂z∧∂w+∂y∧X_h

を取る。これは既知 CA の普遍族のうち binary quadratic が x0 を因子に持つ部分であり、
全17変数で Poisson である。

射影変換を `x0'=x0+p x`、他の四座標は固定、とする。
新座標を再び (x0,x,y,z,w) と書き、`r=x0−p x`、`h'=h(r,x,z,w)` と置く。
このとき有限変換の全150係数について

    (x0↦x0+p x)_* P_A − E∧(p r ∂y)
       = r² J + ∂y∧(p r(z∂z+w∂w)+X_h')
       = P_B(f_B=r²,h')

が恒等的に成り立つ。最後の等号は `(f_B)_x=−2p r` による。
Euler-vertical 項は射影双ベクトルを変えない。
従ってこの17変数族の全ての点は CA∩CB に属する。
二つの退化因子の重複度条件が一致するというだけではなく、実際の双ベクトルの一致を与えている。

## 2. 像の次元

この族を PGL5 で動かした射影像の閉包を N とする。
源は既約なので N も既約である。
p=2、h の十六係数を保存した順で2,3,...,17とした有理点において、
次の列を全150係数で構成した。

- 全25個の線形座標変換の微分。
- 双ベクトル全体のスカラーの微分。
- p と h の全17変数の実際の微分。

Euler-vertical な24方向を定数行列で除くと、126行43列になる。
その28次小行列の行列式は32003を法として7514である。
分母は全てこの素数で可逆なので、標数零の affine cone の像次元は28以上、射影像は27以上である。
有限体の小行列は下界にだけ使っている。

一方、CA と CB は相異なる28次元の既約閉集合なので、
交叉は CA の真の閉部分集合であり、その全既約成分の次元は27以下である。
従って N の次元は正確に27で、N は交叉の既約成分となる。
既存の成分性・相異性の入力は `legacy/v06/ambient_families.tex` の Theorem AB である。

## 3. 磁気族全体と端点 Q

p=0 とすると上の族は

    P_A=x0²J+∂y∧X_h=P_B(x0²,h)

となり、h の十六係数を一つも制限しない。
これは既知の26次元磁気族 M の PGL5 飽和を定める全元の族である。
旧式で使う非零定数 μ=−2/9 と本式の μ=1 は固定した線形座標変換で同値である。
従って M⊂N である。

旧端点の座標を (t,u,v,w_old,z_old) とすると、

    (x0,x,y,z,w)=(t,u,z_old,v,−9w_old/2)

はその双ベクトルを、本式の p=0、

    h=(4/3)x0*x*w+(3/2)x0*z²+(9/2)x²*z

へ正確に移す。全150係数で一致を確認しており、Q は閉包の極限点というだけでなく
この実際の共通族の一員である。
従って Q∈M⊂N であり、局所次元は27以上、前節の上界から正確に27となる。
M は N の真の閉部分集合なので、M 自身は交叉の既約成分ではない。
