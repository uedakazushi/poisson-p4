# 実際の N 二次正規化の一変数 base pullback と全三次 graph 類

2026-11-03。二次 source 持上げは存在しないので、その持上げを仮定した
三次曲率比較は行わない。代わりに、実際の N の二次 cover 自体を R 曲線の
28個の base 座標へ引き戻す。本稿の計算は全次数3の二変数 (T,p) のみ。

## 1. 全物理 source と27変数の陰関数

N の実際の固定19空間 C2=0 を保つ。source は GL19 の行列
`I+Σg_i E_i` と、nilpotent kernel 行列 K の `exp(pK)`、固定8方向である。
固定 source の補償 `−p*C*co` を含める。逆座標代入と exterior pushforward
を、QQ の二変数係数配列で直接計算する。全150物理係数を保持する。

受理済みの27個の実際の標的座標について、固定27次逆行列を使い source の
27変数を次数1,2,3の順に解く。各段階の source 配列を保存し、最後に全27
座標が R 曲線と三次まで一致することを検査する。残る fold 座標の差は
`−3p²+48Tp+O3`。その全三次係数から、単位因子も含めて Weierstrass 二次
式を明示的に作り、元の fold 式との三次までの恒等式を検査する。

全150出力をこの二次式で割り、`a_j(T)+p*b_j(T)` とする。a は T³、b は
T²まで保存する。これは実際の二次正規化の base pullback であり、像環の
任意のイデアル basechange が正確だと仮定する手順ではない。

## 2. 三次 graph 制限の一意な公式

実際の N の最小標的37座標を、base28と物理座標
`[18,19,28,29,60,61,67,46,72]` の9個に取る。その奇係数 b_i は既受理の
全奇イデアルの最小生成元となる。任意の j について本来の base 上では
`b_j=Σh_ji*b_i` と書ける。定数 h0 は、既受理の正規化済み実際の N37
接空間の最後の9列そのものである。

R 曲線の実際の出力との差を `z_j=q_Rj−a_j` とする。二次計算から
`z_j,2=B*b_j,1`、raw monogenic p では `B=300/23` である。
`b_j−Σh0_ji*b_i` の二次係数 r_j を求めれば、未知の h の一次項が R 制限で
与える三次寄与は必ず B*r_j になる。従って、全体の多変数 h を求めなくても
実際の graph 方程式の三次制限は一意に

`(z_j−Σh0_ji*z_i)_3 − B*r_j`

と計算できる。非一意な h の一次項の差は b_i,1 と内積零であり、z_i,2 は
その同じベクトルの B 倍なので寄与しない。ここで使う h0 を個別の抽象的
な環の正規形から推測してはならない。

Weierstrass 式が `p²−(16T+B2*T²)p−A3*T³` の規約では、trace 中心は
`8T+B2*T²/2`。trace 零の変数では平均の二次係数が `116/23` となる。
コードは a の trace shift も実行し、raw p と trace 零の上の三次公式が
全150係数で一致することを別に確認する。
