# 超平面二枠の共通欠落曲線は一般一次ジェット上に現れない

2026-11-02。ここで扱うのは既存の正規化された H8 source だけであり、
全 K=0 層の正規化や全 S61 の尽くしではない。
core を (a,e,d)、nuisance を (p,q,r,h,k) として

    u4=a, u14=(e+1)/5, u35=1, u36=d, u49=e, u50=-5,
    (u25,u26,u27,u37,u48)=(p,q,r,h,k), 他の一次座標=0

と置く。全 nuisance を保持する。

## 1. 二つの core 開集合の補集合

従来の重み付き枠は aFBC≠0、新しい BFREE_FRAME は aF D0 C≠0 で定義される。
いずれもこの段階では nuisance 零の横断模型である。
F,B,C は既存と同じ多項式、D0=50a+9e²+3e−6 とする。
aFC≠0 上で両者の core 開集合から同時に漏れるのは B=D0=0 だけである。

S=3e−2 と書くと D0=0 は a=−3S(e+1)/50 を与え、この代入後に

    C=−5S,  F=9(2−S),  B=S(Sd+20)

が正確に成り立つ。C≠0 より S≠0 なので、共通欠落 locus は

    a=−3S(e+1)/50,  d=−20/S

という一つの有理 core 曲線である。これに nuisance 五変数を加えた六次元 source を H6 と書く。

## 2. 全群作用を含む像の次元

既検証の primitive Sp4 infinitesimal action を A(β)（16×10）とし、
上の H6 の一次ジェット写像を b(e,p,q,r,h,k) とする。
Sp4×H6→W16 の単位元での微分は

    M=[ A(b) | db/d(e,p,q,r,h,k) ]

である。最後の五列は nuisance 五座標における単位ベクトルなので、
対応する五行・五列を消すと 11×11 行列になる。
全分母を 50S² で払った行列を報告に保存し、
QQ[e,p,q,r,h,k] 上で determinant が恒等零であることを検査した。
これは有限個の標本における階数低下ではない。

(e,p,q,r,h,k)=(2,1,2,3,4,5) では 15×15 minor が QQ 上で非零となる。
したがって微分の一般階数は正確に15であり、恒等的に16未満である。
群作用の同変性により同じ上界が任意の Sp4 点で成り立つ。
標数零の像の次元定理から、Sp4×H6 の W16 における像の閉包は15次元である。
特にこれは16次元一次ジェット空間の真閉集合である。

従って十分一般の β では、全 nuisance と全 Sp4 作用を許しても
この共通欠落 core 曲線上の source 点は存在しない。
ここでは群安定化次元を source 次元から推測して差し引かず、全微分を直接使用した。

## 3. 得られる被覆と制限

aFC≠0 にある指定 H8 source の一般 β 上の点については、
その core は旧 B≠0 開または新 D0≠0 開に入る。
これは nuisance 零で高次障害を計算するための二つの正則枠の core 被覆である。
全 nuisance の相対局所環にそれらの枠や冪零性が延びることは、別途証明を要する。

共通欠落曲線を除くためには、その局所 Artin 長の上界や t の冪零性は必要ない。
本結果は四次関係の全射性、長65、他の core 因子、他の binary 層、
全 S61 の飽和支持の除去を追加主張しない。

対応 producer は旧新枠と作用行列の入力ハッシュを再確認し、
四つの曲線恒等式、全多項式 determinant、非零15次 minor を再現する。
出力先は --output で指定し、既存報告を上書きしない。
