# 真正 bar nil の三次積は m⁴Tnil に入る

実十四 cycle の origin は、43 番目の gA odd 座標にだけ非零となり得る。他の Qrad lift 36 座標と zero7 odd 座標の origin は零である。Qrad の native C 最大 ideal order は全 36 列で少なくとも 2、trace の nuA,nuB の origin は零である。従って Qrad の R0-even 成分には定数がなく、各 nil representative y=b0+B tauA は b0,B∈m² を満たす。これは bar-cycle に関する statement で、一般の任意 Tnil class に対するものではない。

ここで honest Koszul homotopy の精度落ちは **高々一** である。sequence は (z0,…,z6,r^n), n=1 または 2 であるが、homotopy は r^n で割らない。cycle identity より v7(0,r)=0 とし、v7 を ordered Hadamard で z_i によって割る。各結果は m^{d−1} に入る。残り wi=vi+r^nHi の order は下がらず、partial_z と正の整数 Euler 逆によっても失う ordinary order は高々一である。係数関数全体にこの operator を適用し、S-linear と誤認して係数を引き出さない。

従って cube の actual honest128 representative (c,H(mc)) は m⁴ に入る。all-order の unit Schur projection は正則なので、actual Tnil class も m⁴Tnil に入る。既証の Loewy 関数 (5,5,3,2,1) よりこれは一次元で、m⁵Tnil=0 である。単なる ambient jet から homology の membership を推論したのではなく、実際の complete presentation における代表と homotopy を構成して order を追っている。
