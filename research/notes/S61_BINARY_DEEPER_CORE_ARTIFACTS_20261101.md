# 深部二平面型：二次 minor に現れる八つの core 因子の除去

2026-11-01。対象は全135式の共通次数二の未飽和斉次化である。
**十分一般の一次部分β上で、下記八因子にある点を全て t-飽和で除く。**
共通 core 開の四次 minor に現れ得る別の未知因子は、この結果に含めない。

## 1. 八つの因子と計算の範囲

QQ上既約な十三因子がある。そのうち五因子は以前に除去済みであり、本結果は残る八因子を扱う。
長い多項式も含めた正確な定義は同報告の `factor_nondivisibility_witnesses` に固定されている。
新報告はその全文を各 case に再掲する。順序を保った一覧は次の通り。

最初の二因子は `11e+12` と `201e³−60438e²−80264e+2432` である。
十三因子のQQ既約性には、既存の独立再計算 `S61_BINARY_DEEPER_UNIFORM_QUADRATIC_REVIEW_20261101`
を依存として用いる。QQ既約性を幾何的既約性と取り違えない。幾何的に分裂する場合は§6で扱う。

五つの nuisance 座標を `(p,q,r,h,k)=(5,7,11,13,17)` とする。
各因子 f の上の六次元 source を

    H_f = { f(e,d)=0 } × A5_(p,q,r,h,k)

とする。八点とも f の勾配は非零、七変数切断の分母と線形消去の分母は可逆である。
元135式を再構成した有限体計算により、全ての点で次を確認した。

- Q0=xw∂y∧∂z における全線形階数33。
- 実際の binary 三方向を切った九変数で、二次階数24、三次までの初期階数131。
- 追跡した真の四次初期条件の495次 minor が非零。
- 同じ P² fiber の Q1=(xw+x²+w²)∂y∧∂z における leading/full 階数34/35、
  二次障害階数5、Hessian階数7。
- 実際の平面曲線の微分階数2、binary 三パラメータへの射影 minor が非零。
- `Sp4×H_f→W16` の微分階数16。

各階数の選択行・列と非零 minor、raw quadratic/cubic 行列の hashを新報告に保存する。
この計算は有限体格子の観察とは別であり、八つの指定された滑らかな点に対する証明書である。

## 2. 四次条件が実際の初期式であること

元135式を指定点の周りで `Jz+H(z,z)` と書き、線形消去33方向を実際に解く。
保存された有理行列 T,U は、元 J に対する kernel/right-inverse 恒等式を満たす。
新コードも各有限体点で `JT=0` と right-inverse の単位行列を検算する。
実際の binary 三方向を切った残る九変数について、二次・三次 implicit jet を再構成する。

二次係数行列と三次尾の連結行列に同じ行操作を施す。二次独立24行の三次尾を F3、
二次を消した残りの実際の三次先頭を G3 とする。
二次先頭24行の一次倍216行には階数129、従って87本の一次 syzygy がある。
各 syzygy に対して、対応する F3 の一次倍を同じ行操作で追跡する。
これが真の四次初期条件である。四次尾 A4 を無視してよい理由は、
この操作で A4 は一次式を掛けられて次数五以上に入るためである。
G3 の一次倍も真の四次条件となる。

二次式の二次倍、G3の一次倍、上記87行の四次条件を合わせた行列は階数495、
すなわち九変数の全四次単項式を張る。
有限体上の**実際の完成横断環**では m⁴/m⁵=0、完備版 Nakayama により m⁴=0となる。
二次・三次の初期階数から、その長さは

    1+9+(45−24)+(165−131)=65

以下である。raw A4 が零だとは主張していないし、有限体の syzygy をそのままQQへ移してもいない。

## 3. Hensel持上げと標数零の横断上界

各点で f の勾配が非零なので、勾配が可逆な core 座標をHensel持上げする。
他方の core 座標と nuisance 五座標は指定された整数に固定する。
これにより f=0を満たすZ_32003上の点が得られる。持ち上げた座標はQQ上の多項式の根なので、
選ばれた32003進埋込みを持つ代数的数である。
線形・実在族パラメータ minor と、§1の一次像 minorは全て32003進単位のままである。

元135式と実際のimplicit消去はこのDVR上で定義される。
九変数横断環の特殊fiberは§2により長さ65以下であり、位相的Nakayamaにより、
積分的な完備横断環はZ_32003上高々65元で生成される有限加群となる。
そのQ_32003一般fiberの全長は65以下であり、指定された原点での完成局所因子の長さも65以下。
従って持ち上げた**標数零の実際の横断環**には同じ上界65がある。
これは各有限体初期syzygyのQQへの個別liftを必要としないgood-reduction論法である。
有限体の無関係な点での階数から標数零の全例外集合を推測する議論ではない。

## 4. 同じ相対 binary C3 の一般下界

`S61_BINARY_DEEPER_CORE_OPEN_FORMAL_20261101` が元135最高式で確認した普遍P²族

    Q(H,K)=(xw+Hx²+Kw²)∂y∧∂z

を、各 H_f に制限する。Q0=Q(0,0) と Q1=Q(1,1) は同じ非平方開部分にある。
平面曲線の微分は

    [ 2, −(6e+1)/5, 3(1−2e)(15e+8)/500 ]
    [ d,             4,                 (3e−2)/5 ]

で、実際の三つのbinaryパラメータへの minor は `2(24e−7)/125`。
八つの点でこれらが可逆なので、H_f 上の実際の binary 部分 C_rel は各section点で相対smooth3である。
選んだ幾何成分上でsectionを含む既約成分を固定する。
その中の同じP² fiberが Q1 に至るため、別の無限遠枝から下界を流用していない。

Q1 の非零35次minorと二次5次minorは持上げ後も非零である。
既存の普遍 binary 階数上界35および普遍二次上界5と合わせ、標数零で等号になる。
実在 C の滑らかな三方向は、一定階数領域では二次障害のHessian radicalに含まれる。
保存したHessianの7次minorにより、radicalは正確にこの三方向である。
従って既存の普遍三次下界 `S61_BINARY_UNIFORM_CUBIC_20261101` を適用でき、
この**同じ既約 C_rel の一般点**における局所長さは65以上となる。
一般法線Hilbert関数の下界は(1,7,23,34)、tの一次・二次法線類は零である。

## 5. 相対自由65とambientへの降下

持ち上げた点で R を実際の C_rel の完成局所環とすると、

    R ≅ Q_32003[[b1,...,b6,u1,u2,u3]]

である。必要なら代数的閉包への拡大を行っても以下は変わらない。
全相対135式の完成局所環を S とし、実際の C_rel への制限を用いて `R→S→R` を分裂させる。
§3の横断上界から全射 R⁶⁵→S がある。
§4の同じ成分の一般局所因子の下界65が、Rの一般点でこの全射の階数を使い切る。
従って核は階数零の自由加群の部分加群であり零、SはR上自由階数65となる。

I=ker(S→R) とすると、一般点で下界のHilbert関数が長さ全体を使い切り、
I⁴=0、t∈I³、It=t²=0が成立する。SのR-torsion-freenessにより、これらは完成環全体へ降りる。

`Sp4×H_f→W16` の16次minorは§1で可逆である。
全135式の同次数斉次化の同変性により、このsource上のfull相対schemeはambient schemeの
smooth（ここでは同次元なのでétale）base changeである。tは可逆因子倍で対応する。
忠実平坦性と完成化の忠実平坦性により、ambient局所環でもt²=0となる。
従ってambientのQQ定義の飽和除去開が、この core 因子の像と非空に交わる。

## 6. 幾何的共役成分と全一般β上の除去

fはQQ上既約であり、`Sp4×H_f` の像のQQ閉包 Z_f はQQ上既約である。
一次像minorが非零なのでdim Z_f=16である。
QQ上既約なfが幾何的に分裂する場合、その有限個の幾何的成分はGalois作用で推移的に移る。
§5で得た除去開はQQ定義だから、一つの幾何的成分と非空に交われば、全ての共役成分と
非空に交わる。その像 Z_f の幾何的成分についても同じことが成り立つ。

従って Z_f 内の除去開の補集合は、各幾何的成分上で次元15以下である。
βへの像の閉包も次元15以下なので、十分一般のβはそれらを全て避ける。
これで八因子それぞれの**全一般βファイバー**がt-飽和から除かれる。
以前の五因子の除去と合わせ、選ばれた二次24次minorの十三因子は全て処理済みとなる。

八因子上の全特殊点でt²=0であるとは主張しない。
共通core開の四次minorに残る未知因子、旗の未処理部分、全アフィン尽くしは別問題である。
