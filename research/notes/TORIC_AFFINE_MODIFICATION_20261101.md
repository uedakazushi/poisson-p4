# T01 の大域的な被約定義：正規三次被覆の affine modification

日付: 2026-11-01. 基礎体は \(\mathbb C\)。このノートは既知成分 \(T01\) の
被約閉包そのものを記述する。全 \(S_{61}\) の他の解の排除や、全成分の尽くしを
主張しない。

## 1. 入力と多項式根座標の独立点検

\(R=\mathbb C[W_{16}]\)、\(B=\mathbb C[T01]\) とする。以下を用いる。

- 標準曲線の不変量 \(c_4,c_6\)、次数8、12。
- 次数5、9の全域多項式共変量 \(U=C_5,V=C_9\)。後者の多項式性は
  `TORIC_C9_POLYNOMIAL_20261101` の余次元2延長論証による。
- 全結合則解上の \(q=\bar q+N(\beta)c\)。\(\bar q\) の次数は2、\(N\) は1。
- `TORIC_POLYNOMIAL_E2_COORDINATE_20261101` の重み4多項式
  \[
  P(\beta,q)=\lambda(\beta)(q-\bar q),
  \qquad\deg\lambda=2.
  \]
  これは一般 \(T01\) 上で三次根座標 \(X\) に一致する。

最後の主張について、実装と証明を独立に点検した。
二次2形式の対称係数を、対角・非対角を一様に「2階微分の半分」として計算し、
256組の全順序付き添字を使った縮約を作り直した。
圧縮された60次計量行列の係数や多項係数を再使用せず、全45個の
\(\lambda_i(\beta)\) が一致した。さらに支配的6変数断面上で残余行と
\(U,V\) の両縮約が零であることを再検証した。
コードは `code/toric_polynomial_e2_review_20261101.py`、証明書は
`reports/TORIC_POLYNOMIAL_E2_REVIEW_20261101.json`。

群作用による拡張の論理も妥当である。ただし、行消去で得た \(N\) の各係数が
結合則から独立な全 \(c\) 空間で単独に同変であるとは仮定しない。
必要なのはトーリック解上の実際の二次部分の差と、その完全テンソル縮約の自然性である。
断面上の三次代数全体での一致を \(\operatorname{Sp}_4\) により移し、支配性で
一般被覆全体へ延長する。その後、\(T01\) の既約被約性から

\[
P^3-27c_4P-54c_6=0\quad\text{in }B
\tag{1.1}
\]

が大域的に成立する。非被約な全 \(S_{61}\) 環に (1.1) を追加してよいという
意味ではない。

## 2. 滑らかな標準曲線の上では実際の成分も正規三次被覆と一致

\[
\widehat\Delta=c_4^3-c_6^2=1728\Delta,\quad
f=X^3-27c_4X-54c_6,\quad A=R[X]/(f)
\]

と置く。\(A\) は正規な整域で、\(\operatorname{Frac}A=\operatorname{Frac}B\)。
今回の多項式 \(P\in B\) によって、\(X\mapsto P\) は単射

\[
A\hookrightarrow B
\tag{2.1}
\]

を与える。単射性は一般関数体の既存の同型から従う。

一方、\(\widehat\Delta\ne0\) では \(f'(X)\) が単元であり、

\[
q=\bar q+N\frac{UX+V}{f'(X)}
\]

から \(B[\widehat\Delta^{-1}]\subset A[\widehat\Delta^{-1}]\)。
(2.1) と合わせて

\[
\boxed{B[\widehat\Delta^{-1}]=A[\widehat\Delta^{-1}].}
\tag{2.2}
\]

従って実際の \(T01\to W_{16}\) は \(\Delta\ne0\) 上で有限 étale な次数3の射であり、
\(\operatorname{Jac}(C_\beta)[2]\setminus\{0\}\) と一致する。
この開部分の被約 \(T01\) は滑らかである。
事前に \(B\) の正規性・平坦性・特殊ファイバーの被約性を仮定していない。

## 3. 全域の affine modification

\(A\) の中で

\[
G=c_4X^2-3c_6X-18c_4^2,\qquad
\frac1{f'(X)}=\frac{G}{486\widehat\Delta}
\]

である。各 \(i=1,\ldots,45\) に対し

\[
F_i=\frac1{486}\,N_i(\beta)(UX+V)G\in A
\tag{3.1}
\]

と定義する。\(F_i\) は重み26の元であり、\(X\) の次数を2以下にして保存できる。
具体的には

\[
(UX+V)G\equiv
(c_4V-3c_6U)X^2+(9c_4^2U-3c_6V)X
 +54c_4c_6U-18c_4^2V\pmod f.
\tag{3.2}
\]

共通関数体の中で \(q_i=\bar q_i+F_i/\widehat\Delta\) なので、
\(B=R[q_1,\ldots,q_{45}]\) と (2.1) から

\[
\boxed{B=A[F_1/\widehat\Delta,\ldots,F_{45}/\widehat\Delta]
       \subset A[\widehat\Delta^{-1}].}
\tag{3.3}
\]

従って \(T01\) は、正規三次被覆 \(Y=\operatorname{Spec}A\) のイデアル

\[
I=(\widehat\Delta,F_1,\ldots,F_{45})\subset A
\]

に沿う blow-up の \(\widehat\Delta\) チャート
\(\operatorname{Spec}A[I/\widehat\Delta]\) である。
これがここでいう *affine modification* の意味である。
全 blow-up そのものや、\(T01\) の正規化だという主張ではない。
\(T01\to Y\) はアフィン双有理射で、判別式の外では同型である。

この記述は、零一次部分にある8次元の欠落軌道と両立する。
その軌道では \(\beta=0\) かつ \(P(\beta,q)=0\) なので、\(Y\) の原点へ写る。
一方で \(q\ne0\) である。modification の全例外集合や中心イデアルの幾何までは
ここでは分類していない。

## 4. 被約素イデアルの飽和による厳密なレシピ

(3.1) の元の多項式代表を選び、\(R[X,q_1,\ldots,q_{45}]\) のイデアル

\[
\boxed{
J=\bigl(f,\
\widehat\Delta(q_i-\bar q_i)-F_i\ (1\leq i\leq45)\bigr)
:\widehat\Delta^\infty
}
\tag{4.1}
\]

を取る。判別式を可逆化すれば各 \(q_i\) は一意に消去され、商は
\(A[\widehat\Delta^{-1}]\) という整域になる。
従って (4.1) はその素イデアルの収縮であり、素イデアルである。
その商は正確に (3.3) の部分環である。

さらに \(X-P(\beta,q)\) はこの素イデアルに属する。
実際、それは判別式の外の一般同型で零になり、飽和による収縮で全域にも属する。
従って \(X\) を忘れる射影は、(4.1) の閉部分スキームから既存の
\(T01\subset S_{61}\) の被約閉包への同型であり、

\[
I(T01)=J\cap R[q_1,\ldots,q_{45}]
\]

はその大域的な被約定義イデアルである。
ここでは飽和を未実行の推測として挙げたのではなく、関数体内の明示的な部分環と
閉包の等号によって (4.1) の正しさを証明している。
巨大な全16変数展開や Gröbner 基底を保存したという主張はしていない。
\(C_9\) は全域多項式として一意な線形系の解であり、その有限な定義を用いる
厳密なレシピである。

この結果で大域的に定義されたのは既知の一成分 \(T01\) である。
全 \(S_{61}\) の素イデアル分解、一般ファイバーの五点による尽くし、判別式上の
全特殊ファイバーや modification 中心の既約分解は別の未解決問題として残る。
