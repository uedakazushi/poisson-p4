# 実際のT01の零一次ジェットファイバーは原点を含め被約である

複素数体上で、被約なトーリック成分 T01 を S61 内に取る。その構造層を一次ジェットの16座標で割ったスキームは、十次元の被約ABと一致する。特に原点や AB の特異点にも埋め込まれた冪零構造はない。

## 重み付き座標

原点での値を標準Poisson行列 J とし、透視変換で一次部分 L を primitive にそろえる。透視パラメータは元の一次ジェットの線形式である。中心化したアフィン双ベクトルの斉次二次部分を Q とする。60係数の全空間で、Q を J で二形式 α に移し、Euler場 E による射影 dι_E(α)/4 を施して元に戻す。Cartanの式により閉二形式上で恒等であり、Sp4 と可換である。

元の S61 で一次部分を零としたとき、45個の実 q 座標を60係数に写す線形写像を C とする。これは全閉二次部分への同型である。上の射影後に C の逆を施した座標を q' と呼ぶ。全座標として L の独立な16係数と q' を選べる。実際、重みを一次部分に1、q に2とすると、アフィン場の一次・二次係数はそれぞれこの重み1・2の多項式である。透視変換 y=x/(1+a·x) のパラメータ a の重みは1で、斉次二次係数の変化は一次部分と a の二次式である。従って q' は元の q に一次部分の二次式を足した形で、一次部分を零に戻せば元の45座標そのものである。これは逆変換も多項式である三角座標変換を与える。producerで C・射影・四つの単純根作用の可換性を有理数で検証する。

## 274本の恒等式

重み4の単項式は L の四次、L の二次と q' の積、q' の二次に分かれる。既知の274本の AB 二次式を最後の空間で表す。二つの単純根作用の共通核を取り、トーラス重み (0,0),(1,1),(2,0),(2,2),(3,1),(3,3),(4,0) でそれぞれ 2,3,1,3,3,1,2 本の代表を得る。最初の二種類の単項式の同じ最高重み空間で、中心化 coframe の26標本を使って補正項を選ぶ。報告には得られた15本の有理係数を保存した。

これらに逆向きの単純根作用を反復し、q' の二次部分で独立な274本を選ぶ。良い素数32003は候補を選ぶ段階で使う。得られた空間を U とし、以下を改めて QQ で検査した。

1. 一次部分を零にした U の像が、既知の AB 二次関係274次元空間に等しい。
2. 274本それぞれに正負四つの単純根作用を施す。非零の814像では、q' の二次部分から係数を解き、一次部分を含む全係数で U 内の線形結合に一致する。残る282像は零である。従って U は四つの根冪零作用、その指数である根部分群、ひいては Sp4 で安定である。
3. U の全274本の coframe 制限が、以下の六変数で全係数零となる。

稠密な coframe の代表を
<pre>
      1 0 0 0
      0 a 0 0
 R₀ = b c 1 0
      d e 0 f
</pre>
と置く。J の上三角の非零標準成分が12,34にある規約で、R₀ J R₀ᵗ の六成分は (a,c,e,−ab,−ad,be−cd+f) である。従って非退化な交代行列の12成分が非零となる開を覆う。同じ交代行列を与える任意の可逆 R は R₀g, g∈Sp4 と表せる。

中心化 coframe で z=Ry、D=diag(1+zᵢ−Σz/5) とすると、Poisson 場は FJFᵗ、F=R⁻¹(I−z1ᵗ/5)DR である。producerはその一次・二次係数を展開し、変数の重みに従って L を 10 det R 倍、q' をその平方倍して分母を払う。従って重み4の恒等式の零性は変わらない。R₀ の上で274式の全六変数係数を整数演算で集計した。指数の圧縮では各変数の次数が基数32に達しないことを各入力で確認した。U が Sp4 不変で coframe 写像が右作用について同変であるため、274式は全GL4の稠密開、従ってその被約像閉包である実際の T01 上で消える。

## スキームの等号

実際の零ファイバーのイデアルを J₀ とする。274本の持ち上げを特殊化するとすべての AB 二次関係を得る。AB の素イデアルはその274本で全次数にわたって生成されるので I_AB⊂J₀。先行する被約台の同定から J₀⊂√J₀=I_AB である。両包含は原点での局所化や飽和を必要としない。従って J₀=I_AB。この結果により既知のABの正規性、有理特異点、Hilbert級数も実零ファイバーに適用される。
