# ZERO12 七次初期部分の独立レビュー

2026-11-01。`S61_FLAG_ZERO12_SEVENTH_INITIAL_20261101` の証明と producer、
`projected_next_initial_replay_20261101.cpp` を監査した。
指定点における真の初期部分の次数7までの主張を受理する。

## 射影と閉包の論理

既証明の64初期生成元を生成する同次イデアルを J とする。
その次数7部分 J7 は、元の形式関係の lift を適切な単項式倍すれば、
m8 を法とした実際のイデアルに含まれる。従って次数7だけを J7 で割る操作は、
未知の関係を仮に加える操作ではない。次数6以下の係数は変更しない。

native replay は各行を元135行または既に再生された行の一次倍から構成し、
現在の QQ 係数に従って先頭から消去する。有限体で零だった係数も飛ばさない。
各行の最初の非零列が予定の pivot に一致する検査があるため、
有限体の pivot 順を選択に用いることが QQ 上の独立性を仮定することにはならない。

再生した3858行の張る空間は実際の射影後イデアルに含まれる。
元135行と全3858行の九変数倍、計34857件の還元が全て零なら、逆の包含も成り立つ。
最高次部分の変数倍は m8 で零、次数6の変数倍だけは保存された J7 射影を通す。
従ってこの閉包検査は有限切断環における完全なイデアル検査である。

## 独立計算と依存範囲

レビューコードは主 producer の module 射影を使わず、保存64式を
QQ[v0,…,v8] の通常のイデアルとして作り、Macaulay2 で独立に Gröbner 基底を計算する。
次数0–7の Hilbert 関数

    (1,9,37,98,202,329,471,618)

を確認した。m8 商の長さ1765、七次関係階数5817、全切断階数9675、
閉包検査件数の算術も独立に一致した。主証明書およびその入力ハッシュを照合する。

元135式からの七次 implicit jet と3858行の QQ replay 全体は、
別実装では再計算していない。その部分はソースと証明手順の監査、および
主 producer の完全閉包証明書への依存である。

七次に新しい初期方向がないことから、全初期イデアルの等号や t の冪零性は導かない。
この区別を主 note と report が明示していることを確認した。
