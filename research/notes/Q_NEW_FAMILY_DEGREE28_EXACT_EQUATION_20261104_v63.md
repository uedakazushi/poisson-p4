# NEW25の28次定義式：有理数上の全係数証明

このノートは既存の108本の28次不変式の中に実際の恒等式があるかを、有理数上で決定する有限計算である。新しい点、素数、次数、係数フィッティングは用いない。

## 不変式の定義

W16は元の原始Sp4表現、Omegaは保存された交代形式とする。C,Dは独立検証された二つの二次随伴共変量、mu^t=-C+2D、theta=rho16(mu) とする。

F=trace(mu²)、H16=Omega^-1 Hess_beta(F/2) と置く。p_iは det(tC+zD) の t^(4-i)z^i 係数で、F²=400p0+1600p4である。さらに

```
Q0=trace(C D² C D²)-trace(D²)*trace(C² D²)/2+det(D)*trace(C²)
Q1=trace(C³ D C D),  Q2=trace(C³ D³),  Q3=trace(theta⁵ H16)
T=trace(theta⁷ H16)
A0={trace(C⁴),trace(C³D)}_Omega
A1={trace(C⁴),trace(C²D²)}_Omega
A2={trace(C³D),trace(C²D²)}_Omega
```

とする。Poisson bracketは元16変数の勾配をOmega^-1で縮約したもので、四つの切片座標の微分ではない。F,p_i,Q_i,T,A_iの次数は順に4,8,12,16,14である。明示的な28次多項式は `equation.txt` と疎係数表 `equation.json` に保存する。

実際に得られた式にはA0,A1,A2は現れない。10個の低不変式だけで

```
G28 = -80000 F(F²-120p1-80p2) T
      + R75(F,p1,p2,p3,p4,Q0,Q1,Q2,Q3)
```

という78項の整数多項式になる。R75の全75項は `equation-linear-T.json` に、全78項は `equation.txt` に省略なしで保存している。整数係数のgcdは1、最大係数のビット数は52である。Tの係数は低次数の非零不変式の積なので、先行する低次単射により一般のNEW像上で非零である。従ってこの式は、その開集合でTの有理回収式にもなる。ただし全不変式環の生成や全域の有限性を意味しない。

## 恒等式の証明書

完全な普遍28次基底108本は、同じ形式2平面上の非零108角係数小行列と文字次元108により独立受理されている。新しい密なv=0切片に対する全108本の正確なQQ係数も保存されている。そのGF(32003)階数107は候補を絞るためだけに使う。

保存された107係数行と107個のpivot列をQQ上で解き、残りの一列を自由係数としたベクトルを得る。共通分母を払い整数成分のgcdを除く。native FLINTは選択した全107方程式を再確認し、その後、全108本の多項式の線形結合がQQ上の零多項式であることを検証する。別のPython Fraction加算も元の全係数を漏れなく加算して零を確認する。これは有限体の欠損からQQ関係を推測する手順ではない。

一回の実行は準備・コンパイルを含め4.600秒、native演算0.060秒で完了した。全96,453項を合計した1,091個の異なる源単項式の係数は、QQ上ですべて零だった。選択した107方程式の正確な有理係数行列・右辺・解と、108成分の原始整数核を保存している。証明書は約0.9MBである。源の108列は独立レビューも完了しており、本QQ恒等式の独立監査は別に行う。

## 定義式への適用

普遍108本がQQ上で独立なので、得られた非零係数ベクトルはW16上の非零不変式である。密な切片上の全係数恒等式により、実際のNEW原始像B15の全体で消える。B15は既に示された既約な次数付き超曲面である。Sp4は連結半単純なので、その既約定義式は不変式になる。先行する独立監査済みの次数下界28と、今回の非零28次式を合わせると、その式は既約定義式の非零定数倍であり、定義式の次数は正確に28である。

最後の適用には源の108列と本恒等式の独立監査を要する。独立レビューの完了状態は別のレビュー成果物で管理する。これは他の成分の式、全不変式環の生成、像の正規性や有限性を主張しない。
