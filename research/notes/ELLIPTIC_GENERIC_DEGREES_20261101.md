# 楕円二成分の一般次数はともに一

2026-11-01。対象は既知の二成分 T39=q(5,1)、T40=q(5,2) から、
primitive な一次部分 W16 への射影である。

**結論：両射影の一般次数は一。** したがって両成分は W16 に双有理である。
五変数パラメータ模型の一般長さは、それぞれ3000である。
既知三成分の一般延長数は T01 の三点と T39,T40 の各一点を合わせて五点になる。
全S61の一般ファイバーがこの五点で尽くされる、有限である、という主張ではない。

証明は、q(5,2) の一次部分からの一意復元と、二族の一次部分のパラメータ被覆を結ぶ
双有理写像からなる。特殊ファイバーの解数や数値ホモトピーから次数を推測しない。

## 1. q(5,2) の定数五次元空間

原族のアフィン双ベクトルを Pλ(z)、Fλ=Pf(Pλ)、
Ωλ=−Pλ⁻¹、Nλ=FλΩλ とする。p=(p1,…,p4) に対し

    A_p=[−p | I4] : C5 -> C4

は [1:p] における商空間を指定したアフィン接空間へ移す写像である。
次の五次元空間 Kλ⊂Λ²C5 を考える。

    Φλ(r)=
    [ 0        r3/λ     λr4       −λr0      −r1/λ ]
    [ −r3/λ    0        r0         r1       −λr2  ]
    [ −λr4    −r0       0          r2        r3   ]
    [ λr0     −r1      −r2         0         r4   ]
    [ r1/λ     λr2     −r3        −r4        0    ].

全 λ≠0 と全 p で

    <Nλ(p), A_p Φλ(r) A_pᵀ> = 0                 (1)

が恒等的に成立する。対は上三角の六成分の縮約である。
この恒等式は q(5,2) の明示係数から直接検証する。
十個の定数 bivector 係数から得られる35×10係数行列の核は正確に五次元であり、
上の五つの基底がその核をなす。独立実装は対応する証明書に保存されている。

p=0 では空間部分の成分 (12),(13),(23),(24),(34) はそれぞれ r0,…,r4。
従って Kλ の空間部分への射影は単射であり、これは基点を動かしても非空開条件である。
その像は (1) によって Ωλ(p)-primitive な bivector の五次元空間に一致する。
この性質は射影座標変換と非零スカラー倍に不変である。

## 2. 正規化後の K は一次部分だけで決まる

全双ベクトルを実際に perspective まで正規化し、P(0)=J、一次部分を primitive とする。
この座標で Ω=−P⁻¹ は Ω(0)=J を満たし、

    β_a = −∂_a Ω(0)

が既存の primitive 一次二形式である。接空間を U とし、同次空間を U⊕Ce0 の順に書く。
前節の K の元は、五次元 primitive 空間を動く Z を用いて一意に

    Φ = [ Z   w ]
        [−wᵀ  0 ]

と書ける。y における射影後の bivector は

    Z_y=Z+ywᵀ−wyᵀ.

Ω(y) と Z_y の縮約は恒等的に零である。原点で y_a について微分すると

    −ell_β(Z)_a + (Jw)_a = 0,
    ell_β(Z)_a = Σ_{i<j} β_{aij} Z_ij.

従って

    w = −J ell_β(Z).                             (2)

つまり、同じ primitive 一次部分 β を持つ正規化済み q(5,2) 双ベクトルは、
固定座標の中で全く同じ五次元グラフ空間 K を持つ。
ここでは一次部分だけを形式的に正規化したのではなく、全双ベクトルへの実際の
projective perspective 変換を先に行っている。

一般 y で射影 K の次元は五だから、その annihilator は二形式の一次元空間である。
従って二つの該当双ベクトル P,P′ の逆二形式 Ω,Ω′ は Ω′=fΩ と比例する。
Poisson 条件により dΩ=dΩ′=0 なので df∧Ω=0。
四次元で Ω が非退化なとき、一形式 η↦η∧Ω は同型だから df=0 である。
よって f は定数であり、原点の正規化 Ω′(0)=Ω(0)=J によって f=1。
従って P=P′。

この議論は q(5,2) 成分の非空開集合での一意性を証明する。
既証明の優越性・一般有限性、標数零を合わせると、一般関数体次数は

    d_T40=1.                                    (3)

独立監査は `ELLIPTIC_Q52_RECONSTRUCTION_REVIEW_20261101.md` にある。
この一意性は全S61の未知成分を排除するものではない。

## 3. 二族を結ぶ二次Cremona写像

添字を mod5 とし、同次二次式

    Q_i(x)=x_i²+λ x_{i−1}x_{i+1}−λ⁻¹x_{i−2}x_{i+2}

を置く。一般 λ と基点 p で、この写像を fλ:P4-->P4 と書く。
明示的な三次逆写像 R を `HESSE_QUADRO_CUBIC_INVERSE_20261101.json` に保存した。
同証明書は R(Q(x))=g5(x)x、Q(R(y))=h5(y)y を全係数で確認し、
g5(e0)=λ²、h5(e0)=λ⁴≠0 により双有理性を証明する。
したがって、λ≠0 と適切な分母の非消失を要求した稠密開集合では、全ての点が一対一に対応する。

採用した二族のスカラー規約では

    fλ* P1 = −P2,       fλ^* Ω2 = −Ω1.           (4)

この式の Poisson 性は、Polishchuk の
[Feigin–Odesskii brackets, syzygies, and Cremona transformations,
Theorem B](https://arxiv.org/html/2204.09152v2) の幾何とも整合する。
ここでは係数・符号の規約を文献から推測せず、直接検証した。
具体的に Bbar_k=λ³B_k、Qbar=λQ とすれば

    Qbar ∧ ((DQbar) Bbar_1 (DQbar)ᵀ + Bbar_2(Qbar))=0

の十成分が QQ[λ,x0,…,x4] 上で恒等的に零である。
Euler bivector の差を許すこの式は、射影双ベクトルに関する (4) を与える。

## 4. 非線形座標変換の一次部分への寄与

非線形写像 (4) は、そのまま一次部分を保存するわけではない。
この節が二つの一次部分被覆を同一視するための追加の恒等式である。

f=Q_i/Q_0 をアフィン表示し、D=Df、Γ_a=D⁻¹∂_aD とする。
primitive 射影を pr と書けば、(4) の微分から

    f^*β2 = −β1 + pr(−Γ_aᵀΩ1−Ω1Γ_a).           (5)

ここで左右の β はそれぞれの原点で primitive 化した三階共変テンソルであり、
f^* は三つの添字全てへの D による引戻しを表す。
primitive 射影は Ω を −Ω に替えても変わらない。

同次写像 Qbar=λQ の五次 Jacobian 行列を B=DQbar とする。
A_p=[−p|I4]、ℓ=dlogQ_0 と置くと

    Γ_ab = A_p B⁻¹(∂_a∂_b Qbar) − ℓ_a e_b − ℓ_b e_a.

これは Qbar=Qbar_0(1,f) を二回微分し、B⁻¹Qbar=(1,p)/2 を用いれば従う。
最後の二項は projective perspective に由来する部分であり、(5) の primitive 射影で消える。

### 小さい多項式恒等式への還元

計算では Pbar_1=λ³P1 を用い、F=Pf(Pbar_1)、N=−F Pbar_1⁻¹ とする。
この一様なスカラー変更は λ を固定した p 微分に関して harmless であり、最後に消える。

    Pbar_1 N = −F I4,           det B = 2F.

F²β1 の各係数行列は

    C_a = −F ∂_aN + (3/5)(∂_aF)N
          − (1/5)N_col(a)(grad F)ᵀ
          + (1/5)(grad F)N_col(a)ᵀ.

また

    G_a=(1/2)A_p adj(B) ∂_a(DQbar|spatial),
    g_a=tr G_a

と置けば、G_a/F は上の Γ から perspective 部分を除いたものに等しい。
よって (5) の第二項に F² を掛けたものは

    −G_aᵀN−NG_a+(2/5)g_aN
       +(1/5)N_col(a)gᵀ−(1/5)g N_col(a)ᵀ.

これが正確に (3/2)C_a であることを、全64成分について
QQ[λ,p1,p2,p3,p4] の多項式恒等式として確認した。
すなわち、(5) は

    fλ^* β2 = β1/2                              (6)

へ簡約される。
`code/elliptic_cremona_jet_20261101.py` は行列の adjugate と Hessian を定義から再構成し、
通常の SymPy Expr の大きな展開を経ずに、QQ 上の多項式環で全ての恒等式を検証する。
Macaulay2 による別の先行検算とも一致したが、主証明書の再現に M2 は不要である。
独立実装 `elliptic_cremona_review_20261101.py` も、保存済み余因子・Hessianを使わず
五つの二次式から全てを再構成し、同じ普遍恒等式を確認した。

## 5. 正規化パラメータ被覆の双有理同一視

source のパラメータを (λ,p,c,S)、その standard frame を F1 とする。
次を定義する。

    p′=fλ(p),           c′=−4c,
    F1(cP1(p))F1ᵀ=J,   F2(c′P2(p′))F2ᵀ=J,
    S0=−2F2(Dfλ)_p F1⁻¹.

F2 は c′P2 を正規化する frame である。(4) により

    S0 J S0ᵀ = F2(−4cP2(p′))F2ᵀ = J.

従って S0 は確かに Sp4 の元である。未スカラー化の P2 の frame と混同してはならない。
(6) と c′=−4c から、三階共変テンソルの全添字に frame を適用すると

    b2(λ,p′,c′) = S0 · b1(λ,p,c).

特に16変数のパラメータ空間の写像

    (λ,p,c,S) -> (λ,fλ(p),−4c,S S0⁻¹)            (7)

は W16 への一次部分写像を保つ。
R による p の逆写像、c=−c′/4、および frame の有理式により (7) は双有理である。
全ての denominator、Jacobian determinant、frame pivot が非零である開部分を取り、
その非空性は保存した二つの有理点でも直接確認する。
除いた真の閉部分は一般に有限な一次部分射影の下で一般 target に寄与しない。
従って二つのパラメータ被覆の一般関数体次数は等しい。

## 6. 成分次数の結論と依存関係

五変数模型の一般長さ（同値に16変数パラメータ写像の次数）を N39,N40 とする。
(7) により N39=N40。
`ELLIPTIC_PARAMETER_REDUNDANCY_20261101.md` の独立した幾何・群論的証明は、
両族の全表示重複が正確に3000であることを示す。ゆえに

    N39=3000 d_T39,       N40=3000 d_T40.

(3) を代入すると

    d_T39=d_T40=1,        N39=N40=3000.

この結論は、Cremona が一次部分を自動的に保存するという誤った推論には依存しない。
その非線形補正は第4節で明示し、(6) を全パラメータの恒等式として検証した。
また、3000は一次部分の延長数ではなく表示の重複であり、二つを混同していない。
