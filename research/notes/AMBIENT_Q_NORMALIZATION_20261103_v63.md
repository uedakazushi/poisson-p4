## 2. 正規化であることと非正規性

既に受理された閉入射の定理は、各 f:E→C が proper birational であり、
E が滑らかであることを与える。
上の全幾何ファイバーは有限なので、proper morphism のファイバー次元の上半連続性により、
Q を含むある開 U 上で f は quasi-finite となる。
proper かつ quasi-finite なので f^−1(U)→U は有限である。

その有限射は birational で、源は正規であるから、U の正規化そのものである。
もし C が Q で正規なら、さらに小さい開で有限 birational 射は同型となるはずである。
しかし Q の scheme-theoretic fiber の長さは2なので同型ではない。
従って C は Q で正規ではない。

この論証は「proper な射のファイバーが連結だから像は正規」という推論を使わない。
必要なのは有限性、birational 性、源の正規性、および実際の長さ2のファイバーである。

## 3. 成分の重複度2

A=O_(C,Q) とし、正規化側の唯一の点の局所環を B とする。
B は有限な A 代数であり、同じ関数体を持つ正則局所環である。
その m_A B による商は長さ2の局所代数である。
完備化後、B の正則座標を選ぶと

    m_A B=(s1,…,s_(d−1),p²)

と書ける。実際、長さ2の商の接埋込み次元は1なので d−1個の独立な線形項が消え、
残る一変数の理想は(p²)である。
これは B の parameter ideal であり、e_(m_A B)(B)=2となる。
有限 birational A 加群 B は階数1であり、B/A は d より小さい次元を持つので、
Hilbert–Samuel multiplicity の加法性から

    e_(m_A)(A)=e_(m_A)(B)=2

が従う。値・perspective の九つの滑らかな方向を戻しても重複度は変わらない。
従って元の射影 CA,CB,N に対しても成分ごとの multiplicity は2である。

## 4. 決めていない局所情報

長さ2の正規化ファイバーは、像の全完成局所環を決めない。
例えば一変数で C[[p²,p³]] と C[[p²,p⁵]] はいずれもその長さ2を持つ。
基底方向との混合項も別に検査する必要がある。
従って A26 と通常 cusp の積、conductor の全式、全 CA∩CB の局所環はまだ主張しない。

    τ*(4CF−D²+τ²/4) ≠ 0

である。指定 Q は両因子が零となる場所にある。
