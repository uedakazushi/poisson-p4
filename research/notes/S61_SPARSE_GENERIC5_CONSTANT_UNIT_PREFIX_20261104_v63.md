# 定数QQ単元を優先する新しいトーリック核の構成

保存されたL51×20に、旧18角Cramer計算とは異なる単元優先消去を一回だけ適用する。非零QQ定数のpivotのみを最初に使い、row/column swap、定数による行の正規化、他行への多項式倍の加減を逐次記録する。列の順序を保存して元のc20座標への核の戻し方を固定する。

選択規則は予測fill、行列中の項数、QQ係数bit数、行列位置の辞書順で決定的である。17回に届かなければ実際のpivot数を保存して停止し、別の順序や一般の非定数pivotへ移らない。

17回できた場合だけ、残り34×3の階数1部分から一つの非零多項式pivotを選び、自由二列を単位行列にした核を作る。この一つの非零多項式を単元とするのは一般係数体QQ(H,L,s0,q0,t0)での操作であり、全パラメータや過去の全Uで単元という主張ではない。

核は20×3の戻し行列と3×2の小核の積として保存し、展開した全51×2方程式L*T=0と自由二行の単位条件を確認する。旧核との同じ関数体内での一致は、旧大きな行列式を再計算せず、双方の分子を交差乗算して全20×2成分で検証する。

N*TとQ52-centerの一つの45×3平面の枠が小さい場合だけ、非零3minorと42normalのアフィン座標変換を作る。元の全45未知数を保持し、未知qの式を単元にしない。134式のnormal42座標への代入、J0代入、Groebner基底、点や素数での試行は行わない。

再現：

```
source /workspace/cloud-setup/activate.sh
.venv/bin/python code/s61_sparse_generic5_constant_unit_prefix_20261104_v63.py --output work/NEW-output --work work/NEW-work
```

一回60秒・2GB・32MiBを保ち、既存の中間150k項capを引き上げない。完成したprefix・核・平面のblockを順次保存する。

## 実行結果

一回の決定的な消去は5.599秒で、非零QQ定数のpivot11回を完了した。残る部分に許されたQQ定数entryがなくなったため、規定どおり停止した。17gateは通っておらず、非定数pivot、新核、旧核との交差乗算、平面やnormal42の構成は実行していない。`all_passed=true` はこのprefixジョブの正確な完了を意味し、核や平面の完成フラグはfalseである。

残余は40×9、非零96成分・合計346項、最大一成分10項・次数7である。元Lの階数18は旧証明で確定しているため、可逆操作後の尾部は関数体上で階数7となる。このジョブで階数18を再計算したとは扱わない。

元の64定数entryの支持matchingが17だったことは、この特定の消去で17回を実現できる証明ではなかった。別の順序が常に11回で止まるという最大性も主張しない。全11回のpivot値、row/column swap、行の消去係数と元のc列への順列を保存し、出発点から再現できるようにした。

読み取りだけの残余支持検査では、H,Lだけの単項式entryはなく、全変数を許せばs0*t0、H*t0²、L*s0、H*s0*t0²に比例する4単項式entryがある。また定数項を持つ非定数entryは4個ある。これらをこのジョブで新しく単元として反転していない。次の別方法として、残余の行を一般係数体でprimitive化するgcd処理、または小さいgeneric pivotを選ぶ方法を検討できる。
