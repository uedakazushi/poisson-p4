# 二つの整合的 Hilbert–Burch 四次源の独立 SOURCE 監査

実際の物理行18,60,67から作る q_p と、二次平面 H 係数行列の定数逆行列を確認した。行列式は `−5/768` であり、R0 の単位である。q_p の z を含む二次項を一次フレームで全て消した上で定数正規化すると、P0,P1,P2 の**全二次項**は r²eH,r ell eH,ell²eH となる。未知 zz 係数は零に置かず、実際の Taylor 係数の順序付き z 除算として補正を定義する。

したがって ellP0−rP1 と ellP1−rP2 は全三次項が消え、四次から始まる。その四次項には P の三次項だけが関わる。z を含む三次項は r/ell 倍の後も z を含み、三次係数倍の一次フレームで消しても補正は五次以上である。H 四次項は二次係数倍の H 二次ピボットで消え、A/B の補正も五次以上である。P の四次項自体も線形因子により五次以上へ上がる。この次数の議論を全不可視感度の個数と併せて確認した。

平面三次の A は元の δ_p3、B は `H*(δ3−γ3)` である。γ3 には全ての負の RB 補正 `δ2_(zi*x)*x*β_i2`、特に r³ の項を残す。RH の混合二次補正が B 平面三次に寄与しない根拠は、実際の δ_i2 平面係数の零化である。行72の省略には、既に独立確認した α72 と必要な旧混合・三次葉の零を使う。未知 ell³ 係数は正規形が消すのであって、係数の値を零に設定しない。

三次多項式を形式的に正規化・移動し、四次関係を単項式書換えで再計算した。24個の旧 C2 葉と三つの未計算 λ に関する全重みが元の SOURCE と一致した。`B4+A4/4` の HB1+10HB0 結合が全 λ を消すことも形式的に確認した。δ4、混合 source3、β3、新しい gauge や jet は不要である。

このレポートは整合的な二つの四次源と、その**未対合の**作用素の SOURCE 証明だけを受理する。三つの λ、四次値、階数は計算していない。後の独立値検証でこの二源が階数2なら C3 の長さ19、HF36640を得るが、階数0または1なら源の部分族に関する結果であり、長さ20は導けない。既存キャッシュを読むワーカーの根・高さ・全予算・コードの別監査が終わるまで、値の実行条件は満たされない。
