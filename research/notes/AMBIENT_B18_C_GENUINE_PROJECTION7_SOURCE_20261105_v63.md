# 元 connecting 用の疎な D 線形射影 q7

真正 C[ell] は C4=C/ell⁴C の ker(ell)/im(ell³) である。既に証明された
D 自由直和因子 F=<A,B,rA,rB>_D を使うと、その計算は D 商 T7=C4/F16 の
ker E7 に移る。F は R0 部分加群ではないので、q を R0 線形とは扱わない。

q は m⁴C4 を消す。したがって三 target A,B,H と九変数の次数三以下の
220 monomial、計660列への作用だけで十分である。新しい作用表や高次 jet
を計算せず、既存の実 source の正規化から疎な affine operator として保存する。

RA_i=z_i A、RB_i=(z_i+beta_i2+beta_i3+…)B を用いる。RH_i の delta_i2 の
z*r、z*ell 部分を消去すると、B の三次平面係数は
E_i3=delta_i3−delta_i2,mixed beta2 となる。この carry を省かない。
同じ負の carry は既に独立検証された P0,P1,P2 の P3_B に含まれる。
z を含む三次項および平面三次 H は m⁴C 内に入り、q で消える。
beta3 の z を含む項もこの意味で消え、係数を零と仮定するのではない。

26個の正規化済み実 source 関係について、次数三までの全1187倍を射影して
零を検証する。また660個の D 線形性の恒等式 q(ell*x)=E7*q(x) と、実際の
21個の基底上で既存 q との一致を検証する。これにより単なる上界モデルではなく、
実 C/m⁴C 上の既存 q の座標表示を得る。既存 cache の affine 葉は記号のままで、
新たな affine 応答や connecting の値は評価しない。

元の五 head は旧56列の行22,23,29,30,55に対応する。実形式 cycle
sigma=(I−nbar*mbar)E を ell に依存しない形で持ち上げ、FULL_R0 の V と掛ける。
ell=0 で厳密に零になる分子を形式環で先に ell で割り、その後 q を適用する。
真正 target の四座標は ker E7 の自由行1,2,5,6から得る。

この SOURCE 射影では、最高次の必要項として分子の A/B 成分の
r³ell と r²ell² が残る。V4、sigma3、V3*sigma1、V2*sigma2 の寄与は
まだ記号として保持する。新しい source/IFT/gauge/jet の値計算は許可も実行も
しておらず、元 H0、K torsion、nil 三乗の結論は得ていない。
