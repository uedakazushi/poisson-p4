# 一般betaを覆う六変数の疎な実切片

元の原始16次元表現W16上で、密なv=0切片の多項式代表を b(H,L,s0,q0) とする。非零9成分は

```
b0=-45s0/16, b1=-30L, b2=2400,
b5=H(5q0+s0+1)/240, b6=s0/54000,
b8=-32H/3, b9=-32/675,
b14=H(s0+1)/120, b15=-64H/3.
```

群作用・源の変数との束縛は既存の事前評価に固定される。xi0=lambda²,r0=H²,B0=L²/H³の次数8の有限被覆と実際のSp4 Cartan pullbackにより、lambda*bは元の密なB15模型と同じ群軌道を覆う。

## 記号的な横断証明書

実際のLie作用10方向と源の5方向による16×15行列からlambda^14を剥がす。源5方向の行2,8,0,1,5のblockは行列式45000Hを持つので、Hを単元とするだけで11×10 Schur行列に縮約できる。元の全160個の列消去恒等式は既に正確に保存されている。

承認された一つの有界ジョブは、まず元の行7を削除する10角式をfraction-free Bareissで計算する。零なら同じ予算内の有限個の他の行を順に扱う。各除算は多項式として割り切れることを確認し、商と除数の積を分子と照合する。未知のpivot多項式を幾何学上の単元とする操作ではない。全段のpivot、元の成分、除数、商を保存する。

非零の行j削除式Dが得られた場合、元の昇順15行のminorは行置換の符号を含め `lambda^14*(45000H)*D` であり、最後のepsilon方向をe_jとした16角Jacobianはさらに `(-1)^(j+1)` を掛けた式である。全係数と非零係数の一つを保存する。

実行は総3.261秒、native0.0056秒で完了した。行7を除く式は零、次の行3も零であり、その後の行4で非零となった。全854回のBareiss除算はexactで、再乗算が分子に一致した。中間の最大項数は95である。

具体的に

```
Gamma=1+5q0+8s0+15H²+115H²q0
D(row4deleted)=2^30/5605041796875 * H²L² Gamma
```

となる。元の昇順15行のminorには行置換の符号-1が付き、最後のepsilon列の展開符号も-1なので、実際の16×16Jacobianは

```
detJac|epsilon=0 = 2^33/996451875 * lambda^14 H³L² Gamma.
```

五つの係数を直接再乗算して確認した。Gammaには定数項1があり、点での試行を使わず非零が分かる。

## 優勢性と利用範囲

`beta6=lambda*b(H,L,s0,q0)+epsilon*e_j`

とする。Sp4の10方向と源の6方向によるJacobianがepsilon=0で非零であるため、標数0で `Sp4×A6 -> W16` は優勢である。両辺の次元が16なので関数体の拡大は有限であり、任意の体拡大と同様に忠実平坦である。したがって一般beta上の消去・空性問題を、この実際の六変数模型に引き戻して確認できる。

得られた固定方向は元の座標e4である。元のb4は零なので、源は非零10成分・合計13項だけからなる。lambda,H,Lが非零の開集合で定義し、上のJacobianはさらにGamma非零の近傍でエタール性を示す。有限性は関数体の意味であって、全域で有限な射であるという主張ではない。

これは双有理性、六つの不変式による生成、すべてのbeta上の解の分類、既存のJ0巨大行列への代入結果を意味しない。元の一般beta研究を進めるための小さい忠実な入力模型だけを与える。
