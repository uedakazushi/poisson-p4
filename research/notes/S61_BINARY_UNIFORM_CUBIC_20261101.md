# 二平面型の一様な三次障害と横断長さ65の下界

2026年11月1日。135式の共通次数二斉次化を対象とする。
係数恒等式は QQ 上、幾何学的主張は C 上である。

## 1. 結論と横断方向

非平方二平面型の滑らかな三次元部分の一般点で、七法線変数の三次までの
初期関係の次元は高々50である。従って法線方向の Hilbert 関数は

    h0=1,  h1=7,  h2=23,  h3≥34

を満たし、三次までの長さは少なくとも65となる。
[特殊横断商の長さ65](S61_BINARY_TRANSVERSE_ALGEBRA_20261101.md)とは異なり、
本ノートは一般点における下界を与える。

既証明の二平面型部分は、標準曲線 Cβ 上の Lagrangian 平面を選び、
その消去変数に関する二元二次形式の射影類を選ぶ族である。
曲線がその点で滑らかで二次形式が非平方なら、これは滑らかな三次元族となる。
一般 Jacobian rank35 の領域では、その接空間は十次元の全接空間中に入る。

その三次元接空間は二次障害の共通 radical に入る。
実際、選択35式を陰関数で消した後の残余式の微分は、この族に沿って零である。
従って残余 ideal は族の ideal の二乗に入り、二次項は族の接方向との混合項を持たない。
証明書は指定点で共通 radical が正確に三次元であり、接座標 v0,v1,v3 の
その radical への制限が独立であることを exact QQ で確認する。
従って一般点でこの三座標をパラメータとして取り、残る

    v2,v4,v5,v6,v7,v8,v9

を七法線変数にできる。

## 2. 大きな二次補正を展開しない存在証明

[九次元の dominant な断面](S61_BINARY_UNIFORM_RANK_20261101.md)に制限する。
J は135×45 Jacobian、R は選択35行、P は既存の射影証明書であり、

    P_R=I,  P J_R=J,  rank J_R=35

が成り立つ。T は上の七法線方向を表す45×7行列で、JT=0、T の t 行は零。
F(z)=Jz+H(z,z) とし、Q=H(Tv,Tv) を二次単項式28個の係数行列として書く。

二次補正 w2 は J_R w2=−Q_R を解けばよい。
証明書は19個の座標 S と16×35行列 L を与え、全九変数について

    L J_(R,S)=0,  L Q_R=0,
    rank L=16,  rank J_(R,S)=19

を厳密に確認する。従って ker L=im J_(R,S) であり、
**S の19座標だけを支持に持つ二次補正 w2 が存在する。**
J_(R,S) の列を J_R の35列基底へ延長すれば、これは通常の陰関数消去による
二次補正として選べる。巨大な有理関数の w2 を保存したり、数値標本で代用したりしない。
S は t 座標を含まない。

## 3. 三次項が残り得る行は21個だけ

Π=I−P E_R とおく。既証明の二次残余 A2=ΠQ の非零行は、
零から数えて19、60、117、123、133の五つだけである。
七法線変数への制限でも、この五行は独立であることを確認する。

三次残余は

    A3=Π(2H(Tv,w2)).

前節で w2 の支持を S に制限できるので、混合 Hessian の
Π(2H(Tv,e_j))、j∈S だけを調べればよい。
全九変数での係数検証により、A2 が零の130行のうち、A3 が残り得る行は正確に
次の21個に限られる。

    18,20,23,39,40,43,59,61,68,90,92,99,102,113,115,116,120,122,129,132,134.

他の109行は、選んだ正しい二次補正に対して恒等的に三次まで零である。
ここでは w2 の非零係数を実際に展開する必要がない。

## 4. 全 Bianchi 恒等式から六つの独立関係

アフィン双ベクトルを P=J+L+Q+C と次数順に分ける。
旧 v02 の不変な入力から、三次 Jacobi trivector J4 の80係数と
四次 Jacobi trivector J5 の140係数を、保存された生成元で表し直す。
検証は q 最高項だけでなく、**全61パラメータの多項式**について行う。
低次数の60係数が恒等的に零であることも同時に確認する。
五次 Jacobi 項 [C,C] は、射影二次双ベクトルのアフィン三次部分が
Euler 場 E と二次ベクトル場 V の積 E∧V であり、[E,V]=V となるため恒等的に零である。

従って全 Schouten–Bianchi 恒等式の空間次数四、五、六の部分は

    [Q,J4]+[L,J5]=0,
    [C,J4]+[Q,J5]=0,
    [C,J5]=0.

全双ベクトルを q 次数一に斉次化すると、これらは135式に対する
q,t の一次係数を持つ、次数三の斉次 syzygy となる。G6 に掛かる係数は零でよい。
無限遠の基点での定数乗数ベクトル a0 は、それぞれ

    [Q∞,J4],  [C∞,J4]+[Q∞,J5],  [C∞,J5]

から直接求める。コードはこれらを構成し、A2 の非零五行における係数が
すべて零であることを確認する。21個の候補三次行への制限には、
指定有理点で非零の六次 minor がある。選ばれた六ベクトルについて
a0 J=0 も全九変数で確認する。

最後の a0 J=0 だけが syzygy の証明なのではない。
上記の**全 Jacobi 係数の復元と全 Schouten 恒等式**が syzygy を与え、
その必要条件を追加で検算している。

陰関数消去後にこの全 syzygy を三次まで展開すると

    a0 A3+a1(Tv) A2=0

となる。a1(Tv) は法線変数の一次式なので、第二項は五つの二次関係の
七変数倍が張る空間に入る。従って21個の三次候補の類には、
この空間を法として六つの独立関係がある。

五つの二次式の一次倍は高々35次元、21個の三次候補が新しく加える次元は
高々21−6=15。よって全三次関係の次元は高々50である。
七変数の三次単項式84個から差し引き、h3≥34を得る。

## 5. 一般点から同じ一定階数領域への移行

九次元断面から一般の二平面型 incidence への移行には、既証明の dominant 性と
[全135斉次化 ideal の同変性](S61_HOMOGENIZED_EQUIVARIANCE_20261101.md)を使う。
この incidence は、Lagrangian 平面に関する一次部分の線形条件と
非平方二次形式の開条件で得られる既約族である。

Jacobian rank35、二次障害 rank5、滑らかな二平面型三次元族とその横断方向が
一定に保たれる開領域では、局所的に可逆 minor を選んで陰関数消去を行える。
二次関係の核束を選ぶことにより、三次初期関係と二次関係の一次倍の係数行列は
その領域上で正則に変化する。その rank≤50 は閉条件である。
従って稠密な断面で証明した上界は、この一定階数の滑らかな領域全体に延びる。
これは任意の特殊 β に無条件で外挿する主張ではなく、上記の局所的な階数と
滑らかさを保持した同じ二平面型部分への移行である。

特に、その領域に属する指定点について、同じ固定 β の滑らかな三次元部分の
一般点における法線長さの下界65が得られる。
[指定横断商の上界65](S61_BINARY_TRANSVERSE_ALGEBRA_20261101.md)と組み合わせる
有限自由性・斉次化変数の議論は、各点での条件を確認した上で別途適用できる。
本ノート単独では全 S61 の一般アフィンファイバーの尽くしを主張しない。
