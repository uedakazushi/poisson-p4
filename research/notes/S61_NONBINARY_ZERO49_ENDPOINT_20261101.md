# 非二元型の最小型二枝との合流点：一般長さ7、横断長さ12、飽和除去

2026年11月1日。全135式の共通次数二斉次化を固定一次部分で考える。
Q=∂y∧(xz∂z−xw∂w)、すなわちu41=−1、他の重み二座標を零とする。
一次座標を保存順の(2,3,…,17)から始め、

    u4=u5=u12=u13=0, u14=1, u49=0,
    u50=−5u35, u51=5u26

と置く。他の一次座標は初期値のままである。

## 1. 指定点の結論

完成局所環Sは、保存された六接座標の一つu=v0についてR=C[[u]]上有限で、

    rank_R S=7,  length S/(u)=12

となる。一般ファイバーは、零モジュラーR0枝、最小型M0枝、M1枝の三因子で尽くされ、
長さはそれぞれ2、3、2である。その三枝は滑らかで接線が相異なる。

R-torsion部分Tは非零の有限長加群で、最小生成元数は正確に5。
従ってSはR上平坦ではなく、一次元局所環としてCohen–Macaulayでもない。
それでも **斉次化変数tはSで冪零**であり、この点はtによる飽和後の閉包から除かれる。
S/(u)ではt≠0、t²=0、length S/(u,t)=10である。
さらに第6節により、対応する十六次元交点stratumの全一般βファイバーも飽和で除かれる。
全Sでt²=0かどうか、Tの長さ、全乗法表はここでは決定しない。

## 2. 全式からの横断計算

元の式から最高Jacobianと全斉次化Jacobianを構成すると、どちらも階数39。
39式を形式的陰関数で消し、六接変数v0,…,v5を残す。
全式をF(z)=Jz+H(z,z)、接核基底をT0、選択39行の右逆をUと書けば、

    w2=−U H_R(T0v,T0v),
    A2=(I−JU)H(T0v,T0v),
    w3=−U(2H(T0v,w2))_R,
    A3=(I−JU)2H(T0v,w2)

が二次・三次の正しい残余式となる。
二次残余の階数は9。u=v0を零にした五変数二次idealのHilbert関数は
(1,5,6,2)、四次以上は零である。よってS/(u)の最大idealの四乗は零となる。

全A2+A3とA2の一次倍を保持し、一次5、二次15、三次35単項式に関する行列を作る。
その階数は44なので、横断商の長さは1+5+15+35−44=12。
純斉次なA2とA3を別々に零と置いて、この長さを計算してはいない。
tの正しい一次から三次までの類を加えると階数が一つ上がり、tは非零である。
t²の類は既存関係に入る。ideal(t)全体を加えた行列の階数は46で、商の長さは10となる。

## 3. 横断長さとは異なる一般階数の上界7

全六変数を保ったA2で独立な九行を選ぶ。各残余式からその定数線形結合を引いて
二次項を零にすると、39本の独立な純三次初期関係が得られる。
九二次式とこの39三次式の斉次idealをJinitとする。
これらは実際の初期idealに含まれるので、

    C[v0,…,v5]/Jinit → gr_m S

は全射である。先のu=0二次商が有限長であるため、左辺もgr_m SもC[u]上有限となる。
u=1に非斉次化したJinitの厳密な有理数Groebner基底は零次元で、標準単項式は七つ。
従って左辺のC[u]上の階数は7で、gr_m Sの階数は高々7である。
この非斉次化だけを見て局所次元や一般階数を結論せず、u=0での有限性を先に証明している。

gr_m SがC[u]上有限であることから、十分大きなnでm^(n+1)=u m^nとなる。
実際、次数の全射性を持ち上げた等式にNakayamaを適用すればよい。
従って(u)はmのreductionであり、Hilbert–Samuel重複度はrank_R Sと一致する。
初期次数列の傾きからもこの重複度はrank_C[u](gr_m S)に等しい。
以上より

    rank_R S ≤ 7

を得る。長さ12の横断商を一般長さと取り違えていない。

## 4. 同じ固定βの実在三枝が上界を使い切る

R0主枝はQの射影Sp4軌道と十次元β核から作る。
指定点のβ微分は階数16で、固定βのq微分像は一次元である。
陰関数定理により滑らかな実在曲線が得られ、その六接座標の接方向は

    (−3596/2605, −32/521, 0, 32/521, 0, 0)

となる。既証明の全十変数の普遍最高階数上界42により、
その一般因子の長さは少なくとも2である。

[最小型二枝の証明](S61_MINIMAL_ZERO49_BRANCHES_20261101.md)は同じ固定βで、
M0とM1の実際の正則な延長族を構成する。その接方向はそれぞれ

    M0: (−237302/2605, −32/521, 0, 32/521, 0, 0),
    M1: (−626812/2605, −32/521, 7082/521, 32/521, 0, 0).

三方向は線形独立で、どれもv0成分が非零。従ってuは三枝で一様化変数となり、
各一般因子の残差体はK=Frac(R)である。
同じ枝に沿う普遍的な全Jacobian階数上界からM0の長さは3以上、M1は2以上となる。
この下界は既存の別標本の局所環の開部分に入るという仮定を用いない。

よってrank_R S≥2+3+2=7であり、前節の上界と一致する。
三つの一般因子以外はなく、それぞれは最小の余接次元を持つので、

    S⊗K ≅ K[e]/(e²)
        × K[e,f]/(e²,ef,f²)
        × K[e]/(e²)

となる。各枝はt=0内に実在するから、tの各残差は零であり、一般点でt²=0である。

## 5. 非平坦性を保ったままtの冪零性を導く

有限R加群Sのtorsion部分Tは、Sのidealでもあり有限長となる。
t²は一般ファイバーで零なのでTに入る。
あるNについてm^N T=0であり、t∈mだからt^(N+2)=0である。
従ってSでtは冪零。完備化の忠実平坦性により元の局所環でも冪零となり、飽和からの除去が従う。
R-torsionを誤って零とした有限自由性の議論は使わない。

DVR上の有限加群の構造定理によりS≅R^7⊕T。
length S/(u)=12だからdim_C T/uT=5で、Tには正確に五つの最小R生成元がある。
これはlength T=5という主張ではない。T≠0はdepth S=0も意味する。

## 6. 十六次元交点stratumの全一般ファイバーを除く

固定Qのβ核にu49=0を加えたH0は九次元である。
三次元射影安定化Lie代数が全H0を保つことを普遍恒等式として確認し、
Sp4×H0のβ微分・(β,Q)微分はいずれも階数16である。
従って対応する既約閉包Zは十六次元でW16を優越する。
また、H0の全九変数で全135斉次化Jacobianの階数上界39を証明した。
指定点の非零39次minorにより、H0の一般点でも階数39である。

以下ではH0上の一般点の係数体K=C(H0)へ移る。
固定Qを中心とする各有限m-adic jet商は、元の135式とその単項式倍の
有限係数行列の余核として記述される。係数はH0の座標の多項式である。
一般点での行列階数は指定点での階数以上だから、すべてのnについて

    length_K S_generic/m_generic^n ≤ length_C S_sample/m_sample^n

となる。各nについて別の開集合を交わして複素点を選ぶ必要はない。
関数体Kでは全ての非零minorが同時に非零である。

指定点の横断二次idealの四次全階数minorは非零で、一般点にも保たれる。
従って一般点でもu=v0がreductionとなり、局所次元は高々一である。
前節の三枝は同じ全パラメータで構成でき、その滑らかさとv0接成分の非零性は
指定点の非零minorにより一般点でも成り立つので、局所次元は正確に一。
上の全nの不等式の一次漸近係数を比較すると

    rank_K[[u]] S_generic = e(S_generic) ≤ e(S_sample)=7

を得る。三枝の普遍下界2+3+2と合わせて等号となり、前節と同じ有限長torsionの議論で
一般点のtも冪零となる。この議論は、横断長さ12や非平坦性が族の全点で不変だとは仮定しない。

Sp4×H0→W16は指定点で微分が全射なので、その近傍で滑らかかつ優越的である。
全135同次数斉次化の同変性により、上の固定Qの一般計算はZの一般点に沿う
局所環の忠実な体拡大・滑らかな基底変更で得られる。
従ってtの冪零性はZの一般点の元の局所環へ降りる。
ある固定冪t^Nがそこで零となることから、coherentな局所化によりZの非空開部分で零となる。

ZはW16×P44の閉部分で、補集合の次元は高々15である。
そのβ像の閉包を除けば、Zの全一般βファイバーが飽和後の閉包から除かれる。
この拡張は十六次元の交点stratumについてのものであり、周囲の十七次元曲線族の
他の点や全無限遠を除いた主張ではない。
