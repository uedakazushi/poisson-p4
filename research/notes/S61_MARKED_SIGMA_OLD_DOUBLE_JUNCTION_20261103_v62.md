# 旧中央平面の実二重根接続：混合切断長五と全 t 消滅

2026年11月3日。h²=−2、u=v10、v=v12 とする。旧中央平面の二重根代表

    u=h, v=2h/3, ρ=全 light=0

において、元の全135式の混合標数完成環は、明示した17切断座標の正則形式環上
自由階数5であり、t=0となる。三根相異成分の厚み2と純二重根成分の厚み3を、
**同じ実際の点を通る二つの閉包**で比較する。一般 β の自由3をこの点へ直接

## 1. 実際の混合17切断と上界五

元の chart は q25=−1である。既存 ambient 証明書の10個の β 座標切断と
7個の軌道座標切断のうち、δu4=0だけを

    δu4+δu20=0

へ置き換える。u4は重み一座標、u20は重み二座標であり、ここでの δ は指定点からの
アフィン差を表す。残りの切断は変更しない。完全な零始まり添字は report に保存した。
切断後は44変数で、全135式の Jacobian 階数は41である。
保存41次小行列式は

    45498860587450368/78125.

核の自由3座標を x0,x1,x2 として、すべての法線ベクトルで δu4=−δu20 を
**元の全62座標に代入**し、元135斉次式の実二次 Taylor 係数を計算する。
Jacobian の列操作だけで二次係数を流用していない。可逆41方向による二次補正も、
同じアフィン混合切断の Jacobian を用いる。

補正後の二次係数行列は階数5で、その保存小行列式は−729h/1792である。
二次形式 ideal の Gröbner 基底は

    x2², x1*x2, x0*x2, x0*x1−h*x1²/2, x0², x1³.

従って次数列は (1,3,1)、長さは5である。これは元の完成横断環の長さ上界5を与える。
高次項を零と仮定するのではなく、有限な二次初期商から上界を得ている。

p=32003に対し h の両剰余根3083,28920で、同じ二次商の長さ5をそれぞれ再計算した。
Jacobian 小行列式、二次小行列式の数体ノルムは p 単元である。
法線・全一次行列・二次原係数・二次補正の計16248係数の分母も p 単元である。
従って各剰余枝の非分岐 DVR V とその完成 V̂ 上で、形式陰関数による41方向の
消去と、この長さ上界が有効である。

再現 source は `code/s61_marked_sigma_old_double_mixed_certificate_20261103_v62.py`、
最終保存先は `reports/S61_MARKED_SIGMA_OLD_DOUBLE_MIXED_CERTIFICATE_20261103_v62_FINAL/`。

## 2. 同じ中心に入る二つの18次元閉包

元の全135式が定める V 上の環を、その実際の中心で完成した環を S とする。
p-torsion の除去や t 飽和を先に施さない。以下の自由性の結論で p-torsion も消える。
Sp4 の全135式への整な作用と chart の単元分母は既存の
[混合標数橋](S61_BINARY_D_ZERO_BRIDGE_20261103.md)に従う。

三根相異型の全入射を Γ3 と書く。固定 q の全一次核は H9、射影 q 軌道は8次元なので、
Γ3 は標数零で既約17次元である。全135式上の真の平方零閉商を構成した
[三根相異層の証明](S61_MARKED_SIGMA_OLD_DISTINCT_ROOTS_20261103_v62.md)により、
S/(t) の Γ3 一般点の局所長は2以上である。

Γ3 の V-flat閉包は実際の二重根中心を含む。具体的には β を固定して

    u=h, v=z, ρ=全 light=0

とした V[z] 上の曲線が元135式を恒等的に満たし、t=0である。
判別式は8+9z²で、一般点は三根相異、z=2h/3が当該中心となる。
V[z] が V-flatなので、一般点で Γ3 に入るこの曲線は、その p-flat閉包に全体が入る。
接続点における Γ3 閉包の平滑性は用いない。
この一変数恒等式は
`code/s61_marked_sigma_old_double_junction_family_20261103_v62.py` と
`reports/S61_MARKED_SIGMA_OLD_DOUBLE_JUNCTION_FAMILY_20261103_v62.json` に独立保存した。

純二重根型の全入射を ΓD とする。全一次核 H10、射影 q 軌道7次元からなる既約17次元入射で、
実際の中心はこの全 H10に属する。階数一定の核・群断面の単元小行列により V-flatな

Γ3 と ΓD の一般 q 軌道は異なるので、これらは異なる既約支持である。
標数零で各17次元、V-flat閉包で各18次元となる。

## 3. 上界五と一般下界二足す三の一致

17個の実際の切断座標を c1,…,c17 として

    R=V̂[[c1,…,c17]]

と置く。Rは18次元の正則整域である。§1の閉ファイバー長さ上界と完備 Nakayama から、
R→Sは有限、SはR上5元以下で生成される。

Γ3とΓDの閉包は S の閉部分であるため、いずれも R 上有限である。
各閉包の次元は18なので、Rへの写像の核は高さ零、従って零となり、両閉包ともRの一般点を覆う。
一般次数を e3,eD≥1とすれば、異なる二つの一般支持の局所長を足して

    rank_R(S/(t)) ≥ 2 e3+3 eD ≥ 5.

一方、生成元上界から rank_R S≤5。よって両者は5、e3=eD=1となる。
R⁵→Sの全射の核は階数零であり、自由加群R⁵の部分加群だから零である。
従って元135式の S 自体がR上自由5である。(t)も階数零の部分加群なので零、
すなわち全Sで t=0となる。R自由性は元の環に p-torsion がないことも同時に与える。
これは横断長さの上界だけから t を零とする議論ではない。

完成とVへの整なモデルの忠実平坦性により、元の標数零周囲にも t=0が戻る。
二重根の全剰余点は、正の重み作用と単元の平方根を取る非分岐拡大でこの代表へ移るため、
当該二重根比の混合標数近傍がすべて除去される。

## 4. 旧平面の全非零方向へ

三根相異層の全有限剰余比は既存の多項式行加群証明書で覆われ、無限遠 u=0,v=1は
数体ノルム単元の上界2で覆われる。§1–3が残りの二重根剰余比を覆う。
従って重み(2,3)の射影直線の閉ファイバー全体が t 飽和支持から除かれる。
内在的な t 飽和支持の閉性と、この重み付き射影直線の properness により、標数零にも
不良比は残らない。アフィン開Δ≠0だけの特殊化で全複素比を除去したとはしていない。

これで h²+2の旧平面の**全非零方向**における実周囲の t 消滅が得られる。
原点 flag そのものの除去には、別の full Smith 中央支持証明書、ρ軸の実点別消滅、
飽和支持から原点への正重み補題を組み合わせる必要がある。本稿だけで全研究課題の完了とはしない。
