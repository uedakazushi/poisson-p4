# 元比較核 K の R0 加群四生成上界

受理済みの honest UCT で、Kbar=K/ellK は七次元であり、基底は `v=z5h4,q1=z5rh4,q2=r²h4,g=r³h4,w=rh3,U,S` である。ITold は最初の四元の span で、`rv=q1,rq2=g` より v と q2 で生成される。

M7 における `rh1=0` は、Told 内では `rh1∈ITold` を意味する。この係数を tv,tq1,tq2,tg として一切評価しない。実 kernel 元 `U=h3-a h1-b rh4` に r を掛けると `rU=w-a rh1-b q2`。従って w は U,v,q2 の R0 span に入る。S も加えれば七基底全体が得られ、Kbar は U,S,v,q2 の四元で生成される。ここで `rU=w` を Told の等式として使ってはいない。

K は受理済みの D=QQ[[ell]] 有限加群であり、R0 上も有限である。この四 barclass の任意の実 K lift を取り、生成部分加群で割ると Q=ell Q になる。ell は局所極大 ideal に入るので Nakayama により Q=0。従って **μ_R0 K≤4**。

これは R0 加群の上界であり、最小数や full lift の展開係数を求めたものではない。μ_D K=7 と区別し、元 H0 の長さ・torsion 指数、nil 三乗・正確な nil 指数を結論しない。M7 の splitting を Told や Kbar の extension へ移してもいない。
