# 線形係数 syzygy の二三次成分：既存値による評価

源随伴前処理で必要なpairは全て既存 B11 内であると確認した。旧 B の typed 根46個は保存済み762節点ADに含まれ、その24個の原子の二次値は保存済み108複合根キャッシュに全て含まれ、未知の正直な除算二次感度は各原子で既に零。P8由来の21根も同じキャッシュにある。従って新しい函数値や源jetを求めず、原子Jacobian×既存原子二次値と既知一次積を足せる。

native値は独立監査済みの有効 `(L0+L1)*S_B11`。119個の線形係数source結合では各変数ごとのnative原点結合が零であるため、全L2項が消えるという源証明を使う。個別native X2を実際の係数だと仮定しない。既知 `-Xp1*a2` 補正を加え、全119本の二三次成分を保存する。第2成分は別の純r³パケットと全件一致して零であることも検算する。

二成分の階数は、119個の線形係数 syzygy が**新しく消す三次候補類**の次元である。全三次関係を尽くしたものではなく、定数係数の二次零源関係から生じる三次部は未計算である。従って残余次元は上界としてだけ記録し、実HF3やT全長とは同定しない。深さ19・二次までのHF(5,3,2)は既存の受理済み結果として保持する。全計算は既存の有限有理数配列の積和と固定階数証明書に限る。
