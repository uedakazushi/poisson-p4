# Kbar の r二乗作用の旧二次層への射影

取得済み四パラメータで指定した七基底に対し、保存済み37本の一次 initial と40本の Groebner 基底だけを使う。rh1 と rh2 の一次 normal form から係数 alpha1,alpha2 を読み、各結果について元37本への厳密な membership 係数を掛け戻す。新しい source jet や full action は問い合わせない。

旧二次基底は q1=z5rh4,q2=r²h4 である。受理済みの正確な HF5321 と既知 initial 商の二次元が一致するため、この二基底は実際の gr²Told の基底である。従って U,S の r二乗像は、この層ではそれぞれ `(-11767/3652-a3 alpha1)q1` と `(alpha2-aS alpha1)q1`。他五基底はこの射影で零になる。全七列に対して degree2 多項式の正確な source reduction と掛け戻しを保存する。

これは旧 m³Told で割った像だけである。実際の r²像に残り得る r³h4 成分は記号のまま残し、full r二乗行列や r-Jordan 型を決定しない。射影が非零なら r³Kbar=0 と合わせて少なくとも長さ三の r-block があると分かるが、ell-DVR torsion 型、元 H0、nil 三乗には移さない。
