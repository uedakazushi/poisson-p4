# 二平面型の階数降下を越える自由階数65と t の冪零性

2026年11月1日。全135式の未飽和二次斉次化を対象とする。
[階数降下族](S61_BINARY_RANK_DROP_FAMILY_20261101.md)の指定有理点で、
前の横断長さ上界67を65へ改め、全完成局所環の有限自由性を証明する。

## 1. 結論と、一般二平面型との相違

点は Q=xw∂y∧∂z、一次座標は保存順 (2,3,…,17) に
u12=u13=u35=u50=0 を課したものとする。
この点での135式の完成局所環を S、既存の三パラメータ環を R=C[[v0,v1,v3]] と書く。
すると

    S は R 上自由階数65、S_red=R、
    I=ker(S→R) は自由階数64、I⁴=0、
    0≠t、I t=0、t²=0、S/(t) は自由階数64

となる。従ってこの点を通るアフィン側の枝はなく、t による飽和で除かれる。
同じ証明の非零 minor 条件を保つ階数降下族の開部分にも適用できる。

指定横断商 A=S/(v0,v1,v3) の Hilbert 関数は (1,8,22,34) である。
[前の一般二平面型](S61_BINARY_FORMAL_RING_20261101.md)では (1,7,23,34) であった。
従って全長さと自由階数は同じでも、埋込み次元は跳ぶ。
ここでは I/I² など各 graded piece が R 上自由とは主張しない。
S の全乗法表や、階数降下曲線の全端点の処理も完了したとはしない。

## 2. 四次の実際の残余式

[局所上界67の証明](S61_BINARY_RANK_DROP_LOCAL_20261101.md)で、
実際の固定 β の滑らかな二平面型三次元族 C と、そこへの v0,v1,v3 の独立性を確認した。
また、この三パラメータの横断商の極大イデアル m_A は m_A⁵=0 を満たす。
後者は792次の非零 minor と Nakayama による特性零の結論である。

従って横断商 A を正確に求めるには、残る八変数について四次までを保てば足りる。
F(z)=Jz+H(z,z)、J_R U=I とし、T は八横断方向への制限とする。
陰関数消去の補正は

    w2=−U H_R(Tv,Tv),
    C3=2H(Tv,w2),       w3=−U(C3)_R,
    C4=2H(Tv,w3)+H(w2,w2),  w4=−U(C4)_R

である。全135式の残余は

    A2=(I−JU)H(Tv,Tv), A3=(I−JU)C3, A4=(I−JU)C4

となる。**A2、A3、A4 を別々の斉次関係とせず、各行の和 A2+A3+A4 を保つ。**
斉次化変数の像も w2、w3、w4 の t 座標の和を使う。

八変数の二次・三次・四次単項式は36、120、330個、合計486個である。
全135個の残余式、それらの一次倍（四次まで）、二次倍（四次まで）を並べる。
これで四次切断環内の全イデアル関係を張る。m_A⁵=0 が既に証明されているため、
この切断商は実際の A と一致する。

## 3. 430次 minor による特性零の上界65

素数32003で上の行列を構成すると、2395×486行列の階数は430となる。
430次小行列の行列式は29756で非零。入力の有理数分母と、J の選択34次 minor は
この素数で可逆なので、この計算は特性零の正しい陰関数展開の還元である。
従って QQ 上の関係階数は少なくとも430であり、

    length A ≤ 1+8+486−430 = 65

となる。ここでは有限体の階数を QQ の上界として使っていない。
行列式の非零性は QQ の階数下界、すなわち商の長さ上界を与える。

さらに、斉次化変数の係数行を加えた431次小行列の行列式は18621で非零である。
この時点では QQ の元の関係階数が431以上の可能性を単独では除けない。
t の非零性には、次節で元の階数が正確に430と決定されることを合わせて使う。

## 4. 同じ固定 β の C の一般点での下界65

前の普遍下界を適用するため、別の β の一般点を代用しない。
**同じ β、同じ支持平面**で二次形式を

    Q1=(xw+x²+w²)∂y∧∂z

へ変える。これは同じ二平面型 P²束 C の点である。
二次形式の判別式は −3 で非零、支持平面の標準曲線も滑らかである。
元の全135式から、Q1 での全 Jacobian 階数35、二次障害階数5、
共通 Hessian radical 次元3を QQ 上で再計算した。

従って C の同じ既約局所成分上に、既証明の一定階数の開部分が存在する。
Q+s(x²+w²)∂y∧∂z という同じ P²ファイバー内の経路を考えてもよい。
Q1 で非零の minor は、この成分上で恒等的に零ではない。
よって C の一般点では[普遍三次下界](S61_BINARY_UNIFORM_CUBIC_20261101.md)が適用され、
七法線方向の三次までの長さは少なくとも65となる。

S は R 上有限で、第3節より高々65元で生成される。
C の一般点の局所因子だけで階数65以上を必要とするため、
R^65→S の核は階数零となる。自由加群の部分加群であるその核は torsion-free なので零。
従って S は R 上自由階数65、A の長さは正確に65である。
また S⊗Frac(R) の全長さは C の一般点の因子が使い切り、他の一般因子はない。

S→R の分裂の核 I は自由階数64である。
C の一般点では法線 Hilbert 関数 (1,7,23,34) と I_K⁴=0 が成り立つ。
I⁴ は torsion-free な S の部分加群なので、その一般点での消滅から I⁴=0 が従う。
従って I は冪零根基で、S_red=R となる。

指定横断商では、接次元8と厳密な二次障害階数14により h1=8、h2=22である。
I⁴=0 と全長さ65から h3=34 が従い、冒頭の Hilbert 関数を得る。
各 graded piece の自由性を必要とせずに、全 S の自由性を証明した。

## 5. 非零平方零の t と、局所飽和

C の一般点では、普遍三次証明の一次・二次 lift が t 座標を持たないため
t_K∈I_K³ である。従って I_K t_K=0、t_K²=0。
S が R 上自由であるため、I t と (t²) は torsion-free な S の部分加群である。
これらが一般点で零なら全域で零となり、I t=0、t²=0 を得る。
この議論には S/I³ の自由性を仮定する必要がない。

A の長さ65が決まったので、第3節の元の関係行列の QQ 階数は正確に430である。
t を加えた431次非零 minor により、t の像は A で非零、従って S でも非零である。
I t=0 から (t)=Rt。自由 R 加群 S の中で t は特殊ファイバーでも非零なので
可逆な係数を持つベクトルであり、Rt は自由階数一の直和因子となる。
従って S/(t) は R 上自由階数64である。

完備化の忠実平坦性により t²=0 は元の局所環でも成り立つ。
よって指定点の適当な Zariski 近傍は t による飽和で除去される。
これは階数降下族のある開部分を除く結果であり、残る端点を一括して除く結果ではない。
