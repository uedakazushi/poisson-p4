# CA/CB の共通一次像：独立点検の補足

2026-10-30。`AMBIENT_WEIGHT1_IMAGE_20261030.md` と
`code/ambient_weight1_image.py` を独立に点検した。旧版の成分性・次元28の全証明を
再監査したという意味ではない。新しい9次元像の議論に論理上の問題は見つからなかった。

- 任意のrank4点は x0≠0 にある。平行移動後も CA の族は保たれ、CB の Euler 項の
  定数ずれは二次以下の Hamiltonian へ吸収できる。定数交差項 d,e を残した frame
  の正規化により、基点を特殊な零点に限定する穴を避けている。
- 閉 incidence の第二条件は、一次係数1形式の空間での比例性である。比例定数を
  導入して affine 空間へ射影するだけでは閉性を結論できない。非零の
  ell_v⊗ell_v と contraction tensor の2次小行列式で書けば閉であり、P3 が proper
  なので像 Z も閉となる。Sp4 同変性から固定 v の核の次元6は一定である。
- 全成分の閉包へ包含を延ばすには、非退化評価開部分上で閉条件として降下することを
  使う。局所的な symplectic frame と primitive 正規化は正則で、Z は CSp4 不変なので
  この条件は座標選択に依存しない。原族の PGL 飽和を閉包に移しても保持される。
- 逆包含は、六次元線形部分空間の任意の点を f=x0²+p x0x、h=x0h2 で実現してから
  Sp4 を作用させることで得る。従って単なる像の閉包の一致でなく、複素点の像が
  正確に Z に一致する。ただし scheme-theoretic image の定義イデアルは計算していない。

次元9には、計算した9次 minor に加えて次の小さな独立証拠がある。

    β = x dx∧dy + (z+w) dx∧dz + w dx∧dw − x dz∧dw.

これは閉 primitive で固定 v=∂y の部分空間に属する。係数行列の行 (12),(13),(14)、
列 x,z,w の小行列は [[1,0,0],[0,1,1],[0,0,1]]、行列式は1。
よって係数階数3で、核は直線 C∂y。階数3の開部分で incidence 射影の逆は
β↦P ker Bβ により代数的に定まる。9次元 incidence の非空開部分が像と同型だから
dim Z=9 が従う。この証明は標本からの次元上界の推測を含まない。

`code/ambient_weight1_image.py` を新しい作業出力へ再実行し、全項目の成功と
9次小行列式 −2016 を再確認した。上の簡単な β の閉性・primitive 性・階数3・
行列式1・核も別の直接計算で確認した。
