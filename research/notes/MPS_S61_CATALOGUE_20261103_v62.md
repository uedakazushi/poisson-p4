# MPS 40成分の一般族と S61 座標写像

2026年11月3日。複素射影四空間上の既知 MPS 成分を全 S61 の座標へ移すための構成である。
全 Poisson 成分の上界、特殊ファイバーの尽くし、全素イデアルの決定は主張しない。
既知成分数の下界57は変更しない。

## 1. 一般係数を残した37族

元の40図式は `legacy/v02/baseline/data/p4_toric_smoothing_diagrams.json` にあり、
一次資料 Table 2 との S5 照合は `MPS40_CROSSWALK_20261031` に記録される。
図式の period 空間の基底から、全 period 変数を残した反対称行列 B を作る。
四次部分の Pfaffian を b として

    A=−b B^(-1)

と置く。四次反対称行列では A の各成分は B の成分の一次式である。
実際の log Poisson の biresidue は `−A^(-1)=B/b` で、B そのものとは区別する。
写像 B↦B/Pf(B) は Pf 非零上の有理的な対合であるから、同じ一般 period 空間を覆う。
smoothability の比と同次線形条件はこの共通スカラーで変わらない。

トーリック二ベクトルに、各 decorated edge {i,j} の一次変形

    t_e · ∏_(k≠i,j) x_k^(m_e,k) · ∂i∧∂j

を加える。まずこの単純な和の projective Jacobi を全係数で検査した。
T02〜T38 のうち19族では恒等的に零である。残る18族の非零結果も保存し、
それを Poisson 族と誤って採用していない。

残る18族では edge torus weights が一次独立である。
全150本の二次斉次二ベクトル単項式の重みから、非負整数の edge 多重次数を持つものを全て列挙する。
各単項式にそのような多重次数は高々一つなので、高次補正の候補は有限である。
多重次数の和の小さい順に、既決定項の Schouten 括弧を、トーリック Jacobi 微分の像へ持ち上げる。
全一般 period 変数の有理関数体上で線形方程式を厳密に解き、最後に全350係数の
projective Jacobi と既存の別の係数抽出による Jacobi を両方確認した。

これにより T02〜T38 の37族は全て、一般 period と全 edge 変数を残した明示的な
有限有理式となった。T37 は7個の高次補正を要し、最大の edge 全次数は6である。
T21 は edge 重みが従属だが、最初の単純和が既に Jacobi を満たすため、
独立重みの有限補正アルゴリズムを無理に適用していない。

再現コードと証拠：

- `code/mps_s61_catalogue_20261103_v62.py`、`reports/MPS_S61_RAW_CATALOGUE_20261103_v62/`。
- `code/mps_smoothing_completion_20261103_v62.py`、`reports/MPS_SMOOTHING_COMPLETION_20261103_v62/`。

T01 の一般トーリック族、T39/T40 の全一次空間上の二次 graph は既存の完了項目であり、
今回それらを未解決へ戻してはいない。

## 2. 族の像の次元と component ID

period 次元を s、edge 数を e とする。全37族の各補正項は、対応する edge 多重次数の
重みの和を持つ。また period と edge の全変数を同時に λ 倍すると二ベクトルも λ 倍される。
従って PGL5 とパラメータ空間の積には、トーラス T4 による自由な作用

    (g,p,t) ↦ (g h^(-1),p,χ(h)t)

があり、各点は同じ二ベクトルを与える。群因子への作用が自由なので、
変形後の個々の二ベクトルの安定化群の次元を仮定する必要はない。
これから像のアフィン次元の上界は `24+s+e−4=20+s+e` となる。

一方、各 period の有理代表、edge 変数零の点で、25個の線形座標変換微分、
s 個の period 微分、e 個の最初の edge 微分を全150係数で作った。
Euler 鉛直24方向を定数線形写像で除き、126行の商行列にする。
T01〜T38 の全38件で、有理分母が32003の単元である実小行列に
`20+s+e` 次の非零行列式を記録した。
18個の高次補正を要する族についても、まさにこの保存代表点で補正の全分母が非零かつ
32003の単元であり、補正自身と period/edge の全一次微分が零であることを独立に確認した。
従って最初の和から作った微分行列は、完成した族の実際の微分行列でもある。
証拠は `reports/MPS_CORRECTION_DENOMINATORS_20261103_v62_REVIEW.json`。
有限体の非零値は標数零の階数下界にのみ使い、階数上界の推論には使わない。
前段の幾何的上界と合わせて像のアフィン次元は正確に `20+s+e` である。
射影像は `19+s+e`、対応する S61 成分は `10+s+e` 次元となる。

コードは `code/mps_s61_dominance_20261103_v62.py`、
全有理行列と行・列・mod32003 行列式は `reports/MPS_S61_DOMINANCE_20261103_v62/` にある。

**成分のラベルと全成分性には別の入力がある。** 上の階数と次元だけでは、
同じ次元の部分族が既知のどの成分に属すかまでは決まらない。
本構成は、各図式の一般 period 条件と、その図式の全 edge の非零一次 cocycle を一致させている。
MPS の局所 Torelli の **Theorem 6.16** による smoothing subdiagram ごとの一意な局所既約成分、
**Corollary 6.23**、および射影空間で条件2が自動的となり40族が全体でも相異なるという
**Example 6.24** を用いて、像閉包を該当する MPS 成分と同定する。
これは Table 2 の番号や次元だけからの同定ではない。
一次資料は [arXiv:2010.08692v2](https://arxiv.org/html/2010.08692v2)。
一次本文の該当箇所は今回の独立監査でも確認した。

## 3. 全 S61 への有限な有理座標写像

一般族 P(p,t) の点 (1:1:1:1:1) を e0 へ移し、その projective な値を C とする。
固定した座標の並べ替えの後、C の六成分を (a,b,c,d,e,f)、
δ=af−be+cd と書く。`aδ≠0` の開で

    F=[[1,0,0,0],[0,1/a,0,0],[d/a,−b/a,1,0],
       [e/δ,−c/δ,0,a/δ]]

は `FCF^T=J` を満たす。もとの係数の分母も反転する。
次に **任意の g∈Sp4** を作用させ、既存の Euler 鉛直商と有限 perspective 正規化を取る。
perspective 4座標への定数応答行列を R、選択した4係数を v とすれば、
使用する perspective パラメータは `−R^(-1)v` である。
最後に固定された61自由係数を読む。これは有限個の有理演算だけからなる明示的な写像である。

Sp4 自身も、位置・運動量の順で対称行列 S,T と可逆2行列 A を用いて

    g=[[I,0],[T,I]] · [[A,0],[0,A^(−T)]] · [[I,S],[0,I]]

とする10変数の大セルで与えられる。ここでは `det A≠0` も反転する。
既存の通常順の J へは固定した座標置換で戻す。
この Sp4 の10変数を省いて、period/edge 変数だけの61座標を全 S61 成分の密な写像と呼んではいけない。

全成分の一般点で固定点が非退化である開を取る。PGL5 の座標枠でその逆像 p の
五座標が全て非零となることも一般条件である。
上の T4 の同変性により、対角変換で p を全て1の点へ移し、その変化を edge パラメータへ吸収できる。
値を J にする二つの線形枠の差は Sp4 であり、残る4 perspective 方向は一意な有限正規化で消える。
従って上の **period/edge/Sp4 の全写像** は対応する S61 成分を優越する。
その源と像はともに `s+e+10` 次元なので一般に有限である。
一般次数や全特殊ファイバーの記述は今回計算していない。

この写像が S61 の元134式を満たす理由は、一般 P の projective Jacobi 恒等式、
有限射影変換による保存、および既存の全 Poisson 模型への S61 還元定理である。
有限個の値を代入しただけで一般恒等式を結論しているのではない。

## 4. 実際に展開して直接検算した61座標

一般変数を残す coefficient-field の有限 perspective 演算を
`code/s61_rational_family_adapter_20261103_v62.py` へ実装した。
既存の `s61_model.py` は改変していない。
T02,T03,T04,T05,T17 については61個の有理式を実際に展開して保存し、
元134式への代入と150復元係数の一致を QQ 上の多変数多項式演算で直接確認した。
さらに一つの正確な有理特殊化で旧 normalizer の全61係数と比較した。

- T02〜T05：`reports/MPS_S61_EXACT_DIRECT_20261103_v62/Txx.json` と対応する `.in.gz`、`-native.log`。
- T17：`reports/MPS_S61_EXACT_COMPLETED_20261103_v62/T17.json` と対応する `.in.gz`、`-native.log`。
- 検算コード：`code/mps_s61_exact_maps_20261103_v62.py`、`code/s61_rational_map_verify_20261103_v62.cpp`。

検算では parameter weight を保った共通分母を使う。
134式の重みは4または5であるが、各式が斉次なので分母の4乗・5乗を展開する必要はない。
復元式の重みは3以下である。native 演算は元変数に関する多変数 Horner 法で行う。
T03 では134式と全150復元係数が17.4秒で零となり、最大中間項数は16289であった。
未整理な全単項式積を cache する初期試行は100式まで確認後180秒で停止し、約5GBを消費したため、
この Horner 法へ変更した。失敗した試行を成功として数えない。

T06 では一般変数の134式・150復元係数の native 検算は成功したが、
補助的な有理特殊化の選び方が値の退化因子に入ったため、成功した最終 map JSON へはまだ採録していない。
他族について巨大な分子を展開する検算は継続可能な別作業として残す。
上の一般写像の数学的な構成と、個々の展開出力の直接検算済み範囲を区別する。

一方、全38件の **完全な Sp4 を含む有限有理演算 circuit は凍結を完了した**。
`code/mps_s61_arithmetic_circuits_20261103_v62.py` と
`reports/MPS_S61_FULL_CIRCUITS_20261103_v62/` に、各61出力、入力変数、
全演算節点、正規化行列、反転する値の節点を保存した。
演算は有理定数、入力、加法、乗法、逆元だけで、式の巨大な展開を必要としない。
全38族で正確な有理特殊化における旧 normalizer の全61出力との一致と
元134式・全150復元係数・Jacobi を再検査した。この特殊化検算は実装の検査であり、
一般恒等式の証明は第3節の全パラメータの構成による。

T39/T40 も既に証明された全 W16 上の二次 graph から同じ演算形式へ移した。
その入力は16一次座標であり、全 graph 自体を覆うので Sp4 をさらに足す必要はない。
`reports/MPS_ELLIPTIC_GRAPH_CIRCUITS_20261103_v62/` は旧普遍恒等式・独立監査の
入力 hash も保持する。40件をまとめた
`code/data/mps_s61_coordinate_catalogue_20261103_v62.json` は各 archive と復号後の hash、
18族の完成した元テンソルの個別 hash、次元証拠、開条件、成分同定の依存関係を持つ。
生成器は `code/mps_s61_catalogue_index_20261103_v62.py` である。

## 5. 残す課題

これは既知 MPS 40成分の一般パラメータ族を一つの座標規約へ移す作業である。
全51階数四成分の定義素イデアルが完成したわけではない。
追加11成分の同じ規約での一般族、例外開の補集合と特殊一次ジェット、
未知成分を除く全 S61 の根基比較は別に必要である。
既知成分の座標化や局所 Torelli による同定を、全 Poisson 空間の尽くしと同一視しない。
