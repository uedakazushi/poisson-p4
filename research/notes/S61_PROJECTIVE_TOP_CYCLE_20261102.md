# 元135式の一般射影ファイバーの最高次サイクルと t 作用

一般の一次ジェット β を固定し、q 次数二で斉次化した全135式の射影スキーム X⊂P⁴⁵ を取る。基礎体は標数零で、以下の幾何学的次数は代数閉包上で計算する。三次元の基本サイクルは

    [X]₃ = 65[B] + 5[Fβ],      deg B=30,    deg Fβ=70.

従って全次数は2300である。B と Fβ はともに t=0 にあり、アフィン部分の次数を2300とする結論は出ない。

## 二つの三次元部分と旗の blow-up

非平方二平面と旗以外の無限遠層は高々二次元であり、アフィン部分そのものも高々二次元である。従って三次元の被約成分はこの二つの閉包に尽きる。非平方族の閉包は、C=Cβ⊂G=LG(2,4) 上の B=P_C(Sym²V) である。V=ann(Π) は symplectic 同型で tautological 平面束 U|C に等しい。テンソルの q 表示 [F]⊗[∧²Π] は Segre 表示なので、支持と二次形式の両方を正則に復元できる。[全層の次元](S61_AFFINE_BOUNDARY_DIMENSION_20261102.md)、[アフィン次元上界2](S61_AFFINE_SURFACE_BOUND_20261102.md)

Plücker 線束を O_G(H)=det U* とする。primitive 一次項の断面 sβ∈H⁰(G,U*⊗O_G(H)) は、v∈Π で sβ(Π)(v)=β_v|Π と与えられ、その零スキームは滑らかな C である。平方旗の v=Jℓ, [ℓ]∈P(annΠ) を取る。標準旗 Π=⟨∂y,∂w⟩, ℓ=x では sβ(Π)(Jℓ) の係数は −u4 で、同じ平面での二つの独立評価は u4,u5 である。この一式は旗代表の全最高135式の被約条件で、Sp4 同変性によりすべての旗へ運べる。従って Fβ は P_G(U) 上の sβ(v)=0 の零因子である。旗から q への写像は相対 Veronese と Segre の合成で閉埋込みである。[C の元テンソル](PRIMITIVE_JET_ELLIPTIC_CURVE_20261101.md)、[旗の全最高核](S61_FLAG_UNIFORM_OPEN_20261101.md)

この因子は Bl_C G に等しい。局所枠で sβ=(f,g) と書けば、C は正則列 (f,g) で定義される。旗の式 f v₁+g v₂=0 は、有理写像 Π↦[g:−f] のグラフ閉包の方程式である。正則列の Rees 代数は二生成元間のこの一次関係で表示されるため、C の上にも余分な成分はない。例外因子は P_C(U|C) で、q 表示では B と Fβ の被約交叉に一致する。以下ではこの交叉のスキーム重複度を用いない。

## 埋込み次数

P は一次元部分空間の約束とし、その双対 tautological 類を ξ とする。G は滑らかな三次元二次曲面なので ∫H³=2。U の symplectic 商 W/U=U* と四次元定束 W の全 Chern 類から 2c₂(U)=H² である。π:P_G(U)→G の押出しは π₍*₎ξ=1, π₍*₎ξ²=H, π₍*₎ξ³=H²−c₂(U), π₍*₎ξ⁴=H³−2Hc₂(U)=0 である。ここで π₍*₎ は Chow 群の押出しを表す。Fβ の因子類は ξ+H、q の超平面類は 2ξ+H なので

    deg Fβ = ∫ (2ξ+H)³(ξ+H) = 20·1+18·2+7·2 = 70.

B 上では q の超平面は ξ_B+H である。det(Sym²V)=(det V)³、deg V=−5 より ∫ξ_B³=15、∫ξ_B² H=5 となり deg B=30 を得る。共通の被約例外面 P_C(V) で q の超平面は 2ξ+H なので、その次数は4·5+4·5=40である。

## 三つの一般線形切断

B の一般点で全局所環の横断長は65、t は非零でその像は長さ1、t²=0である。旗の一般点では長さ5で t=0 である。これらは同じ固定 β の滑らかな三次元を底とした実際の自由な局所模型で、β と点について稠密な開で成り立つ。特に t=0 商での一般長はそれぞれ64,5である。[非平方の局所環](S61_BINARY_FORMAL_RING_20261101.md)、[非平方相対開](S61_BINARY_ENDPOINTS_20261101.md)、[旗の局所環](S61_FLAG_UNIFORM_OPEN_20261101.md)

一般の三つの射影超平面は、下の次元の全成分と上の開の補集合を避け、B と Fβ の滑らかな開にそれぞれ30点と70点で横断的に会う。三つの切断関数は各被約三次元の局所パラメータをなし、一般の有限平坦性、または proper な線形切断の局所交叉数から、各点の長さはそれぞれ65,5である。t=0 商へも同じ議論を適用すると各点の長さは64,5となる。t は線束の切断なので、各有限局所環で自明化して乗算を考える。その階数はそれぞれ1,0であり、周囲で既に t²=0 である。

全切断の長さは2300、t=0 による商の長さは2270、t の像の長さは30である。代数閉包上の t の Jordan 型は大きさ二が30本、大きさ一が2240本になる。これは三つの **一般の** 超平面による切断の計算である。指定した二座標だけを固定したファイバーの長さや、アフィン五点による尽くしはここからは従わない。
