# 全階数33へ下がる二平面型の十七次元族でも自由階数65が成立する

2026年11月1日。全135式の同次数二次斉次化について、
[十八次元族](S61_BINARY_HYPERSURFACE_RANK_DROP_20261101.md)の中のさらに低い階数の部分を扱う。
core を (a,b,c,d,e,f)=(u4,u14,u35,u36,u49,u50) とし、一次部分 source を

    H_*={u12=u13=0, K=5c+f=0,
         Q*=600b²−255be−63e²+100af=0}

とする。Q* は (a,b,e,f) に関する階数4の二次形式なので、H_* は幾何学的既約十二次元である。
その Sp4 飽和像は W16 を優越する十七次元族で、最高/全 Jacobian の一般階数は32/33。
指定点とその ambient 開近傍では、全完成局所環が三パラメータ環上自由階数65で t²=0となる。
全一般 β 曲線の除去は主張しない。

## 1. 普遍階数と優越性

先の残余上三角行列 E の中央ブロック B は12×9である。
f≠0 の稠密開で

    c=−f/5,
    a=−(600b²−255be−63e²)/(100f)

と代入すると、B には独立な二本の有理的右核がある。
自由二行が単位行列であり、100f を掛けた B との積が恒等的に零であることを検証した。
従って B の階数は高々7。この上界は H_* の既約性によりその全閉包に延長する。
上三角構造から rank E≤4+7+5=16、最高 q-Jacobian は階数32以下、全 chart Jacobian は33以下である。

指定点は重み一の保存順 (2,3,…,17) に

    u12=u13=0, a=−621/220, f=−55

を課す。他の core は b=6,c=11,d=12,e=15である。
この点の全階数は正確に33なので、上記の一般上界は等号となる。

射影 Q=xw∂y∧∂z の五次元安定化群が H_* を保つことを全 Lie 方向で検証した。
従って joint image 次元は10+12−5=17。
四つの source 制約方向への群微分は指定点で四次 minor −15654735000/11を持つ。
よって β 像の次元は16で、一般 β 上に一次元のより低階数部分が残る。

## 2. 九変数の横断商

指定点の接次元は12である。
固定 β の実際の二平面型三次元部分 C は滑らかで、v0,v1,v3 が独立パラメータになる。
九変数の横断商 A を取り、二次から四次までの実際の非斉次残余を構成した。

| 検証 | 結果 |
|---|---:|
| QQ 上の横断二次障害階数 | 24 |
| 五次初期関係1287次 minor、mod32003 | 17442 |
| 実際の関係650次 minor、mod32003 | 17962 |
| t を追加した651次 minor、mod32003 | 2191 |

入力分母と全消去 pivot は32003で可逆である。
厳密な二次階数24により、三次初期式を得る modular 消去は QQ の消去へ持ち上がる。
五次 minor は m_A⁵=0を保証する。
二次・三次・四次単項式は45、165、495個で、合計705個。
従って650次 minor は長さ上界

    length A≤1+9+705−650=65

を与える。
各残余行の A2+A3+A4 を一つの非斉次関係として保持し、次数ごとに別の式へ置き換えていない。

## 3. 同じ C の一般点と有限自由性

β を変えず、Q1=(xw+x²+w²)∂y∧∂z を取る。
元135式から全階数35、二次障害階数5、共通 Hessian radical 次元3を確認した。
従って同じ C の一般点には普遍三次下界65を適用できる。

特殊横断上界65と一般下界65から、完成局所環 S は R=C[[v0,v1,v3]] 上自由階数65。
I=ker(S→R) は自由階数64で、一般点の I⁴=0、It=0、t²=0が torsion-freeness により降下する。
元の関係階数が正確に650と決定した後、651次 minor で t≠0を得る。
従って

    S_red=R、I⁴=0、0≠t、It=0、t²=0、S/(t) は自由階数64

となる。横断 Hilbert 関数は (1,9,21,34)。
接次元がさらに一つ跳んでも長さ65は保たれるが、graded pieces の自由性は仮定しない。

H_* の十二パラメータも動かした相対既知部分は指定点で滑らかな十五次元部分である。
同じ有限自由性の議論を相対完成環へ適用できる。
Sp4×H_*→W16 は上の四次 minor により smooth なので、
全135同変性と忠実平坦性を通じて t²=0が ambient 局所環へ降下する。
これにより十七次元像の非空開部分が飽和で除かれる。

その補集合は十六次元で W16 を優越し得るため、全一般 β 曲線が除去されたとは結論しない。
より低い rank locus の別の部分、交点・端点は引き続き個別に処理する。
