# primitive 一次部分に付随する楕円五次曲線

2026-11-01。複素数体上で論じる。一般一次部分の **内在的な曲線** を構成する。
Poisson 延長の復元、楕円二成分の次数、全 S61 の尽くしはまだ結論しない。

## 1. 定理と構成

4次元シンプレクティック空間を `(V,Ω)` とし、
`W={β∈V*⊗Λ²V*: dβ=0, ΛΩβ=0}` を16次元の primitive 閉一次2形式の空間とする。
`Q=LG(2,V)⊂P(Λ²₀V)≅P⁴` は滑らかな3次元二次曲面、`U` はその階数2普遍部分束、
`O_Q(1)=det U*` とする。線形写像

\[
 W\longrightarrow H^0(Q,E),\qquad E=U^*\otimes\det U^*,\qquad
 s_\beta(\Pi)(x;v\wedge w)=\beta_x(v,w),\quad x,v,w\in\Pi
\tag{1}
\]

は同型であり、各点での評価は全射である。十分一般の `β` に対して零点スキーム

\[
 C_\beta=Z(s_\beta)\subset Q\subset\mathbb P^4
\tag{2}
\]

は滑らかで連結な楕円正規五次曲線である。この構成は `Sp(V,Ω)` と可換であり、
βの非零スカラー倍で曲線は変わらない。

ここで楕円曲線・spinor 束の一般論自体の新規性は主張しない。S61 の第一ジェットから
(1)を取り出し、無限遠の一次障害と接続することが今回の研究上の用途である。

## 2. 評価、切断空間、一般の滑らかさ

代表平面 `Π₀=〈−e₂,−e₄〉` を取る。保存済み S61 座標を primitive gauge に直すと

\[
 \beta_y(-e_2,-e_4)=-(u_{26}+u_{51}/5)y_1+u_4y_2
 +(-u_{14}+4u_{49}/5)y_3+u_5y_4. \tag{3}
\]

したがって平面への制限の二係数は独立な `u4,u5` であり、評価写像は全射である。
Sp4 の推移性から全平面で全射となる。

切断写像は単射でもある。`sβ=0` なら全 isotropic pair で `β_v(v,w)=0` となり、
既存の infinity-flags ノートの単射性補題が β=0 を与える。今回のコードは別に、
下記の Plücker 二次式を二次曲面の式で剰余化し、その β係数行列の階数16を厳密に確認した。

`S=U*` は `det S=O(1)` の規約の spinor 束であり、
`0→S*→O⁴→S→0`、`S*(1)=S`、`h⁰(S)=4`、`H¹(S)=0` を満たす。
この列を1回捻ると `h⁰(S(1))=4·5−4=16` であり、(1)は同型となる。
これらの既存の束の事実は Ohno, *Nef vector bundles on a quadric threefold with first Chern class two*,
§3 の規約と一致する（同所は Ottaviani の結果も明記する）。
[一次資料本文](https://www.cambridge.org/core/journals/proceedings-of-the-edinburgh-mathematical-society/article/nef-vector-bundles-on-a-quadric-threefold-with-first-chern-class-two/A30A0DFEB6D7BA030E24F4B8D72DD982)。

評価が全射なので incidence `{(β,Π):sβ(Π)=0}` は Q 上の階数14ベクトル束であり、
滑らかで既約、次元17である。以下の非零な `c₂(E)` から切断は必ず零点を持つ。
したがって W への射影は全射であり、標数0の generic smoothness によって一般の零点は
滑らかな純1次元である。単なる特殊化での点数や階数だけを一般の滑らかさの証明には使わない。

## 3. 次数、連結性、種数、線形正規性

`H=c₁(O_Q(1))`、`ℓ` を直線のサイクルとすると `H²=2ℓ`。
普遍列 `0→U→V⊗O→U*→0` から `c₁(U*)=H`, `c₂(U*)=ℓ`。
よって

\[
 c_1(E)=3H,\qquad c_2(E)=c_2(U^*)+Hc_1(U^*)+H^2=5\ell.
\]

非零な第二 Chern 類は nowhere-zero 切断を排除し、一般曲線の次数は5である。
`K_Q=O(-3)` なので正則切断への随伴公式は `K_C=O_C` を与える。

連結性はここでは省略できない。Koszul 列は

\[
0\longrightarrow O_Q(-3)\longrightarrow E^*=U(-1)
 \longrightarrow I_{C/Q}\longrightarrow0. \tag{4}
\]

`H⁰(U)=0` は全てのラグランジュ平面に共通する非零ベクトルがないことから従う。
普遍列を −1 捻った `0→U(-1)→O(-1)^4→U→0` と
二次曲面上の直線束の中間コホモロジー消滅から `H¹(U(-1))=0`。
また `H²(O(-3))=0` なので (4) は `H¹(I_C)=0` を与え、`H⁰(O_C)=ℂ`。
従って滑らかな C は連結、既約、種数1である。

(4)を1捻ると `0→O(-2)→U→I_C(1)→0` であり、`H⁰(I_C(1))=0`。
従って C は P⁴ の超平面に含まれない。種数1・次数5から `h⁰(O_C(1))=5` で、
周囲の5個の一次式は完全線形系を与える。これが楕円正規五次曲線である。

## 4. 五つの Pfaffian による完全に線形な入力公式

Plücker 座標を `(a,b,c,d,e)=(p12,p13,p14,p23,p24)` として `p34=−a` と置く。
行列と共変ベクトルを

\[
 P=\begin{pmatrix}0&a&b&c\\-a&0&d&e\\-b&-d&0&-a\\-c&-e&a&0\end{pmatrix},
 \quad A_k(P)=\sum_{i<j}\beta_{ij,k}P_{ij},
\]

とする。Q の式は `q=Pf(P)=−a²−be+cd`。Q 上では `ker(P)=Ann(Π)` なので
`Cβ` は **スキームとして** `q=0, P A=0` で定義される。
実際、Q 上の束写像 `V*→U` の核は `Ann(U)` であり、この四式は階数2の切断の零点を表す。

\[
 D=\begin{pmatrix}0&-a&-e&d\\a&0&c&-b\\e&-c&0&a\\-d&b&-a&0\end{pmatrix},
 \qquad M_\beta=\begin{pmatrix}D&A\\-A^t&0\end{pmatrix}.
\]

この符号では `P D=−q I₄` であり、0始まりの番号を使った符号付き最大 Pfaffian
`((-1)^i Pf(M without row/column i))_{i=0}^4` は正確に `(P A,q)` である。
全 β を変数のまま保持した恒等式 `Mβ·(P A,q)^t=0` も検算した。
この公式は Fisher 型の種数1不変量計算、楕円 Poisson 族の元の曲線との照合に直接入力できる。
その照合や j 不変量の一致は本ノートだけでは主張しない。

## 5. 旗への持ち上げと無限遠解析への意味

各平面に対する制限前の共変ベクトル `Aβ(Π)=β(·)(v,w)` は
`V*⊗det U*` の切断である。(3)の四係数は独立なので、W からこの階数4束への評価も全射。
従って `{(β,Π):Aβ(Π)=0}` は次元15であり、射影的な Q 上の閉 incidence の W への像は
真の閉部分集合である。一般の β では `Aβ(Π)` はどの平面でも零にならない。

Cβ 上では `Aβ(Π)∈Ann(Π)` であり、シンプレクティック同型で得る線
`〈J Aβ(Π)〉` は Π に含まれる。この線を v とする旗は
`β(·)(v,w)∝−Jv` を満たし、一意である。したがって一般 β についてこの
**内在的な強化旗条件** の零点は Cβ と同型である。

別ノートの S61 一次障害計算では、代表旗 `q=u38=1` の未飽和 incidence 条件は `u4=0`、
さらに斉次化変数 t を一様化変数とする一次持ち上げの70本の重み4条件の根基は
`(u5,u14−4u49/5)` となる。(3)はこれを上記強化旗条件に同定する。
**この計算だけで真の射影閉包の無限遠を決定してはいない。**
特に `t=s^e (e>1)` の分岐した弧は一次接方向だけから排除できず、高次障害も残る。
