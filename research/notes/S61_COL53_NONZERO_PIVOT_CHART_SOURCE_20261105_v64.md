# 固定 row6・col53 による一個の追加汎用ピボットの存在（SOURCE のみ）

両端 H 面の独立した符号付き係数再計算が PASS し、指数 (-3,0,6,-1,10) の係数 241815/134217728 が確認された。この係数は、現在の係数側 **全1203ノード・根1202の有限式 F11** の係数である。411項の H=-3 面そのものを F11 と取り替えない。

受理済み係数側恒等式は、現在の full167×14 における固定 entry を

    p = P7 * F11 / (U² * F10),
    P7 = (5q0+1)(q0+1) = Q R,   U = Q⁴ R² E

とする。二つの第9段式と UF10=C10*N9[58,56] を代入した反対称恒等式を、独立な自由記号の多項式で再確認した。P7 は既存パラメータ単元であり、F9 は約分表現に現れなくても歴史的 chart とその補集合を残す。F10 は既存の317項非零証明と同じものを使う。

非零係数があるため、F11 は係数体 QQ(H,L,s0,q0,t0) で非零である。旧 chart 内の D(F11) では p は単元で、逆元は U²F10/(P7 F11) と定義できる。追加するのはこの一つの full-DAG スカラーの逆だけであり、既存および新しい補集合はすべて未解決として残す。新しい因数分解・既約性・互いに素性は仮定しない。

現行 manifest による full167×14、top101×14、選択14×14、追加RHS87本、零制約RHS66本を照合した。復元文にある旧49単元・制約10単元・型付き10単元から、既に69個、今回の存在証明は型付き第11個／元83列の第70個に相当する。row6 と col53 を一個ずつ除いた場合の寸法は full166×13、top100×13、選択13×13であり、87本と66本は残る。選択正方行列を full の cokernel と同一視しない。

これは一個の追加ピボットを使えるという SOURCE 存在証明である。新しい Schur 行列、全列応答、RHS値、逆行列係数はまだ更新・評価していない。形式的な行列とRHSの同じ行演算および逆代入式だけを記録し、全体の逆や exhaustion は主張しない。P290 は既存の一回を維持する。
