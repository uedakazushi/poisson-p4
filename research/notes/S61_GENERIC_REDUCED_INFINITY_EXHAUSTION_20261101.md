# 135式の一般一次部分上の被約無限遠：全型の帰着

2026年11月1日。対象は全135式を q次数二へ斉次化した未飽和スキームの t=0 部分。
以下は複素数体上の被約点集合についての主張であり、飽和後のアフィン延長を分類するものではない。

## 結論

W16 のある非空 Zariski 開部分では、全被約無限遠点は

1. 零モジュラーの R0 正常形群、
2. 最小冪零型 M0、M1 の正常形群

だけで尽くされる。R0 の全正常形は `S61_R0_GENERIC_EXHAUSTION_20261101` と
`S61_R0_UNIFORM_VERTEX_20261101` の根基表に、M0/M1 は修正済み
`S61_MINIMAL_VERTEX_EXHAUSTION_20261101` の有限 chart 表に記述される。
後者には四つの追加 baseline 直線を必ず含める。
この二項目は大域既約成分の個数を表さない。

## 全点被覆の証明

最高重み四式は、q が J と compatible な斉次二次 Poisson テンソルであることを要求する。
そのモジュラー行列は sp4 に属するので、零、非零冪零、非冪零に分かれる。
旧 Q45 分類の全点正常形を依存として保持し、各場合を次のように処理する。

| モジュラー型 | 一般 β についての結論 | 証明 |
|---|---|---|
| 非冪零、半単純および混合型 | β像の次元15以下なので除外 | NONNILPOTENT_INFINITY_EXCLUSION、同REVIEW |
| 正則冪零 | β像の次元14以下なので除外 | OTHER_NILPOTENT_INFINITY_EXCLUSION、SMALL_NILPOTENT_INFINITY_REVIEW |
| 冪零 Jordan (2,2) | β像の次元15以下なので除外 | NIL22_INFINITY、同REVIEW |
| 最小冪零の六次元固定トレース開層 | β像の次元13以下なので除外 | OTHER_NILPOTENT_INFINITY_EXCLUSION、SMALL_NILPOTENT_INFINITY_REVIEW |
| 最小冪零の二つの九平面 M0/M1 | 全点が指定した有限 chart の像に入る | MINIMAL_VERTEX_EXHAUSTION、同REVIEW |
| 零 | C0/L0 の R0 外は β像の次元14以下で除外、R0を全点分類 | ZERO_MODULAR_INFINITY_REVIEW、R0_GENERIC_EXHAUSTION |

非冪零の証明には、最初の正常化で落ちる A=0 の半単純境界を追加済みである。
一般階数12、四例外値でも階数11の全一パラメータ族を検証したため、その境界も残らない。
最小型では、一般解の約分済み分母だけを調べる方法では不十分だった。
実際の三角線形系の pivot の零点を調べ直し、M0 の k=−1/3,−2/3 と
M1 の k=−4/9,−5/9 に残る四直線を加えた。
これらは vertex incidence の余次元一に現れるので、一般 β の議論でも省けない。

最小型で残る関数体計算の例外は、正規化前の intrinsic な悪い vertex locus として扱う。
滑らかな正規化表示の全逆像が余次元二以上の例外集合に含まれることから、
その次元は17−2=15以下となる。q ファイバーの次元が増える可能性を、
vertex-base の像の評価と混同していない。

各除外は有限個の次元15以下の構成可能な像に帰着する。
その閉包の和を W16 から除き、他の正規化に必要な既証明の開条件と交われば、
非空な基底開部分が得られる。その上では表の全場合が処理され、全点の被覆が従う。

## 残る局所問題

これは未飽和無限遠の被約台の尽くしである。未知のアフィン成分を除外した証明ではない。
旗型、二平面型、非二元型、最小型の正次元無限遠族には、局所環の公式が変わる
交点・端点・共鳴層がある。一般点で t を消せても、その例外層が W16 を優越する可能性がある。
従って全無限遠の飽和による除去と、全一般アフィンファイバーの有限性・五点による尽くしは別に必要である。

ここまでの個別成果では、旗型・非二元型・最小型の指定開部分、
一般に有限な M0 axis 成分、および二つの非二元共鳴交点 stratum が処理された。
他の rational tail と二平面型の例外層は引き続き扱う。
複素射影四空間の Poisson 成分数の下界57は変更しない。
