# 深部 binary chart の三次制約を二変数へ降ろす

2026年11月1日。対象は `S61_BINARY_DEEPER_SEVEN_SLICE` と
`S61_BINARY_DEEPER_TRIANGULAR_CHART` の七変数表示である。
本ノートはその**宣言済み有理法線枠における三次初期制約**について述べる。
四次上界、全深部層の自由階数65、全S61の尽くしは主張しない。

## 1. 対象と結論

七変数を `(e,d,p,q,r,h,k)` とする。一次jetの非零となり得る座標は

    u4 = 3(1−2e)(15e+8)/500,  u14 = (e+1)/5,
    u25=p, u26=q, u27=r, u35=1, u36=d, u37=h,
    u48=k, u49=e, u50=−5,

であり、u5=u12=u13=u34=u51=0である。固定binary無限遠点、45変数chart、
33個の線形消去式と九つの横断法線列は前証明書のものを使う。
各法線列の分母を払う可逆な対角座標変更を施した枠をT、法線座標をzとする。
三つのbinary底方向を横断切断した形式方程式を考える。

K=QQ(e,d)、K'=K(p,q,r,h,k)、S=K[z0,…,z8] と置く。
二次初期式が生成する次数二の空間 I2 はK上で定義され、次元24である。
新しい厳密計算により次が成り立つ。

1. 一次倍の空間 M3=S1 I2 のK次元は129であり、dim(S3/M3)=36である。
2. 元135式の二本の追跡可能な組合せから、真の三次初期制約 C92,C134 が得られる。
3. その剰余類は `(S3/M3)⊗K K'` の中でK上へ降りる。すなわち、五つの補助変数
   p,q,r,h,kへの依存は、二次初期式の一次倍を差し引くことで全て消える。
4. この二つのK上の剰余類は一次独立である。

従って、二次24式とこの二つの三次制約から成る既知の初期ideal部分の
次数0,1,2,3のHilbert関数は `(1,9,21,34)` である。
その和が65であっても、次数四以降を消したことにはならず、横断長≤65はまだ従わない。
また、他の133式やsyzygyがさらに独立な三次初期制約を与えないことは本計算では証明していない。

結論はK'上、または使用分母が全て可逆な非空開上のものである。
この開の補集合を全てproperなβ像へ落としたとの主張も含めない。
特に、七変数表示の一般点の結果を、一般β上の深部ファイバーの全点へ外挿しない。

## 2. 元式から三次初期制約を追跡する

固定点を原点として通常二次斉次化した135式を

    F(y)=J y + H(y,y)

と書く。Hは元の通常二次式から得られる対称双線形写像であり、
この規約では三次項は 2H(Tz,w2) となる。
前証明書の33行をEとし、J_E U=1、JT=0を満たす枠を使う。
選択式を形式的に解いた二次liftは

    w2=−U H_E(Tz,Tz)

である。残余の二次・三次項は、それぞれ

    A2=(1−J U E)H(Tz,Tz),
    A3=2(1−J U E)H(Tz,w2)

となる。ここでEは行選択写像でも表す。
producerはこのJ,T,U,Hを保存された結論から仮定せず、前証明書の枠を使い、
元134式とG6の全135式からHを再構成する。

係数分母Duを払った二次行を Ai、各行の多項式contentをgiとし、
primitive行を ai=Ai/gi とする。係数入力にはi=92,134について

    ai = Σ(j∈B) cij aj

の二組だけを保存する。Bは既存の24行basis候補である。
これらは信頼する定理ではなく検査対象であり、共通分母を払った45成分全ての
多項式恒等式をFLINTで確認する。
したがって、実際の形式残余式の組合せ

    Fi/gi − Σ cij Fj/gj

は二次まで消え、その三次部分は真の三次初期制約である。
単に三次係数の行空間から便宜的な行を選んでいるのではない。

## 3. 二次倍を除く操作の正当性

二次行空間の24行RREF候補Rを別の係数入力として与える。
そのpivot列は単位行列であり、全53非零primitive行について

    ai = Σ ai,pivot(j) Rj

を、全七変数を残した多項式恒等式として検証する。
元の24行minorの非零性も元式の標本計算で確認するので、Rの行空間とI2は一致する。
Rの係数はKだけに属する。

w2をI2のベクトル倍だけ変えたw2'へ置き換えると、三次残余の差は
`2(1−J U E)H(Tz,w2'−w2)` であり、S1 I2に属する。
従って真の三次剰余類を変えずにw2の二次RREF成分を除ける。
この具体的な縮約liftについて、t成分が恒等的に零、残る成分のsupportが保存された17個だけ
であることを全変数で確認する。Tのt成分が零であることも明示assertする。
よってこの三次収縮では、Hのtを含む項を省いてよい。
この省略を四次計算まで自動的に拡張してはいけない。

全分母を払って計算した二本の三次候補は、補助変数について
`C0(e,d;z)+q Cq(e,d;z)+h Ch(e,d;z)+k Ck(e,d;z)` の形となる。
p,rへの依存およびそれ以外の補助単項式が現れないことは、生成した全係数で確認する。

## 4. 階数129と普遍的な補助変数消滅

Rの24行を九つの法線変数で掛けた216行を、三次単項式165列の行列としてK上で消去する。
全216行を厳密に処理した結果、非零pivotは129個であり、残りは全て零である。
前進消去だけでこの階数判定は完結し、巨大な完全RREFは証明書に必要ない。

最初の114個のpivot係数が全て非零有理定数であることを、FLINTの定数判定で明示的に検査する。
この114行だけで、Cq,Ch,Ckは二本とも厳密に零へ簡約される。
従って、全五補助変数の依存を消す恒等式はK上で成立する。
有限個の標本から補助変数消滅を推定したものではない。

生成・消去はQQおよびQQ(e,d)上で行う。
C++ backendの分数演算では分子・分母を多変数多項式として保持し、
乗算前の交差gcdと加減算時の共通分母gcdを払う。全演算が正確であり、浮動小数点を用いない。
数学的入力は元式、前証明書の枠、および検証される係数sidecarだけである。
ignored workの中間行列や探索結果を主producerの入力にはしない。

## 5. 二つの剰余類の独立性

別経路として、素数32003と

    (e,d,p,q,r,h,k)=(2,3,5,7,11,13,17)

で、元135式のHessianと通常の二次・三次implicit liftを直接再構成する。
元の二次24行minorは可逆であり、保存syzygyの特殊化がこのminorから一意に求めた係数と
一致することを確認する。全使用分母はこの標本で可逆である。

二次式の一次倍の階数は129、二本を加えた階数は131となる。
K上の一般階数が既に129と証明されているため、129minorが可逆な近傍で商は自由36である。
二本を加えた非零131minorは、分母を払った標数零のminorが非零であることを証明する。
従って二つの三次剰余類はK上で独立である。
この標本の役割は非零minorの証明であり、普遍恒等式や全ファイバーの尽くしの代用ではない。

## 6. 再現と残件

```
.venv/bin/python code/s61_binary_deeper_cubic_nuisance_20261101.py \
  --output /tmp/s61-binary-deeper-cubic.json
```

C++17、GMP、FLINT 3.5のヘッダとライブラリを使う。
`--flint-include`、`--mpfr-include`、`--flint-library` で場所を指定できる。
この環境の既定値は、既存Macaulay2 runtime用のローカルbottleから展開したものを指す。
producerは追加downloadや依存インストールを行わない。
コンパイルと大きな中間多項式は一時ディレクトリに置き、出力reportには
恒等式検査、正確な階数、独立標本のminor条件、全ソースと係数入力のSHA256を保存する。

次の課題は、真の四次初期式を追跡して横断長上界を証明し、さらにその分母・例外因子を
全て管理することである。現在の結果だけでは、深部層の全一般β除去もアフィン五点の尽くしも
結論しない。
