# H11 への相対拡張と非平方二平面型の残余有限性

全135式の同次数二次斉次化の無限遠で、非平方二平面型の点を取る。十分一般の一次ジェット β では、固定 β の射影chart Jacobian が階数34以下となる点のうち、ambient で t²=0 の開近傍が得られていないものは高々有限個である。既存の十八次元族の一般ファイバーは曲面なので、これを単に一つの一般点で調べても有限性は出ない。ここでは八つの nuisance 座標を全部保って相対化する。残余点数、空性、通常階数35の全点、平方の場合、全 S61 のアフィン部分は対象外である。

## 1. 八つの座標を残す正規化

Q₀=xw∂y∧∂z、u12=u13=0 とし、(a,b,c,d,e,f)=(u4,u14,u35,u36,u49,u50)、K=5c+f、L=5b−e とする。十八次元表示 K=0 の cL≠0 上で、Q₀の射影類を保つ対角 torus diag(x,x⁻¹,z,z⁻¹) は c を zc、L を L/x に送る。x=L、z=1/c により c=L=1、f=−5、b=(e+1)/5 とできる。

残る source H11 は、三つの core (a,e,d) と八つの任意座標

    u5, u25, u26, u27, u34, u37, u48, u51

の直積である。H8 の切断で零にしていた三座標に対し、ここでは方程式を課さない。ここで Q₀-section は u12=u13=0 の全一次部分で全135最高式を満たすという既存の普遍式を使う。全135式を保つ [収縮作用](S61_BINARY_NUISANCE_CONTRACTION_20261102.md) における八座標の重みは順に (2,4,2,4,2,2,2,2) であり、六 core 座標の重みは零である。特に unipotent 群で三座標を零にできない core も含む。

## 2. 相対消去と像の次元

[横断上界定理](S61_BINARY_HYPERPLANE_TRANSVERSE_CODIMENSION_20261102.md) の開 U は三coreの補集合が次元1以下で、H11 の nuisance 零sectionも H8 の零sectionと同一である。従って U の各零section点で、同じ三切断による実際の横断長は65以下、実在する二平面三次元部分への微分は可逆である。この上界だけを先行結果から使い、全 H11 を保持した相対完成環を改めて考える。

U の零nuisance各点では、平面曲線の二式の平面方向微分が階数二であり、選択切断は三接方向上で可逆である。八nuisanceを自由に加えても指定点でのこの微分は同じであり、相対Jacobian基準によって実在部分はその近くでH11上相対滑らかである。三つの切断座標と十一の底座標がその完成環 R の正則な14座標になる。Sp4×H11→W16 は既知の優越 H8 表示を含み優越する。一般点で実在する二平面族は幾何的既約な曲線上の P² 束の開部分なので、引戻しの優越成分は一つで、今の section の滑らかな実在部分はこの成分上にある。従ってその一般点の長さ下界65と t²=0 が使える。全相対完成環 S にこの十四座標から R→S→R の分裂がある。S/m_R S の長さは65以下なので、完備性から S は R 上有限であり、生成元65個で足りる。同じ実在成分を定める素ideal I に沿う長さ下界は完成後も保たれる。実際、完成環の I の商が整な R なので、I の拡大を一般点で局所化する平坦写像の閉ファイバーは剰余体の拡大である。したがって一般階数65以上がこの全射の階数を使い切り、自由加群 R^65 の中の核は零となる。よって R 上の torsion-freeness から t²=0 が S に降りる。H8 局所環を H11 へそのまま持ち上げる議論ではない。

完備化から元の有限型局所環へ降ろし、(t²) の支持を Q₀-section に引き戻す。これは閉かつ収縮作用で不変である。八座標が正重みなので、U 上では零sectionに入らないこの閉集合は全 nuisance 値に対しても空。さらに Sp4×H11→W16 は十分一般の β 上で滑らかであるから、全135式の同変性と忠実平坦降下によって該当する ambient 局所環でも t²=0 となる。

不適格 core の集合を Z とすると dim Z≤1 である。Q₀を固定する三次元可換 unipotent 群 N は、K=0 上で六つの core と u12=u13=0 を保つ。producer は四次元表現 I+ΣtᵢAᵢ の加法性・忠実性・symplectic 性と、一次ジェット表現の有限多項式指数によるこの恒等式を直接確認する。従って Sp4×(Z×A⁸)→(β,[Q]) の各ファイバーは自由な作用

    (g,b₀) ↦ (n⁻¹ g,n* b₀),  n∈N

による三次元軌道を含む。ここでは joint 写像を (g,b₀)↦(g* b₀,[g*Q₀]) の pullback 規約で記しており、(n⁻¹g)* (n* b₀)=g* b₀ となる。二形式の有限 pullback と Q₀ の固定は元の四次元行列表現で直接検証した。b₀ 自身の安定化群が零である必要はない。像閉包の次元は高々 10+1+8−3=16。よって十分一般の β 上に出る残余点は高々有限個である。

## 3. 他の階数降下表示

K=0 かつ L=0 の β 像は [深部の被約表](S61_BINARY_DEEPER_REDUCTION_20261101.md) で次元15以下と証明済みである。K=0 かつ c=0 なら f=0 となる。c=f=0 の joint 像閉包は既約十七次元であり、[端点定理 §3](S61_BINARY_ENDPOINTS_20261101.md) の ambient t²=0 の非空開がその中の u14=0 表示の点を含む。従ってこの十七次元像閉包全体も同じ開と非自明に交わり、開の補集合は次元16以下である。十六次元の端点表示の除去結論をそのまま十七次元全体へ延ばしていない。K と L を交換する有限 symplectic 対称性により、L=0 表示にも同じ結論が成立する。

[全階数降下表](S61_BINARY_RANK_DROP_COVER_20261101.md) の残る表示は、有限対称性を除くと十七次元の線形族と十七次元の二次完全交叉族である。いずれも幾何的既約で、[二つの相対完成環](S61_BINARY_CODIM_TWO_FORMAL_20261101.md) が各像と交わる非空な ambient t²=0 の開を既に与える。その補集合も各々次元16以下である。有限個の像のうち β を優越しないものは一般 β に現れず、優越するものも一般ファイバーは零次元以下。有限型の零次元ファイバーの点集合は有限である。以上は全非平方型のうち**階数34以下**の点についての有限性である。
