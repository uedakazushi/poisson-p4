# 自由 M0 基線の旗端点：十次までの有限体初期関係

2026-11-01。**有限体での探索結果であり、全初期イデアルとの一致も、
標数零での飽和除去も主張しない。** 点は
`S61_MINIMAL_FLAG_ENDPOINT_TABLE_20261101` の `free_M0`、
実在する長さ4の商は `S61_MINIMAL_FREE_FLAG_FLAT4_PROBE_20261101` と同じである。

## 1. 計算対象と結果

全135斉次化式の指定点の Jacobian 階数は34である。
34個の変数を形式的に消去し、11個の接変数に残る式を十次まで求めた。
基礎体は \(\mathbf F_{32003}\)。接基底の順序は旧基底 \(T_0,\ldots,T_{10}\) から

\[
(T_3,T_4,T_5-T_1,T_6,T_7,T_8,T_9,T_{10},T_0,T_2,T_1)
\]

へ変えている。以下の \(v_0,\ldots,v_{10}\) はこの順序である。
真の十次切断環の累積長 \(\dim S/\mathfrak m^{d+1}\) は、\(d=0,\ldots,10\) について

\[
1,12,66,234,625,1365,2568,4335,6745,9843,13683.
\]

十次までに得た全初期関係が生成する斉次イデアルを \(J_{10}\) とする。
CAS による厳密な有限体計算では
\(\dim k[v]/J_{10}=3\)、次数は70である。
その最小素イデアルは、実在する旗3次元族の接3平面、
実在する非平方二元型3次元族の接3平面、実在する M0 基線の接直線に一致する。

三つの部分を分離する飽和は

\[
B_F=J_{10}:(v_9(8v_8+97v_4))^\infty,\quad
B_B=J_{10}:(v_9v_2)^\infty,\quad
D=J_{10}:(v_0+2v_4)^\infty.
\]

各商の次元・次数は順に \((3,5),(3,65),(1,4)\) である。
\(D\) は、別途厳密に構成した実在 flat4 商の初期イデアルそのものと一致する。
しかし

\[
E=(B_F\cap B_B\cap D)/J_{10}
\]

は **次元2、次数31** であり、有限長ではない。
この差を無視して、以前の有限長 torsion の補題を適用してはならない。
\(E\) の高次変形、全初期イデアルとの差、相対的な制御が残る。

探索中には、六・七・八・九次の初期関係による最高次元・次数が
それぞれ \((4,8),(4,3),(4,1),(3,77)\) となり、九次の旗部分だけが次数12であった。
十次でこの部分が次数5へ落ちた。
基底 \((v_8,v_9,v_{10})\) を零にした横断商は八次で長さ141に安定する。
この141は全局所環の自由階数ではない。
これら途中の数字は探索の経緯であり、正式報告の再現対象は十次と六次の独立比較である。

## 2. 有限切断標準基底

`code/truncated_local_standard_basis_20261101.cpp` は
\(k[v]/\mathfrak m^{D+1}\)、\(k=\mathbf F_{32003}\)、\(D<16\)、変数数15以下で計算する。
入力単項式順は全次数の昇順、その中で指数の辞書式降順であり、
既存 `truncated_local_ideal_io_20261101.py` がこの順で生成する。
任意の単項式順の入力を受け付けるとは主張しない。

各余りの最初の単項式を標準化し、既存の先頭単項式で割れる項を消去する。
消去は指定された有限単項式順の後方へしか進まないため停止する。
S-pair の最小公倍単項式の次数が \(D\) 以下の場合だけを処理する。
互いに素な先頭単項式の product criterion と、既に standard representation を
得た二つの pair による chain criterion を用いる。
非零余りを基底へ追加した pair も、その追加式を用いて standard representation を持つ。
\(\mathfrak m^{D+1}\) の境界との pair は全項が切断で零となり、追加条件は生じない。

先頭単項式の線形関係は pairwise な最小公倍単項式の関係で生成される。
全 pair の standard representation により、先頭項の相殺を後方へ移せる。
有限順でこの操作を繰り返すと、生成イデアルの任意の元の余りは零となる。
従って標準単項式は有限切断商の基底を与える。
計算途中の式は元の入力の組合せなので、出力された初期形は真の初期イデアルに入る。
ただし \(D\) を超える未知の初期関係がないことまでは証明しない。

係数演算は32bit整数に収まる正の積を用い、法32003で厳密に行う。
単項式倍した行をキャッシュすることで、旧方式で七次が240秒未完だった同じ問題の
七次が約3秒、九次が約70秒になった。十次 native 計算は約273秒だった。
全 native 出力は一時ディレクトリへ書き、open/flush と読取を検査する。

## 3. 検証と再現

六次では別アルゴリズムである旧疎 Macaulay 行空間の完全閉包と比較した。
全累積長が一致し、新基底のすべての初期行が旧次数別行空間に入ることも確認した。
これは単なる長さの比較より強い照合である。
標準基底法の product/chain/切断境界の論理は別 agent の概念監査を受けたが、
新 backend 全体の独立数値再実装による監査は未実施。

```
.venv/bin/python code/s61_minimal_free_flag_initial_probe_20261101.py \
  --maximum-degree 10 --m2-binary /path/to/M2 \
  --output /tmp/free-flag-initial.json
```

通常の Macaulay2 が必要であり、ローカルな一時 runtime のパスは producer に埋め込んでいない。
`--m2-binary` を省くと native の初期関係と六次比較までを計算する。
正式報告は native 初期行を gzip/base64 で保存し、非圧縮内容の SHA256 も保存する。
入力モデル、基底、係数の順序および CAS スクリプトを併せて再現できる。
正式 producer は全十次 jet の再構築、六次の別アルゴリズム照合、
十次標準基底と全 CAS assert を含めて506.91秒で PASS した。
保存報告の全入力 SHA256 と圧縮データの展開後 SHA256 も検査した。

この段階では、有限体の次数70を標数零の全完成局所環の階数へ自動的に移していない。
特に2次元の差 \(E\) を有限長として扱わず、固定点・相対基底・飽和の各段階を分けて進める。
