# CUT1 の非零残余と C3 長さ19の独立確認

独立に構成した CUT1 の24個の重みを使い、旧 C2 葉との積を作者と逆の順序で対合した。24個の項別積が一致し、残余は

`d=759275/1728 ≠ 0`

となった。既知 HB の第1座標は−3/5なので、二つの実際の四次源の小行列式は

`(−3/5)d=−151855/576 ≠ 0`

である。

追加の A4,B4 演算子は対合していない。A4=t を未計算の実際の座標を表す形式変数のまま保ち、行列 `[[-3/5,t],[0,d]]` と保存された逆行列を、通常の QQ[t] 上で独立に掛け合わせた。両方向の積が恒等行列となった。t の数値や冪零性は仮定していない。

SOURCE の全補正項の証明と既知 HB を合わせると、二つの四次初期関係は独立で、既知四次商の二方向を全て消す。従って **C3=C/ell³C の HF は (3,6,6,4)、m4C3=0、全長19** と確定する。DVR 切断から C のねじれ指数は (1,1,2,e≥3) と分かるが、長い指数 e は未確定である。

これは C 自体の全長、真正 C[ell] の作用、元の H0 や nil ideal の長さ・立方・指数の結果ではない。新しい source、物理係数、IFT、gauge、jet、パラメータ点は用いていない。三つの τAB 応答の fallback は未計算のまま、この C3 結論には不要となった。
