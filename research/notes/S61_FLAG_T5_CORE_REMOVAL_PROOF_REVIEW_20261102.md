# T5通常旗coreの除去に対する証明監査

r=−6/25 の二切断特殊環の孤立成分、対応する非零T5点の周囲長23、および相対冪零性への移行を点検した。主報告の83入力ハッシュを照合した。元135式からの標準基底と高次行列は主証明書に依存する。

孤立因子の parameter x4,x1 に torsion がなく、各 parameter を零とした商は有限長である。次数付き中山と parameter 作用の完全列により、それぞれ自由階数5,7である。根基は一本の滑らかな直線で、一般ファイバーは一つの Artin 局所環である。底で torsion のない全環に対し、一般点で非零因子となる元は全域で非零因子となる。これにより記載の二因子は primary である。二曲線の交叉長6、残る有限加群の長さ78、最高重み6により原点因子 I+m⁷ を加えた等号が従う。実際の T5 曲線は二番目の還元直線の全てを与える。

非零点の18座標は実在T5成分の局所座標である。全周囲横断の Hilbert 関数 (1,3,5,6,5,3) による長さ23と、同じ成分の一般長23を個別に使うことで、18変数底上の完成環は自由23となる。一般局所因子の極大イデアルの23乗が零であるため t²³=0 が全周囲へ降りる。固定ジェットの二切断での長さ7はこの23の代用に使われていない。

M=t²³S の特殊化の支持を元の相対環で調べる。旗側の一般点では平坦な実D5商と特殊化の核の消滅、T5側では非零点を含む上記周囲開によって、Mがそれぞれ消える。従って M の底特殊化は原点に支持され有限長であり、完備中山により M は底上有限となる。底重みが非正、t の重みは正なので、有限個の斉次生成元に現れる最大重みを越える t の冪は零である。群方向・補償の二小行列式と正nuisanceの収縮、smoothな源での忠実平坦降下によって、指定T5旗coreの全一般β点へ及ぶ。全冪指数を23に限定する推論は行われていない。
