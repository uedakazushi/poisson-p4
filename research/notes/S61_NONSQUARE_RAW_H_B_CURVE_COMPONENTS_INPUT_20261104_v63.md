# 二つの共通根曲線成分での小さい厳密入力

Gの因子Q（aモニック2次）とL（aモニック1次）のそれぞれについて、a⁵H,g,kを
aのモニック除算だけで還元する。全6個のquotientとremainderの恒等式を保存する。
未知係数の逆元、field GCD、subresultant、終結式、GB、点評価はまだ使わない。

L成分のgeneric fieldはQQ(e)。Qはaモニックかつ既約なのでQQ(e)[a]/Qは2次体。
次にdについてfraction-free pseudo remainderを計算する場合は、この小さな
還元入力を使える。各leading coefficientの非零性をgeneric fieldで確認し、
消失する有限残余を保持しなければならない。

定数d項が全て0なら、d=0が三本共通の根であることまでは分かる。他の共通根が
無いとは限らず、FULLU内の共通根の除去にはgeneric GCD等の別の証明が必要。
L上のB=(3e−2)((3e−2)d+20)も、候補境界根を同定するための恒等式であり、
その根だけしか無いという主張ではない。
