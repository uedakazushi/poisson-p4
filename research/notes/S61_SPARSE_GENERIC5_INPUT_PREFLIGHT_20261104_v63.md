# 一般betaの疎な五変数入力と歴史S61座標への正確な変換

これは一般betaの網羅問題へ戻るための入力事前評価である。42normal/J0行列への代入、Groebner基底、点や素数での試行は行わない。

## 原始betaと保存S61 gauge

原始beta16は、保存された24×16 Cartan基底での係数とする。歴史S61の重み1座標は u4,u5,u12,u13,u14,u25,u26,u27,u34,u35,u36,u37,u48,u49,u50,u51 である。定数Jにおける元の150×16再構成列からaffine一次項Lを取り出し、Lee成分alpha=d(L12+L34)/5を除いて原始形式を作る。その24×16係数行列MとCartan基底Kの間の A は K A=M を満たし、det A=36/625である。両方向の16×16行列を保存する。

この変換は原始一次部分の変換であり、歴史gaugeの物理一次項そのものをprimitive gaugeと同一視しない。perspective変換は重み2項も変えるので、q45に別gaugeの値をそのままコピーしない。本模型は歴史gaugeの45個の未知数をすべて残す。

受理済みの疎な六変数模型からlambdaを剥がすと、原始betaはb(H,L,s0,q0)+t0 e4となる。その歴史S61入力は

```
u4=-32/675, u12=-s0/54000, u25=-2400, u27=-t0,
u34=-45s0/16, u35=H*q0/48, u36=-30L,
u50=H*(s0+1)/48, u51=-160H/3
```

で、他の重み1座標は零である。9成分・10項しかない。

## lambdaを除く理由

元の61パラメータは重み1が16個、重み2が45個で、全134式は重み4が70本、重み5が64本である。元の全150係数再構成も同じ重みで同変である。物理変換はlambda²倍とdiag(1,lambda^-1,...,lambda^-1)のpushforwardの合成で、affine P(y)をP(lambda y)へ送る。

従ってepsilon=lambda*t0、q45=lambda²Q45により、lambda単元上で134式はlambdaの重み4/5の因子を除ける。これはSp4だけでlambda=1模型がW16を覆うという主張ではない。既存の優勢被覆はSp4とこのGmを両方使う。

Q51,Q52は全て重み1座標の二次式なので、このGmで保たれる。T01の普遍モデルもL,Nがbetaに線形、中心が二次で、cをlambda倍すればq=center+Ncがlambda²倍される。単一のアフィン3平面とその既知3+1+1被覆が生成的に保たれる。

## 134式と既知平面の入力サイズ

元の134式を上の9成分へ正確に引き戻し、45個のq未知数と5パラメータの疎係数を保存する。q次数は2以下である。q一次部については、各行のlex最大パラメータ単項式の係数行列を使う点を用いない階数下界も保存する。これが45未満なら、それを関数体上の正確な階数とは呼ばない。

既知平面のL51×20、N45×20、中心45座標、Q51/Q52も同じ入力へ引き戻す。固定18×18selectorの支持、次数、最大matchingを調べるだけで、その行列式や逆行列はまだ計算しない。Delta=det L_selected を名前付き条件として残す。

注意すべき点は、Sp4×源の優勢性だけでは、非不変な固定selectorが群変数を恒等元にした源上で非零であるとは言えないことである。既知3平面の生成的な存在と、保存された固定18行やq座標0,1,2のchartがこの切片で使えることは分ける。後者には別の正確な多項式検証または適応したchartの選択が必要である。

事前評価は3.533秒で成功した。134式はすべて非零のまま、元の97,809項から28,316項へ減った。q次数0/1/2の項数は1,012/9,868/17,436、各部分のパラメータ次数は8/5/2以下、一本の式は最大609項である。q一次行列は134×45、非零3,849成分、各成分最大10項。行先頭単項式による点を用いない39角minorの非零最高係数を保存したので関数体上の階数は少なくとも39、45以下である。正確な階数はまだ決定していない。

歴史gaugeのLee成分は、この源では `(0,0,H(s0+1)/240,-32H/3)` であり、primitive gaugeではない。元の40個のP0jのy二次係数はaffine三次尾部に対応し、重み3を持つ。元の全150係数の重みチェックはこの尾部も含み、重み1/2を同一視して省く操作ではない。

既知切断はQ51が49項、Q52が51項、中心が74項で、`3center=2Q51+Q52` を引戻し後も正確に確認した。L51×20は非零236成分・266項、N45×20は245成分・297項にすぎない。保存18角blockは103非零成分・122項で、支持matchingは18である。このmatchingは実際の行列式の非零を証明しない。

Lの元の全行をCartan重みで検算すると、選択18角行列式Deltaはbeta次数18、Cartan重み(-1,-3)を持つ。原始座標b4=t0を加えた支持条件を使うと、源でのDeltaは最大4,826項に覆われる。従って次の一回の記号的18角計算・二つの右辺の解・全51行の核確認は、巨大な16変数の汎用逆行列を展開する方法より具体的に小さい。今回はDelta自体や逆行列、42normal代入は計算していない。
