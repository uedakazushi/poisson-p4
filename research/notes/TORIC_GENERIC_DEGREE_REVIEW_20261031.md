# Toric一般次数3の独立点検

2026年10月31日。対象はprimitive一次部分への射影を、横断的な五超平面の
toric開部分に制限した写像である。一般次数3、順序付きcoframeでの次数360という
結論を、別の有理数消去計算と局所幾何の点検で確認した。
全S61の一般ファイバーの尽くしや、T39/T40の次数を意味しない。

## 1. 独立性と確認した証明書

`code/toric_degree_review.py` は `toric_algebra_degree.py` の関数をimportしない。
先に監査した20変数の乗法行列からトレース形式qと96個の交換子成分を再構成し、
二次単項式210個の係数行列の左核を直接計算した。
元実装の疎な行消去とは異なる方法で、以下を得た。

| 計算対象 | 独立計算の結果 |
|---|---:|
| 二次斉次部分の階数 | 45 |
| その定数左核の次元 | 51 |
| 得られる独立な一次式 | 18 |
| 独立に選んだ18列小行列式 | 480638149200/2401 |
| 残る変数 | x=c18, y=c19 |
| 残余96式の係数行空間 | 3次元 |
| 最初の3式のx²,xy,y²係数の行列式 | −41639/189823367328 |

元証明書の18個の96式に対する有理係数線形結合、pivot行列、全20変数の代入式、
残余96式、商代数の乗法行列、qの行列式のBézout恒等式も直接再検算した。
独立な一次式の基底を選んだためpivot行列式は元証明書の−1とは異なるが、
消去後の全20変数の表示と残余式は完全に一致する。

## 2. 特殊ファイバーのイデアルをそのまま計算する

残余96式は選んだ三つの二次式の有理線形結合であり、その逆の包含は自明である。
従って両者は同じイデアルを生成する。独立したGröbner基底計算で

\[
I_*=\left(x-\frac{13}{3430}y^2+\frac y7+\frac{14}3,
             y^3-\frac{24010}{13}y\right)
\]

を得た。これは候補点をいくつか代入した計算ではなく、特殊ファイバーの
全イデアルの計算である。三次式の判別式は
`55365148804000/2197 ≠ 0`。従ってこのファイバーは被約で長さ3である。

トレース形式の行列式をこの商で計算すると

\[
\det q\equiv
\frac{3904426812809}{28824005000000}y^2
-\frac{299231725939}{50421000000}y+\frac{784}{3125}.
\]

これは上の三次式と互いに素である。保存されたBézout係数でも積和1を確認したので、
三点すべてが `det q≠0` に属する。また、省略された交換子の右上ブロックも
この商で零となることを別に確認した。

## 3. 特殊点から一般次数への移行

**三点の特殊ファイバーがあるだけでは、一般次数3の証明にならない。**
ここでは次の有限性とétale性を併せて使う。

96式をF(β,c)とする。cに関する二次斉次部分はβによらない。
これを、一般の完全対称テンソルだけから再構成した二次部分と係数比較した。
従って特殊点で得た定数左核の18行は、すべてのβに対して二次部分を消去する。
結果はβに依存する係数を持つ、cに関する一次式である。

18列の行列式が零でない基底の開集合で、c0からc17までをx,yの一次式として
解ける。これは元イデアルに属する式による消去であり、解を捨てたり追加したりしない。
さらに残る三つの二次式の最高次係数行列式を可逆化する。
特殊点での値は上表の非零数なので、この二つの局所化は特殊点を含む非空開集合を与える。

この開集合ではx²,xy,y²を次数1以下の式で表せる。
任意の高次単項式は次数を下げる帰納法で1,x,yの線形結合になる。
従って、**全96式の商**は基底環上で1,x,yにより生成される有限加群である。
ここで特殊点における残余式の行空間次元3が、基底全域で一定だとは仮定していない。
三式が全域で与える次数低下だけで有限性は従う。

特殊ファイバーの三点はすべて半単純であり、`TORIC_ALGEBRA_FIBER_REVIEW_20261031.md`
§3の冪等元持ち上げによって、全半単純構造スキームは滑らかな16次元スキーム
GL4/S5である。各点のファイバーが被約零次元なので、ファイバー接空間は零。
始域と終域Wが共に滑らかな16次元であることから、微分は同型となり、写像は三点でétale。

有限写像では閉集合の像は閉じている。`det q=0` の像と非étale locusの像を
基底から除くと、特殊点を含むさらに小さい非空開集合上で写像は有限étaleとなる。
Wの非空開集合は既約なので、その次数は一定。特殊ファイバーの長さ3に等しい。
これで一般toric次数3が従い、自由なS5による順序付けを戻すとcoframe次数は
`120×3=360` となる。

## 4. 全S61への含意と限界

既知の全S61におけるT01の滑らかなétale開部分の補集合は次元15以下である。
その像の閉包と他成分との交叉の像を避ければ、上の三点はいずれも全S61で
孤立被約となる。T39,T40について既に得た各一つ以上の延長と合わせ、十分一般の
一次部分には少なくとも五つの相異なる孤立被約延長がある。

この下界から「全一般ファイバーは五点」「全一般ファイバーは有限」
「未知の支配成分は存在しない」のいずれも導かない。楕円型の次数、分岐因子、
特殊一次部分、判別式零の境界、全成分の尽くしは別の未解決問題である。
