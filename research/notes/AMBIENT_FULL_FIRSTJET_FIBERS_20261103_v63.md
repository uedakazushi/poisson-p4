## 定理と対象の scheme 構造

X=S61 とし、CA,CB を既知の二つの **被約19次元既約成分** とする。
以下で CA または CB のファイバーと呼ぶものは、この被約閉部分スキームの scheme-theoretic fiber である。
全 X のファイバー、primary component の選び方、他成分の混入や埋込み構造を決定する主張ではない。
π:X→W16 を一次ジェット射影、Z⊂W16 を既知の共通9次元被約閉像とする。
β の係数写像を Kβ:U→Λ²₀U* とし、

    Z3={β∈Z : rank Kβ=3}

と置く。これは非空の稠密開部分である。

**定理。**

1. CA×Z Z3 と CB×Z Z3 は、それぞれ Z3 上の Zariski 局所自明な A10 束である。
   各ファイバーは45個の q 座標空間に埋め込まれた affine10平面であり、
   一般点の次元だけでなく、全ての rank3 一次ジェットでの全ファイバーを記述する。
2. `(CA∩CB)×Z Z3` は scheme として Zariski 局所自明な A9 束である。
   特にこの開で交叉は被約である。
3. Z を優越する CA∩CB の既約成分は一つだけであり、その S61 次元は18である。
   これは v62 の27次元射影交叉成分 N の S61 部分に一致する。
   他の交叉成分は、存在すれば rank Kβ≤2 の上にある。

従って K=C(Z) 上の **全 generic fibers** は、それぞれ A10_K,A10_K、交叉は A9_K である。
代数閉包上だけの記述や、密な部分族だけの記述ではない。

## 1. 固定線での閉16次元模型

座標を (x0,x,y,z,w)、J=∂x∧∂y+∂z∧∂w とし、基準線を L0=C∂y とする。
六つの基底変数 τ,A,B,C,D,F に対し

    h2=A*x*z+B*x*w+C*z²+D*z*w+F*w²

と置く。h3(x,z,w) は x³ を法とした任意の三次式で、九係数を持つ。
一つの変数 r と合わせた十変数を η=(r,h3) と書く。

    fA=x0²+(5τ/2)x0*x+r*x²,
    fB=x0²−5τ*x0*x+r*x²,
    h=x0*h2+h3

を旧 PA,PB 普遍式へ代入する。両族は全16変数で Poisson で、値は常に J である。
従ってこの段階で値の非退化開や分母因子を追加する必要はない。
元の perspective 四方向を有限に除く正規化 N を行い、像を TA,TB⊂X とする。

固定した61座標を (β16,q45) と書くと、保存した行列により両写像は正確に

    β=B*u,                 u=(τ,A,B,C,D,F),
    q=qγ,0(u)+Mγ*η,        γ=A,B

となる。B は同じ16×6の定数行列で階数6、Mγ は45×10の定数行列で階数10である。
qγ,0 は u の次数2以下の多項式である。
両行列の定数左逆行列と定数左零化行列を QQ 上で保存した。
従って TA,TB は X の **閉部分スキーム** であり、それぞれ S6×A10≅A16 に同型である。
具体的に、β∈im B を課し、u=B_left β と戻してから

    Hγ (q−qγ,0(B_left β))=0

という35個の affine 線形 q 条件を課せばよい。
閉性は affine10平面の稠密性から推測したものではなく、この全方程式による。
元族の全パラメータ Jacobi と有限正規化により、これらの方程式で得る像は全て X に入る。

β の16座標から内在的な閉 primitive 二形式の24係数への定数変換も計算した。
その変換に B を掛けると、既知の共通六平面

    L0=τ*x*(∂x∧∂y−∂z∧∂w)
       +∂y∧(X_h2+(τ/2)*(z∂z+w∂w))

の β=−J L0 J と全係数で一致する。
従って既存の直線入射の S6 と、ここでの S61 座標の S6 は同じである。

## 2. 連結放物部分群による全族の不変性

G=Sp4、P=StabG(L0) とする。P は連結な7次元放物部分群である。
生の二次双ベクトル空間で、上の未正規化族は

    x0²J + DA,      x0²J + DB

という16次元線形部分空間の平行移動である。
G は x0²J を固定する。P の Lie 代数の全7基底について、
DA,DB の各16基底の実際の係数作用を全150係数で計算し、
それぞれの部分空間の中へ戻ることを正確に確認した。

線形部分空間の安定化群は閉代数群である。
標数零で、その Lie 代数が Lie(P) 全体を含み P が連結であることから、
Lie 不変性は P 全体の不変性を与える。
有限個の群点での標本一致を群不変性の根拠にはしていない。

値 J を保つ点固定の射影群は G と四次元 perspective 群 U の半直積である。
U は G で正規化され、四個の gauge 係数への応答行列は定数可逆である。
従って有限正規化 N は U の全体で定義された代数的な商断面となり、

    g⋆N(P)=N(g_*P)

は X 上の正則な G 作用を定める。特に TA,TB は P⋆ で保たれる。
正規化は一般点だけでなく、両16変数族の全域で定義される。

この作用は重み deg β=1,deg q=2 を保つ。
従って45個の二次座標について

    g⋆q=Ag*q+bg(β)

という形で、bg は β の二次式である。
Ag は原点の重み2接空間の G 表現なので可逆である。
従って固定 β におけるこの作用は q 空間の affine 自己同型であり、
affine10平面を affine10平面へ移す。

## 3. 閉入射を proper に射影する

P3=P(U)=G/P とし、次を考える。

    EA=G×^P TA,       EB=G×^P TB.

これは単に抽象的な商として使うだけでなく、

    Eγ={([v],u)∈P3×X : g^−1⋆u∈Tγ for any gL0=[v]}

という **閉入射** を与える。P 不変性により g の選び方によらない。
閉性は G→G/P の Zariski 局所切断で確認できる。
例えば v_y≠0 の chart で [v]=(r:1:s:t) とすれば

    g(r,s,t)= [[1,r,−t,s],
              [0,1,0,0],
              [0,s,1,0],
              [0,t,0,1]]

は symplectic で、g∂y=v、逆は g(−r,−s,−t) である。
その G 平行移動で P3 を覆える。この各 chart では、上の条件は
TA または TB の既知の閉方程式を正則な g(v)^−1⋆ で引き戻すだけである。

よって Eγ⊂P3×X は閉部分スキームで、X への射影は proper である。
ここで affine の TA,TB を射影化していない。proper 性は P3 因子の射影から得る。
各 Eγ は P3 上局所的に A3×A16 なので、滑らか・既約・19次元である。

## 4. 像は全成分と一致する

既存の一次像の直線入射を

    I=G×^P S6 ⊂ P3×W16

とする。その像は Z である。
rank Kβ=3 なら Kβ の核はただ一つの線であり、3次小行列でその線を正則に復元できる。
従って I|Z3→Z3 は同型である。特に Z3 は滑らか・既約・9次元である。

Eγ の proper 像を Yγ とし、その被約構造を取る。
Tγ は元の CA または CB の実族に属し、G 作用と正規化はその成分を保つので、
Yγ⊂Cγ である。
Z3 上では Eγ の旗線は正則な関数 ker Kβ として一意に復元される。
このため Eγ|Z3→Yγ|Z3 は、

    u ↦ (ker Kπ(u),u)

を逆射とする同型である。
Eγ|Z3 の次元は9+10=19なので、閉既約部分 Yγ は19次元である。
既知の被約既約成分 Cγ 自体も19次元だから **Yγ=Cγ** となる。
これが、密な明示族から成分全体のファイバーへ進むための閉性の議論である。

従って

    Cγ|Z3 ≅ Eγ|Z3 → I|Z3 ≅ Z3

は Zariski 局所自明な A10 束となる。
第2節の affine q 作用により、その各ファイバーは実際の45座標内でも affine10平面である。

なお、この同定は **被約成分** に対するものである。
全 X の同じ β ファイバーに他の既知・未知成分や非被約構造がないとは主張しない。

## 5. 全 generic 交叉と一意な優越成分

固定線の二つの族について、M_A,M_B の九個の三次 potential 方向は同じであり、
`rank[MA MB]=11` である。全61座標の交叉条件は正確に

    rA=0,       rB=25τ²/4,
    h3,A−h3,B=(5τ/2)*x*h2  (mod x³)

となる。
係数行列は定数で、右辺は基底変数の多項式としてその像に入る。
従ってこれらは全基底上の scheme-theoretic intersection を与え、
固定線では TA∩TB≅S6×A9 である。余分な基底方程式、重複したファイバー、冪零構造はない。

rank3 開では両成分の旗線は同じ正則な ker Kβ なので、
CA∩CB の交叉を同じ P3×X の graph に持ち上げてよい。
局所的には上の固定線交叉そのものとなり、定理の A9 束が従う。

TA∩TB は P 不変であるから、

    EN=G×^P(TA∩TB) ⊂ P3×X

も閉で、滑らか・既約・18次元、X への射影は proper である。
その像 N_S61 は、rank3 開での交叉全体の閉包である。
Z を優越する交叉成分は Z3 の上に非空稠密開部分を持つはずだが、
その部分は上の既約 A9 束の中にある。よってその閉包 N_S61 だけが優越成分となる。
N_S61 はこの開で交叉 scheme の被約で滑らかな成分である。

この固定線交叉は CA の rA=0 の実族であり、v62 の
fA=x0(x0+px) の共通族に含まれる。
PGL5 飽和と標準の値・perspective 九方向を戻すと、18+9=27次元である。
従ってその閉包は既存の27次元交叉成分 N に一致する。
