# 二元型超平面の完全三次行列：二段の良い還元による余次元

## 1. 対象と結論

本節の結論は、D≠0 の三 core 空間で rank(N)<57 となる閉集合の次元が高々1、というものである。一般階数57と全点での上界57は既存 GENERIC_RANKS に依存する。

全点でのrank57、重み四次全射、相対長65、ambient の t 冪零性、全二元型の除去は主張しない。

## 2. 有限体上で使う有限個の小行列式

既知 a,F,B,C の冪を取り除いた二つの bag の共通支持は、三つの既約多項式 H1,H2,H3 に限られる。それぞれ21,92,6項を持つ。有限体の多変数因子分解を行い、因子の再展開も照合する。

## 3. d に依存する未知因子の排除

Vd=Z_(p)[a,e]_(p) は離散付値環で、その分数体は QQ(a,e)、剰余体は Fp(a,e) である。B は Vd[d] で先頭係数が単元の一次式である。

水平証明書は、QQ(a,e)[d] 上で deg_d(P)=79 と B^12 による完全整除を示す。次数の証明では、Hungarian 上界107から最高係数の厳密多項式核14,9,5を順に取り、元の全行列で δ の完全除算を行う。最後の最高係数行列は還元後も正則なので、次数は107−28=79であり、LC_d(P) は Vd の単元である。

B の整除は、厳密な部分 Schur 表示の既知 B 重複度2と残18行列の重複度10から得る。残行列の B=0 における階数は11で、左右の7次元核を全係数恒等式として確認する。最初の Schur 係数の7×7行列は階数4である。従って形式的に正則な11ブロックを除いた行列式は、少なくとも7+3=10次で消える。有限体側の正確な重複度12が逆の上界を与える。

B を monic に直して除けば Q=P/B^12 は Vd[d] に属し、その d 先頭係数は単元である。また Qbar は Bbar と互いに素である。

いま QQ[a,e,d,D^−1] に未知の高さ1階数欠損があり、その既約因子 h が d に依存すると仮定する。h は QQ(a,e)[d] 上でも非定数で、B と互いに素だから Q を割る。Vd-primitive にした h とその商は Gauss の補題により Vd[d] に属する。Q の先頭係数が単元なので h の先頭係数も単元であり、hbar は非定数のまま残る。

h は全36小行列式を割るので、hbar は §2 の五小行列式の還元を割る。Fp(a,e)[d] でその共通因子は Bbar の冪だけである。しかし hbar は Qbar も割り、Qbar と Bbar は互いに素である。矛盾する。従って未知の共通因子は a,e のみに依存する。

## 4. 垂直因子の排除

垂直証明書で P3(a,e)=P(a,e,3) を扱う。QQ(a) 上の厳密核により deg_e(P3)=213、その最高 e 係数を a 一変数で再び厳密に扱い、lex(e,a) の先頭単項式が e^{213}a^{39}、先頭係数が Z_(p) の単元であることを示す。単なる有限体の次数から QQ の上界を推測していない。

同証明書は QQ(e) 上で a,F,C の各中心へ変数を移し、P3 の重複度37,10,26を厳密に確認する。最後の最高係数行列は有限体でも正則で、還元後も同じ重複度である。

Q3=P3/(a^37 F^10 C^26) とする。既知積は Z_(p)[a,e] 上 primitive であり、Gauss の補題から Q3 も p 整である。既知積と P3 の lex(e,a) 先頭係数はいずれも単元なので、Q3 の先頭係数も単元である。Q3bar は a,F,C のいずれでも割れない。

§3 の後に残り得る未知共通因子 h(a,e) は a,F,C とは異なる既約因子である。P3 を割り、既知積と互いに素なので Q3 も割る。V=Z_(p) 上 primitive に取れば、その非定数先頭項は単元係数を持ち、hbar は非定数となる。

hbar は §2 の五小行列式全ての還元を割る。Bbar の d-content は

gcd(50a+18e²−9e−2,60e−40)=1

であり、Bbar は d に依存する primitive な一次式である。従って d に依存しない hbar の既約因子は a,F,C のいずれかでなければならない。しかし hbar は Q3bar も割るので矛盾する。

これで QQ 上の未知共通因子は存在しない。UFD QQ[a,e,d,D^−1] の高さ1素イデアルには階数欠損がないため、欠損閉集合の余次元は少なくとも2、三 core 空間内の次元は高々1である。
