# 非二元二重根型の見掛け因子：幾何学的推論の点検

2026年11月1日。
[主証明](S61_NONBINARY_DOUBLE_ROOT_ARTIFACTS_20261101.md)とそのコードを読み、
以下の幾何学的推論を受理した。本点検は数体上の全係数の独立再計算ではない。

- QQ 上既約な P2/P3 の厳密数体での恒等式・非零 minor は、全ての複素埋込みで保持される。
  一つの近似複素根から他の根を推論していない。
- 全 Sp4×H source の β 微分全射は、指定 β の下で滑らかな形式ファイバーを与える。
  その q 微分が一次元で非零なので、実際の滑らかな曲線 germ を選べる。
  この曲線の接方向が Hessian 共通核と一致することが、横断二変数の二次上界3を正当化する。
- 同じ曲線の一般点に適用される普遍最高階数上界41は、S/(t) の法線埋込み次元を少なくとも2とする。
  従って同じ無限遠因子の一般長さは少なくとも3であり、指定点の横断上界3と比較できる。
  有限加群 R³→S の核は階数零の torsion-free 部分加群なので零となる。
  S/(t) が一般階数3を使い切るため t=0、曲線 ideal の平方も零となる。
- H_a の安定化群の単位成分不変性と、射影 Q の安定化次元3により、像 Z_a の次元は正確に16。
  制限 source の β 微分全射が優越性を与える。
- 局所消滅を一般点へ広げる際は、全 source 上の有限 jet と同じ曲線の長さ下界を併用している。
  その後の忠実平坦な体拡大・完備化・分母の除去により、Z_a の非空開部分に nilpotence が降りる。
  proper 十六次元像の補集合は次元高々15なので、全一般 β ファイバーの除去が従う。

これらは六つの複素比 stratum の各々に適用する議論である。
三つの QQ 多項式を三つの複素成分と数えていない。
他の比、U=0、V=0、B=0 全体への外挿はなく、全二重根軌道や全無限遠の除去も主張していない。

この点検は主証明書の数体上の正確な階数・二次障害計算と、独立監査済みの普遍最高階数41・全135同変性を依存として保持する。
