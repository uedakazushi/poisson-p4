## 2. 非正重み底上の有限性補題

A=V̂[[δβ₁,…,δβ₁₄]] を上の十四非正重み座標の完成環とし、五切断後の I^flat による全相対完成環を S とする。S/(p,δβ₁,…,δβ₁₄) が正重みを持つ有限次元代数なら、S は A 上有限である。特殊商の有限斉次基底を持ち上げ、完備 Nakayama を適用すればよい。特殊商で正変数のある冪が消えるので、全極大イデアル位相と (p,δβ₁,…,δβ₁₄) による位相も一致する。

持ち上げた有限生成元の重みの最大値を D とする。A の重みは非正だから、各有限商で D を超える重みの元はない。逆極限を取っても同様であり、正重みの t は冪零となる。D≤5 なら wt(t²)=6 より t²=0 である。V の p 自身は重み0なので、この議論は混合標数のまま成立する。五切断から群方向を戻す写像は滑らかで、t は単元倍されるため、結論は元の全周囲へ忠実平坦に降りる。

この補題には実在 binary 部分の長65という下界も、有限中央環の平坦な厚化の構成も不要である。非有限な六中央環には、この補題だけを直接使うことはできない。

## 3. 非零 ray の同じ実在 incidence

ray 上の非零代表 Q について、O=Sp4·[Q] と置く。Q を固定した全最高式の β 核 H は一定次元であり、その全 H 上で第135式を含めた最高式が恒等零である。従って

    Γ={(β,[Q′]):[Q′]∈O, β∈H_(Q′), t=0}

は O 上のベクトル束で、滑らかな実在 incidence である。ray geometry は、H 座標と実際の射影軌道座標を合わせた小行列式が V の単元であることを確認する。Γ の形式座標はこれらの実座標から取れる。

Q(G)=∂y∧(G_w∂z−G_z∂w) と書くと、五つの非滑らかな型の Hamiltonian は次の通りである。

|e/b|G|同じ既知の軌道|dim O|dim H|一般法線長 L|
|---|---|---|---:|---:|---:|
|2|x(w²−z²/12)/2|xzw|7|10|2|
|5/3|xw²/2−z²w/44|T2|8|9|2|
|5/4|w²(8x−z)/16|純二重根|7|10|3|

第一行の二元二次式は非退化なので、SL2(z,w) と射影スカラーで xzw に移る。第三行は Darboux shear z↦z+8x で純 zw² に移る。T2 と T5 は表示された二項の非零係数を対角 torus と射影スカラーで正規化する。最後の行は (z,w) の symplectic 交換の後に同様に T6 となる。shear は y の補償項を加えた既存の symplectic 行列を使う。これらの式と元 Q テンソルの一致は QQ で検査した。

一般長の依存は、[xzw](S61_NONBINARY_CANONICAL_EXHAUSTION_20261101.md)、[T2/T6](S61_R0_MIXED_CURVE_EXHAUSTION_20261101.md)、[純二重根](S61_NONBINARY_DOUBLE_ROOT_EXHAUSTION_20261101.md)、[T5 下界23](S61_R0_T5_FORMAL_RANK23_20261101.md) である。今回の線形計算はそれらの普遍法線証明を再証明するものではない。独立コードは各 Q の **同じ H** 内に一般 β を選び、[H, infinitesimal Sp4·β] の非零16次小行列式を具体的に出力した。従って Γ は W16 を優越し、上の一般長は実際にこの Γ の一般点に適用できる。

注意すべきことに、保存された七代表 β **自身** ではこの β 写像の階数は全て15である。指定点で Sp4×H→W16 が滑らかだと仮定して固定 β 結果を移す議論は使えない。以下では β を含めた全 Γ の正則座標を使う。

e/b=−10 の二代表では dim O+dim H=17、全周囲の Jacobian 階数は44である。従って全周囲は指定点で滑らかな17次元であり、同じ17次元の滑らかな t=0 incidence と局所的に一致する。この二点では t=0 となり、未知の一般長の主張を必要としない。

## 4. 混合標数上での等階数の持上げ

五つの非滑らかな ray について、V 上の Γ の指定点での完成環を

    R=V̂[[ξ₁,…,ξ_(dim O+dim H)]]

とする。H と q 軌道の小行列式が p 単元なので、Γ は V 上も滑らかであり、R の座標は上の実際の切断座標から取れる。Γ は V 上 flat であり、raw135 はその標数零部分で消えるため、Γ 全体は I^flat の閉包に含まれる。その全周囲の完成環 S には R→S→R の分裂がある。

これらの座標を零にした横断環を法 p で計算する。元式からの陰関数消去の Jacobian minor も p 単元である。六次まで低次関係の後尾を全て保持した truncated Macaulay 計算により、六次が零、全長が表の L 以下である。従って完備 Nakayama により全相対 S は R 上 L 元以下で生成される。単に有限 jet の Hilbert 関数から全初期 ideal を推測しているのではなく、特殊横断環の有限性から加群有限性を得ている。

一方、R の一般点は標数零で、同じ Γ の一般法線長は上の依存結果により L 以上である。この長さは完成後も保持される。Γ の商が正則整域 R であるため、その素 ideal に沿う局所化での平坦な完成写像の閉ファイバーは剰余体の拡大となり、同じ Artin 局所因子の長さを変えない。

従って rank_R S≥L。全射 R^L→S の核は自由 R 加群の階数零部分加群なので零であり、

    S ≅ R^L  （R 加群として）

となる。一般点では Γ に沿う長 L の因子が全階数を使い切り、t はその Artin 局所環の極大イデアルに属する。従って t^L=0。R 上の torsion-freeness により、この恒等式は p を反転する前の S 全体へ降りる。

こうして ray の非零代表の**全混合標数周囲**で、順に t²,t²,t³,t²³,t² が零となる。二つの滑らかな代表では前節により t=0。この証明は、特殊横断長 L だけから相対平坦性を推論せず、同じ実在 incidence の一般長を別に使用している。

## 5. 非有限中央環を飽和支持で処理する

六つの非有限中央環の法 p の被約台は、表の七つの weighted ray の和に正確に一致する。中央環で t=0 だったという事実だけから相対 t 冪零性を結論してはならない。そこで I^flat による全相対五切断環で t 飽和した商を U とする。すなわちこの有限型環を B と書けば U=B/(0:t^∞) であり、U 上で t は単射である。

第4節は各非零 ray 代表の**全周囲**で t が冪零であることを与える。重み作用は core を固定して ray の全非零点を動かし、t を単元倍するので、U の中央特殊ファイバーは全ての非零 ray を避ける。中央の台は既にその ray と原点だけであるから、U の中央特殊ファイバーは原点に支持される有限スキームである。

原点で完成すると、第2節と同じ完備 Nakayama により Û は十四の非正重み β 座標の環 A 上有限となる。U は重み作用を継承するため、その中の正重み t は冪零である。一方、U 上の t の単射性は平坦な完備化の後も保たれる。従って Û=0 であり、原点は元の全相対 t 飽和支持に入らない。

この論証は中央の ray の平坦な厚化を一括構成することを必要としない。代わりに、非零 ray での**周囲の**冪零性を先に証明し、飽和商の有限性と重みで中央点を除く。中央の長70と d=0 の長65は第2節で直接除ける。

## 6. 試験直線の有限部を全点で覆う

(1) の中央環では、四つの重みの線形消去 block の行列式は b に依存しない有理数であり、全て p 単元である。残る15変数の重みは 1 が七つ、2 が五つ、3 が三つ。

F_p[b] 上の重み4の531行386列の行加群は、体定数のみを逆にする weak Popov 操作により、次数17の正方行列式を与える。その全根は

    b=857, −16012, −7, −3770, 2526, 3, −42

で、表の七つの有理 b の還元に一致する。重み3の残る三変数の係数行列の全3次 minor の gcd は

    (b−857)(b−3)²  mod p

である。従って七根以外では重み3変数を低い重みの多項式に消去でき、残る重み1,2の全重み4単項式が消える。それ以上の単項式も消えるため中央環は有限で、第2節が全混合標数周囲の t 冪零性を与える。七根では第2〜5節を使う。これにより閉ファイバーの**全代数的有限 b**を処理している。

有限体の因子を標数零の行列式の完全因子だと主張してはいない。次節の固有性がこの区別を埋める。

## 7. 正しい無限遠端点と混合標数の固有性

対角 torus diag(x,x⁻¹,z,z⁻¹) の core 指標は

    b,e ↦ x⁻¹(b,e),  c,f ↦ z(c,f),  d ↦ xz²d,
    a ↦ x⁻²z⁻¹a.

b=u² として (1) を引き戻し、x=u²,z=u⁻¹ を使う。v=u⁻¹ の chart で同じ点は

    (a,b,c,d,e,f)=(0,1,v,1,8/3+7v²,−5v)            (2)

となる。重なりでは torus が全135式と t 可逆部分を保ち、五切断も座標重みの零条件として保たれる。

無限遠 v=0 は c=f=0、(b,d,e)=(1,1,8/3) である。**d=0 の試験点ではない。** 今回はこの core の元135式から中央環を直接 QQ と F_p の両方で再構成し、重み付き Hilbert 関数 (1,7,23,34)、単項式基底長65、被約台が原点だけであることを確認した。法 p の直接入力と出力は [無限遠証明書](../../reports/S61_BINARY_A_ZERO_INFINITY_MODP_20261103.json) に固定した。従って第2節によりこの無限遠の全混合標数周囲も t²=0 である。

既存の零対層の証明への接続も検算できる。x=1/6,z²=72 の有限 étale 拡大後の torus はこの点を (a,b,d,e)=(0,6,12,16) へ移す。p は2,3を割らず z は単元である。今回は無限遠の有限性にこの既存の体定数行列式証明書を必要としない。

全相対 t 飽和支持を Q₀-section に引き戻した閉不良集合は、上の二 chart で一致し、P¹_V 内の閉集合となる。第6節と v=0 により閉ファイバーは空である。P¹_V は V 上固有なので、不良集合の一般ファイバーも空。従って標数零でも (1) の**全有限 b と端点**が全周囲で飽和除去される。これは有限体の一般点だけの成功を標数零に移す議論ではない。

## 8. 全 a=0 層の悪い divisor を排除する

K=a=0 の全12次元 source を core A⁴_(b,c,d,e) と八 nuisance の積として扱う。全相対飽和支持の Q₀-section への引戻しを Z、その nuisance 零 section への引戻しを B とする。両方とも閉である。元の収縮作用は八 nuisance を同じ core の零点へ送るので、

    Z ⊂ B×A⁸.

B は連結対角 torus で保たれる。その core divisor があれば、各幾何学的既約方程式は半不変である。c=0 自身は零対の上の良い点と交わるため B の divisor になれない。d=0 自身は第1節の長65の良い点と交わるため同様に除ける。

残る半不変既約式 F(b,c,d,e) を考える。d を反転して

    C=c²/d

と置くと、b,e,C は全て同じ指標 x⁻¹を持つ。半不変式の各単項式 b^i e^j c^k d^l の指標は (−i−j+l,k+2l) である。F が c,d のいずれも因子に持たないため、最小 k と最小 l はそれぞれ0である。従って k+2l=2L、i+j=m+l（L,m≥0）となり、

    F=d^L Σ_(l=0)^L C^(L−l) P_(m+l)(b,e),

ただし P_j は次数 j の二元斉次式である。右の総和は (b,e,C) の正次数 m+L の斉次式であり、P² の曲線を定める。

完全試験曲線 (1),(2) は、この P² における直線

    e=(8/3)b+7C

の全点を覆う。C≠0 の点は torus で c=d=1 に正規化して (1) に入り、C=0 の一点は (2) の端点である。射影平面の任意の曲線はこの直線に必ず会う。しかし全試験曲線は B を避ける。従ってそのような core divisor は存在せず、dim B≤2 である。

最後に [H11 の有限三次元加法群](S61_BINARY_H11_RANK_DROP_RESIDUAL_FINITE_20261102.md) は K=0 上で六 core を全て固定する。これと対角二次元 torus を合わせた Q₀ の五次元連結射影安定化群は、K=a=0 source と intrinsic な Z を保つ。Sp4×Z から (β,[Q]) への joint 写像の各ファイバーには、群因子への自由作用による五次元軌道がある。従って

    dim joint image ≤ 10 + (2+8) −5 =15.

その β 像閉包も15次元以下である。これを避ける十分一般の β では、**K=a=0 の全非平方点が全135式の t 飽和で除去される**。根を交換する既存の有限 symplectic 対称性にも同じ結論が適用される。

## 9. 射程と残る課題

点別の有限体横断上界、同じ incidence の一般長、混合標数上の全周囲の冪零性、完全試験曲線、半不変 divisor の排除を順に用いた結論である。全 a=0 層で一つの共通冪 t^N=0 を計算したわけではなく、特殊な全 β での除去も主張しない。

K=0 の c≠0,a≠0 の残余、d=0 の別試験直線、指定平方型 c=2a の有限値、固定二座標モデルの t 可逆長、全一般アフィンファイバーの五点尽くしは別の未完課題である。既約成分数の下界57と、上界未証明という状態はこの結果で変わらない。
