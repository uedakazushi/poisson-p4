# 共通 core 開部分の相対自由65と全一般一次部分上の飽和除去

2026-11-01。135式の共通次数二の未飽和斉次化を扱う。
`S61_BINARY_DEEPER_QUARTIC_NUISANCE_20261101` で得た非空 core 開集合を U とする。
必要なら U を、同じ証明書の分母・非零 minor および三角 chart の分母の補集合へ縮める。
以下では U の例外曲線の尽くしは行わない。

## 1. 主張

七変数 source を `H=U×A5_(p,q,r,h,k)`、標準の無限遠点を
`Q0=xw∂y∧∂z` とする。H 上の全135式の相対 scheme の、各 section 点の完成局所環は、
実際の二平面型部分の完成局所環 R10 上自由階数65である。
R10 は H 上形式的に滑らかな相対三変数環である。
その部分への制限の核 I に対して

    S_rel,red = R10,    rank_R10 I=64,
    I^4=0,    I*t=0,    t^2=0

となる。各一次部分を特殊化した**全固定β完成局所環**も R3 上自由階数65で、
同じ冪零恒等式を満たす。ここで R3 は実際の滑らかな二平面型三次元部分の完成局所環。

Sp4 と H の source が W16 に submersive な点では、t²=0 が全 ambient 局所環にも降りる。
さらに十分一般の β では、この source の全 preimage が submersive である。
従って **共通 core 開 U にある全一般β点は t-飽和で除かれる**。

これは U の補集合を除去する結果ではない。t≠0 や S/(t) の自由階数64も一様には主張しない。
特殊βで source が submersive でない点について、ambient の t²=0 を結論していない。

## 2. 同じ相対三次元部分

Lagrangian 平面の局所表示を

    v1=(A,1,0,C),   v2=(-C,0,1,D)

とし、primitive first jet による二式を

    β_v1(v1,v2)=β_v2(v1,v2)=0

と書く。H の零sectionでは常に成立する。平面方向の微分は、元βから再構成して

    [ 2, -(6e+1)/5, 3(1-2e)(15e+8)/500 ]
    [ d,             4,                 (3e-2)/5 ]

であることを検算する。既存三角証明書の実際の二平面型接写像と、
その三つのパラメータへの射影 minor は `2(24e-7)/125`。
従って U 上の全section点で、平面曲線は H 上相対的に滑らかな一次元部分であり、
その上の二元二次形式の射影束は相対三次元の滑らかな部分 C_rel となる。
二次テンソルの像から支持平面と二次形式を正則に復元できるので、これは局所的な埋込みである。

ここで必要な既約成分を固定する。H は既約であり、零sectionも既約である。
C_rel はその全ての点で滑らかなので、sectionを含む既約成分はただ一つである。
異なる成分がsection上で出会えば滑らかさに反するため、同じ成分が全sectionを含む。
以下ではこの成分の滑らかな開近傍だけを C_rel と呼ぶ。

同じ平面を保った

    Q(H1,K1)=(xw+H1*x^2+K1*w^2)∂y∧∂z

は同じ P² fiber に入る。新証明書は、七変数と H1,K1 を記号のまま保ち、
全135最高式がこの族で零になることを確認する。
非平方条件は `1-4H1K1≠0` であり、Q0 と Q1=Q(1,1) の両方を含む既約開部分である。
従って Q1 は別の無限遠成分から持ってきた標本ではなく、同じ C_rel の点である。

## 3. 同じ相対成分の一般長さ65下界

七変数を `(2,3,5,7,11,13,17)` にした Q1 で、元135式から次を exact QQ で検算する。

- 実際の平面曲線と二次形式の三接方向がこの radical と一致する。

従って同じ既約 C_rel の非空開上で、これらの階数と滑らかさは保たれる。
`S61_BINARY_UNIFORM_CUBIC_20261101` §5 の一定階数領域への延長を適用すると、
この**同じ相対成分の一般点**で法線切断の三次までの長さは少なくとも65である。
ここで「各特殊固定βの C に ordinary な点がある」と推測していない。

## 4. 各section点の相対有限自由性

C_rel の任意のsection点を固定する。その完成局所環 R を取ると、
相対滑らかさと§2のパラメータminorから

    R ≅ C[[b1,...,b7,u1,u2,u3]]

であり、b は H の局所座標、u は実際の C の三つの座標となる。
これらの関数を full相対schemeへ持ち上げることで `R→S_rel→R` は恒等写像となる。

quartic nuisance 証明は、U 上の全五 nuisance 値で、b,uを切った**実際の横断商**の
長さが65以下であることを与える。したがって完備版 Nakayama により S_rel は R 上有限で、
高々65個の元で生成される。必要なら零元を加え、全射 `R^65→S_rel` を取る。

一方、§3の非空開の補集合は、同じ既約 C_rel 上の真閉集合である。
その非零局所方程式は、各section点での滑らかな局所環から完備化しても零にはならない。
従って R の一般点に対応する S_rel の局所因子には、同じ65下界が適用される。
K=Frac(R) とすれば

    65 ≤ dim_K(既知 C_rel の一般局所因子)
       ≤ dim_K(S_rel⊗K) ≤ 65.

全て等号であり、他の一般局所因子は存在しない。
`R^65→S_rel` の核は階数零の自由加群の部分加群なので零。
よって S_rel は R 上自由階数65である。

分裂の核を I とする。一般点では65下界が長さ全体を使い切るため、
`I_K^4=0`、`t∈I_K^3`、従って `I_K*t=t²=0`。
I^4、I*t、t²S_rel は R-torsion-free な S_rel の部分加群で、一般点で零だから全て零となる。
この段階で graded pieces の自由性は仮定しない。
I は冪零根基であり、R上自由階数64である。

bを特殊化すると R は R3 になり、S_rel は自由R3加群階数65となる。
この fiber は元135式の**全固定β完成局所環**である。余分な q方向を切り落としてはいない。
I^4=I*t=t²=0も特殊化する。これにより§1の固定βの主張が従う。

## 5. ambient への降下と一般β上の全点

`f:Sp4×H→W16` は滑らかな source からの射である。
新証明書は上記の β における16次非零 minorも独立に確認し、優越性を記録する。
全135同次数斉次化の同変性により、相対 full scheme と Sp4 の積は、
ambient full scheme の f による base change と同型である。
t はこの同型で可逆因子倍になる。

f が submersive なsource点では局所 base change は忠実平坦である。
§4の相対 t²=0 は、その点に対応する ambient 局所環にも降りる。
完備化の忠実平坦性も用いるので、これは単なる一つの restricted fiber 上の主張ではない。

char0の一般滑らかさにより、source の critical locus の像の閉包は W16 の真閉部分である。
具体的には、その各既約成分で f の微分階数は高々15であり、
char0の separability により像の次元も高々15となる。成分は有限個なので、
十分一般の β はこれらの像を全て避ける。
従ってその β の source preimage は全て submersive であり、
U に正規化される全点について ambient t²=0 が得られる。
tを可逆にした局所環は零であるから、これら全ての点は t-飽和で除かれる。

これは core 開の補集合の像が真閉であるという議論ではない。
