# CA/CB/N の零一次ジェットと既存 Q45 成分の認識

2026年11月3日。ここで CA,CB,N はそれぞれ既に同定された **被約** S61 部分多様体で、
次元は19,19,18である。以下の零ファイバーの同定は underlying reduced closed variety
について述べる。全 S61 の零ファイバー、target の非被約構造、全 CA∩CB の分解は述べない。
入力は受理済み `AMBIENT_FULL_FIRSTJET_FIBERS_20261103_v63.md` の閉 proper 入射である。

## 定理

β=0 上で

    (CA_0)_red=M0,    (CB_0)_red=M1,    (N_0)_red=R0.

右辺は既存の Q45 分類の M0,M1,R0 と同じ集合であり、次元は順に13,13,12である。
M0,M1 は既存22成分中の最小冪零型の二成分である。
R0 は既存の零モジュラー層の12次元成分で、M0,M1 の双方の境界に含まれる。
新しい全域成分を加える主張ではない。T01 の零ファイバー AB10 とは別の対象である。

三つの入射の零基底変換は、P3 上の rank10,rank10,rank9 の線形ベクトル束である。
これらから M0,M1,R0 への射は proper birational である。
全ての幾何点 Q における **入射側の scheme-theoretic flag fiber** は次の通りである。

* δQ≠0 の M0,M1 点では一つの被約点で、線は im(δQ) から戻る。
* δQ=0 で Q≠0 なら `P F(Q)` である。ただし
  `F(Q)={v∈C4 : v∧Q(y)=0 identically in y}`。
  dim F(Q)=1 なら被約一点、dim F(Q)=2 なら被約 P1 となる。
* Q=0 のファイバーは被約 P3 である。

この一覧は target のファイバーの被約性を証明するものではない。
また proper 射の連結ファイバーだけから target の正規性を推論しない。

## 1. 零基底変換と全閉像

座標を y=(x,y,z,w)、J=∂x∧∂y+∂z∧∂w とする。
固定線 L0=C∂y で、G は x,z,w の三次式を x³ を法として動かす九変数である。
受理済み全16変数模型に β=0 を代入すると、六つの一次パラメータが全て零になる。
これは β の埋込み行列が定数左逆を持つため、scheme としての主張である。
perspective 補正も零となり、残る双ベクトルの二次部は

    QA(r,G)=r*x²*dxy+dy∧(-G_w*dz+G_z*dw),
    QB(r,G)=r*x²*(dxy+dzw)
                +dy∧((-r*x*z-G_w)*dz+(-r*x*w+G_z)*dw),
    QR(G)=dy∧(-G_w*dz+G_z*dw).

いずれも [J,Q]=[Q,Q]=0 である。QA,QB の固定線空間は10次元、QR は9次元である。
β=0 上で Sp4 の正規化作用は q の線形作用となり、放物部分群によるこれらの空間の
不変性は既存の全16変数の不変性から従う。従って零基底変換は実際に線形ベクトル束である。

全 EA→CA, EB→CB, EN→N は proper かつ全射であり、β を保つ。
従って任意の target の β=0 点は上の零基底変換へ持ち上がる。
逆の包含も明らかなので、その proper 閉像が **全** underlying reduced zero fiber である。
一般点の稠密な族だけを零ファイバー全体と同一視したのではない。

## 2. 線の回復と次元

divergence を `(δQ)^j=Σ_i ∂_i Q^{ij}` とする。

    δQA=2r*x*∂y,    δQB=4r*x*∂y,    δQR=0.

従って r≠0 では δQ の一次係数行列は階数1で、像は旗線 L そのものである。
この回復は Sp4 同変であり、rank1 開で正則である。
よって二つの rank10 束はその像のこの開へ同型となり、像の次元は3+10=13である。

QR では β の係数行列も δQ も線を戻さない。
代わりに F(Q) を用いる。G=z³+w³ なら Q の非零係数の共通定数因子は ∂y だけで、
F(Q)=C∂y となる。従って rank9 束も一般的に線を一意に戻し、像の次元は3+9=12である。
全13,13,12次元の source-to-image 微分について、60個の実際の二次係数による QQ 上の
非零小行列も保存した。次元の上界は束の次元から得ており、標本の階数だけに依存しない。

## 3. 既存 M0,M1,R0 との正確な照合

`legacy/v07/quadratic_classification.tex` の固定 trace=x²/2 の九変数表示では、
c=0 が M0、c=1/4 が M1 である。
QA で r=1/2、QB で r=1/4 とすれば、同じ trace になる。
G の係数を

    (k0,…,k8) ↔ (x²z,x²w,xz²,xzw,xw²,z³,z²w,zw²,w³)

の順に取ると、旧九係数への写像は

    t1=−k1, t2=−2k4, t3=−3k8,
    t4=k0, t5=2k2,
    t6=k3            (QA),
    t6=k3−1/4        (QB),
    t7=3k5, t8=2k6, t9=k7.

その線形部は可逆で、旧表示の全六成分と恒等的に一致する。
線を保つ symplectic diagonal torus は r を非零の平方で動かすので、C 上の任意の
r≠0 はこの固定値へ正規化できる。proper 像は閉で、この開は source で稠密だから、
上の像は旧 M0,M1 の全閉包と一致する。

QR は旧 `zero_boundary_section.tex` の
`*(dL∧dG), {L,G}_J=0` と同じ定数因子族である。
L の符号を変えれば、旧体積形式の符号慣習でも上の表示に一致する。
旧証明と同じ rank9 束・一般線一意性により、その全閉像は R0 である。

特に M0 と M1 の零モジュラー部分はどちらも R0 と集合として一致する。
これは r=0 の像であることから直ちに従う。
さらに両者は δQ≠0 の点では相異なる固定線10平面で、同じ線上の交叉は r=0 だけなので、
**被約集合として M0∩M1=R0** も従う。
これは target の scheme-theoretic intersection ideal を計算したものではない。

## 4. 全旗ファイバーの分類

固定した非零 v を ∂y へ移す。Q が [J,Q]=0 を満たす二次双ベクトルなら、
δQ=0 と v∧Q=0 はちょうど上の QR 九次元空間を定める。
実際 v∧Q=0 から Q は ∂y∧Y と書ける。
[J,Q]=0 と δQ=0 から trace Q=0、Y_y=0、および z,w に関する divergence zero が得られ、
Y=(-G_w,G_z) と積分できる。G の核は Cx³ である。
コードはより直接に、全60係数に対する線形方程式の核が正確にこの九次元空間であることも検査した。

従って δQ=0 を固定した旗ファイバーは、全 chart で v∧Q=0 という **v に線形な**
方程式だけで与えられる。scheme として P F(Q) であり、余分な冪零元はない。
非零の二重ベクトル Q(y0) を一つ選べば、F(Q) はその定数因子平面に含まれるので
dim F(Q)≤2 である。R0 では少なくとも1なので、可能性は1と2に尽きる。
G=z³+w³ は1、G=z³ は2の実例である。Q=0 では全 P3 となる。

δQ≠0 の場合は、固定された rank1 行列 δQ の像を含む線が唯一である。
入射には im(δQ)⊂L の scheme 条件も含まれるため、非被約な旗の厚みも残らない。
この結論は β≠0 の指定端点 Q における二重旗ファイバーとは異なる計算である。

## 5. 有限多項式による認識と prime の消去表示

60係数空間で V45={[J,Q]=0} と置く。trace を s=Q12+Q34 とすれば、この空間で

    δQ=−J grad(s)

が恒等的に成立する。
M0,M1 の proper 入射は次の内在的な全方程式で書ける。

    EA,0={([v],Q): Q∈V45, (δQ)(y)∧v=0, v∧Q(y)=0},
    EB,0={([v],Q): Q∈V45, (δQ)(y)∧v=0,
                             v∧(Q(y)−s(y)J/2)=0}.

固定 v=∂y での線形方程式の核はそれぞれ厳密に QA,QB の10次元空間である。
従って上の条件は必要条件だけではなく全閉入射の定義式である。
δQ≠0 では rank(δQ)=1 とし、im(δQ) から v を一意に選ぶだけで M0/M1 を認識できる。
δQ=0 の境界では、v の存在は dim F(Q)≥1 と同値で、両像とも R0 である。

これは expanded generating set を計算せずに、prime ideal の有限消去表示も与える。
R=QQ[q0,…,q59,v0,…,v3] とし、上の coefficient equations が生成する homogeneous
ideal を Iγ とする。Jγ=Iγ:(v0,v1,v2,v3)^∞ と置けば、

    I(Mγ)=Jγ∩QQ[q0,…,q59]      (γ=A,B)

である。理由は、その射影入射が integral なベクトル束で、proper 像が閉であり、
integral source の scheme-theoretic image は reduced integral だからである。
R0 についても `[J,Q]=0, δQ=0, v∧Q=0` を使えば同じ prime 消去表示を得る。
この記述は prime の存在や標本だけの同定ではなく、具体的な有限多項式からの定義である。
一方、45変数での展開済み最小生成系や、非被約零ファイバーの primary ideal は未計算である。

## 6. rank Kβ と真の旗入射を区別する診断

零ファイバーとは独立だが、rank-drop の誤認を防ぐため同じ証明書に正確な反例を保存した。
固定六平面の (τ,A,B,C,D,F)=(0,3,5,7,11,13) では Kβ は

    [[0,0,0,0],[3,0,14,11],[5,0,11,26],[0,0,0,0],[0,0,0,0]]

で階数2、核は span(e_y,(243,0,−23,−37)) である。
しかし真の基底旗入射には Kβv=0 だけでなく

    i_v β(y) ∈ span(ell_v(y)*ell_v),    ell_v=i_v J

がある。v=e_y+a(243,0,−23,−37) を代入すると後者の全比例条件の GB は(a)となり、
chart 外の核の線も条件を満たさない。従ってこの点の基底旗ファイバーは一つの被約点である。
基底六変数と Sp4 方向を合わせた β 写像の微分も QQ 上で階数9となる。
`rank Kβ=2 ⇒ 旗ファイバーP1` は成立しない。
従来の rank3 開の定理はこの追加事実を必要とせず、そのまま正しい。
