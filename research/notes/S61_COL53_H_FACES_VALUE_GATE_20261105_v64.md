# 固定 H 両端面の VALUE 実装・所有量ゲート（未実行）

固定行6・列53の既存 SSA1203ノードに対し、H=-3 および H=21 の完全な係数面だけを評価するための SOURCE／コード準備である。両面の正の支持は766点と214点で、5座標すべてを保持する。10個の頂点係数が零だったことによる枝刈りは一切行わない。積は同じ H 端面の畳込み、和は端 H が一致する子だけを取る。既存 SOURCE の q=0 による恒等零だけを除外する。

各ノードの既存有理スケール q を固定し、係数写像を整数で持つ。コピー・積・和の整数倍率をすべて既存 q から再確認し、正の絶対値上界で部分和まで覆う。通常係数640ビット・一時整数1921ビット、既存 VALUE2048ビットの制限を変えない。codec の q*c*G を単純な積のまま見積もっても1372ビット以下である。変数や未知正規方向の逆元を取らない。

VALUE ワーカーは既存 SOURCE 文書の実際の数値個数に加え、各種索引、M上界、両面の許容点集合の複製、ROOT文書、Python実行領域、失敗時保存領域を別に課金する。固定メタデータ98,171、係数写像は全5座標と係数の7数値を課金し、葉の全文書復号16,152と作業分を含めて最大126,262となる。和・積の親の最終使用後に写像を解放し、移動時に係数写像を複製しない。

出力は非圧縮の primitive binary cell とし、各面の全係数を逐次読み戻す。部分状態は完了面と区別し、失敗時には全 live 写像および未完了ノードを別の cell と逐次索引に保存する。葉の復号、codec のソート参照、GCD、係数正規化、読戻しの領域を含める。生成RAWは2MiB、将来のゲート・ROOT報告等も含めた全読込／出力RAWは32MiB未満である。旧履歴を削除したり gzip でRAW制限を回避したりしない。

SOURCEゲートの --prepare は固定グラフの整数倍率・端面枝・最終使用予定・codec固定fixtureのみを確認し、実際の面係数を計算しない。VALUE の --execute は別の ROOT レビューとそのハッシュを必須とする。この準備自体は VALUE 実行許可ではない。

少なくとも一つの面係数が非零なら固定 entry の非零を示す。両面が零でも entry 全体が零とは結論しない。全167×14、87本の追加RHS、66本の制約、P290一回、F9/F10とすべての chart 補集合を保持し、行列全体の逆・階数・網羅性は主張しない。
