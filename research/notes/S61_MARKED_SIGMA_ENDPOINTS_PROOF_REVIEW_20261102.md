# 指定平方の二つの16次元層と特殊斉次 pencil の監査

純三次尾の四表示は既存の内在 quartic と射影 core の方程式で同じ既約16次元閉包を持つ。[1:2:4] では h²+16a²(c−3a)=0。正重み中央環の ρ=1 切断長6は、標準旗の接空間から得る下界4と、二つの相異なる有理点の下界1,1で使い切る。ρ の重みが1なので非零 ρ の全域はこの切断の積となり、原点完成の極小素 ideal は三本の滑らかな軸に尽きる。

追加二点のそれぞれで全61変数の周囲接次元は17である。一方、固定 q の9次元 β 核上で第135の二次式も恒等零で、q 軌道の次元8にこの線形束を広げられる。滑らかな17次元の t=0 部分を含み、周囲の接次元も17であることから周囲は正則であり、この部分の局所定義 ideal は零である。よって周囲環自体に t=0 が成り立つ。標準旗の相対 D5 等号を合わせれば、実 ideal tS の特殊化は三本の軸すべての一般点で零となる。A 上有限な重み加群の議論と étale 復元により ambient 除去開を得る。既約16次元の閉包から補集合の β 像が高々15次元となる段階も適切である。[純三次尾の端点](S61_MARKED_SIGMA_PURE_ENDPOINT_REMOVAL_20261102.md)

h=0 については [1:2:0] の中央環を別に用いる。ρ=1 で長さ4が標準旗の横断長さの下界に一致するので唯一の軸が残る。全 H15 の通常旗で得た t=0 をこの軸の一般点で用い、同じ実加群の有限重み議論に戻せる。h=0 の意味は正規化された core における一条件であり、群の下での半不変性が固定旗上の既約12次元部分を保つ。旗軌道と合わせた既約16次元の除去開から一般 β 上の全 h=0 点が除かれる。[h=0 の除去](S61_MARKED_SIGMA_ZERO_H_REMOVAL_20261102.md)

特殊な [1:3:0] と [0:1:0] での実直線はこの結論と両立する。それぞれは固定射影 core なので joint 像は高々15次元である。保存された分類は symplectic スケールに対して不変な直線だけを取り、線形 pivot の全零点と二次数体の両共役を分けている。任意の非斉次直線や高次の弧の分類へ拡張していない。[斉次 pencil の場合分け](S61_MARKED_SIGMA_HOMOGENEOUS_PENCILS_20261102.md)

監査は上の幾何と主要 producer の分岐、長さと次元の整合、入力ハッシュを対象とした。元135式の再構築や Gröbner 基底の別計算は行っていない。
