# 保存済みD12剰余の二成分射影の入力設計

本書は入力と算法の準備のみであり、二つの射影値は計算しない。
独立Newton検証済みの固定軸 `e=d=0`、既存素数32003上の
`D12 mod H_axis=[27788,575,7510,2387]` を再利用する。

厳密因子表から同じ軸の二因子は

```
S4_axis = 160-4000a,
R7_axis = -6408+63000a-5605000a²+24000000a³.
```

両先頭係数と定数項は32003で非零である。従って受理済みの四次商環から
各一次・三次商環へ自然な写像があり、`a` および既存のLCDの単元性が
継承される。新しい物理源の評価、点、素数、因数分解、GCDは不要である。
商環が体であるという仮定は置かない。

値計算が別途承認された場合に行うのは、保存済み四係数の最大4回の
単項式長除算と積戻し検査だけである。成分剰余が非零なら、その成分因子の
`D12` に対する非整除性が従う。零ならこの固定像についてのみ未決着である。
幾何的既約性と完全な六因子局所化への素性が別に閉じている成分では、
非零結果はその成分内の非空な二次元開集合を与える。
実際のFitting不良集合、全域の立方次数57、または分類の完了は主張しない。

出力は `reports/S61_TWO_TAIL_COMPONENT_AXIS_SOURCE_20261105_v63/`。
値ワーカーの実行には親の新しい承認を要する。
