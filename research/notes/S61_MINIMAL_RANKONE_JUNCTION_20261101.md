## 1. A1曲線の普遍長さ下界

M0テンソルを

```
Qxy=x², Qyz=−b x²−2d xw−3h w², Qyw=a x²
```

と書く。次のDarboux変換を直接検証する。

```
A=−a, B=b−2da+3ha²,
(x,y,z,w) ↦ (x, y+A z−B w, z+B x, w+A x).
```

変換後はa=b=0、dがd−3ha、hは不変となる。
さらに対角行列diag(ρ,ρ⁻¹,λ⁻¹,λ)と射影スカラーρ⁻²は

```
d ↦ d λ²,   h ↦ h λ³/ρ
```

を与える。h(d−3ha)≠0なら、一般二次体拡大でλ²=(d−3ha)⁻¹を選び、
ρ=hλ³とすることでQcan（a=b=0,d=h=1）へ移す。
全135斉次化のSp4同変性は既存の独立点検済み証明に依存する。

Qcanに対する元134最高式のβ核は九次元である。
この**全九変数**を保った最高135式の射影chart Jacobianは階数42。
報告書は最初の70行の定数核、残余行列、その二次元の有理核を保存し、
全行列との積が恒等的に零であることを照合する。
階数上界は全小行列の恒等的消滅なので、特別なβ係数への代入でも失われない。
従ってこの正規化開で実在する一次元曲線の一般無限遠局所長は少なくとも2。

## 3. 三次初期式による上界5

二次残差A2と三次残差A3を計算する。

正確なQQ上のGroebner計算で

- v0=1とした商の長さは5

を確認する。前者を確認してから後者を使用しており、無限遠方向を落とした点数だけを数えていない。
従ってgr SはC[v0]上有限で、SはR=C[[u]]上有限となり、
その一般階数は高々5。有限加群のフィルトレーション比較により、
この階数は一次元のHilbert–Samuel多重度と一致する。

同じ二本の枝は**全環S**の一般長さを少なくとも3+2=5にする。
従ってSのR一般階数は5であり、二つの一般因子の長さは正確に3と2で、他の因子はない。
主曲線因子は全Jacobian階数上界42によりArtin埋込次元が少なくとも2。長さ3なので、その極大イデアルは平方零であり、t²=0となる。

従って(t²)のR一般階数は零で、有限長部分に含まれる。

S/(t)のR階数が5であるとは主張せず、(t)自体のR捩れ性も使用しない。
この論法はR捩れを許し、Sの平坦性を必要としない。
