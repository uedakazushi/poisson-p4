# 全S61の重み6帰結の独立点検

2026年10月31日。`S61_UNIVERSAL_WEIGHT6_20261031.md` の新しいイデアル帰結G6を受理する。
G6は全一次部分を記号のまま扱う普遍的恒等式から得られ、一般一次部分上で二次式の線形包を
134次元から135次元へ増やす。元のイデアルは変わらず、ファイバーの有限性・次数は未決である。

## 1. 先行する階数証明書の範囲

`s61_fiber_quadratic_span.py` の134次小行列式の論証に問題はない。
70個の重み4式のq²係数は一次部分βによらず、64個の重み5式のq²係数はβに線形である。
従って非零の小行列式はβに関して高々64次であり、非空開集合上で134個の二次斉次部分が独立となる。
この64は**小行列式のβ次数**であり、ファイバーの次数の上界ではない。

定数係数の行操作では一次式を得られない、という結論に限る。
qの多項式を係数とするイデアル帰結の存在は、この階数から否定できない。

完全な三次Macaulay計算の行数6164、列数17296も確認した。
行は134式とその45個ずつの一次倍数、列は45変数の三次以下の単項式である。
F32003上のrank6073は三次pivot5938と二次pivot135の和であり、全行の関係は91次元。
6030個の一次倍数の三次部分の核は92次元となる。
純Pythonの1979行で止まった計算と、C++で全行を処理した計算は正しく区別されている。
疎行消去の実装・中心化・列順序を点検し、指定した素数32003での計算方法に誤りは見つからなかった。
これらの有限体データだけから標数零の追加式やファイバー次数は推論しない。

## 2. 70個の二次斉次式の線形syzygy

β=0の二次方向をQ(q)、`[J,Q]=0` とする。`Jac(Q)=[Q,Q]/2` はアフィン三次のtrivectorで、
生の係数は80個である。保存された70式への80×70定数行列の等式を確認した。
この等式によって、Schouten括弧から得る恒等式と保存式の正規化・符号が対応する。

本文の `[Q,T]` の成分式は、`Jac(Q)=[Q,Q]/2` の規約と整合する。
標数零のgraded Jacobi恒等式 `[Q,[Q,Q]]=0` の四次係数35個が、
70式の一次係数syzygyを与える。この35次元部分をBとする。

全線形syzygyを求める行列は3150×16215である。
行番号 `j*70+i` は正確に `q_j F_i^{top}` を表し、添字はすべて0始まりである。
保存された36本の核ベクトルについて、独立コードが各恒等式をQQ上で直接再計算した。
さらに、これら36本の独立性は32003を法としても保たれる。

独立コードは3150行の三次係数行列を別の有限体消去で計算し、rank3114を得た。
ここで使う論理は次の二つの厳密な不等式である。

- 36本の独立な**有理係数**核ベクトルがあるので、QQ上のrankは3150−36=3114以下。
- 分母と互いに素な素数でrank3114なので、QQ上のrankは3114以上。

よってQQ上のrank3114、核次元36が確定する。有限体のrankをそのまま持ち上げたのではない。
Bの35本も有理恒等式として確認し、Bと選んだ125係数のsyzygyを合わせたrankが36となることを確認した。
従って選んだ一本はBに属さない。

## 3. 全61変数での普遍的帰結

選んだsyzygyを `Σ γ_ji q_j F_i^{top}=0` と書く。
同じ係数で**元の全重み4式**を用いて

\[
G_6(\beta,q)=\sum_{j,i}\gamma_{ji}q_jF_i(\beta,q)
\]

と定める。q³部分は普遍的syzygyにより消える。
F_iの重みが4、q_jの重みが2なのでG6の重みは6である。

独立コードはS61の生成・再構成コードをimportせず、不変な134式JSONからこの積和を直接作った。
保存された9257単項式すべてと一致し、各項の重みが6、q次数が1または2であることを確認した。
従ってこれはβの特殊化や有限体だけで現れる関係ではない。
また、この明示的な積和により `G6∈(F_1,…,F_134)` はスキームのイデアルとして成立する。

指定されたtoric点でβを固定し、q=q*+vと中心化すると、G6は790項の二次以下の多項式となる。
乗数もq_j=v_j+q*_jへ移すことが必要であり、証明書と独立実装はその定数項も含めている。
この790項の全係数を再現した。

元の134式とG6から作った135次の二次係数小行列を独立に組み立て、その有理行列式が
保存値と一致し、非零であることを確認した。この行列式のβ次数は高々
`70×0+64×1+1×2=66`。
従って非空開集合上で二次斉次部分の線形包は135次元となり、この135式の定数結合にも一次式はない。
これは多項式乗数を用いた、さらに後の消去を妨げる結論ではない。

135次小行列式を32003で還元した値も854で非零である。
G6は明示的な一次乗数結合であり、有限体三次Macaulay計算の追加二次方向は一つだけなので、
G6の還元はそこで検出された追加方向を張る。この意味で、以前の有限体の一方向が
有理係数かつ普遍的なイデアル恒等式へ持ち上がった。

## 4. 35個のBianchi帰結が追加方向にならない理由

再構成された双ベクトルを `Π=J+L+Q_total+C` とし、Jacobiの残余をJ4,J5と書く。
低次Jacobiは既に零で、Cはradialな三次型なので `[C,C]=0`。
普遍的Jacobi恒等式のアフィン係数次数4の部分は

\[
[Q_{total},J_4]+[L,J_5]=0
\]

である。`Q_total=Q_dir(q)+Q_0(β)` と分けると

\[
[Q_{dir}(q),J_4]=-[Q_0(\beta),J_4]-[L,J_5].
\]

右辺の係数はqに依存しない。従って35個の通常のBianchi syzygyを全重み4式に適用しても、
元の134式の定数線形包に吸収される。この幾何学的説明と、指定点で保存された
35個の定数係数復元式を独立に再検算した結果は一致する。
36本目の選択には、この35次元部分から外れていることが重要である。

## 5. 無限遠・アフィン有限性についての制限

その幾何学的議論を次節に記す。計算証明書自体の確認範囲とは区別する。

G6は新しいPoisson条件でも、新しい成分を切り落とす方程式でもない。

## 6. 幾何学的補強：既存flag incidence全体の残存

**命題。** 固定primitive一次部分βについて、旧134式を個別に二次斉次化した模型に
`G6^h` を追加しても、既に構成したisotropic flag incidence

\[
\{[Q_{v,w}]:\Omega(v,w)=0,\ \beta_v(v,w)=0\}
\]

は無限遠に閉部分集合として残る。従ってβ≠0なら純3次元、β=0なら4次元のこの部分を、
G6一つの追加では取り除けない。真のt飽和やアフィン次元についての主張ではない。

**証明。** 以下は複素数体上のSp4表現を用いる。
`d=[J,·]` とし、Kを `dQ=0` を満たす二次双ベクトルの45次元空間とする。
またEを、アフィン三次trivectorのうちdで閉じたものの空間とする。
生の三次係数は80個、dの像は10次元なので `dim E=70` である。
低次Jacobiを消した全再構成の残余J4も、下位のBianchi恒等式 `dJ4=0` によりEに属する。
この点はβ=0のJac(Q)に限った主張ではない。
保存済みの重み4の70式は、このEの固定線形座標であり、80→70の対応と整合する。

qに線形な係数を持つ70個の最高二次式の関係空間は、Sp4同変写像

\[
K^*\otimes E^*\longrightarrow\operatorname{Sym}^3 K^*
\]

の核Sである。上の厳密計算によりdim S=36。
Schouten恒等式 `[q,Jac(q)]=0` の35係数の像Bは、Sp4に安定な35次元部分空間である。
したがってS/Bは一次元表現である。Sp4には非自明な代数的characterがないため、この表現は自明。
選んだsyzygyをkとすると、任意のg∈Sp4について `g·k−k∈B` となる。

この事実を、一次部分が非零の再構成へ移す際にはqのアフィンな変換を処理する。
primitive gaugeを取り、低次Jacobi条件
`dQ_total=−[L,L]/2` を考える。
Sp4は標数零で簡約群なので、dの像への線形全射にSp4同変な線形右逆を選べる。
これによりLの二次式として同変な特解Q0(L)を取り、
`Q_total=q+Q0(L)`、q∈Kと書ける。ここでqはSp4に対して線形に変換する。
三次部分Cは既存の低次Jacobi消去により一意なので、その再構成も同変である。

この座標でkをJ4へ適用した式をGとする。
`g·k−k∈B` により、gによるGの差は `[q,J4]` の係数の定数線形結合となる。
第4節の全Bianchi恒等式から

\[
[q,J_4]=-[Q_0(L),J_4]-[L,J_5].
\]

保存式へ戻す際、重み5の残余係数J5は、保存された重み5式の定数結合と、
重み4式にβの一次式を掛けたものの和として復元される。
これは154式から134式へのBianchi除去と、元のJacobi係数の線形復元による。
重みにより、この復元にq依存の係数は入らない。
従ってGの変換差は `β² F4 + β F5` 型の、qに関して定数係数の結合である。
qに関する最高二次部分を取れば、Gの変換差は旧134式の最高二次部分のイデアルに属する。

旧座標gaugeとの差についても同じ結論が保たれる。
Q0の選び方の変更はqをβ²の式で平行移動し、kがqに線形なのでGをβ²F4型の結合だけ変える。
旧gaugeとprimitive gaugeの間のperspective変換も、二次座標には同じ型の平行移動を与える。
低次Jacobiが零であるため、その最初の残余J4は原点で微分が恒等なperspectiveにより変わらず、
J5の変化はβF4型である。
従って、保存されたG6の二次最高部分の消滅条件は、旧134式の二次最高部分の零点集合上でSp4不変である。

Sp4はisotropic flag多様体に推移的に作用する。
代表 `u38=1` ではG6の二次最高部分が全βで零であることを厳密に確認した。
任意のflag incidence上の点をこの代表へ移すと、βも同時に変換されるが、
旧最高二次式の零点集合への所属は保たれる。
その集合上では上記の変換差が零なので、G6の二次最高部分も零となる。
β=0ではG6自体が恒等的に零である。以上で命題が従う。□

この補強は、二つのflag標本から全flagへ外挿した結果ではない。
厳密な36次元・35次元の計算と、Eの同定、同変な低次再構成、Bianchiによる
q非依存係数の復元を用いた幾何学的証明である。
同じ研究タスク内の別担当も、この二つの同定を明示した論証を点検し、論理上の問題を指摘しなかった。
