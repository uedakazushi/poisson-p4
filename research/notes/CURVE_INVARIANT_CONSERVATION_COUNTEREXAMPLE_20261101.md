# 全S61上の不変量保存則に対する反例

2026-11-01。**canonical Pfaffian curve の c₄,c₆ が基点移動で一定である、という
主張は全Poisson構造については偽である。** 以下は全S61の134式で検証した反例である。
ただし canonical curve の判別式は恒等的に零であり、Δ≠0 に局所化した保存則の
成否は決めない。既知の三つの支配成分について証明した保存則とも矛盾しない。

後続更新：`CURVE_INVARIANT_SMOOTH_COUNTEREXAMPLE_20261101.md` に Δ≠0 の反例も得た。
以下の単純な例は、局所的な極の存在を示す独立した反例として保持する。

## 1. 射影四空間へ延長する明示双ベクトル

四変数 z₀,…,z₃ の log-symplectic 双ベクトル

    P₀=z₀ ∂z₀∧∂z₁+∂z₂∧∂z₃

に、多項式自己同型

    y₀=z₀+z₁²+z₂²+z₃²,   yᵢ=zᵢ (i=1,2,3)

を施す。得られる P の非零な上三角成分は

    P01=y₀−y₁²−y₂²−y₃²,
    P02=−2y₃,   P03=2y₂,   P23=1.

Poisson 性は自己同型による押出しから従い、計算でも全Jacobi恒等式を確認した。
これはアフィン二次式なので、同次座標 (x₀:x₁:x₂:x₃:x₄)、yᵢ=xᵢ₊₁/x₀ で

    B12=x₀x₁−x₂²−x₃²−x₄²,
    B13=−2x₀x₄,   B14=2x₀x₃,   B34=x₀²,
    B0i=0

と斉次化し、P⁴ 上の大域的Poisson双ベクトルを得る。
射影双ベクトルの Jacobi 式も厳密に零である。
アフィン退化因子 y₀−y₁²−y₂²−y₃²=0 は滑らかで、その上の一般階数は2である。

## 2. 基点に沿う厳密不変量

p(t)=(t,0,0,0)、t≠0 とする。定数項を J にする線形 frame は
F=diag(1,t⁻¹,1,1) である。一次部分を既定の perspective によって primitive 化し、
canonical 行列 Φβ を作る。その最後の行・列に5tを掛けて分母を払えば、Fisher の
tensor 縮約は全て QQ[t] 上で行える。

計算結果は

    c₄(βp(t))=256/t⁴,
    c₆(βp(t))=4096/t⁶,
    Δ(βp(t))=(c₄³−c₆²)/1728=0.

従って dc₄/dt=−1024/t⁵、dc₆/dt=−24576/t⁷ はともに零でない。
これは有限個の標本値からの推測ではなく、QQ(t) 上の恒等式である。
全双ベクトルへ実際の射影 frame と perspective を適用して61座標を求め、
復元150係数、全134式、射影Jacobiを同じ QQ(t) 上で独立に確認した。

## 3. 排除される方法と残る問題

この例により、不変量の基点微分が無条件に全S61イデアル、またはその根基に属する
という主張は否定される。微分条件を全方程式に追加すれば、真のPoisson解を失う。
また、滑らかな rank-2 退化因子の近くで局所Jacobiだけから c₄,c₆ の極が消えると
証明し、射影空間のコンパクト性で一定性を導く案も成立しない。

一方、この例は Δ=0 に含まれる。Δ≠0 上の保存則、すなわち飽和イデアル
I_S61:Δ^∞ の根基への微分条件の所属は、この例だけでは決まらないが、後続ノートの
別の反例によって否定された。
一般一次部分 β* は Δ≠0 なので、この区別は一般ファイバーの探索に実質的に関係する。
本ノートは反例の既存成分への所属を決定せず、新成分としても数えない。
