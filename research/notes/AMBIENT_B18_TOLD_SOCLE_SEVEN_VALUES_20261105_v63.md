# 七つの旧 socle 障害の固定値

既証 source gate の七汎関数だけを、保存済み実 R37 二次値へ適用した。各値は独立に、同じ source を既存 C0 root の ordinary rA² 係数へ fold した式でも計算し、一致する。

七値はすべて零である。これは選んだ十分条件が陰性だったことだけを示す。新 Tnil の二つの候補 HF5533 と HF55321 のどちらも、この結果では除外しない。完全917三次像、元の nil 理想の積、DVR ell の指数について結論しない。

入力はすべて凍結済み値であり、新たな physical source、jet、implicit solve はない。rA は source の一変数で、DVR ell とは別である。
