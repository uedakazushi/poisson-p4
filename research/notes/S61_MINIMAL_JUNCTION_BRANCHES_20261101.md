# 最小冪零型の八つの交点における実在枝と長さ下界

2026年11月1日。本証明書は固定βの全135斉次化の中にある実在枝を構成し、
同じ枝上の一般長さの下界を与える。上界・t飽和による除去は別証明書の課題である。

## 1. 点の指定

頂点座標は

```
u4=u5=u12=u13=0, u14=k, u49=2k+1,
u26=2, u35=3, u50=4, u51=5,
(u25,u27,u34,u36,u37,u48)=(2,3,5,7,11,13).
```

従ってK=19,L=5,U=2,V=3。
各点のqは `S61_MINIMAL_VERTEX_EXHAUSTION_20261101` の
`baseline_solution` を指定kへ代入したものである。
以下の表の八点を扱う。

|---|---|---|---:|

各点で、表の枝の接ベクトルは互いに一次独立である。
したがってこれらを同じ枝として重複計数していない。

## 2. 主枝は固定βのまま存在し、kが動く

十一個の頂点パラメータ(k,K,L,U,Vと他の六係数)とSp4の積をsourceとする。
既存の基線解q(k,K,L,U,V)は、ここで列挙したkで分母を持たず正則に延びる。
四つの自由基線曲線がある特殊値でも、この正則な主枝の延長自体は一意に指定される。

βへの微分は各点で階数16。
k方向を除いた微分も階数16であることを、非零小行列で確認した。
さらに全微分の核からdk≠0かつdq≠0の方向を明示的に選んだ。
sourceの固定βファイバーは滑らかなので、この方向に沿う形式曲線が存在する。
qへの微分が非零であり、その像は滑らかな主枝Cを与える。
全135最高式のSp4同変性からCはt=0内にある。

選んだC上でkは一様化変数である。
三項Gの係数cは

\[
c_{M0}=-\frac{2}{3(2k+1)},\qquad
c_{M1}=-\frac{3k+1}{3(2k+1)}
\]

で、両方のk微分は指定点で非零。
従って同じCの一般点ではcの有限個の例外値を避ける。
既存の有限symplectic shearとM1の規約変換c_can=2c+1により、
`S61_MINIMAL_INFINITY_FORMAL_RANKS_20261101` の全九次元β核上の普遍上界を適用できる。
全135斉次化JacobianはM0で42以下、M1で43以下。
45次元のchartで一次元枝を除くと、相対埋込み次元はそれぞれ2以上、1以上なので、
同じ主枝の一般Artin局所因子の長さはそれぞれ3以上、2以上となる。
別のβ標本における形式環の結果を、そのまま流用した議論ではない。

## 3. 固定頂点の曲線

修正・独立点検済みの `S61_MINIMAL_VERTEX_EXHAUSTION_20261101` に保存された
全グラフを用いる。同じkの各曲線について、その自由係数をtとし、
t=0（自由基線の場合は主枝の該当係数の値）で指定qに一致することを確認した。
さらに同じ固定βの全135最高式に代入して、tの恒等式として零であることを再確認した。
微分は非零で、主枝を含む他の表中の枝と接線が独立である。

単に実在する滑らかな枝であることから一般長さは少なくとも1である。
自由基線M0,M1については、同じβのまま自由係数を1とした点が
`S61_MINIMAL_BASELINE_THICKENINGS_20261101` の指定点に完全一致することを照合した。
それぞれ同じ既約有理曲線上の非空開部分で長さ4、3が既に証明されているため、
ここで扱う同じ枝の一般因子も少なくともその長さを持つ。

M1,k=−1/3のg2曲線についても、g2=1の点が
`S61_MINIMAL_CUBIC_TAIL_20261101` の指定点に完全一致することを照合した。
同じ既約曲線の非空開部分で長さ3が証明済みである。
このように一般長さ3を、交点だけの接空間から推測していない。

## 4. 上界計算への入力

ある線形接パラメータuが表の全枝で非零一次項を持ち、完成局所環SがC[[u]]上有限なら、
各滑らかな枝は一般ファイバーに剰余体C((u))の異なる局所因子を与える。
したがって一般階数は表の合計以上である。
後続の初期イデアルによる上界がこの合計に一致すれば、既知のt=0枝が一般ファイバーを使い切る。
本ノートだけではその上界や飽和除去を結論しない。

```sh
.venv/bin/python code/s61_minimal_junction_branches_20261101.py --output /tmp/minimal-junction-branches.json
```

全検査は有理数体上で行う。主枝の普遍階数、二種類の既証明の形式環、
全135斉次化の同変性は明示的な依存結果として保持する。
