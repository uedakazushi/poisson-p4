# K=0 chart の一次 light frame の独立監査

2026-11-02。対象は `S61_BINARY_HYPERPLANE_LINEAR_LIGHT_FRAME_20261102`。
主 source・候補の使用方法・全 implicit 模型の同一性を監査し、主 producer を
別実行した。保存された座標変換行列の二 determinant は、主実装の DomainMatrix
determinant と別の疎 Laplace 展開で QQ[a,e,d] 上再計算した。
元135式の係数や候補の整数関係探索を第二実装したという意味ではない。

## 1. 可逆な枠変更

主 producer の別実行は3.114秒で成功し、実行時間を除く全出力が主 report と一致した。
候補の七列は元135式の J に対して kernel 条件を全係数で検査される。
heavy 列は旧列の `B/50` 倍であり、新旧の重みはともに
`(1,1,1,1,1,2,1,1)` である。

自由行射影は元座標での単純な行抜き出しではなく、定数 chart 基底 W の逆を
通した射影である。この射影 pi について、主 source は
`pi*Told=I8`、`R=pi*Tnew`、全45×8成分の `Told*R=Tnew` を確認する。
旧三つの切断行が新枠でも零であることも直接確認される。
従って新枠は別の横断切断を選んだものではない。

保存行列に対する独立の Laplace 展開は

\[
\det R=51200000\,aB,\qquad
\det R_{\mathrm{light}}=2560000000\,a,
\qquad \det R=(B/50)\det R_{\mathrm{light}}
\]

を再現した。`aFBC != 0` 上でこれらは単元で、未知の追加因子を反転する必要はない。
light の全係数は整数で絶対値240以下、core 次数は一以下、heavy の core 次数は
三以下であることも主再実行で確認した。

## 2. 陰関数再帰への代入

core を係数環 A の元とし、旧自由変数を `x=Rv` と置く。
これは重みを保つ A 上の多項式環・完備局所環の同型である。
線形項は `Told*R=Tnew` により一致する。
同じ選択行と旧右逆 U を使う補正再帰では、A 線形な U の作用と
双線形な H の評価がこの代入と可換である。
従って各通常次数に関する帰納法で、新補正は旧補正への代入と一致する。
また旧自由射影で U の像は自由行零なので、補正は同じ自由座標を保持する。

既証明の正重み条件から旧 implicit 解は通常四次で正確に止まる。
よってこの一致は接空間だけでなく、全135残余を含む完全な多項式模型について成立する。
t は元の z の一成分として同じ代入で引き戻されるので、別の t 関数へ取り替える操作でもない。

## 3. 受理範囲

指定 `aFBC` 開の同じ transverse scheme を、core 一次の七 light 列と
多項式 heavy 列で表示できるという主張を受理する。
新しい階数被覆、全点の長さ65、ambient 飽和除去はこの枠変更から主張しない。
最終入力 hash と再実行・独立 determinant 検査の範囲を同名 report に保存した。
