# Toric 三次被覆の根座標は S61 上の重み4多項式である

2026-11-01。`TORIC_JACOBIAN_TWO_TORSION_20261101` と
`TORIC_E2_SCALAR_INVERSE_20261101` の一般被覆の根座標 X を、S61 の変数
(β,q) の多項式として構成する。β の分母も q の分母も用いない。
以下の三次方程式と被覆の同定の主張は **T01 の被約閉包** に限る。
全 S61 の各解がこの三次方程式を満たすとは主張しない。

## 1. 多項式の定義

標準 Poisson 行列を J とし、primitive な線形2-form を β(y) とする。
従って逆2-form の定数行列は J⁻¹=−J である。
既知の二つの二次 section を Q51,Q52 と書き、

    qbar = (2 Q51 + Q52)/3

と置く。同じ β を持つ二つの S61 点の二次双ベクトルの差は、45次元の
線形空間 K に属する。その affine 二次双ベクトルを δP₂ とし、

    ηδ = −J δP₂ J

と置く。これは閉な二次2-form である。ここでは δq=q−qbar に対応する
δP₂ を用いる。

β から次の二つの閉な二次2-form を作る。

    ξ(y) = −J β(y)y,
    η₁ = (Dξ)ᵀ J(Dξ),
    η₂ = d( Pf(β(y)) · (−Jy) ).

最後の括弧は係数列が −Pf(β)Jy である1-formを意味する。
いずれも β の係数に関して二次である。η₁ は定数2-form の pullback、
η₂ は exterior derivative なので閉性を持つ。

ηᵢⱼ(y)=Σₐᵦηᵢⱼ,ₐᵦ yₐyᵦ と書く。テンソルは i,j に反対称、a,b に対称であり、
a≠b のテンソル成分は多項式の yₐyᵦ 係数の半分である。内積を

    ⟨η,θ⟩ = Σᵢⱼₐᵦₖₗ꜀d ηᵢⱼ,ₐᵦ θₖₗ,꜀d Jᵢₖ Jⱼₗ Jₐ꜀ Jᵦd

と定める。和は全順序付き添字について取る。この規約は係数の2倍因子を含めて
証明書に固定した。K 上のこの内積は非退化であることも45次行列で検証した。

求める多項式は

    Xpol(β,q) = −18 ⟨η₁,ηδ⟩ −9 ⟨η₂,ηδ⟩.                 (1)

従って Xpol は q に関して一次、β の重みを1、q の重みを2とすると重み4である。
コードは45係数からなる二次多項式行 λ(β) と四次多項式 λ(β)qbar(β) を保存し、
`Xpol=λ(β)(q−qbar(β))` として直接評価できる。

## 2. 一般 toric 被覆との一致

既存の普遍再構成は、96本の associativity 方程式の解上で

    q = qbar + N(β)c

を与える。また K=Q(W16) 上の toric 代数全体は

    K[X]/(X³−27 c4 X−54 c6)

と同型であり、その中で

    c = (U X + V)/(3X²−27c4),    X = ⟨D₃,c⟩.            (2)

U,V はそれぞれ次数5、9の共変量、D₃ は以前構成した次数3の共変量である。
ここで V の定義には一般点での有理共変量の構成のみを用い、このノートの証明は
V の全域多項式性を仮定しない。

(1) の λ と (2) の線形汎関数を比較し、20成分の三次多項式行

    r(β) = λ(β)N(β) − ⟨D₃(β),−⟩

を作った。全16変数で659単項式を持つ。次の二恒等式を有理数体上で確認した。

    r(β)U(β)=0,    r(β)V(β)=0.                          (3)

計算は次の6次元線形 slice 上で、6変数すべてを記号として残して行った。
重み座標 b において

    b = s₀(1,2,…,16) + s₁e₁₁+s₂e₁₂+s₃e₁₃+s₄e₁₄+s₅e₁₅

（添字は0始まり）を用いる。10個の Sp₄ 軌道方向と6個の slice 方向を合わせた
微分の行列式は 8428695240≠0 であり、今回のコードでも再計算した。
従って Sp₄ と slice の積から W16 への写像は支配的である。

(3) を (2) に代入すると slice 上の三次代数全体で Xpol=X となる。
これは根の有限個の標本における検査ではない。
Xpol は完全なテンソル縮約であり、同じ第一ジェットを持つ二点の差に対する
K の作用を用いるため Sp₄ 不変である。旧 S61 gauge から primitive gauge へ移す
同一の perspective は、二点の二次部分の差を変えない。qbar は二つの共変 section の
アフィン結合なので、その差も K のテンソルとして変換する。
(2) の共変構成も Sp₄ と整合する。したがって slice の三次被覆での一致は、
支配性によって一般 toric 被覆全体へ延長される。

ここで N の各係数が、associativity 方程式から独立な全 c 空間上でも
単独で共変であるという余分な主張は用いない。必要なのは toric 解上の
普遍的な再構成と、その幾何学的な共変性である。

## 3. 被約閉包への延長

T01 の被約 S61 閉包の座標環を B とする。既約性から B は整域である。
Xpol は B の元であり、一般点で (2) の X に等しい。従って

    Xpol³ −27c4 Xpol −54c6 = 0

は B 全体で成立する。これは一般点での等式を、既約被約閉包上の正則関数の
等式へ延長したものである。非被約な全 S61 環への延長は含まない。

この結果は、全域の多項式 U,V が別途得られれば、さらに強い結論を与える。
R=Q[W16]、Δ=(c4³−c6²)/1728 と置く。A=R[X]/(X³−27c4X−54c6) は
Δ≠0 上で有限 étale で、f'(X)=3X²−27c4 は A[Δ⁻¹] の単元である。
(2) と q=qbar+Nc により全 q 座標が A[Δ⁻¹] に属し、B[Δ⁻¹]⊂A[Δ⁻¹]。
逆に今回の Xpol∈B と R⊂B より A[Δ⁻¹]⊂B[Δ⁻¹] である。
両者は同じ一般関数体内の部分環として等しい。この包含の議論には B の正規性や
平坦性を先に仮定する必要はない。**この段落の全域結論は U,V の全域多項式性という
別の証明を依存条件とする。**
