閉性4式・primitive 条件4式を作った。制約行列の階数は8、核は16次元である。

1. Plücker 二次曲面上の四式 P A を法 Pf(P) で簡約した切断写像の階数は16。
2. 代表 Lagrangian 平面での U*(1) への評価は階数2。

4. 任意の四成分 covector A に対し、5×5交代行列の符号付き Pfaffian は
   正確に (P A,Pf(P)) であり、交代行列とその列の積は零。

特に最後の恒等式は β の標本に依存せず、A 自体を独立変数として確認した。

**零点スキームそのもの**を与える。

## 2. 一般曲線の滑らかさ・連結性・正規五次性

代表平面での評価階数2と Sp4 の推移性により、E=U*(1) は W の切断で大域生成される。
零点 incidence は Q 上の階数14ベクトル束で、滑らかな既約17次元多様体である。
Q は射影的なので、この incidence から W への射影は proper である。
非零の c2(E) は nowhere-zero 切断を排除するため射影は全射。
標数零の generic smoothness と properness により、W の非空開集合上の
**全ファイバー**が滑らかな純一次元になる。この properness を使えば、
単に全空間のある開部分で滑らかという結論との混同も生じない。

普遍列と H²=2[直線] から c2(U*)=[直線]。
従って c1(E)=3H、c2(E)=5[直線] であり、一般曲線の次数は5。
随伴公式は K_C=O_C を与える。

切断空間と Koszul で用いるコホモロジーも、spinor 束の名称に依存せず確認できる。
U*=U(1)、H0(U)=0、および二次曲面上の直線束の中間コホモロジー消滅を用いる。
普遍列の負の捻りから

    H1(U) ≅ H2(U(−1)) ≅ H3(U(−2)) ≅ H0(U)* = 0,
    H1(U*) ≅ H2(U) ≅ H3(U(−1)) ≅ H0(U(−1))* = 0.

最後の同型は Serre 双対性と K_Q=O(−3) による。
H0(U(−1))=0 は U(−1)⊂O(−1)^4 から従う。
よって H0(U*)=C4 であり、捻った普遍列から h0(U*(1))=20−4=16。
上の単射性と合わせ、W→H0(E) は同型である。

正則切断の Koszul 列

    0 -> O(−3) -> U(−1) -> I_C -> 0

について、H1(U(−1))=0 は
0→U(−1)→O(−1)^4→U→0 から従い、H2(O(−3))=0。
従って H1(I_C)=0、H0(O_C)=C であり、滑らかな C は連結・既約・種数1となる。
一回捻った列から H0(I_C(1))=0。
次数5の正の線形束の Riemann–Roch により h0(O_C(1))=5 だから、周囲の P4 の
五つの一次式は完全線形系であり、C は楕円正規五次曲線である。

制限前評価の階数4も確認したので、一般 β では全ての平面で Aβ(Π)≠0。
Cβ 上の線 J Aβ(Π) は Π に含まれ、強化旗条件への一意な持ち上げを与える。
この議論は真の射影閉包の無限遠を決定するものではない。

## 3. 局所次元3の計算を原方程式から再構成

元の局所実装・specialize・chart は import していない。
保存された S61 の134式と普遍的 G6 の疎な単項式から、指定 β を代入し、
各 q 次数dの項に t^(2−d) を掛け、u38=1 の射影チャートを直接作った。
その45変数チャートについて以下を確認した。

- 元の全135式から再構成した Jacobian は保存行列と完全一致し、階数38。
- 保存した接空間基底の階数は7で、t 成分は零、Jacobian との積も零。
- 保存された十個の左核行は実際に Jacobian の左核にあり、その二次射影を
  全チャート二次式から再計算すると保存された十形式に完全一致する。
- 十形式は独立で、全 Hessian の共通核は三次元。
- S61 の全復元式から一次部分を取り直し、primitive gauge を適用して
  v=−e2,w=−e4+a e3 の incidence 微分が非零であることを確認した。

二次形式の共通 radical が三次元なので、十形式は四次元商空間の Sym² に属する。
その次元は10であり、独立性からその全空間を張る。

次元の上界を得る際の正当化は次の通りである。Jacobian の独立な38方向を使って
形式的陰関数定理により38変数を消去すると、完成局所環は七変数の冪級数環の商になる。
残る式の二次初期項は、左核への射影後の上記十形式を含む。
従って接錐の台は三次元の共通 radical に含まれ、局所次元は高々3。

一方、G6を加えた全135式にも旧旗 incidence が含まれるという別途監査済みの結果
（`S61_UNIVERSAL_WEIGHT6_REVIEW_20261031.md` §6）と、上の非零微分により、
この点には滑らかな三次元の旗部分が含まれる。これが下界3を与える。
従って局所次元は正確に3である。

接錐の台はその三平面であり、接空間が七次元なので接錐スキームは非被約である。
これは元の局所スキームの非被約性や完成局所環の完全な表示を証明しない。
