# R0二重根端点を通るM0/M1の二本の実在枝

2026年11月1日。βを

```
(u4,u5,u12,u13,u14,u25,u26,u27,u34,u35,u36,u37,u48,u49,u50,u51)
=(0,0,0,0,−2/3,2,2,3,5,3,7,11,13,−1/3,−15,10)
```

に固定する。これはk=−2/3、K=L=0、U=2,V=3である。
R0端点はG=z²w、従ってQyz=−z²,Qyw=2zwで、他成分は零。

M0の枝を

```
G=z²w+τ(−18x²z−3x²w+2xzw),
Qxy=τx², Qyz=−G_w, Qyw=G_z
```

とする。M1の枝は

```
G=z²w+τ(12x²z+2x²w−xzw),
Qxy=Qzw=τx²/2, Qyz=−τxz−G_w, Qyw=G_z.
```

いずれもτ=0で指定R0端点になる。
τ≠0では射影的に既存g6-tailのt=1/τ表示に一致する。
対応するGの全係数は既存の最小頂点尽くしに記載されている。

証明書は両枝をS61の45座標へ変換し、固定βの元134式と追加G6の
最高q次数二部分に直接代入して、τの多項式としてすべて零であることを確認する。
二本の射影chart接線は独立であり、全斉次化135式のJacobian核に入る。
全61座標、射影chart、両接線と核基底における接座標を報告書に保存する。
したがってこれは同じβの二本の滑らかな実在枝で、各一般局所長の下界は少なくとも1。

R0の主枝との接線の関係、局所多重度上界、およびtの冪零性はこの証明書では主張しない。
それらは独立した局所解析と組み合わせる必要がある。

一般K,Lを保った両tailの射影端点はともに

```
(z−Lx/2)²(w+Kx/3)  mod x³
```

である。今回のK=L=0はこの二重根端点の具体的な有理点である。
