# 元 connecting 二列の下位キャッシュと63次元代数

ここでは新しい source 応答や connecting の値を求めない。変数順を同じ実 R0 の `(z0,…,z6,r,ell)` とし、単項式基底を、plane 四次以下十五個、各 zi と plane 二次以下の積四十二個、z0,z4,z5 の二次積六個とする。残りの単項式を零とする単項式商 B63 を用いる。

未知入力が残るのは plane 四次五個、zi と plane 二次の積二十一個、上の zz 六個で、これら三十二個はすべて B63 の socle である。既知三十一個は、同じ common105 の提供済み plane 三次入力と、Q20 の全九方向一次・zi-r/zi-ell 二次入力から正確に決まる。plane 二次以下の630入力は両キャッシュで一致する。未知を零とした表は下位拡張の選択であり、実際の未知係数を零と仮定したものではない。

`f(Phi)-f(L)=Df(Phi0)(Phi-L)`

を満たす。和・積・逆元に関する帰納法で従う。積の交差項は S²=0、非定数係数との積は mS=0 によって零になる。δ63=original20144−original40922 の全105原点微分は、独立 forward-AD 監査 d3af22d2 で零と確認済みである。従って **δ63 の B63 全体の値** はこの下位拡張だけで決まり、真の Phi 四次、mixed 三次、zz 二次の入力を新たに解く必要はない。
