# 新しい v=0 切片における26次制限の支持・分母の事前評価

このノートは計算量の事前評価だけを扱う。既存の完全な45本の26次不変式を新しい密な v=0 切片に制限する係数展開、階数計算、新しい点の評価は実行しない。

切片の座標を `(xi0,r0,s0,q0,B0)` とする（以前の t=2 切片の同名座標とは異なる）。原資料は `Q_NEW_FAMILY_V_ZERO_BETA_SECTION_20261104_v63` とその独立レビューである。

## 分母を除く有限被覆上のシンプレクティック作用

各非零係数の xi0 指数は `(1-w1-w2)/2` である。したがって次数 d の重み零不変式の xi0 依存は xi0^(d/2) で、26次では xi0^13 を最後に戻せる。

xi0=1 とし、T²=B0、R⁴=r0 の有限被覆で正重みの pullback

`diag(T/R,R/T,T²R²,T^-2R^-2)`

を作用させる。H=R²、L=R³T とすると、9個の非零成分は

```
b0=-45s0/16; b1=-30L; b2=2400;
b5=H(5q0+s0+1)/240; b6=s0/54000;
b8=-32H/3; b9=-32/675;
b14=H(s0+1)/120; b15=-64H/3.
```

すべて多項式で、合計12項しかない。有限被覆は不変式の値を変えず、残余作用から不変式中の H^a L^b は `2a+3b=0 mod4` を満たす。したがって `r0^((2a+3b)/4) B0^(b/2)` に戻る。指数は非負整数で、変数に依存する分母は残らない。有限被覆の次数を実際の像の次数とは同一視しない。

## 係数展開を使わない支持上界

上の9座標は Cartan 第2重みにより、L の座標が重み2、その他は重み±1に分かれる。次数 d、Cartan 重み (w1,w2)、L 指数 b の項では、重み+1の座標の使用個数は `(d+w2-3b)/2`、重み-1の座標は `(d-w2+b)/2` である。s0,q0 は重み+1の座標だけに現れ、一座標当たり合計次数は1以下なので、その個数が s0,q0 合計次数の上界になる。H 次数は d-b 以下である。さらに `b=w1 mod2` および `2a+3b=-w1+2w2 mod4` を使う。

これらを数えると、26次重み零の制限一本の支持は最大2874項である。この上界は消去や係数の偶然の相殺に依存しない。

L 指数 b=0,2,4,6,8 ごとの上界は1470,792,432,150,30項で、奇数指数および b>8 は出ない。12次値の上界は251項、14次は396項、18次は860項となる。原16方向の8次・12次 trace 勾配は各成分最大222項、今回必要な4×4/16×16行列 word の中間成分は最大450項で覆われる。

## 勾配と再現範囲

コードは原16変数の C,D 二次係数を微分してから切片に代入し、全32成分・全512微分を正確な有理数で再構成し、Euler 恒等式を確認する。四つの切片変数に関する微分で置き換えない。Omega^-1 の縮約は原16変数の Poisson 縮約のままである。全域の2theta、2H16も元の四次式から再構成して重みを確認するが、26次の展開は行わない。

候補45本は既に独立受理された `Q_NEW_FAMILY_DEGREE26_POISSON_BASIS_20261104_v63` の選択をそのまま用いる。Hessian は4×4の第二随伴行列Dとは異なり、唯一必要な12次 Hessian 値 `tr(theta^5 H16)` を保持する。

事前評価は1.780秒で成功した。実際の二次入口は C,D の各成分が最大5項、その原16微分が最大3項、theta/H16 が最大7項である。定数分母を払う54000、4、5を基に、行列積の係数 l1 ノルム、trace、全16方向微分と Omega^-1 縮約の三角不等式から、45本の各整数分子係数のビット上界は最大707と得られる。全支持を使う保守的な合計は、係数と四指数を固定長で記録する場合12,131,154 bytes、十進 JSON の項を32 bytesの固定オーバーヘッド付きで記録する場合28,280,160 bytes以下である（小さい共通分母・定義メタデータは別途必要）。これは実際の係数サイズの測定ではない。

したがって次の実装案は、四変数整数 FLINT で32個の C,D と512微分を構成し、cyclic trace 微分から3個の14次 bracket と6個の18次 bracketを計算し、既存12次値と積を取って選択45本を逐次保存する方法である。theta^5 H16 は独立した16×16 Hessian 値を使う。有限作用の合同条件を全出力で確認した後に r0,B0 へ戻し、最後に xi0^13 を記録する。係数の階数検査は一つの GF(32003) で行う案であり、まだ実行・承認済みの結果ではない。60秒・2GB・32MiB、出力100k項/中間150k項の停止条件を保つ計画には十分小さい厳密な支持上界だが、実時間の保証はない。
