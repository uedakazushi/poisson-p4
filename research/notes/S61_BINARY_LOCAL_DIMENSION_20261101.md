# 非平方の二平面型無限遠点：三次障害による局所次元3

2026-11-01。固定 β の135式の二次斉次化について、非平方の二平面型の一点で
標数零の局所次元が3であることを証明する。旗型・非二元型と異なり、二次障害だけでは足りず、
三次障害を加える。完成局所環、斉次化変数 t の消滅・冪零性、飽和後の枝は未決である。

## 1. 指定点と下界

Q=(x²+w²)∂y∧∂z とする。重み1座標を保存順に (2,3,…,17) としてから
u12=u13=0 と置く。この条件は Π=〈∂y,∂z〉が Cβ 上にある条件である。

Lagrange平面のchartを

    v1=(a,1,0,b), v2=(−b,0,1,d)

とすると、切断 (β_v1(v1,v2),β_v2(v1,v2)) は a=b=d=0 で零となり、その2×3微分行列の階数は2である。
従って Cβ は Π で滑らかな曲線。Cβ 上の二次形式の P²束はこの Q の近傍で滑らかな3次元部分を与える。
支持平面 Π は Q の二次係数の像として正則に復元できるので、この部分は実際に埋め込まれている。
全135最高式への包含は `S61_R0_INFINITY_20261101` §2 の普遍式による。
よって局所次元は少なくとも3である。

## 2. 有理数上の接空間と二次障害

射影chartの44変数と t をまとめて z∈A45 とし、指定点を原点へ移す。
式を F(z)=Jz+H(z,z) と書く。ここで J は135×45 Jacobian行列であり、固定Poisson行列とは区別する。

QQ上で rank J=35、接空間の次元は10。接空間上の t は零である。
最高式だけのJacobian階数は34である。TをJの核基底45×10行列とする。
左核へ射影した H(Tv,Tv) の係数行列は **正確に階数5** となる。
その五つの二次形式の共通Hessian核は3次元だが、七つの法線変数に対する
全28個の二次積を張るわけではない。これだけでは局所次元3の上界にはならない。

この段階は全て有理数上で計算し、全Jacobian・核・選択した左核・二次形式・
曲線の微分行列を `S61_BINARY_QUADRATIC_OBSTRUCTION_20261101.json` に保存した。

## 3. 三次の初期関係を求める

Jの非零35次小行列の行を R、列を C とし、列Cへの埋込みと逆小行列を合わせた
45×35行列を U とする。すると J_R U=I である。
形式的陰関数定理により、独立な35式を解いた局所空間は

    z=Tv+w2(v)+w3(v)+…,   w2=−U H_R(Tv,Tv)

と書ける。全式に対し、残余の二次・三次係数行列は

    A2=(I−JU) H(Tv,Tv),
    A3=(I−JU) 2H(Tv,w2).

三次で現れる Jw3 は左の射影により消える。
A2の五つの独立行を使って他の行の二次部分を消せば、残る三次式は
完成局所イデアルの正当な初期形式となる。

素数 p=32003 でこの有限演算を行った。全有理入力の分母はpで可逆で、
選択したJacobian小行列も非零である。
A2のQQ階数が既に5と分かり、還元後も5であることが重要である。
したがって二次部分の行消去は、pで可逆な小行列式を用いるQQ上の演算へ持ち上がり、
二次部分の消滅はQQ上でも厳密である。
その後の三次行操作も、非零の還元を持つピボットだけを用いて持ち上げられる。

得た三次初期関係の還元行空間は21次元である。
二次式の十変数倍だけでは三次空間の階数50だが、これらを加えると65となり、
少なくとも15個の独立な新しい三次初期関係が得られる。
この数字をQQ上の全三次関係の厳密な総数とは主張せず、必要な下界として用いる。

## 4. 210次小行列による標数零の上界

三つの線形パラメータ v0,v1,v3 を零とし、残る七変数で上の二次式と三次式を考える。
それらの四次単項式倍を全て並べた係数行列は287×210で、p上で階数210となる。
選択した210行、全係数、非零行列式を証明書に保存した。
同様に、二次の階数5、三次の階数50も確認する。

これらは第3節で構成したQQ上の多項式の係数行列の還元である。
非零還元を持つ小行列式はQQ上でも非零なので、QQ上の商も全四次単項式を消す。
よって初期式の商のHilbert関数は

    degree0,1,2,3: 1,7,≤23,≤34; degree≥4:0

であり、長さは高々65である。有限体のKrull次元をそのまま標数零へ移したのではなく、
明示的な非零小行列式が有限長性を標数零で保証する。

三つのパラメータを加えた完成局所環の商は有限長となるから、元の局所次元は高々3。
第1節の滑らかなP²束による下界と合わせ、指定点で **局所次元は正確に3** となる。
長さ65はこの計算による横断上界であり、実際の一般重複度や局所環全体の長さを決定したものではない。

## 5. 再現と残る問題

```sh
.venv/bin/python code/s61_binary_quadratic_obstruction_20261101.py --output /tmp/binary-quadratic.json
.venv/bin/python code/s61_binary_local_dimension_20261101.py --output /tmp/binary-local.json
```

本証明は外部CASのGröbner基底に依存せず、SymPyによる有理線形代数と、
NumPyのint64演算による厳密な有限体線形代数で再現できる。積・和の範囲はint64内に収まる。
探索用Macaulay2でも二次・三次初期式の次元3、次数65を得たが、その結果は本証明の依存先ではない。

tの二次項は二次障害の行空間に入るが、これだけではt=0やtの冪零性は結論しない。
同じ次元のアフィン枝が接する可能性を排除するには、高次の局所環または飽和の制御が必要である。
原134式だけの未飽和局所環についても、このノートでは次元3と結論しない。
