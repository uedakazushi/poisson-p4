# 五変数源のplane二次式を識別する五汎関数

2026-11-04。一般係数体K=QQ(H,L,s0,q0,t0)で、既存の全134式のplane制限から独立な五行を選ぶための別手法である。全ファイバーの既知五点による尽くし、cross126の階数は主張しない。

## 既存の五点スキームと二次式空間を分ける

`S61_KNOWN_FIVE_POINT_SECTION_20261101` は保存した特定のβで、全134制限の係数行空間が五次元であること、明示五二次式がその全イデアルを生成すること、長さ5の被約交叉であることをそれぞれ厳密に確認している。`TORIC_UNIVERSAL_THREE_PLANE_20261101` は一般βでの3平面と有限エタール長さ5交叉を証明する。一方、長さ5という事実だけから、任意の表示の二次式係数が五次元だとは推論しない。

後続の `TORIC_E2_SCALAR_INVERSE_20261101` は普遍的にTr(c)=0を証明する。三つのトーリック点はker L内で平均0、一般には非共線である。この非共線性、三次被覆の判別式の非零性、および3方向の独立性はSp4および重みGm不変の開条件である。受理済みのsparse6のSp4×Gm軌道和はW16に稠密だから、これらの条件は今回のKでも成立する。これは古い固定小行列式が同じ行で非零だとする議論ではない。

平面をq=C+A0*a+A1*b+d*sigmaと書く。二つの楕円点は(a,b,sigma)=(0,0,-1/2),(0,0,1)、三つのトーリック点はsigma=0にある。平均0の非共線三角形は幾何的係数拡大上のGL2変換で(1,0),(0,1),(-1,-1)に移る。

この五点で消える次数2以下の全多項式空間は五次元である。例えば上の三角形で、次の五式が基底になる。

```
1+sigma-2sigma²-a²+ab-b²,
a-a²+2ab, b+2ab-b², a*sigma, b*sigma.
```

五つの係数汎関数(定数,a,b,a*sigma,b*sigma)による行列はI5である。任意の元でこの五係数が零なら、楕円二点の条件によってsigmaとsigma²も零、残る同次二次式は三角形の三つの異なる射影方向で消えるため零である。この議論はGL2によらず、五汎関数の単射性はKへ降りる。

従って全134制限が既知五点で消える事実から行空間は高々五次元。今回の実際の五列でrank5を証明できれば、元の134制限の五行が全二次式行空間の基底になる。次に残る129行をこれらから引く処理は可能になるが、本packetではcross行列を計算しない。

## Eの二乗を避けた実際の五列

元の式をF=c+Σl_iq_i+ΣQ_ijq_iq_j、既存の共通分母をP、W_h=P*A_hとする。五列すべてをP倍すれば、選択行列は厳密に

```
[P*F(C), J_F(C)*W0, J_F(C)*W1,
 ΣQ_ij(W_i0*d_j+W_j0*d_i),
 ΣQ_ij(W_i1*d_j+W_j1*d_i)].
```

対角i=jも二項とも含める。すべてQQ[H,L,s0,q0,t0]の多項式であり、AやEの二乗、3×3adjugateの大きい展開を要しない。Pは非零parameter式なので、Kで五列をP倍する操作は階数を変えない。

一回60秒・2GB・32MiB、各多項式および体の分子分母150000項を上限とする。正確な五列を保存した後、行の多項式gcdを厳密に除き、低support行から高々五つの体pivotを採用する。行gcdの除算は元への積で検証し、pivotと正規化行・前段消去係数を逐次保存する。非零selectorが得られても、任意parameterの一様な非零性ではなくKの非空chart上の結果である。

再現は `code/s61_sparse_generic5_plane_five_selector_20261104_v63.py --output work/NEW-output --work work/NEW-work`。新しいβの標本、有限体、GB、J0/Euler計算は使用しない。
