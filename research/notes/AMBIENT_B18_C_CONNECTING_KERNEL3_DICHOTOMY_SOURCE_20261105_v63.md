# honest 七次元 source の接続 kernel：J2⊕k または k³

既に独立検証された source から、head1,2,3 の定数 cycle は e23,e29,e30。
低い二つの genuine 座標に寄与するのは H2*sigma0 だけで、これら三列は零である。
従って cyclic top は chi=(0,0,0,0,d)、単純 target k1 行は (a0,0,0,0,a4)。
surjectivity は d と a0 の非零を強制するが、数値は選ばない。
残る実 head 座標は十七から十三の記号 parameter に減る。

M7=J2²⊕k³ の三つの単純 source は h0,h1,h2−h3/4。
genuine G4=J2⊕k² の ann(r)/rG に射影した行列は

    [[a0, 0, 0], [b0, b1, b2−b3/4]]。

この rank は surjectivity により一以上。rank二なら target の二つの単純項が
source k³ から split し、残る J2²⊕k→J2 の kernel は J2⊕k。
rank一なら cyclic top の kernel 方向が残った単純 target を埋めるため、
実 kernel の全 vector の J2 top が零となり、長さ三の kernel は k³である。
これは A=k[r]/r² 加群の二つの厳密な場合分けであり、標本分類ではない。

したがって head23 の canonical k2 座標 b1 が非零である一つの witness だけで
J2⊕k の場合が確定する。b1 が零なら残る b2−b3/4 を未確定に保つ。
この三次元 kernel は元 K/ellK の ITold4 による商であり、全 Kbar の型、
元 H0 の長さ・指数や nil 三乗をこの結果から決めない。
