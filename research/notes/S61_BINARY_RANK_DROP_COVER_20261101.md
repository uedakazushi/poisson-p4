# 非平方二平面型の全 Jacobian 階数降下を三つの表示族へ帰着する

2026年11月1日。対象は全135式の同次数二次斉次化であり、局所的な飽和除去とは別の結果である。
Q=xw∂y∧∂z と H={u12=u13=0} を固定する。
H 上の全 chart Jacobian の一般階数は35であり、**階数が34以下となる被約 locus を全て決定した**。
有限 symplectic 対称性を除くと、十八次元の表示族一つと十七次元の表示族二つでその全点を覆う。
これらの一般 β ファイバーはそれぞれ二次元・一次元・一次元である。
表示族が三つの異なる S61 成分であるとは主張しない。

## 1. 正確な五つの素 ideal

六つの core 座標を

    (a,b,c,d,e,f)=(u4,u14,u35,u36,u49,u50)

とし、残る八個の一次座標は全て自由のままにする。
K=5c+f、L=5b−e と置き、

    P=600c²+25bd−155de+230cf−18f²,
    Q=600b²−25ac−255be−63e²+95af

と定義する。階数降下 locus は、次の五つの零点集合の合併と正確に一致する。

| ideal（常に u12=u13=0） | core 次元 |
|---|---:|
| (K) | 5 |
| (L) | 5 |
| (d,15c−f) | 4 |
| (5b−3e,a) | 4 |
| (P,Q) | 4 |

特殊点を捨てた一般開集合だけの表ではなく、H 内の全被約階数降下集合を表す。
ただし Q が平方となる別の射影軌道は含めない。

## 2. 六変数の有限 ideal 証明書

[十八次元族の証明](S61_BINARY_HYPERSURFACE_RANK_DROP_20261101.md)で得た残余行列 E を元135式から再構成する。
同じ上三角ブロック A(4×12)、B(12×9)、C(17×5) を全十四変数上で確認する。
C のうち十二本の一次係数行からなる C_lin を選ぶ。
対応する maximal-minor ideal を I_A、I_B、I_C とし、表の五 ideal の共通部分を J とする。
次の有限個の恒等式・ideal membership を QQ 上で検証した。

    I_B ⊂ J,
    J の保存生成元 g 全てについて g²∈I_B,
    (KL)²∈I_A,
    (KL)³∈I_C.

従って √I_B=J であり、A または C_lin が full rank でない点は KL=0 に含まれる。
表の四つの線形 ideal は明らかに素で、最後の二次 complete intersection の素性と次元も検証した。
実装は推測した radical の出力だけに依存せず、上の包含と個々の平方 membership を再計算する。
Macaulay2 に渡す全入力と出力は report 内に保存する。

最後の ideal の幾何学的既約性は次の直接の議論でも確認できる。
P は d に関して一次、Q は a に関して一次で、その係数は

    A1=25b−155e, A2=−25c+95f

である。A1A2≠0 では a,d を解け、四変数 b,c,e,f の開集合と同型になる。
A1=0 では b=31e/5 かつ

    P|A1=0=2(15c−f)(20c+9f)

であり、二つの分岐それぞれで残る Q は零多項式ではないため次元高々3。
同様に A2=0 では c=19f/5 かつ

    Q|A2=0=3(5b−3e)(40b+7e)

となり、境界は次元高々3である。
二式は共通因子を持たず complete intersection は純四次元なので、境界に別の成分はない。
稠密開集合で被約であり、complete intersection の unmixedness により理想自体も幾何学的に素となる。

## 3. 残余階数との同値

B の階数が8以下なら、上三角構造から

    rank E ≤ 4+8+5=17

である。逆に B が階数9なら K,L は共に非零である。
第2節の membership によって A は階数4、C_lin は階数5であり、従って E は階数18。
実際、A の四列・B の九行・C_lin の五行を選ぶと、非零 maximal minors の積が E の18次 minor になる。
よって全 H で

    rank E≤17 ⇔ rank B≤8 ⇔ β∈V(J)

が成り立つ。
最初70行の階数は定数16だから、最高 q-Jacobian の階数が33以下である条件も同じである。

## 4. t 列の追加による別の例外はない

最初70行の左核で t 列を射影した54成分を F_i とする。
保存された左核順序について、全十四変数上で

    L²=10F_8−20F_28, K²=10F_13+50F_29

を検証した。また全 F_i は (K,L) に属する。
従ってこの compatibility ideal の根基は正確に (K,L) である。

B が full rank の場合は K,L≠0 なので、t 列は既に最初70行で最高 q 列の張る空間の外にある。
従って最高階数34は全 chart 階数35になる。
B が rank deficient なら最高階数は33以下で、t 一列を加えても34以下である。
以上により表は **全 Jacobian 階数≤34の全被約 locus** を記述する。
最高式だけの階数降下と全斉次化の階数降下を同一視する未検証の推論を使っていない。

## 5. 対称性、像の次元、一般 β での残件

有限 symplectic 変換 S(x,y,z,w)=(w,−z,−y,x) は Q を −Q へ送り、core へ

    (a,b,c,d,e,f)→(−d,c+f/3,b−e/2,−a,2f/3,3e/2)

と作用する。これにより K↔L、(d,15c−f)↔(a,5b−3e)、P↔Q となる。
従って表の五表示は三つの Sp4 飽和表示族で覆える。

射影 Q の五次元安定化群の単位成分は、表の各 ideal を保つ。
全 Lie 作用の ideal membership を確認した。
固定 Q の source ファイバー次元は正確に5なので、像の次元はそれぞれ

    10+(8+5)−5=18,
    10+(8+4)−5=17,
    10+(8+4)−5=17

である。
各表示の滑らかな有理点で、β の制約方向への群微分の非零 minor は順に

    −18300, 117688120, 400918770471424/805255

となる。従って三つとも W16 を優越する。

十八次元族の指定開部分は既存の自由階数65で飽和除去済みだが、補集合には十七次元部分が残り得る。
新たな二つの十七次元表示族についても、階数の表だけから t の冪零性は従わない。
元の十七次元族 {c=f=0} は K=0 の中の特殊部分であり、今回の二つの十七次元表示を置き換えるものではない。
次はこの有限表に沿って局所長さ・交点・全非零条件を検証する。
