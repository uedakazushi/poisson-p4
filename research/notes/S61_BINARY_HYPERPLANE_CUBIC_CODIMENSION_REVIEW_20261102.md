# K=0 完全三次行列の余次元証明：独立監査

2026-11-02。対象は `S61_BINARY_HYPERPLANE_CUBIC_CODIMENSION_20261102` と、
その MODULAR・HORIZONTAL・VERTICAL の三証明書である。
結論を、nuisance-zero の三 core 開 `aFBC != 0` における
完全 weighted cubic 階数57未満の集合は次元高々一、という範囲で受理する。

## 1. 監査の方法と再現範囲

組合せ producer の別実行は0.021秒で成功し、35種類の primary 入力 hash と
実行時間以外の全出力が一致した。三証明書が同じ42×70 Schur 行列と
同じ first minor を用いること、既存の全点階数上界57との接続を確認した。
元135式からの `cubic_matrix` helper、既知単元のみによる21 pivot、
有限体 factor bag、水平核・垂直核・定数先頭係数 native の source を監査した。

VERTICAL producer は一致する Schur 行列を入力として、別のOS一時作業先で
34.644秒かけて再実行した。全数学出力が一致した。
この再実行は元135式からの行列再生成を再度行ったものではない。
また水平の大きい QQ 核と有限体の大きい determinant bag は、今回第二実装していない。
それらは凍結した元135式からの fresh run、入力 hash、source・証明監査を依存とする。

追加の独立小検算として、保存された元 Schur 行列を別に読んで手書き有限体
Gaussian 消去を行い、三未知因子上の36 minor をそれぞれ
`12960,1145,2503` と再現した。既知四因子の pairwise GCD と B の d-content が
一であることも別に確認した。

さらに垂直再実行で得た一変数 `lc-input` に、Python の有限体列核・列補完・
δ除算だけを用いた別のアルゴリズムを適用した。主 native の二側消去とは異なる
階数列

`15,17,23,26,28,31,32,33,35,35,36`

を経て、δ重複度85、a次数 `156-85=71`、変換前の先頭係数 `20071 mod 32003`
を得た。e方向95核の自由対角分母の先頭係数と列置換符号を戻すと、P3 の
lex(e,a) 先頭係数は `11932 mod 32003`、先頭単項式は `a^39 e^213` と再現された。
この最後の別計算は有限体であり、QQ 上の次数上界の代用には用いない。
QQ 上界と単元性は、主側の全核恒等式・完全除算の再実行と併せて判断した。

## 2. 有限体支持と水平移送

完全 cubic 行列 N は63×91であり、指定開で可逆な21 pivot を消去した M に対し
`rank N=21+rank M` となる。各段の行 content 除去は既知四因子と有理単元に限られる。
元の重み三残余21本と、二次六本の light 一次倍42本を全て保持しているので、
三次空間の一部だけを調べた行列ではない。

有限体では最初の二つの36 minor の共通未知支持を三つの既約因子まで絞り、
各因子上の非零 minor でそれを排除する。よって五つの実際の minor の共通支持が
既知 aFBC に限られることだけで十分であり、全 minor の列挙は不要である。
primitive Schur の中間負指数を保持し、最終指数非負と完全除算を検査する方式は、
点評価から大きい多項式を推測する方法とは区別されている。

水平では `Vd=Z_(p)[a,e]_(p)` が DVR である。Hungarian 上界107と
QQ 全核の corank `14,9,5` により、d次数は79となる。
変換の自由対角分母が mod p で非零、終端 leading determinant が mod p で非零なので、
d先頭係数も Vd の単元となる。

B における部分 Schur の既知重複度2に加え、18行列の leading rank11と
左核に射影した一次係数の rank4 から、追加次数は少なくとも `7+3=10` である。
一次係数までで次の leading rank15を決められるため、ここで高次行列全体の再展開は不要である。
有限体の正確な B重複度12と合わせ、QQ 側でも正確に12である。

従って `Q=P/B^12` は Vd[d] に属し、d先頭係数は単元で、還元は B と互いに素となる。
未知の d依存共通因子を Vd-primitive に取れば、Gauss の補題で Q の商も整となる。
Q の先頭係数が単元なので、その因子の還元は非定数のまま残る。
しかしそれは五 minor の還元の共通因子、従って B の因子でなければならず、矛盾する。

## 3. 垂直移送と結論

残り得る未知因子 h(a,e) は P3 を割る。a,F,C 以外の既約因子を選ぶので、
正確な完全商 `Q3=P3/(a^37 F^10 C^26)` も割る。
既知積は Z_(p)[a,e] 上 primitive であり、Gauss により Q3 全体が p整である。
P3 と既知積の lex(e,a) 先頭係数が単元なので、Q3 の先頭係数も単元となる。
従って h の primitive 還元は非定数である。

一方、h の還元は五つの三変数 minor を全て割る。
B は dに依存する primitive な一次式であり、dに依存しない共通因子の支持は
a,F,C だけである。Q3 の還元がそのいずれでも割れないという正確な重複度証明と矛盾する。
この段階で、三変数全体の先頭係数を直接計算する必要はない。

以上より、局所化した UFD `QQ[a,e,d,(aFBC)^-1]` に未知の高さ一階数欠損はない。
複素数体へ拡大した共通超曲面があれば、その共役因子の積が有理数体上の共通因子を
与えるため、同じ余次元結論は複素数上でも成立する。

## 4. 限定

今回受理したのは nuisance=0、指定三 core 開内の余次元二以上という主張である。
残る曲線・点での階数57、重み四次全射、相対長65、ambient の t冪零性、
全二元型や全S61の尽くしは含めない。
単一の同名 REVIEW report に、三依存証明書を含む最終 hash と上記の検査範囲を記録する。
