# 二平面型の二次障害 rank 五の一様化

2026年11月1日。対象は135式の共通次数二斉次化、非平方二平面型の無限遠点である。
[一般 Jacobian と九次元断面](S61_BINARY_UNIFORM_RANK_20261101.md)の記号を使う。

## 定理

十分一般の一次部分とその二平面型無限遠点で、十次元接空間上の二次障害の
線形空間は正確に五次元である。
これは特殊点で確認済みだった rank 五を、一般点へ広げる結果である。
三次障害や一般横断重複度65、斉次化変数 t の冪零性までは主張しない。

## 証明書の構成と独立検証

既証明の dominant な九次元断面に制限し、係数体をその有理関数体 K とする。
射影チャートの135×45 Jacobian を J と書く。
証明書には135×35行列 P と35個の行番号 R を保存する。
検証コードは元の135式から J を作り直し、次を全て K 上で確認する。

    P_R=I35,    P J_R=J,    rank J_R=35.

最後の下界は指定有理点の exact QQ rank で確認する。
従って P は J の像を選択行の値から復元する写像であり、
Π=I−P E_R は Jacobian の像を核とする余核への射影である。
ここで E_R は選択行を取る写像。

同様に45×10行列 T について JT=0 と rank T=10 を確認する。
各列の分母を払ってから計算しており、この操作は K 上で接座標を可逆に変えるだけである。
全方程式を局所的に Jz+H(z,z) と書くと、二次障害の係数行列は

    A2=(I−P E_R) H(Tv,Tv)

である。十変数の二次単項式55個に関し、135個の全係数行を計算する。
その結果、保存順を零から数えた行19、60、117、123、133だけが非零となり、
残る130行は九個の独立変数を持つ多項式恒等式として零になる。
従って障害 rank は高々五。指定有理点での五次非零 minor が下界五を与える。

P は探索段階に Macaulay2 で求めたが、最終検証は Macaulay2 を呼ばない。
保存データから P を読み、上記射影恒等式、接空間恒等式、130個の全係数零を
元の135式に対して Python の低水準多項式環で確認する。
分母は行または列ごとに払い、すべて exact QQ の多項式演算へ帰着している。
従って探索ソフトの rank 出力を証明の代わりに使っていない。

最後に、[全135斉次化 ideal の Sp4 安定性](S61_HOMOGENIZED_EQUIVARIANCE_20261101.md)と、九次元断面の dominant 性を使う。
局所二次障害の rank は同型で不変なので、断面上の一般 rank 五は
一般の二平面型点へ戻る。特別な一次部分や退化二次形式に対して
同じ rank を主張するものではない。
