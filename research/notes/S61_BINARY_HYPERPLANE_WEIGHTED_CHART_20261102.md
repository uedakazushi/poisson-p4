# K=0 二平面型の八法線変数・正重み有限模型

2026-11-02。既に除去した深部 Q*=0 から a=u4 を自由に戻し、次の有限問題を得る。
本結果は座標と有限性の定理であり、新しい層の飽和除去や長さ65を証明したものではない。

## 1. 指定された三core断面

Q0=xw∂y∧∂z を固定し、一次部分を

    u4=a, u14=(e+1)/5, u35=1, u36=d, u49=e, u50=−5,
    他の十個の一次座標=0

とする。従って K=5u35+u50=0、L=5u14−u49=1 である。
七変数深部切断の nuisance 五変数を零にし、a の制約だけを外した断面であり、
全 K=0 source の同一点局所環を扱う断面ではない。

次の多項式を定める。

    F=500a+90e²+3e−24,
    B=50ad+18de²−9de−2d+60e−40,
    C=100a+18e²−9e−2.

旧深部方程式 Q*=600u14²−255u14*u49−63u49²+100u4*u50 は、この断面で −F となる。
以下は aFBC≠0 の明示開集合での結果である。これら因子の零点はここでは処理しない。

## 2. 元135式からの34方向の陰関数消去

射影chartの45変数をy、元135式を Jy+H(y,y) と書く。
深部の33選択式の Jacobian minor は

    −a³(3200a+468e²+84e−159)B /1220703125

である。その33式を消した残余一次部分は一つの自由座標だけに支持を持ち、
行103の係数は −F/(3200a+468e²+84e−159)、行133はその −4a 倍となる。
行番号は零始まりである。この残余は元135式から全係数で検査する。

そこで行103と対応する自由列を加え、初めから34次blockを逆にする。
その determinant は

    a³ F B /1220703125

であり、旧33枠の余分な因子は消える。
保存した45×11行列 T と45×34行列 U は、全元式について JT=0、選択行について
J_selected U=I34 を満たす。保存された定数chart基底 W の座標では、W⁻¹T の自由11行は
単位行列、W⁻¹U の同じ行は零である。
全係数分母は aFB の因子だけからなることも正確な多項式除算で検査した。
単なる標本の階数を一般関数体の証明としていない。

## 3. 実在binary三方向の切断

Lagrangian平面を v1=(A,1,0,Cp)、v2=(−Cp,0,1,Dp) と書く。
primitive一次部分による平面曲線の原点での二式の微分は

    [ 2, −(6e+1)/5, a ]
    [ d, 4,           (3e−2)/5 ]

である。平面方向の核と二つの二元二次形式方向から、実在binary三次元部分の接写像を
S61への元の正規化で再構成する。選択した三自由座標への射影 determinant は −C/25。
従って C≠0 上では三つは実在する滑らかな部分の局所座標であり、その三座標を零にして
八つの法線変数を残す。接写像が JT の同じ核に入ることも元135式で検査する。

この段階は正しい横断商の同定であり、周囲の完成環の有限自由性をまだ与えない。

## 4. 形式解が四次で正確に止まる理由

nuisance=0 のこの三core断面では、元135式そのものが既存と同じ非負重みで斉次となる。
局所45座標の重みは0から4、tの重みは3である。
34選択式の最大重みは4であり、T,U の全非零成分は重みを保つ。
上の三つの切断後、八つの法線座標の重みは

    (1,1,1,1,1,2,1,1)

となる。零重み座標は切断と選択式の解で零となり、自由な零重み変数は残らない。
可逆blockによる形式陰関数解は一意であるから重み作用と可換する。
正重み変数から重みwの座標への形式級数は重みwの多項式であり、通常次数もw以下である。
従って全34消去座標は通常次数四以下の**正確な多項式**となる。

係数を展開する必要がある場合は W1=T_normal*v とし、r=2,3,4 の順に

    Wr = −U · [H(W1+…+W_(r−1), W1+…+W_(r−1))]_selected,degree r

を計算すればよい。重みの理由から高次補正は生じない。
本報告はこの全expanded多項式を計算したとは述べず、元 H と T,U による有限再構成処方を与える。
全残余式の最大重みは6なので、全横断schemeも有限個の正確な多項式で記述される。

重み2・3・4の単項式数はそれぞれ29、91、239である。
七light変数と一heavy変数を持つので、重み4には light⁴が210、light²×heavyが28、heavy²が1ある。
重み4を全て消せれば高い全重みも消えるが、長さ65にはさらに低重みの階数確認が必要である。
今回はそれらの全core被覆も、標本での長さ65も追加主張しない。
