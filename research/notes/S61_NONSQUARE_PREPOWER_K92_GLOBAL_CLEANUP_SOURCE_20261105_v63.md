# K92：generic行cleanupと一列callbackの新しい目的

保存済みABCとN0はformal Kronecker代入後の一変数多項式であり、generic(a,e,d)の関数そのものとして使わない。genericな元M11の有限source loaderを指定し、potentialのt^rをa^{-r}で持ち上げる。aはFULLU単元であり、a=t^{-1},e=t^{-2244},d=t^{-68}では既存の全入力へ厳密に戻る。

generic block行列をGとする。delta=deltaP deltaQ、元の行6をdelta row6−59375 delta row4−w0 row0−w1 row1−vp0 row2−vp1 row3で置き換える。この行列Eの行列式はdelta、逆も一行だけで明示できる。最初の四列は普遍adjugate恒等式で零、後ろ七列は全generic N callbacksになる。

generic N0はその保存済みformal代入が非零なので非零RFである。deltaP,Qも非零RFだがFULLU全体の単元ではない。新chart D(deltaP deltaQ N0)とその補集合を保つ。pivot行[0,1,2,3,6]・列[0,1,2,3,4]の五角行列はdet=delta N0、残余は六角である。これは一つの固定候補行列の操作であり、全域57や全11行列式非零ではない。N0の独立peer前はaccepted pivotにしない。

残る六個のcallbackを旧STOPの単なる続行として評価しない。新目的はgeneric cleanup行を用いた可能なpivotと、その同じformal代入の厳密値・valuationを結ぶことである。実際に完成した五つのprefix多項式だけを使い、一列ずつのstorage/height/pair数を新しく測る。source段階ではN1〜N6の符号付き値を計算しない。
