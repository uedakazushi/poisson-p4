# eta 非零なら比較 C の torsion は (1,1,2,3)：追加の純粋四次証明

これは新しい条件付き定理であり、eta の値をまだ読まない。
完全 full-C source の四 eta に非零があれば、実三次 initial は
ell³(A-B/4) を含む。その r 倍と ell 倍は、no-cut 四次六 NF において
(0,1,0,0,-1/4,0)、(0,0,1,0,0,-1/4) だから独立である。
従って full HF4<=4。一方 m⁵C=ell*m⁴C と rank_D C=4 により HF4>=4。
よって m⁴C は D-free 四、全 HF は(3,6,6,5,4,4,...)となる。

ell⁴C⊂m⁴C が torsionfree なので、現在の型(1,1,2,e),e>=3 は e=3又は4。
F=m³C は rank四・最小五生成で ellF=m⁴C が torsionfree だから Tor_D F=k。
さらに m Tor_D F=0。仮に e=4 なら ell³Tor_D C=k=Tor_D F である。
実 C3 の長十九と full C/m⁴C の長二十から ell³C/m⁴C=k、従って
ell³C=m⁴C⊕Tor_D F（D加群としてのみ）。

任意の x に対して ell³x=ell y+q、y∈F,q∈Tor_D F と書く。
t=ell²x-y なら ell t=q。rt∈F かつ ell rt=rq=0 なので
rt∈Tor_D F⊂ell³C。よって r ell²x=ry+rt∈ell³C。
これは実 C3 の非零 r ell²A と矛盾するので e=4 はない。従って e=3。

比較 C の torsion長七・C/ell⁴C長二十三は、この条件付き結論の範囲だけ。
元 H0(D0) の長、nil 三乗、原問題の全尽くしへは読み替えない。
eta が全零ならこの証明は適用しない。
