# 三二次類の源根集約と既存原子への随伴

受理済みの三双対・620個の一次零結合を用いる。31個の源 X2 感度を全620結合に適用し、**同じスカラー根のラベルをまずまとめる**。対象は旧 B48 の typed scalar root と、正直な D0 関係の下位 P8 の原始 C0 root。native128 の下位8成分は全次数で文字どおり零であり、残りは型付き未知 X2 として保持する。

旧 B の typed 多項式だけを、保存済み79個の C0 原子の定数・一次値で微分する。新しい函数値、源 jet、陰函数解、Gröbner 計算は使わない。P8 が同じ原子ラベルなら統合し、それ以外は元の根を未知のまま保持する。C0 の未保存の変数勾配を作り出したり、旧 r/g を座標や零で置き換えたりしない。

各二次係数は `Jac(atom0)*atom2 + known(atom1 products)` と分ける。原子二次値を零とした演算は既知積を抽出するだけであり、実際の原子二次値が零だという仮定ではない。固定27源列の一次補正 `-Xp1*alpha1` も厳密に加える。全ての未知根感度が消える組合せがあれば、この既知ベクトルが実三類への関係像を与える。非零の**関係像は残余類を消す**証拠であり、T の長さが増える証拠ではない。

源変数順は `(zA0,...,zA6,rA)`。対象二次単項式は `zA0*rA,zA1*rA,zA4*rA,zA5*rA,rA²`。三類公式は実 cycle 上かつ既知177関係 modulo で成立し、未射影圧縮係数そのものの公式ではない。既知 source-atom の読み戻しである `r` 型・順序付き prefix は原始分子三次、`g` 型は最大五次を要求し得る。複合 C0 根には、このラベルだけから必要次数を勝手に与えず、源依存 gate を残す。

実行前に、定数根集約支持、構造的な Jacobian 支持、出力支持の上限を算出して合計150000未満を要求する。実演算の全保存・生存 QQ 支持も再検査する。各段階を先に保存し、60秒・2GB・32MiB に達した場合はその境界を保持する。次の高次係数計算、native source 二次評価、全 T 長さ・元の深さはこのパケットでは実施しない。
