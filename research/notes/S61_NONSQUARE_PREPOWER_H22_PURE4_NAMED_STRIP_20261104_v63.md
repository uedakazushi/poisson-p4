# 三純行小行列式からの実 pure4 小行列式と既知単元の除去

前の固定三小行列式1895項だけを入力し、九成分や行列式は再計算しない。Q9 の pivot q=22、h=Q9[q]、三純行 P1,P2,P3 に対して

    det(h P_i[j]-P_i[q]Q9[j]) = h² det([Q9;P1;P2;P3]_[q,11,13,25])

が成り立つ。普遍整数多項式環で h を反転して第一行で消去すれば右の4行列式は h det(M/h)=det(M)/h²。これは多項式恒等式なので反転前にも成立する。元の row LCD 単元は変更しない。

実 h22² での除算を QQ で一度検証した後、既知 FULLU 単元 a,d,F,B,C,J だけを固定順に除く。全除算に quotient/remainder を保存し、成功時の積と最後の元1895項への再乗算を全係数で検証する。一般因数分解も別の小行列式も計算しない。最初の不割り切れ remainder も保存する。

h22 はこの中間消去のチャート単元であり、FULLU 全域の単元ではない。一方、得られる除算前の4行列式は元の pure4 部分の実小行列式である。残余が非零定数ならこの4小行列式が既知 FULLU 単元となり、h22=0 を含めた pure4 pivot を与え得る。非定数なら未知の残余多項式を保持し、その零 locus を捨てない。どちらの場合も全九核や full57 は従わない。
