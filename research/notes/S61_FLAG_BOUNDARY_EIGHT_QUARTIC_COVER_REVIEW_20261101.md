# 通常八変数旗の四次 minor 被覆：独立概念監査

2026-11-01。`S61_FLAG_BOUNDARY_EIGHT_QUARTIC_COVER_20261101` の note と
cover engine を、既に監査した元の四次証明書と照合した。
これは論理・実装範囲・保存 hash の監査であり、元四次や十六行列式の独立再計算ではない。

六つの nuisance を含まない18候補行と補正 t4 の行について、各 h 指数が
行重みと列重みに分解する恒等式を確認する構成は正しい。
h が可逆なら対角的な行・列変換なので、QQ[r] への移行で階数は変わらない。
分母と行 content を除く際の零集合を、最終 gcd とは別に条件へ含めている。

QQ[r] は一変数主イデアル環である。
八つの12次行列式の gcd が指定点で非零なら、全八個がそこで同時に零になることはない。
これは八つの13次行列式についても同じである。
有限体計算を行・列の選択のみに用い、その後に整数多項式の行列式と gcd を検算する手順は、
有限体での階数をそのまま全標数零点へ移す議論ではない。

元候補の関数体上の階数12から、全13次 minor は有理関数として恒等的に零である。
従って候補と低次行操作が正則な開では、特殊化後の上界12が保たれる。
core 行の minor 被覆が下界12を与えるので、元216候補も厳密に階数12となる。
補正 t4 を加えた下界13から、その剰余の非零性も保たれる。

旧証明書の分母・射影・共通座標変更に由来する因子も照合し、途中の次数9・16因子を
消していないことを確認した。従って保存された十因子の積が非零の開上で、
全 nuisance 値に対する HF=(1,9,36,97,201)、ord(t)=4 を受理する。
十因子の零集合が本当の階数降下とは限らず、全 core 被覆、全初期イデアル、
完成環の自由性、t 冪零性、飽和除去は引き続き未主張である。
