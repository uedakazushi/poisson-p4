# 全 C の三次 HF は五又は六：graph ell 三次は値を読まず零

全 actual 比較加群 C と、その ell 三乗商 C3 を区別する。
同じ regular9 R0 の極大 ideal を m、D=QQ[[ell]] とする。
独立確認済みの m³C=ell*m²C、rank_D C=4、C3 の実 HF(3,6,6,4,0)
を使う。以下は保存済み root の新しい値を一切読まない純粋証明である。

F=m³C とおくと mF=ellF=m⁴C である。仮に全 C の HF3 が四なら、
F は D-rank 四・最小生成数四なので D-free である。
C3 の m⁴ が零なので ellF⊂ell³C⊂F となる。
F/ellF と F/ell³C=m³C3 はともに長さ四だから、ell³C=ellF=m⁴C。

任意の x∈C に対して ell³x=ell y、y∈F を選ぶ。
t=ell²x-y は C[ell] に属し、任意の u∈m に対して ut は F 内の
D-torsion なので零である。従って m ell²C⊂ell³C。
しかし C3 の実三次基底は A r²ell,A r ell²,B r²ell,B r ell² であり、
r ell²A は非零である。これは上界 cover だけの非零ではなく、
完全155 source と全 alpha 四値の零から確定した実基底である。矛盾。

従って全 C の HF3 は五又は六である。五 graph 行のいずれかの
delta_ell³ が非零なら、別に独立確認した no-cut cubic minor d² により
全 HF3 は四以下となるため、五つはすべて source だけで零と分かる。
準備した新 graph03 値 worker は実行不要となった。旧 graph r ell² の
V1/V2 と新 graph03 の SOURCE/custody は、未実行のまま別々に保管する。

長い D-torsion 指数 e は依然 e>=3 である。この議論から e>=4 とも
e=3 とも言えない。全 C の HF3 と C3 の HF3 を混同せず、
Tor_D(m³C) と m³Tor_D(C) も区別する。元 H0(D0) や nil 三乗の結論はない。
