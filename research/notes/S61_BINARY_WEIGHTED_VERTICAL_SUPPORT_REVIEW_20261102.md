# 重み四次の縦曲線支持除去：独立の小代数・source・証明レビュー

2026-11-02。主証明書 VERTICAL_SUPPORT を elliptic_jets が独立に監査した。
269次・538次の全多項式積を別実装で再計算したというレビューではない。
その大きい係数恒等式は、元135式からの主 producer の再現可能な厳密計算への依存とする。

## 検査した有限代数

二次式 f3=270e²+321e−388 の QQ 既約性、判別式522081、regular representation の
f3(T)=δI、および det(δI)=δ²を別の小さい SymPy 計算で検査した。
δ=1334における特性多項式は (e−2)(e+287/90) である。
元小行列の二次因子重複度が Norm の δ 消滅次数の半分であることと整合する。
QQ(δ) 上の二次拡大はδ=0で剰余体次数2の非分岐拡大であり、
単に538行列の核次元を269行列の核次元と取り違えた計算ではない。

四つの有理根が既知 D 因子の零点であることを、保存された十三因子から別に確認した。
1241−(70+113+176+197+2×92)=501、元無限遠次数1607−366=1241を照合した。
法32003で四一次因子と二次 f3,f4 から二つの660次多項式を別に組み立て、
共通 gcd の次数476、f3 と d=4 の全行 determinant の互いに素性を検査した。
これらは主 producer が求めた巨大 determinant 自体の第二計算ではなく、
その正確な因子分解を入力とした独立な算術の確認である。

## 核による因子取り出しの source 監査

定数 QQ 行列の RREF の pivot 座標単位列と、free block が単位行列の核 K を合わせた
列変換は行列式±1を持つ。従ってその変換によって余分なδ因子を失わない。
source は L K=0 に加え、全多項式 M K の定数項消滅を検査してからδで割っている。
各段の核次元の和と、最後の定数行列の全階数を主報告から別に照合した。
これにより単なる下界ではなく、報告された正確な消滅次数が得られる。
整数版は各行・各核列の定数分母を先に払って積の加算を行い、最後に復元する。
多項式による未追跡の約分をする実装ではない。

元269行の選択は有限体で行ってよい。その後の原指数非負の検査、QQ 核恒等式、
最終全階数、同じ行番号の有限体 determinant を用いるため、候補選択を証明と混同していない。
全390行の有限体計算も非定数行contentを割らず、元行spanを保つ操作だけを行う。
その span 内に既知因子だけの determinant を持つ269行があることで、必要な支持包含には十分である。

## 有限 DVR 加群と縦曲線の論証

R=Z_(32003) とする。原係数の p 整性、QQ と mod p の同じ次数1241により、
選択 determinant P3 は R 上 monic 化できる。
既知因子冪 U も monic にできるため、QQ での完全整除 P3=UV は monic division により
R[e] に降り、V は次数501の monic 多項式である。
V mod p と既知因子積 D3 mod p の互いに素性から resultant は R の単元、
従って D3 は R[e]/V の単元となる。

元余核 C の D3 局所化では U が単元なので VC[D3⁻¹]=0。
D3 が R[e]/V で既に単元だから、この局所化余核は有限自由 R 加群
(R[e]/V)^269 の商となり、実際に R 有限である。
特殊fiberが零なので Nakayama を適用できる。
局所化一般が R 有限であると仮定しているのではなく、monic V と resultant により有限性を証明している。

縦直線が二変数の階数欠損支持に含まれるなら、その QQ 最小多項式は全最大 minor を割る。
d=3 の断面全射から五つの既知因子のいずれかに限られる。
f3 の場合、monic division と p 整性で d=4 の完全整除が mod p に降りるが、
全行span determinant と f3 の互いに素性に矛盾する。四一次根は D=0 なので別途既処理である。
水平定理と合わせて D 開の支持に曲線がないという結論を受理する。
孤立core点の存在、全 nuisance 同一点での上界、ambient の飽和除去は本レビューから結論しない。
