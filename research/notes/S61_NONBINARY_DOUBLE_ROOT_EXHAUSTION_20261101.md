# 非二元の純二重根軌道を全一般一次項上で飽和除去する

2026年11月1日。R0正常形G=z²wおよびzw²について、十分一般のβ上の全無限遠点を
全135式のt飽和から除去できる。これは純二重根軌道の全点についての結論である。
他の特殊混合型・旗・二平面型や、最小型の残余まで除いたものではない。

Q=∂y∧(z²∂z−2zw∂w)を固定する。一次項核Hは十次元で、
A=u14、B=u49、U=u26、V=u35と書く。
普遍42次minorは非零定数倍を除いて

    U V² B(A−2B)(A−B)(A+B)(2A−B)^4
      (5A−7B)(5A−4B)(5A−3B)(5A−B)P2 P3,
    P2=20A²−59AB+65B²,
    P3=11A³−39A²B+51AB²−7B³

である。消去・法線基底の全分母はこのminorの因子に含まれる。
この非零開では完成環は一変数底上の平方零二変数拡大、自由階数3、t=0。
固定βの実在曲線はEτ上の二根を順序付けたエタール被覆から構成する。
十分一般のβではEτが滑らかであり、minor非零は二根の相異性も保証するため、
この議論は当該開の全点に適用できる。

零因子の全被約集合は次の有限表で処理済みである。

| 因子 | 処理 |
|---|---|
| 2A−B、5A−4B、5A−B | Sp4一次像の次元が16未満なので一般βでは不在 |
| A+B、P2、P3 | 各複素根の十六次元層。自由階数3の指定点と有限jetで全一般β除去 |
| A=B、5A=7B、U=0、V=0 | 一般階数3、横断4、有限長torsion内のtの冪零性から全層を除去 |
| A=2B | R0と二つの最小尾、一般階数5、横断6。t冪零で全層を除去 |
| B=0、5A=3B | R0と混合尾、自由階数5、平方零の冪零部分、t=0。全層を除去 |

各閉層の結論は、指定点での計算だけではなく、九次元H超平面の安定化保存、
十六次元像のβ優越性、有限jet特殊化と同じ実在枝の長さ下界を組み合わせたものである。
補集合の次元は高々15となるので、そのproper像を避ける一般βでは層の全ファイバーが除かれる。
各層の閉包を扱うため、表の因子同士の交点を別の未処理領域として残していない。
数体P2/P3は全共役根を含み、有限個の基底開の共通部分を取る。

Hのどの点も、minor非零開または表のいずれかに入る。
全135同次数斉次化のSp4同変性で軌道全体へ移し、
有限symplectic変換(x,y,z,w)→(x,y,−w,z)でzw²軌道も覆う。
以上で二つの純二重根表示の全一般β無限遠が除去される。
