# B18 における実際の被約交叉：長さ4の明示的 DVR 接着

2026-11-03。基点 P0 と実際の R 曲線、実際の N37 標的座標を用いる。
独立受理済みの h=4 と全150三次 graph 消滅から **k=h=4** が成立している。
本稿はその有限写像を具体化する。元の非被約交叉 D の全環は同定しない。

## 1. 実際の37生成元から C4 への写像

`u_i=q_i−q_i(P0)` を実際の物理標的の局所座標とする。N の最小37生成元は
証明書に列挙する28個の base 座標と、9個の物理座標
`[18,19,28,29,60,61,67,46,72]` である。

R 曲線上での全37個の制限は厳密な二次以下の多項式で、その非零項は

```
u16=13T,  u22=−25T²,  u65=−12T,  u112=−13T.
```

他の33個、特に9個の選択された奇**物理座標**は零となる。
`T=u16/13` なので、これらは全射

`A_N,full → C4=C[T]/(T⁴)`

を与える。I_N の R 制限が厳密に `(T⁴)` という受理済み結果により、写像が
N の全定義関係を保つことが分かる。37変数の正則 presentation に戻した
kernel は、36個の三角関係
`u_i−image(u_i)(u16/13)` と `u16⁴` で正確に生成される。この記述を N の
環上の正則列や complete intersection だと主張しない。

物理的な奇座標が零でも、trace を引いた本来の奇部分が零とは限らない。
先の二次 cover の計算から、その9生成元の even a(T) を T³、odd β(T) を
T²まで同伴証明書に転載する。たとえば行61は
`a61=−232T²`、`β61=46T` である。raw monogenic 方程式は三次まで
`p²−16Tp`、trace 零にすると判別式は `64T²` である。これにより有限写像を
実際の Cohen 二次模型へ結び付ける。別々の抽象座標 ν,s,w,v の同一視を
推測してはいない。

## 2. 群方向を含む完全な接着 recipe

共通 G19 切断 Γ の最初は文字どおりのスカラー `1+g0`、残りは保存した
18個の GL 行列で `G=I+Σg_i E_i` とする。作用写像
`Γ×R曲線→R` の微分は階数20。R はこの点で滑らか20次元なので、完備化で
実際の R の形式座標 `(g19,T)` を与える。

N の各物理生成元を

`(1+g0)*G_*P_R(T) − P0`

の対応係数へ送り、T⁴で割る。これは N のスキームとしての不変性により
正確な写像である。G の逆行列の分母は原点で単元であり、形式的に一意。
この有限逆行列 recipe を証明書に保持する。19変数全展開は必要ない。

従って reduced component 同士の実際のスキーム的交叉は

`(N∩R)hat ≅ C[[g19,T]]/(T⁴)`。

N は既知の実際の解析的整域、R は正則で、これらが被約交叉の全二枝である。
イデアルの和と共通部分に対する標準完全列から、全被約交叉は厳密に

`(D_red)hat = A_N,full ×_(C[[g19,T]]/(T⁴)) C[[g19,T]]`。

これは任意に選んだ抽象的な写像による fiber product ではない。写像は上の
全物理37生成元と実際の群作用で指定されている。共通形式的 G19 積を除くと
`A_N,slice ×_C4 C[[T]]` となる。抽象的な九次元 N 正規形の座標軌道までを
分類したのではない。

## 3. 不変量と残件

受理済みの別の純代数検証により、横断被約環の深さは1。直接には
`0→F→A_N,slice⊕C[[T]]→C4→0` の中央項の深さが1、末項が0なので深さ補題
から1となる。R の一変数極小枝からの上界とも一致する。

横断被約環は `(dim,edim,depth,e)=(9,18,1,2)`、錐では
`(28,37,20,2)`、射影では `(27,36,19,2)`。既知の実際の非被約錐 D の
埋込次元39と比べ、冪零根基の cotangent への像は**正確に2次元**である。

被約環の seminormalization は既受理の
`C[[g19,x1,...,x9,T]]/(T*x1,...,T*x9)` を再利用する。本稿ではその導出や
次数計算をやり直さない。元の被約環の conductor の明示式、非被約 D の
