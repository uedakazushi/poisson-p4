# 深部二平面型・重み四次行列の縦曲線支持を除く有限証明

日付: 2026-11-02。対象は既存の nuisance-zero 二変数 core `(e,d)` 上の
多項式行列 `A(e,d)`（390 行、269 列）である。
元135式からの weighted finite model と `prepare` の構成を依存に保持する。
本稿は全 S61 や全 nuisance での同一点局所環を同定しない。

## 1. 結論と範囲

`A(e,3)` は

\[
 \mathbb Q[e,((24e-7)(10e-1)(2e-1)(15e+8)
 (270e^2+321e-388))^{-1}]
\]

上で全射である。二変数の階数欠損閉集合に含まれる縦曲線の候補は
`e=7/24,1/10,1/2,-8/15` の四本に限る。これらは既存13因子開から
除かれている。従って同開上に未知の縦曲線成分はない。
別証明 `S61_BINARY_WEIGHTED_HORIZONTAL_SUPPORT_20261102` の水平支持除去と
組み合わせれば、同開の階数欠損支持は高々零次元である。
**残る孤立 core 点の除去、全 nuisance への伝播、ambient の t 飽和は別問題である。**

主producer:

```sh
.venv/bin/python code/s61_binary_weighted_vertical_support_20261102.py \
  --output /tmp/vertical-support.json --workdir /tmp/vertical-support-fresh
```

既存の局所FLINTランタイムを用い、native出力は `/tmp` に置く。
正式producerは大きい候補行列や `/tmp` の旧ファイルを入力に使わず、元模型から
raw weighted rows を再生成する。

## 2. 固定した269小行列と定数体上のpeeling

`d=3` で有限体 `p=32003` の一点評価を用いて269行を選ぶ。
その行番号を固定し、以後の次数・局所重複度は `QQ` で検証する。
各成分の正確な `e` 次数にHungarian双対上界 `r_i+c_j` を与えると、
その総和は1607である。

\[
 M_{ij}(\delta)=\delta^{r_i+c_j}A_{ij}(1/\delta,3)
\]

は多項式行列であり、`det M=δ^1607 P3(1/δ)` である。
コードは全成分の指数非負を直接確認する。

任意の段階の多項式行列 `M` の定数項を `L` とする。
正確な `QQ` RREFから `L K=0`、自由座標部分が単位行列の核基底 `K` を作る。
RREFのpivot列の座標ベクトルを並べた `E` に対し、`[E,K]` の行列式は
符号を除いて1である。全多項式積を計算し、各 `M K` 成分の定数項が0で
あることを検査して

\[
 M'=[M E,\delta^{-1}M K]
\]

へ移る。この操作は核次元だけ `δ` の行列式因子を取り出す。
最後の定数行列が全階数なら、取り出した総数は正確な消滅次数である。
これは近似行列式の補間ではない。整数版backendも同じ変換を行い、各 `M` 行と
各 `K` 列の定数分母を先に払って整数多項式積を加算する。途中の高価な分数
約分を避けるだけで、全係数と全 `δ` 割算を検査する点は同じである。

無限遠の18回の核次元は

\[
115,50,45,35,30,25,17,15,12,7,5,3,2,1,1,1,1,1
\]

で、合計366。最終定数行列の階数は269。
従って `deg P3=1607-366=1241` が `QQ` 上で確定する。
別計算の元269小行列式の `Fp[e]` 次数も1241であり、選択行番号も一致する。

## 3. 既知因子の正確な重複度

有理根では `e=r+δ` を代入し、同じ全多項式peelingを行う。

| 因子 | 正確な重複度 |
|---|---:|
| `24e-7` |70|
| `10e-1` |113|
| `2e-1` |176|
| `15e+8` |197|
| `f3=270e²+321e-388` |92|

最後の二次式の判別式は522081であり、`722²<522081<723²` なのでQQ既約。
二次体計算の代わりに、`QQ[δ][e]/(f3(e)-δ)` の基底 `(1,e)` に関する
regular representationを使う。`e` の乗法行列は

\[
 T=\begin{pmatrix}0&(\delta+388)/270\\1&-321/270\end{pmatrix},
 \qquad f_3(T)=\delta I_2.
\]

各元の成分 `a(e)` を `a(T)` に置き換えた538行列の行列式は
`Norm(P3(e))` である。`δ=0` の拡大は剰余体次数2の非分岐拡大だから、
この行列式の `δ` 消滅次数は `P3` の `f3` 重複度の2倍となる。
538行列の核次元は92、86、6、最後は全階数538であり、総数184。
よって元の重複度は92。コードは小さい恒等式 `f3(T)=δI` も独立に確認する。
さらに `δ=f3(2)=1334` で、共役二根 `2,-287/90` を使った有限体行列式積との
一致を別の基底・符号チェックとして保存する。

全次数1241からこれらを割った残余の次数は
`1241-(70+113+176+197+2*92)=501` である。

## 4. 全390行の有限体行加群とQQ断面への帰着

`d=3,4` の各場合に、全390行の `Fp[e]` 行加群を弱Popov化する。
行交換、定数単位による除算、多項式倍の行加減だけを使い、非定数の行contentは
割らない。零行の廃棄以外は行spanを保つ。異なる先頭位置を持つ269基底行を
得るので、その行列式は全行加群のFitting支持を与える。
非零定数倍を除いた結果は

\[
 H_d=(e-7/24)^{65}(e-1/10)^{113}(e-1/2)^{138}
      (e+8/15)^{160}\,f_d(e)^{92},
\]

ここで `f_d=90d e²+(600-93d)e+(4d-400)` をmonicにする。
両者の次数は660、共通monic gcdの次数は476。
`f3` のmod p像は `H4` と互いに素である。

この有限体情報だけからQQ結論を推測しない。以下の有限加群論を使う。
`R=Z_(p)` とし、元の有理係数がp整であることは全成分で確認済み。
`P3` のQQ次数とmod p次数が一致するので、その先頭係数はRの単位であり、
定数倍を除いてP3をmonicにできる。上で証明した五因子もR上monic化できる。
これらの正確な冪の積を `U` とすると、monic多項式除算により

\[
 P_3=U V,\qquad V\in R[e],\quad V\text{ monic},\quad\deg V=501.
\]

元269小行列のmod p行列式から、`V mod p` と五因子積 `D3 mod p` が互いに素で
あることを直接検査する。従って `R[e]/(V)` ではD3が単位である。
全390行写像の余核を `C` とすると、adjugateにより `P3 C=0`。
D3を反転後はUが単位なのでVが余核を殺す。この余核は有限自由R加群
`(R[e]/V)^269` の商、従ってR有限である。
そのmod pは上記全行加群計算と互いに素条件から0。
Nakayamaにより余核自体が0となる。QQへの拡大で§1の断面全射を得る。

## 5. 動く二次式に沿う縦曲線を除く

二変数の全最大minorがQQ既約な `F(e)` で割れると仮定する。
`d=3` の断面全射から、Fは四つの有理一次因子または既約f3のいずれかである。
後者なら、`d=4` の全最大minorもf3で割れる。
f3はR上monic化でき、原行列の係数はRにあるので、Gaussの補題・monic除算により
この整除はmod pにも降りる。しかし保存した `d=4` の**全行加群**の行列式H4は
`f3 mod p` と互いに素であり、矛盾する。
したがって未知の縦曲線はなく、可能なのは既処理の四直線だけである。
これは任意の一つの標本minorの非零性ではなく、全行加群の証明を使っている。

## 6. 再現・失敗した経路・限界

最初に行列式の直接QQ展開を試したが、整数化後最大55bit、269行列、次数上界1607
の `fmpz_poly_mat_det_interpolate` は180秒で未完となり停止した。
全61原行のQQ[e]contentは定数で、行ごとの既知因子約分も効かなかった。
同条件の延長は行わず、定数核peelingへ変更した。
二次Normの通常分数積版は120秒で停止したため、共通分母を払った整数dot版へ変更し、
全係数の正確性を保持して完了した。
これら失敗は上の有限証明の仮定ではない。

主reportは全入力hash、再生成raw hash、全kernel hash、最終行列hash、各段階の階数、
mod pの行加群行列式と五因子との比較を保存する。
独立レビューは別に記録する。
