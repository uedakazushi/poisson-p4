# 深部二平面型の四次条件を二つの core 変数へ降ろす

日付：2026-11-01。対象は既存の `K=Qstar=0` 七変数 chart。
本ノートの係数体は `K=QQ(e,d)`、残る五変数は `p,q,r,h,k` である。
core の例外因子の尽くし、深部層全体の飽和除去、全 S61 の尽くしは主張しない。

## 1. 結論と依存

`S61_BINARY_DEEPER_CUBIC_NUISANCE_20261101` の二十四個の二次初期式を
`q_1,...,q_24` とする。これらは九つの normal 変数 `v` の二次式で、
係数は K に属し、その一次倍空間は次元129である。
以前に追跡した二つの真三次初期式 `c_1,c_2` と併せると、三次空間は次元131となる。
後述の標本では二次倍空間の次元が453、三次式の一次倍も加えた四次空間の次元が467である。
これら二つの標本階数を、関数体上の階数上界として使用してはいない。

今回、二次式の一次 syzygy から二十八個の真四次条件 `h_s` を構成する。
それぞれの `I2*S2` における剰余は K に降りる。
五つの nuisance 変数への依存はすべて、二次式の二次倍として厳密に消える。
この二十八個を加えた四次空間は、九変数の四次式全体（次元495）になる。
従って生成した斉次部分イデアルの Hilbert 関数は

    (1,9,21,34), 以後0

であり、長さは65である。実際の implicit residual ideal の初期イデアルは
この部分イデアルを含むので、横断 colength は65以下となる。

以上の構成の分母と一つの非零 maximal minor はすべて e,d のみの有理関数である。
従って、ある非空 core 開集合 `U ⊂ A2_(e,d)` が存在し、**全ての五つの nuisance
変数に同時に**この65上界を与える。分母や minor の例外曲線を除去したという主張ではない。
既存の一般 binary 枝の長さ65下界・同じ枝の滑らかさと組み合わせる場合も、
その幾何学的仮定は別に確認する必要がある。

依存は既存の triangular chart、universal quadratic、cubic nuisance の三証明書。
新 producer は元135式から quadratic lift と全 Hessian operator を再構成し、
既存 quadratic RREF の全53行の所属も再検算する。

## 2. 二次生成元の nuisance に関する逆行列

既存の二十四 pivot 行を primitive 化し、二十四 pivot 単項式の係数行列を B とする。
係数は `K[p,q,r,h,k]` で、`B0=B|_(p=q=r=h=k=0)` は可逆である。

    B = B0 (I+N).

全係数の厳密計算により、N の非零位置の有向 graph は144辺の DAG となる。
このため有限三角代入で `(I+N)^(-1)` を構成できる。producer は
構成した `B^(-1)` と B の積が単位行列になることを全七変数で検算する。
逆行列の分母は e,d のみであり、nuisance の開条件は導入していない。

## 3. 三次 syzygy から四次初期式を得る

線形部分を除去した実際の残差の二次・三次部分を A2,A3 とする。
上の inverse B を用いて二十四本を normalise すると、二次部分は q_j
（実装では共通の core 単元倍）、三次尾を f_j と書ける。

`q_j*v_a` の216行を K 上で消去する。初めの114 pivot はすべて非零有理数であり、
この114行の張る部分に216行中200行が属する。選ばれた114行以外から、
実際に追跡した86本の一次 syzygy

    sum_j l_sj(v) q_j(v) = 0

を得る。この等式は K 上の係数恒等式である。
従って actual residual の同じ一次結合は次数3まで消え、その四次初期式は

    h_s(v) = sum_j l_sj(v) f_j(v)

となる。**この構成には raw A4 は要らない。** raw 四次項を捨てた主張ではなく、
一次係数を掛けた三次尾が四次にあり、四次尾は次数5以上になるためである。

新しい二十八 source は report の `selected_quartic_syzygies` に記録する。
すべて上記86 syzygy の中にある。

## 4. quadratic implicit lift の変更の正当化

線形残差を `Jy`、Hessian の二次写像を H とし、選んだ線形式の右逆を U とする。
`JT=0`、選んだ行を E とすると、実際の implicit quadratic lift は

    w2 = -U H_E(Tv,Tv).

計算では w2 の各成分を I2 modulo に減らしてよい。変更を `δ ∈ I2 ⊗ V` とすると、
残差の三次尾の変更は `2(I-JUE)H(Tv,δ)` で、係数線形式を掛けた I2 の元である。
したがって、上記一次 syzygy から得た四次式の変更は `I2*S2` に属する。
実際の式に二次生成元の線形倍を加えることで、この変更を実際のイデアル内に持ち上げられる。

この論法は今回の syzygy 由来四次式に限って用いる。
変更した w2 を実際の implicit 解だとは主張しないし、一般の raw A4 に
無条件で同じ変更を適用していない。実装は T と減らした w2 の t 成分が零であることも検算する。

## 5. nuisance の消滅と階数

二十八 h_s を FLINT の厳密 QQ 多項式積で構成する。全出力に現れる nuisance 単項式は
`1,q,h,k` だけであり、p,r およびそれらを含む他の単項式は現れない。
各非定数 nuisance 係数を I2*S2 の行空間に対して消去する。
この消去では、同空間の389個の**非零有理数 pivot** のみを使い、
二十八本それぞれの q,h,k 係数がすべて零になる。
これが全パラメータに関する証明であり、有限個の nuisance 標本からの外挿ではない。

残る core 行列の full rank は、core `(e,d)=(2,3)`、nuisance `(5,7,11,13,17)`、
素数32003での非零495 minorによって確認する。全ての係数・分母は有理数であり、
この非零剰余は QQ 上の非零 minor を証明する。
同じ点で、二十八 h_s 全てを元135式から別に作った A2,A3 と比較し、
差が I2*S2 に属することを検算する。raw A4 には依存しない。

三次条件については既存の全 nuisance 消滅証明を用いる。
以上の core 有理係数行列を分母を払って表示し、その一つの非零 minor も除けば、
§1の共通 core 開集合 U を得る。U の補集合の因数分解や、その全ての点の
normal length・飽和除去を今回の rank witness から推定してはいけない。

## 6. 再現

主コード：`code/s61_binary_deeper_quartic_nuisance_20261101.py`。
同 stem の六つの C++ helper と field header を用いる。
必須 `--output` は新規ファイルに限る。FLINT include/library は CLI で変更できる。
全 native 中間ファイルは一時ディレクトリに置き、report は入力 SHA256 と
非零 minor、syzygy source、全係数検証の範囲を記録する。

通常の実行例：

    .venv/bin/python -u code/s61_binary_deeper_quartic_nuisance_20261101.py --output reports/S61_BINARY_DEEPER_QUARTIC_NUISANCE_20261101.json

この producer の PASS は、ここに列挙した恒等式と行空間の主張を証明する。
core 例外の尽くしや全成分数の上界を追加するものではない。
