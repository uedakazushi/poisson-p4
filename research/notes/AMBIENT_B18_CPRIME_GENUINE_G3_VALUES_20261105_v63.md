# 既存二次 cache からの実九次元作用と真正 G3

別 SOURCE gate に固定した公式の prepared worker。新 source・gauge・jet・connecting 値は計算しない。実九基底に関する全九変数作用、全 44 関係、可換性、三層 support と cyclic 基底 I9 を検査する。

ell は first basis F0,F1,F2 を quad basis Q0,Q1,Q2 に文字通り送る。head の first 部分は F0,0,F2 で、quad 部分を S とする。従って rank 5 の固定単元 block minor と rank 2 の ell² I2 minor があり、逆行列探索は不要である。

ell kernel は K=H1−Σ S_i1 F_i、Q0,Q1,Q2 であり、ell² image は Q0,Q2 である。genuine target の二基底は K,Q1 で、kernel 上の quotient projection は九次元の座標 1,7 である。全変数は K を scalar 倍の Q1 に送り、Q1 を消す。全 scalar を保存する。

この二次元 target は Cprime の真正 ell-torsion であって、有限 kernel 四次元そのものではない。formal radical 比較の target は native (tauA,tauB,tauAB) の順なので、connecting numerator の係数 (a,b,c) を (a,c,b−11a/12) に変換してからこの module へ送る。formal ell division は別の source gate で行い、有限商内で ell を反転しない。
