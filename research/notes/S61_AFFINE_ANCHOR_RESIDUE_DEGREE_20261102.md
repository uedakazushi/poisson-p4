# 有限な marked 境界点の支持面は次数10以上

2026年11月2日。\(K=\mathbb C(W_{16})\)。真の一般アフィン境界と marked 因子 \(D\) の交わりで、各閉点 \(a\) の支持面 \(\Pi(a)\in C_\beta\) の剰余次数は10以上である。従って \([\kappa(a):K]\ge10\)。次数10と15の支持面を与え得る相対不変式空間は、それぞれ次元3と1である。これは残点の存在や閉点の個数を主張する定理ではない。

## 1. 支持面を固定した二元三次式と一次式

標準 Lagrangian 平面を \(\Pi=\langle e_1,e_2\rangle\) とする。一次 jet \(\beta\) が \(\Pi\in C_\beta\) を満たす空間は \(H_{14}=\{u_{12}=u_{13}=0\}\)。\(v=r e_1+t e_2,\ n=t e_0+r e_3\) とおき、二元三次式 \(P(v)=\beta_v(v,n)\) と一次式 \(l(v)=\omega(v,\alpha)\) を取る。ここで \(\alpha\) は既知の marked 汎関数に対応する商空間のベクトルである。\(n\) を \(\Pi\) の元だけ替えても \(P\) は変わらない。実際、\(\beta_v|_{\Pi\wedge\Pi}=0\)。また \(\omega(v,n)=0\) であり、平面の面積形式を固定すれば \(v\mapsto n\bmod\Pi\) は \(\mathrm{SL}_2\) 同変である。[marked 汎関数](S61_AFFINE_SURFACE_BOUND_20261102.md)

元の primitive tensor から得る式は
\[
\begin{aligned}
P&=u_4r^3+(-u_{14}+2u_{49})r^2t+(-u_{35}+u_{50})rt^2-u_{36}t^3,\\
l&=-(5u_{14}-u_{49})r+(5u_{35}+u_{50})t.
\end{aligned}
\]
二式の六係数と従来の六 core の線形変換は行列式54で可逆である。残る八変数はこの対に現れない。支持面の基底を \(sI\)、双対補空間を \(s^{-1}I\) で変える pullback では全六係数が \(s\) 倍される。これは三次式を与えるテンソルが \(\Pi\) 方向二つと補空間方向一つを取ること、一次式の評価が同じ中心重みを持つことからも確認できる。

## 2. 一般底を支配する有限点の支持面因子

有限 anchor の一つの閉点を取り、その普遍族での既約閉包と、支持面 incidence \(I=\{(\beta,\Pi):\Pi\in C_\beta\}\) における像閉包 \(Y\) を取る。両者は一般の16次元底上で有限であり、\(Y\) は滑らかな17次元 \(I\) の水平な素因子である。有限個の水平成分は連結な \(\mathrm{Sp}_4\) と一次 jet のスカラー作用で個別に保たれる。支持面固定の放物型群も連結であり、\(I\) の大セルでの群による自明化から、固定標準面での \(Y\) は \(H_{14}\) の既約超曲面となる。[有限 anchor](S61_AFFINE_BOUNDARY_FINITE_ANCHORS_20261102.md)、[普遍曲線 incidence](S61_GENERIC_BOUNDARY_INDEX_20261102.md)

この固定面での因子は六 core のみに依存する。これを残余が有限という結論だけから推測せず、以下の二種類の源を用いる。

* 非平方では因子を順序づけ、marked 因子側を \(5u_{35}+u_{50}=0\) とできる。二因子での \(\alpha\) の同時零は一般底に現れず、他方 \(5u_{14}-u_{49}\ne0\)。\(u_{35}=u_{50}=0\) の部分も一般底で既に全て除去済み。従って二つの torus スカラーで \(u_{35}=5u_{14}-u_{49}=1\) にする開で扱える。残る三 core における未処理集合は次元1以下で、八 nuisance の全値を含むその逆像が上界を与える。固定した二因子について torus 二次元を戻すと core 像は次元3以下。支持面内の順序付き二因子の選択は二次元だから、固定面での像は六 core 内の次元5以下の閉集合と自由八変数の積に入る。枠変更後にも、三次式・一次式という内在的な商座標は八変数を混入させない。[H11 への全変数拡張](S61_BINARY_H11_RANK_DROP_RESIDUAL_FINITE_20261102.md)、[零対の全除去](S61_BINARY_ZERO_PAIR_STRATUM_REMOVAL_20261102.md)
* 平方は marked section \(\Sigma\) である。固定旗の \(b_1=0\) は一般底で全て除去済み。\(b_1\ne0\) の \(H_{13}\) は正規化用の \(\mathbb G_m\times\mathbb A^1\)、三 core \((a,c,h)\)、残る八変数の積である。非零 core の重み付き射影平面には除去済みの非空開があるので、残る中心の円錐は次元2以下。固定旗の五 core 中の像は次元4以下である。これら五座標 \(b_1,b_{12},b_5,b_{14},b_6\) は、実際に \((P,l)\) を marked 枠へ移したときの座標である。三次式の係数は \(b_1,9b_{12}/5,b_5+b_{14},b_6\)、一次式は \((b_{14}-5b_5)t\)。支持面内の旗線を動かす一次元を加えても、六 core 像の次元は5以下となる。[平方 core の正規化](S61_MARKED_SIGMA_PROJECTIVE_CORE_20261102.md)、[交叉の除去](S61_MARKED_SIGMA_INTERSECTION_REMOVAL_20261102.md)

従って13次元の固定面素因子は、この「次元5以下 \(\times\mathbb A^8\)」という上界の一成分と等しい。その既約方程式 \(f(P,l)\) は六 core 上の多項式で、一次 jet のスカラーで斉次、\(\mathrm{SL}_2\) に対して不変である。後者は群による多項式の変化が非零定数倍であり、\(\mathrm{SL}_2\) に非自明な指標がないことによる。

## 3. 剰余次数と低次数の候補

\(n=\deg f\) とする。支持面の中心スカラー \(sI\) のもとで \(f\) の値は \(s^n\) 倍、Plücker 座標は \(s^2\) 倍になる。支持面の放物型群の指標は平面上の行列式の整数冪で決まる。従って \(n=2k\)、大域因子は \(I\to LG(2,4)\) で引き戻す \(\mathcal O(k)\) の零因子である。これは固定面での既約方程式を群枠で貼り合わせる記述であり、任意の底の分母に伴う縦因子を次数に足していない。一般 \(C_\beta\) への制限は一つの被約閉点で、標数零だから剰余次数は \(5k=5n/2\) となる。

\(\operatorname{Sym}^3\oplus\operatorname{Sym}^1\) の係数六個に二つの \(\mathfrak{sl}_2\) 生成元を作用させ、斉次多項式の全係数で計算した。不変多項式空間の次数2,4,6の次元は順に \(0,3,1\)。これにより支持面の剰余次数5は排除される。剰余次数10の anchor が残るなら、支持面自体が次数10で、その上の \(F\) は同じ剰余体に定義される。支持面の式は \(\operatorname{disc}(P)\)、二次 Hessian の \(\ker(l)\) への評価、三次式 \(P\) の \(\ker(l)\) への評価の定数線形結合しかない。厳密な符号と係数は report の三次元基底に記録した。剰余次数15でも支持面と anchor の剰余体は等しく、次数6の唯一の不変量の零点に限る。高次数の閉点はこの表で尽くしていない。

## 4. 平方 section 上の整数と具体例

平方の \(b_1=1,b_{12}=0\) の chart では \(p=a+c,\ q=c-5a\ne0\) とすると \(P=r^3+prt^2+ht^3,\ l=qt\)。従って上の三つの四次不変量の空間は \(27h^2+4p^3,\ pq^2,\ q^3\) で張られる。六次不変量は非零定数を除いて \(hq^3\) なので、次数15の平方候補は \(h=0\) に限られる。

より一般に \(\Sigma\) の三 core の重みは \((2,2,3)\)。次数 \(m\) の既約な重み斉次式 \(g\) が水平な真の有限点を与える場合、その全分子を \(g(A,C,H)\) と書く。ただし \(A=b_1^2a,\ C=b_1^2c,\ H=b_1^3h\) である。\(A,C,H\) の対角指標は順に \(x^{-2},x^{-2},x^{-3}\)、\(b_1\) は \(x^{-2}z\)。\(b_1\) の共通冪 \(j\) を除いた strict 方程式は標準旗の連結安定化群の半不変式で、その指標は \(x^{-m+2j}z^{-j}\)。\(C_\beta\) 上で旗の因子線は \(L=\det U=\mathcal O_C(-1)\)、残る商線は自明なので、剰余次数は \(5(m-2j)\)。奇数重みの既約式は \(h\) 一つだけである。実際、奇数重みの各単項式は \(h\) を因数とする。\(H|_{b_1=0}=54b_{12}^3/125\ne0\) よりこの場合の次数は15。偶数重みなら10の倍数となる。\(b_1\) の共通冪以外を除かない根拠は、正規化が \(H_{13}[b_1^{-1}]\) 上の同型であり、固定旗の除数 \(b_1=0\) が既約な一つの線形除数だからである。一般底では \(\alpha=0\) が存在しないため、marked section の旗枠降下は \(C_\beta\) 全体で使える。

例として既知の pure-cubic endpoint 表示に対応する core の式は \(g=h^2+16a^2(c-3a)\)。その \(b_1\) 次数を払う前の全分子の \(b_1\) 付値は正確に2で、\(b_1^2\) を割った \(b_1=0\) 制限は
\[
 (9/125)b_{12}^2(12b_{12}b_6+165b_5^2-70b_5b_{14}+5b_{14}^2)\ne0 .
\]
従ってこの既約な最高式の部分族は一般 \(C_\beta\) に次数10の一閉点を定める。算出したのはこの部分族の剰余次数であり、真の境界に残ることを意味しない。[pure-cubic の既約方程式](S61_MINIMAL_FLAG_ENDPOINT_INVARIANTS_20261101.md)

## 5. 上界へ使う閾値

任意の真の境界曲線の一般点で \(t\) の超平面交叉重複度は少なくとも2である。非平方では元70式の横断障害があり、平方で一次横断を許す唯一の候補 \(\Sigma\) は真の境界との交わりが有限である。[一次横断障害](S61_AFFINE_SURFACE_DEGREE_OBSTRUCTION_20261102.md)、[marked 平方の有限残余](S61_MARKED_SIGMA_RESIDUAL_FINITE_20261102.md)

ゆえに曲面が存在すれば、真の境界の有限 anchor 交叉数 \(c\) には「剰余次数10以上 \(\times\) 超平面重複度2以上 \(\times\) 正の局所交叉数」の寄与が少なくとも一つある。従って \(c\ge20\)。明示 chart の有限 Artin 商 \(T\) は \(c\le\dim T\) を満たすので、\(\dim T\le19\) の有効な上界で曲面は全て排除される。現在この数値上界自体は未証明である。[有限 anchor 商](S61_AFFINE_ANCHOR_LENGTH_BOUND_20261102.md)
