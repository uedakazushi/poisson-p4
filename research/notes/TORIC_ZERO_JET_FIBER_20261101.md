# T01 の零一次部分ファイバー：10次元の実際の境界と上界12

2026-11-01。被約閉包についての主張である。

`code/toric_zero_jet_fiber_20261101.py` と
`reports/TORIC_ZERO_JET_FIBER_20261101.json` が対数型退化の全係数、
S61 の全134式、10次小行列、旧正規形への座標変換を記録する。
旧 v06/v07 の分類全体を今回独立に再証明したとは主張しない。

## 1. 結論と範囲

既約被約トーリック成分の S61 閉包を T01、一次部分への射影を
π:T01→W16 とし、F0=(π⁻¹(0))red と書く。

1. F0 は旧 v07 の互換二次 Poisson 空間 Q45 における
   **冪零型 (2,2) の AB 成分全体**を含む。この成分は10次元である。
2. F0 の任意の点 Q について、s=Q12+Q34 の Hamilton 行列は二乗零である。
   従って零、(2,1,1)、(2,2) 以外のモジュラー型は現れない。
3. 旧分類および旧全射影空間の滑らかな証拠点を用いると
   **10 ≤ dim F0 ≤ 12** となる。

AB 成分だけで F0 を尽くすとは主張しない。上界12が達成されるか、
零モジュラー成分 R0 等のどの部分が T01 に入るかは残る。
これは既存成分間の特殊ファイバーの結果であり、全 Poisson 成分の個数を増やさない。

## 2. 零一次部分の座標と完全分解による必要条件

S61 の重みは β が1、q が2である。β=0 では三次アフィン尾部も消え、

    P=J+Q(y),   [J,Q]=[Q,Q]=0,
    J=∂r∧∂u+∂z∧∂v

となる。ここで Q は斉次二次である。零一次部分と零モジュラー場を混同しない。
斉次化した実際の退化五次式は

    D=x0 (x0⁴+s(y)x0²+p4(y)),
    s=Q12+Q34,   p4=Pf(Q).

T01 の一般点では D は五つの超平面の積である。この性質は射影的な
掛け算写像 (P4*)⁵→P(Sym⁵ C5*) の像という閉条件なので、全 T01 で成立する。
D は x0⁵ の係数が1だから零式にはならない。

四次因子も完全分解し、その各一次因子の x0 係数は非零である。
x0 係数を1に規格化し、一意分解と x0→−x0 対称性を使うと、
ある一次式 a,b（零、比例、重複も許す）について

    x0⁴+s x0²+p4=(x0²−a²)(x0²−b²),
    s=−a²−b²,   p4=a²b².                                      (1)

特に rank(s)≤2 だが、さらに次の制約がある。

標準体積形式に関する BV 発散作用素の恒等式と [J,Q]=0 から、
δQ は s の Hamilton 場（規約によって共通の符号が変わる）に等しい。
[Q,Q]=0 に δ を作用させると [δQ,Q]=0 である。
δQ は Hamilton 場なので標準体積を保ち、従って

    {s,p4}J=0.

式 (1) を代入すると、コードでも全係数を確認した恒等式

    {−a²−b²,a²b²}J = −4 {a,b}J ab(a²−b²)

を得る。a,b が独立なら右の積の後半は非零多項式なので {a,b}J=0。
比例するときも反対称性から同じ結論となる。
従って s は等方部分空間上の二次式であり、その Hamilton 行列 Hs は

    Hs²=0.

より具体的には a=Aᵀy,b=Bᵀy として

    (J Hess(s))² = 4(AᵀJB) J(ABᵀ−BAᵀ)

である。二乗零 symplectic 行列の可能な階数は0,1,2であり、上記三型だけが残る。
ここでは完全分解の十分性を使用していない。

## 3. 三パラメータ族の実際のトーリック退化

任意の二変数二次式 g(r,z) に対して

    Pg=(1−r²)∂r∧∂u+(1−z²)∂z∧∂v+g(r,z)∂u∧∂v                 (2)

は F0 に属する。Jacobi と互換性だけでなく、実際の T01 への帰属を以下で証明する。

パラメータ t に対して四つのアフィン一次式を

    ℓ1=1+r+t u,  ℓ2=1−r+t u,
    ℓ3=1+z+t v,  ℓ4=1−z+t v

と置く。これらと無限遠超平面 x0=0 は t≠0 で射影座標系を与える。
四次アフィン行列の行列式は4t²である。

二つの組について

    θr=(dlogℓ1−dlogℓ2)/2,   ψr=(dlogℓ1+dlogℓ2)/2

および θz,ψz を同様に定め、二次微分形式

    Ωt=−(dlogℓ1∧dlogℓ2+dlogℓ3∧dlogℓ4)/(2t)
       −a θr∧θz−b ψr∧ψz                                      (3)

を考える。dlog 座標の交代行列 K の行列式は

    det K=(ab t²−1)²/(16t⁴).

従って t(abt²−1)≠0 で (3) の逆 Poisson 構造は標準的なトーリック構造である。
係数 a,b の特別値も、一般の交代行列を持つトーリック族の閉包に属する。

逆行列を元のアフィン座標で実際に計算すると、その全係数は分母
ab t²−1 を持つ二次式であり、t=0 で正則である。その極限は

    Pt→(1−r²)∂r∧∂u+(1−z²)∂z∧∂v−(a+b rz)∂u∧∂v.

定数 symplectic 行列を規格化する線形座標変換と、その後の symplectic shear を
まとめて

    r'=r,  u'=u+(a+c)z,  z'=z,  v'=v+c r

と取る。この変換は極限の定数項を J にし、二次交差項を

    g(r,z)=c r²−b rz−(a+c)z²

にする。三係数への写像 (a,b,c) は可逆であり、(2) のすべてを得る。
この座標変換自体が変換前の J に関して symplectic であるとは言っていない。
定数項が既に J となった後の c による二つの同時 shear は symplectic である。

極限 (2) は定数項 J、一次項零、視点パラメータ零である。従って全射影空間での
トーリック閉包への帰属がそのまま S61 の F0 への帰属を与える。
コードは (2) の全134式、再構成、直接のアフィン Jacobi を確認した。
Pf(Pg)=(1−r²)(1−z²) は g に依存しない。

## 4. 次元10および旧 AB 成分との同定

g=r²+2rz+3z² で、Sp4 の10本の作用方向と (a,b,c) の3本の方向を
全60個の二次係数で比較すると階数は10となる。
非零10次小行列の行・列・全係数・行列式を証明書に保存した。
これは接空間の過大評価ではなく、実際の族の微分による像次元の下界である。

旧座標を (x,y,z,w) として、定数 symplectic 変換

    r=i(x+z)/2,  u=−i(y+w),
    znew=(x−z)/2,  v=y−w

を使うと (2) の斉次二次部分は

    Q12=Q34=xz/2,  Q13=0,
    Q14=(x²+z²)/4,  Q23=−(x²+z²)/4,
    Q24=p3 x²+p4 xz+p5 z²

となり、p3,p4,p5 は任意である。これは旧 nil22 正規形の
c=u=v=0,d=1/2,ab=−1/16 の AB 枝である。
中央化群の x,z の逆向きスケーリングにより a=1/4,b=−1/4 と
旧代表の a=1,b=−1/16 は同一の飽和を与える。

旧 `legacy/v07/proofs/closed_squarezero_theorem.txt` はこの飽和閉包が
Q45 の10次元既約成分であることを証明している。
従って新しい対数型退化は **その被約成分全体が F0 に入る**ことを与える。
旧一般法線環 K[u,v]/(u,v)² の非被約構造が T01 のファイバー局所環に
そのまま移るとは主張しない。

## 5. 旧分類からの上界12

必要条件 Hs²=0 の下で、旧分類の可能な層は以下で尽くされる。

| モジュラー型 | 旧被約層の次元 |
|---|---|
| (2,2) | 固定ファイバー17成分の Sp4 飽和はすべて10 |
| (2,1,1) | M0,M1 が13、残る M が10 |
| 零 | R0 が12、C0 が9、L0 が10 |

出典は `legacy/v07/quadratic_classification.tex` と
`legacy/v07/proofs/zero_reduced_components_theorem.txt` である。

M0,M1 の全体が F0 に含まれる可能性は排除できる。
旧 `legacy/v06/ambient_families.tex` の二族 PA,PB において

    f=x0²+x²,   h=xzw+z³+w³

とした点は、定数項 J、一次項零であり、それぞれ M0,M1 に属する
（固定トレースの係数は Sp4 による再尺度化で揃えられる）。
同ノートと独立証明書
`legacy/v06/data/independent_ambient_families_audit.json` は、両点が
**全射影 Poisson スキームで滑らか**であり、その唯一の成分が
それぞれ28次元の CA,CB であることを証明している。
CA,CB の退化因子は全域で重複超平面を持ち、一般に五つの相異なる
超平面を持つ T01 とは別成分である。従ってこの二点は T01 に属さない。

F0 は閉集合なので、13次元既約集合 M0,M1 との交叉はともに真の閉部分で、
その次元は高々12である。他の許される層もすべて高々12だから
dim F0≤12 が従う。これと第4節を合わせて10≤dim F0≤12となる。

上界は上記の旧証明を依存関係に持つ。今回の短いコードが旧22成分分類や
全射影空間の滑らかさを再計算したという主張ではない。

## 6. 残る問題と別経路の検算

零モジュラー層では s=p4=0 なので D=5H となり、超平面の完全分解条件は
制約を与えない。特に12次元の R0 が全部または一部 T01 に入るかは未解決である。
M0,M1 内の真の閉部分にも未分類の可能性が残る。

探索中には、既存のアフィン変形表示から分岐上の留数を取り、別経路でも
零一次部分への実際の極限を構成した。固定 Lagrange 平面での臨界点条件から
得た有理数点の留数族の微分は、Sp4 方向と合わせて厳密に階数10となった。
作業記録は `work/zero_toric_20261101/residue_tangent.py` と同 JSON にある。
第3節の短い普遍対数型退化がこの下界を直接証明するため、本定理は
この探索用留数計算や高次数共変量の再評価には依存しない。

再現コマンド:

```sh
.venv/bin/python code/toric_zero_jet_fiber_20261101.py --output work/zero_toric_recheck.json
```

この新しい10次元境界の非零点はすべて、β=0 では q=0 しか与えない
有限可換代数模型の像から外れる。既知の「少なくとも8次元」という欠落は
「少なくとも10次元」へ強化された。

## 7. 独立監査と次の局所計算

elliptic_jets 担当の独立読解は、対数型退化、完全分解から二乗零を導く議論、
旧 PA/PB の滑らかな証拠点による上界12を受理した。
特に PA の Q12=x²,Q34=0 は M0、PB の Q12=Q34=x² は M1 に
トレースの再尺度化後に属すること、全射影空間での滑らかさによる唯一の
成分を用いることを確認した。この監査は旧22成分分類の別証明や
今回の係数コードの別実行を含まない。

続いて、実際の β=0 における R0 点として

    G=x²z+2x²w+3xz²+4xzw+5xw²+6z³+7z²w+8zw²+9w³,
    P=J+∂y∧(−G_w∂z+G_z∂w)

を全134式へ代入した。正確な有理数計算で、全61変数の Jacobi 行列の
階数は36、β方向だけの階数は8、q方向だけの階数は28となる。
従って全接空間次元25、固定 β 接空間次元17である。
この結果は `work/zero_toric_20261101/affine_R0_tangent.py` と同 JSON に保存した。
これは実際のアフィン点の計算であり、一般 β の未飽和無限遠 R0 の計算とは異なる。
余分な接方向が多く、この階数だけで CA,CB 以外の局所枝を排除できない。

別案として、五超平面が一つに衝突する対数型2-form の Taylor 展開を調べた。
等しい衝突速度 ℓi=1+tLi+…、Li が三変数を張り、その唯一の affine 関係が
Σei=ΣeiLi=0 の場合、t⁻⁴ の係数の候補は e∧v 型となる。
低次の発散を消すには二次 moment ΣeiLi² が一次式 Lv の平方に比例する必要があり、
任意の三変数三次 G が得られるとはまだ言えない。
異なる衝突速度や、この二次 moment 条件の幾何を調べることが次の具体的課題である。
この探索段階の観察を R0 の包含・非包含の証明には使用していない。
