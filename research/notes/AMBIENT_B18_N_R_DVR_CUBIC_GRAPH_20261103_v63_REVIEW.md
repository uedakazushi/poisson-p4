## fold、Weierstrass と全 remainder

同じ27行のほかに fold の物理行27を取り、その出力差は三次まで正確に

    −3p²+48Tp = −3(p²−16Tp)

である。単位 −3 と monic 二次式を独立に掛け戻す。
二次式は、実際の正規化の局所28次元 base 上の finite free 二次 cover から得られる。

高い全次数の項はこの除法で低い全次数に移らないため、これだけで必要な係数が決まる。

## 非一意な除法でも三次値が決まる理由

二次 cover の元として全 physical 出力を `q_j=a_j(X)+p b_j(X)` と書く。
ここで X は実際の28個の base 座標であり、R 曲線の X(T) へ代入する。
選んだ九出力の奇係数 b_i は、その奇係数 ideal を生成する。
これは、actual37座標が全完成像環を生成し、二次 cover の odd 成分を取ると
奇次数の積も b_i の R 倍になることから従う。従って **元の base 上** で

    b_j=Σh_ji(X)b_i

と書ける。この等式は像イデアルの非平坦な basechange で kernel が保たれるという主張ではない。
それぞれの actual physical graph 方程式は

    G_j=q_j−a_j(X)−Σh_ji(X)(q_i−a_i(X))

である。九つの b_i は minimal なので、h_ji(0) は actual odd cotangent class から一意に決まり、
上記の実際の N37 接行列の定数 h0 に等しい。

R 出力との差を z_j=q_Rj−a_j(X(T)) と置くと z は次数≥2である。
独立した全150係数で

    z_j,2=μ b_j,1,   μ=300/23

を確認する。元の除法を T²まで比べれば

    r_j=(b_j−Σh0_ji b_i)_2 = Σh_ji,1 b_i,1.

よって actual graph 方程式の三次制限は

    G_j,3=(z_j−Σh0_ji z_i)_3−μ r_j.

となる。h の非一意性の差は、定数項が零で、一次係数と b_i,1 の内積も零であるため、
この三次値を変えない。未知の h の高次係数は z の次数が2以上なので寄与しない。
二つの core odd 座標については b_i,1=z_i,2=0も確認する。

この公式で **全150行、特に非基底113行すべての三次値が零** となった。
別に p を trace 中心 `8T` で移し、a も実際に変換して、
trace-zero 平均 `116/23` による式と全150行で一致することを検査した。
`(116/23)²−64=−20400/529` は既受理の二次曲率差とも一致する。
