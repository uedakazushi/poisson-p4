# 共鳴点での滑らかなT39商と、零sectionの二つのgraphへの交点

2026年11月3日。全35変数の正確なQ模型内で、既知成分T39の局所枝を定める
45本の有限な正則関数を構成した。共鳴点Qstar=Q_(2/9)での45×35一次行列は
QQ上で階数26であり、選んだ26次小行列式は

    −50031545098999707/95420416

である。さらに正重みによる有限な三角消去を行い、**この45式による実際の商は
親模型の開集合全体でQQの9変数多項式環と同型**であることを確認した。
従って完成局所環もC[[v1,…,v9]]となり、T39はQstarで滑らかである。
全35変数模型に他の枝がないとは主張しない。

別の厳密なQQ(a)計算により、同じ零section Q_aは

    T39=q(5,1) に入る ⇔ a=2/9,
    T40=q(5,2) に入る ⇔ a=−8/9

であることを、親模型のD(a)≠0上で確認した。標本からの外挿ではない。

## 1. 全模型上で定義される固定点の正規化

親模型の生係数の順序は、添字対(i,j)と二次単項式の辞書順である。
群切断によって、固定射影点e0での接空間上のskew行列は恒等的に

    C = [ 0   c    d    a ]
        [−c   0  −2/9   0 ]
        [−d  2/9   0    0 ]
        [−a   0    0    0 ],

となる。ここでaは親入力a、c,dはそれぞれ生係数60,75である。
Pf(C)=−2a/9は親の局所化環上の単元である。
次の四次元の座標変換を用いる。

    F = [ 1  0   0      0     ]
        [ 0  0   0      1/a   ]
        [ 0  1   0     −c/a   ]
        [ 0  0  −9/2    9d/2a ].

厳密にFCFᵀ=J、det(F)=−9/(2a)であり、逆行列は

    F⁻¹ = [ 1  0  0    0   ]
          [ 0  c  1    0   ]
          [ 0  d  0   −2/9 ]
          [ 0  a  0    0   ]

である。斉次座標x0は固定する。
その後、既存の24次元vertical商と四つのperspective座標の消去を実行する。
後者の応答行列は定数有理行列であり、正重み変数を分母にする操作はない。
親模型の演算グラフにこれらの**有限な**操作を追加し、正規化された生150係数と
S61の全61座標を保存した。親の全9647節点はそのままで、追加の逆元はaだけである。

この正規化は全Poisson点で既存S61模型への実際の座標写像を与える。
固定点e0が全模型上で正則階数4なので、特定の共鳴曲線にしか定義されない写像ではない。
S61の二つの全域二次graph Q51,Q52を合成して、それぞれ45本の関数G51,G52を得る。
全追加節点の正重み斉次性と依存入力を検査したところ、両graphの25番目の関係は
全35変数模型上でもaだけに依存する。その全域での恒等式はそれぞれ
(9a−2)/(2a²)、(9a+8)/(2a²)である。
従ってT39の逆像はa=2/9、T40の逆像はa=−8/9に含まれる。

## 2. 一次行列と9次元の局所商

親入力(a−2/9,z0,…,z33)について正確な一次演算を行った。
親の全350式の一次項は零である。
正規化した全150係数とS61再構成は一次項まで一致し、
全134正規化式も一次項まで零となる。
G51はQstarで零で、その一次行列の階数は26である。
行、列、全45×35有理行列および小行列式を証明書に保存する。

ここでP=QQ[a,D(a)⁻¹,z0,…,z33]、Iを全350残差ideal、
J=I+(G51_0,…,G51_44)とする。まずQstarにおける局所環を考える。
既知T39はcanonical affine空間で次元26であり、親のétale群切断の滑らかな群因子は17個である。
T39は群不変でQstarを含むので、切断との交わりの局所次元は26−17=9となる。
T39の被約S61閉包は全域graph Q51だから、この交わりはJの零点集合に入る。
従ってdim(P/J)≥9である。一方、独立な26個の一次項から埋込み次元は35−26=9である。
Krull次元は埋込み次元以下なので等号が成立し、P/Jは9次元の正則局所環となる。

より具体的には、保存した26行の関数だけで割ったPの完成は9変数の形式冪級数環である。
その中の残るidealが非零なら次元が9未満になるため、全350式と残る19個のgraph式も
この完成局所idealに入る。従って全45式による商に隠れた追加切断はない。
この商は、群方向を除いた既知T39の被約局所枝を定める。
T39自体のcanonical affine局所環はさらに17個の滑らかな変数を持つので次元26で滑らかである。
射影化後は次元25となる。

これはJによる商の主張であり、I=Jや、Iの根基がJであることは主張していない。
T39とは別の成分、T39上の非被約厚み、他成分との交叉は残る問題である。

## 2a. 局所近似ではない9変数の有限表示

この商は、次元論だけによらず正確な多項式計算でも構成できる。
G51_25によってa=2/9となる。選んだ残る25式を正重みで並べると、
同じ重みの未知変数に関する定数有理正方行列と、より低い重みの未知変数を含む項に分かれる。
同じ重みdの未知変数に二次以上で依存する項は正重みのため存在しない。
残す九つの自由入力は

    (z22,z24,z27,z28,z29,z30,z31,z32,z33),
    重み (5,2,3,2,3,4,4,5,6)

である。重み1,…,6のblockの大きさと行列式は次の通りである。

| 重み | 大きさ | 行列式 |
|---|---:|---:|
| 1 | 2 | −729/8 |
| 2 | 4 | −1594323/3584 |
| 3 | 5 | 59049/64 |
| 4 | 6 | −729/26 |
| 5 | 5 | 1/12 |
| 6 | 3 | −16/243 |

各逆行列を保存し、低い重みから掛けると、他の25入力は九つの自由入力の
有限な有理係数多項式となる。高次jetの打切りも新しい変数依存の分母もない。
得た代入を親の全350式とG51の全45式へ合成し、
QQ[z22,z24,z27,z28,z29,z30,z31,z32,z33]の指数辞書上で**全395式が恒等零**となることを確認した。
生150係数と親の全35入力の復元式を保存する。
九つの自由入力は指定した生係数を読むだけで回収できるので、写像は閉埋込みである。

Lを選んだ26式のidealとすると、三角消去はP/L≅QQ[九変数]を与える。
全395式の恒等零からJ⊂ker(P→QQ[九変数])=Lであり、L⊂Jは定義から明らかである。
従ってJ=Lとなり、親模型内での商R/(G51)≅QQ[九変数]が厳密に従う。
これは第2節の局所正則性を強めるが、Rそのもののideal尽くしにはならない。

## 3. 零sectionの全aに対するgraph判定

全正重み入力を零にし、親の全演算グラフをQQ(a)で評価した。
生150係数のうち非零なのは

    P14=a x0²,  P23=−2x0²/9,
    P24=4x0x1/3,  P34=2x0x2/3+x1²

である。全350式は恒等零となる。
上記Fはc=d=0になり、perspective四座標も恒等零である。
別に物理的な斉次テンソルへ座標変換を行い、全150の再構成、全134式、
全射影JacobiをQQ(a)上で確認した。

Q51の45関係は、零始まり25番目以外が恒等零であり、残る一式は

    (9a−2)/(2a²)

である。Q52についても同じ25番目だけが残り、

    (9a+8)/(2a²)

となる。従って、全域graphの同定から冒頭の二つの必要十分条件が従う。
a=2/9とa=−8/9はともに親のD(a)≠0を満たす。
この25番目の式がaだけに依存することは、全模型の依存節点でも確認している。
後者における全Poisson局所枝や非被約構造は今回計算していない。
