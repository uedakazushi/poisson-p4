# 有限基底加群のR-adic商を有限多項式計算に戻す補題

2026年11月2日。旗境界の実際の有限加群とt作用を調べるための補題であり、
有限jetから全完成局所環のt冪零性を推論するものではない。

## 1. 重み付き有限打切りの厳密性

体kと

    R=k[[u1,...,ud]],  S=k[[u1,...,ud,x1,...,xn]]/I

を取り、a=(u1,...,ud)S、n=(x1,...,xn)Sとする。
横断商S/aでn^e=0が証明されていると仮定する。
この仮定は実際の商についてのものであり、低次の初期関係だけでは足りない。

商写像の定義からn^e⊂aである。従って各j≥0について

    n^(ej)=(n^e)^j ⊂ a^j.

base単項式の次数をb、normal単項式の次数をcとすると、その像は
a^b n^c⊂a^(b+floor(c/e))に属する。
uの重みをe、xの重みを1と置く。重みeb+c≥e(r+1)なら
b+floor(c/e)≥r+1なので、この単項式はa^(r+1)に入る。

元の形式冪級数環において、この重み以上の全単項式で生成される
monomial idealをJ_rとする。上記の包含は有限個の最小monomial生成元に適用できる。
従って無限個の項の和を勝手に交換することなく、ideal全体の像がa^(r+1)に入る。
逆にu次数r+1の全単項式はJ_rに含まれるので

    J_r S = a^(r+1).

よって

    S/a^(r+1) = k[u,x]/(J_r, F mod J_r : F∈I)

は厳密な有限次元代数表示である。Iの有限生成系だけを使えばよい。
形式冪級数はJ_rを法として有限多項式になり、陰関数消去の係数も
この有限monomial集合だけで計算できる。

normal次数を一回落とすごとにbase次数が一つ上がるため、
r+1回以上の落下はa^(r+1)で零になる。上のideal包含はこの反復をまとめたもので、
収束を仮定する書換えアルゴリズムではない。

残すmonomial数は

    Σ_(b=0)^r binom(d+b−1,b) binom(n+e(r+1−b)−1,n).

指定zero12では(d,n,e)=(3,6,6)なのでr=1の一律上界は13762列、
trueDでは(3,7,6)なので34200列となる。
これは必要十分な最小打切りを意味せず、実際の式でさらに早く有限化することがある。

## 2. 初期下位idealがある場合の線形打切り

通常の全変数次数についてIの初期idealに含まれる斉次ideal Jが既知とする。
G=k[u,x]/J、P=k[u]とし、G/(u)の次数e以上が零と仮定する。
この条件はS/(u)のnilpotenceだけより強く、保存済みの初期関係から別に検証する。

Gの次数e未満の各成分のk基底を選ぶ。次数d≥eの元はG/(u)で零なので
Σu_i g_i、deg g_i=d−1と書ける。次数による帰納で、選んだ有限集合はGを
P加群として生成する。Gが既にP有限であると仮定してNakayamaを使う循環はない。
従ってG/(u)^rの非零次数は高々r+e−2である。

元の形式環でK=I+(u)^rと置くと

    J+(u)^r ⊂ in(K).

よってA=S/a^rの極大ideal mについて、D=r+e−1で
m^D/m^(D+1)=0となる。m^DにNakayamaを適用すれば

    m^(r+e−1) S ⊂ a^r S        (全r≥1)

を得る。従って原式の通常次数r+e−2までの項とa^rを用いた有限商が、
S/a^rそのものである。この線形打切りにはJ+(u)の最高非零次数だけが必要で、
J=in(I)やG/(u)=S/aを仮定しない。

指定zero12では既存の64個の有理数初期関係J6に対して

    HF(G/(v0,v1,v3))=(1,6,13,15,10,6)

を有理数で得る。長さは51であり、実横断長49との一致は主張しない。
最高非零次数5により全rでm^(r+5)S⊂a^rSとなる。
従ってr=2のfirst base-adic商はraw六次まで、r=3の商はraw七次までで完結する。

## 3. より小さい打切りで停止できる条件

A=S/a^(r+1)、mをその極大idealとする。
元の式を実際に用いた有限商A/m^(D+1)の計算で

    dim A/m^D = dim A/m^(D+1)

を確認すれば、m^D=m^(D+1)である。
m^DはNoether局所環A上の有限加群だから、Nakayamaによりm^D=0となる。
従ってその有限商はAそのものであり、打切り次数をさらに上げる必要はない。

この議論には全有限商の一致、または両包含を与える標準基底・閉包証明書が必要である。
有限Macaulay行列の階数下界だけから商の正確な長さやobservableの非零性は得られない。
有限体上で確認した場合、結論もその有限体上の実際の商についてのものに留まる。
有理数上の長さやt作用は有理数で別に再構成するか、必要な移送仮説を証明する。

## 4. 旗の閉平方零商との関係

[実在の閉平方零厚化](S61_FLAG_BOUNDARY_SQUAREZERO_QUOTIENT_20261101.md)により、
指定zero12/trueDのSには同じR上の全射S→D=R⊕R^4があり、tの像は零である。
Sは49生成以下でrank5なので、核Mは有限R-torsionで44生成以下となる。
DがR自由だから、各rについて

    0 → M/a^(r+1)M → S/a^(r+1)S → D/a^(r+1)D → 0

も正確である。従って本補題の有限計算は実際のkernelのR-adic商を計算する。

しかし一つ、または有限個のrについてt²が零でも、Sにおけるt²=0は従わない。
次の目的はMの有限表示やt作用の有限恒等式を得ることである。
初期差加群E111との同一視、固定βのnilから相対ambientへの外挿は行わない。
