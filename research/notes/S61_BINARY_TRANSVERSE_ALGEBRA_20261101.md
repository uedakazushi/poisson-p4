# 二平面型の横断Artin代数：長さ65と非零の斉次化変数

2026年11月1日。係数体はQQ、幾何学的な主張はCへの基底拡大でも成り立つ。
対象点と135式は [二平面型局所次元の証明](S61_BINARY_LOCAL_DIMENSION_20261101.md) と同じである。

## 結論と範囲

固定βの135式の未飽和斉次化の指定点での完成局所環をSとする。
35式の形式的陰関数消去で残る十変数を保存順にv0,…,v9と書き、

    A = S/(v0,v1,v3)

と置く。この**指定横断商**は長さ65の局所Artin代数で、極大イデアルmはm⁴=0を満たす。
斉次化変数tの像は

    0 ≠ t ∈ m³ ⊂ Soc(A),   t²=0,   length A/(t)=64

となる。特にtは元のSでも非零である。
旗型・非二元型で証明したt=0という局所結論は、この二平面型の点には当てはまらない。

S自体におけるtの冪零性、Sのパラメータ環上の平坦性、実際の局所重複度、
飽和後に点が残るかはまだ決定していない。横断商でのt²=0だけでS内の冪零性を主張しない。
例えばC[[u]][e]/(e(e−u))では、u=0の商でe²=0でも、全環ではeは冪零でない。

## 1. 有限長性から四次冪の消滅へ

前ノートでは、三つのパラメータを零にした七法線変数について、実際の形式的イデアルの
二次・三次初期関係が全四次単項式を消すことを、210次非零小行列で標数零上に証明した。
従ってAにおいてm⁴/m⁵=0、すなわちm⁴=m·m⁴である。
AはNoether局所環でm⁴は有限生成なので、Nakayamaの補題によりm⁴=0となる。

この段階は初期式の商の長さ上界65だけを使っている。
実際の長さを得るためには、二次と三次を別の斉次生成元として扱わず、
各残余式の非斉次な和A2+A3を保持する必要がある。

## 2. 元の方程式からの厳密な三次展開

前ノートの記号でF(z)=Jz+H(z,z)、Jの核基底をT、可逆35次小行列の行をR、
その逆の埋込みをUとする。ここではTのうち七法線方向の列だけを残す。
J_R U=I、JT=0、Tのt行が零であることをQQ上で確認する。

形式的陰関数消去により

    z = Tv+w2(v)+w3(v)+O(v⁴),
    w2 = −U H_R(Tv,Tv),
    w3 = −U (2H(Tv,w2))_R.

残る135式の二次・三次部分は

    A2 = (I−JU)H(Tv,Tv),
    A3 = (I−JU)2H(Tv,w2).

である。m⁴=0が既に分かっているため、Aは七変数の次数四切断多項式環を
全135個のA2+A3で割った商と正確に同型である。
計算で高次項を無根拠に捨てたのではない。

## 3. 非斉次関係のQQ階数

七変数の二次単項式は28個、三次単項式は84個ある。
各A2+A3を112係数の行として並べ、各A2の七変数倍の三次行も追加する。
これが次数三以下の全イデアル関係の線形空間である。
二次以上の変数倍は既に次数四で零となり、一次・定数関係は存在しない。

この行列の階数を**QQ上の厳密な行簡約**で計算すると55である。
従って

    length A = 1+7+28+84−55 = 65.

tの像の係数行はw2のt行とw3のt行を連結したものである。
その一行を加えるとQQ階数は56となるため、tはAで非零である。
またA2の階数は5、w2のt行を加えても5なので、tの二次部分は二次関係で消去できる。
実際のA2+A3を引けばtは純三次の非零類になる。
よってt∈m³、m·t=0、t²=0であり、イデアル(t)は一次元である。
これによりlength A/(t)=64を得る。

この長さは指定した三パラメータの商の長さであり、一般の横断重複度とはまだ同一視しない。
またtを零にした局所環全体の次元・長さを64と主張するものではない。
