# T5 二次 pivot 例外の独立した概念レビュー

2026年11月1日。担当 `/root/elliptic_jets` が主証明ノートと前段の全開部分の証明を読み、以下の論理を確認した。今回、主 producer の数値再実行や別実装による係数検算はしていない。係数恒等式・分母・Bezout は凍結済み主証明書に依存する。

## 重みと有限被覆

重み w の元の式の単項式を β^a q^b と書くと a+2b=w である。通常二次斉次化後は β^a qhat^b t^(2−b) なので、β→cβ、t→c^(-2)t はこれを c^(w−4) 倍する。従って c が可逆なら全135式のスキーム自己同型である。

固定 Q の torus が L→λL、b9→λ³b9 と作用することを前証明書の入力とすれば、cλL=cλ³b9=1 は λ²=L/b9 と c=(λL)^(-1) に同値である。b9L≠0、標数零では有限エタール二重被覆であり、幾何点ごとの正規化も、恒等式の忠実平坦な降下も正当である。これは固定 β 内の移動である必要はなく、全族の局所環同型を用いている。

## 全点上界と自由化

数体の二つの埋込みは A(r) の二根を同時に扱う。可逆法線変換の行列式 −2、全 nuisance 変数を保持した計算、除算因子が p の冪と非零数体定数だけであること、六次二行列式の gcd=p^18 と Bezout を組み合わせれば、p≠0 の全点で必要な六次方向が消える。一般点での初期 ideal の特殊化だけを使っていない点が重要である。

従って各点の横断上界23と、同じ実在滑らかな T5 曲面に沿う普遍下界23が適用される。二変数底 R 上の23元全射 R^23→S は階数を比較して同型となる。一般因子の唯一の被約台では t は長さ23の局所 Artin 環の極大 ideal に属するので t^23=0 であり、R 上の無 torsion 性により全 S に戻る。

相対版では同じ曲面族の smoothness と source β 微分の全射性 b9P≠0 を用い、特殊横断上界と一般下界を相対十四変数底上で比較する。その後の smooth な同変 base change と忠実平坦降下は有効である。主証明の結論は b9LP≠0 の全点の除去であり、残る L=0、全 T5、全 S61 の尽くしをこのレビューから主張しない。

判定：上記範囲で概念上の異議なし。
