# 一次ジェット像 Z の7次元臨界軌道に沿う正確な完成局所環

2026年11月3日。対象は CA/CB の共通 **被約9次元一次ジェット像 Z** である。
CA,CB,N 自体や全 S61 の完成局所環へこの結論を移してはいけない。
その二次座標は、以下の環にさらに奇数次の函数を加える可能性がある。

## 定理

固定六平面の点

    b0 : (τ,A,B,C,D,F)=(0,0,1,1,0,0)

の Sp4 軌道は7次元である。その各点で Z の完成局所環は

    C[[u1,…,u7,s,p²,p³,s*p]]

に同型である。二次元の横断環を a=p²,b=p³,c=sp と書けば、その表示は

    C[[s,a,b,c]] /
    (b²−a³, a*c−s*b, b*c−s*a², c²−s²*a).

その正規化は C[[s,p]]、正規化商は residue field に同型な長さ1加群であり、
conductor は正規化側で(s,p²)、像側で(s,a,b,c)である。
従って Z はこの軌道上で非正規・非 CM、multiplicity2、embedding dimension11、depth8である。
通常 cusp と滑らかな7次元空間の積ではない。

## 1. 閉旗入射と有限正規化

受理済みの基底旗入射を I=Sp4×^P S6→Z とする。
源は滑らかな9次元多様体で、この射は proper birational である。
基底点 b0 の係数行列 Kβ は階数2、核は span(e_y,e_w)である。
真の旗条件 Kβv=0 と追加の収縮条件を chart v=(r,1,q,w) へ代入すると

    GB=(r,q,w²)

となる。chart 外の唯一の核の線 e_w は収縮条件を満たさない。
従って全射影ファイバーは長さ2の一点である。
properness により b0 の近傍で I→Z は有限となり、滑らかな源を持つ有限 birational 射だから
その近傍の正規化である。

## 2. 正確な二変数 slice

I の源を、固定線六係数と三つの旗 chart 変数(r,q,w)で記述する。
旗を送る symplectic 行列

    g(r,q,w)=[[1,r,−w,q],[0,1,0,0],[0,q,1,0],[0,w,0,1]]

による二形式の正確な有限作用を用いる。
源の次の二変数族 S≅A2 を取る。

    τ=p, A=0, B=1, C=1, D=−p/2, F=s,
    (r,q,w)=(0,0,p).

β の24係数は `weight1_structure.py` の COORDS の順とする。
零でない係数は厳密に次の通りである。

|2|p²|
|3|−2ps|

従ってこの族の affine scheme-theoretic image の環は正確に
QQ[s,p²,p³,sp]である。必要な四つの生成元が実際の出力係数として現れるので、
一方向の包含や最初の三次 jet だけを検査したのではない。
四つの toric 関係式は、変数p,sを消去した全 ideal と QQ 上で一致することも検査した。

## 3. この slice の像が全 Z の形式的横断環を与える理由

V16 を全一次ジェット表現とする。24係数は閉 primitive 条件の八本を満たすので、
16次元の線形空間を表す。
上の二変数族で次の七係数は b0 の値から動かない。

    indices=(0,4,5,6,7,8,16).

この七値を固定した V16 内の affine9平面を T とする。
Sp4 の b0 での軌道接写像の七座標への射影は階数7である。
従って単位元を通る滑らかな7次元局所部分多様体 H⊂Sp4 を選び、

    Φ:H×T→V16,   (h,z)↦h*z

を (1,b0) で étale にできる。これらの七軌道方向と T の九方向が全16方向を張るからである。
完成局所環で Φ は同型である。

Sp4 は Z を保つので、Φ による Z の逆像は scheme として H×(Z∩T)である。
同じく、旗入射の同変性から、I の逆像は H×I_T である。
この同定は (h,e)↦h*e と逆作用 h^−1 で直接与えられる。
従って完成局所的に、全射は滑らかな七次元因子と I_T→Z∩T の積に分かれる。

源 I における七係数の微分も階数7であるので、I_T は旗の唯一の台の点で滑らかな二次元である。
上の二変数族 S は I_T に入り、その二つの接方向は

    ds=dF,
    dp=dτ−(1/2)dD+dw

である。七係数の微分の核を全て張るため、S→I_T はこの点で étale で、
完成局所環は同じ C[[s,p]] となる。

ここで任意の hyperplane section と scheme-image を交換していないことが重要である。
I→Z はこの近傍で有限 birational であり、完成後の Ahat→Bhat は単射である。
上の群作用による厳密な product 分解の下で、この単射は七次元滑らかな因子と
Ohat_(Z∩T)→C[[s,p]] の積となる。
忠実平坦性から後者も単射であり、その像は第2節の全 coefficient functions が生成する完備部分環である。
従って **全** 横断完成局所環は C[[s,p²,p³,sp]]であり、
Zhat は定理の七次元 product となる。

## 4. 正規化商、conductor、depth

B=C[[s,p]]、A=C[[s,p²,p³,sp]] と置く。
p 次数が2以上の単項式は全て A に入り、p 次数1の単項式も s を含めば A に入る。
従って B/A は p の類のみで張られ、s,p²,p³,sp がその類を零化する。
これは A の residue field と同型な長さ1加群である。
その零化 ideal が conductor なので、A 側では(s,p²,p³,sp)、B 側では(s,p²)となる。

A の次元は2、B は正則、B/A は長さ1なので、完全列0→A→B→C→0からdepth A=1となる。
また m_A B=(s,p²)はBの colength2 parameter ideal であり、有限 birational rank1 の
multiplicity 加法性から e(A)=2である。
四つの表示生成元は m_A/m_A² で独立なので embedding dimension は4である。
七つの smooth variables を戻すと、次元9、depth8、embedding dimension11となる。
