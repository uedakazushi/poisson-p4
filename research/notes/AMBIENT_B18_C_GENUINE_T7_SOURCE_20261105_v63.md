# 真正 C[ell] のための source-bound D 商七次元

C4の実 filtered基底を、A,B,rA,rBの四本のell鎖十六個と
七個 t=(H,rH,ellH,r²A,r²B,r²ellA,r²ellB)で選ぶ。
各次数の個数は(3,6,6,6,2)と実HFに一致する。
三次までの完全NFと、四次の既知unit minorの補行1,4から、実際の基底である。

四本のell³像は ell³A,ell³B,r ell³A,r ell³Bで独立。
Ctorがell³で消えるので、四 source の full Dspan F は C/Torにmodellで基底を与え、
D-NakayamaによりF≅D⁴、C=F⊕Tor（D加群としてのみ）となる。
従って C4/F16は実torsion七次元で、上の七 monomial classが基底である。

この七商でell作用は、H→ellH、r²A→r²ellA、r²B→r²ellB、最後二つ→零。
rHとellHの像は最後二つへの四係数だけであり、
a1*Pk_A,r³-Pk_A,r²ell と b1*Pk_B,r³-Pk_B,r²ell（k=1,2）で与えられる。
全m⁴C4がF16内なので未知四次は消え、zを含む三次もm⁴へ上がってFに入る。
四係数は既存C2のr³/r²ellと既知beta二次carryだけで求まり、新jetは要らない。
値はまだ読まず、symbolic E7のrank三unit minor、全28 kernel積とfree I4を検証する。

qは kerE23/imE23³からkerE7への同型を誘導するため、真正のC[ell]四次元を得る。
ただしFはR0安定ではない（r(rA)=r²AはF外）。商に単純にr/z作用を落とさない。
R0作用のtransport、元比較RegDivellのsource投影、四代表の全形式liftは別gateであり、
ここで元H0やnil三乗を決めない。
