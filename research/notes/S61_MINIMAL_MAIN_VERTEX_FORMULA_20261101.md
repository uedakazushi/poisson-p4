# 最小型主曲線の非対角頂点公式とM1階数一頂点

2026年11月1日。M0/M1の主曲線を、頂点二次式を対角化せずに書く。
これにより二次式の判別式零への延長を証明し、M1の階数一頂点の16次元族を
一般βで飽和除去する。M0の階数一A1族とその主曲線接続点は、この結論に含めない。

## 1. 頂点の十四変数

v=∂y、(x,y,z,w)をDarboux座標とし、頂点条件はu4=u12=0とする。

```
P=u5, R=u13, A=u14, B=u49,
U=u26, V=u35, K=u50+5V, L=5U−u51.
```

他の六つのβ座標は自由である。二次式と二つのスカラーを

```
q_v = R z²+(2A−B)zw−P w²,
d = (2A−B)²+4PR,
E = 25A²−25AB−14B²+25PR = (25d−81B²)/4
```

と置く。以下はB E≠0上の有理公式であり、dで割らない。

G=a x²z+b x²w+xHと置き、M0では

```
Qxy=x², Qyz=−G_w, Qyw=G_z, その他0,
H=2q_v/(3B),
a=−2(10A²K−ABK−45ABV−2B²K−18B²V+9BLR−45BRU+10KPR)/(3BE),
b= 2(10A²L−19ABL+45ABU+7B²L−63B²U+9BKP−45BPV+10LPR)/(3BE).
```

M1では

```
Qxy=Qzw=x²/2, Qyz=−xz−G_w, Qyw=G_z, その他0,
H=−q_v/(6B)−zw/2,
a=(5A²K+7ABK−60ABV+2B²K−24B²V+12BLR−60BRU+5KPR)/(3BE),
b=−(5A²L−17ABL+60ABU+14B²L−84B²U+12BKP−60BPV+5LPR)/(3BE).
```

証明書は元134最高式に全十四変数を保って代入する。
残るa,bの線形方程式の70,84行から解き、全134行を照合する。
さらに保存された普遍G6のq次数二部分も直接再構成し、恒等的消滅を確認する。
P=R=0,A=k,B=2k+1への代入は既存の主曲線公式に一致する。
この稠密開での同定により、式は既存のSp4同変な主曲線を延長する。

**解の分母と線形方程式のpivotを区別する。** 二行二列の未約分行列式は

```
M0: 4(A²−AB−2B²+PR)E/(225 B²),
M1: (A²−AB−20B²+PR)E/(900 B²).
```

余分な零因子は既存の四本の自由基線の共鳴を含む。
上式はその上でも主曲線の一つの正則な選択を与えるが、全解の一意性を主張しない。

## 2. 階数一への延長

階数一の正常形P=−1,R=0,A=1,B=2,K=L=0では、

```
M0 G=−2V x²z/3 + 2(9U−5V)x²w/27 + xw²/3,
M1 G= 4V x²z/9 −4(9U−5V)x²w/81 −xzw/2−xw²/12.
```

前者は既存M0のA1族のg8=0点、後者は既存M1の唯一の点である。
B≠0,d=0ならE=−81B²/4≠0なので、階数一への延長に極はない。
二次式が零となる部分やB=0は、階数一開の一般点と混同しない。

## 3. 実在する固定βの主曲線

U=2,V=3、六係数=(2,3,5,7,11,13)とする。
十四頂点変数にSp4の十方向を加えたsourceの微分を、実際の有理点で計算する。
両型でβ微分階数16、(β,[Q])微分階数17である。
固定βの核方向でdの微分が非零となる方向を保存した。
従って階数一の指定点を通る滑らかな実在主曲線があり、その一般点ではd≠0である。
その同じ曲線を対角化すると、正規化されたcパラメータの平方はd/B²の非零定数倍となる（M1は定数シフト後）。従って必要な一般二次体拡大の後でもcは定数ではなく、有限個の例外値に恒等的には入らない。
既存の普遍最高階数上界（M0は42、M1も42）は、この同じ曲線に適用できる。
係数体上で確認した上界は小行列の恒等的消滅なので、未知の一般開へ入るという仮定は不要である。

## 4. M1の局所二重曲線

M1指定点の元135式から直接得られる階数は、最高42、全43。
接空間は二次元で、唯一の二次障害は非零な平方である。
そのradicalは前節の主曲線接線と一致する。
主曲線に沿うパラメータuで切った局所長は高々2であり、完備局所環Sは
R=C[[u]]上、二元以下で生成される有限加群になる。

同じ実在主曲線の一般点で、最高式の普遍階数上界42は無限遠局所長を
少なくとも2にする。従ってS/(t)のR階数は少なくとも2。
Sの生成元数の上界と合わせると、SとS/(t)は共にR自由階数2であり、t=0となる。
一般の唯一の被約支持は主曲線である。
一つの法線生成元eは冪零で、一般点ではe²=0。R自由性からe²=0が全体で成立し、

```
S ≅ C[[u,e]]/(e²),  t=0.
```

を得る。M0点にはこの論法の長さ2の上界はなく、別問題として残す。

## 5. M1階数一16次元族の全一般βファイバー

頂点incidence I⊂W16×P3は次元17である。
既存の全六評価（頂点条件二つ、q_v三係数、B）階数6により、
d=0は各頂点ファイバーで階数三の既約二次錐を定める。
その非零階数一開は既約次元16であり、主曲線公式の像の閉包Zも既約である。
非零modular像から頂点vを回復できるのでdim Z≤16。
保存されたd=0制限sourceのβ微分階数16によりdim Z=16で、W16を優越する。
Z⊂W16×P44はW16上properである。

上の局所計算はZの一般点へ延長できる。
固定β局所式の有限jet行列の階数は一般点で指定点以上となり、
指定点の長さ2上界と同じ主曲線の普遍長さ下界2が一致するためである。
Zの関数体はW16の関数体の有限可分拡大であり、全sourceの関数体への拡大は
忠実平坦な体拡大である。特別な低次元β部分空間への単なる制限を忠実と扱っていない。
有限jet比較だけから必要なtの冪零性がZの一般点に降下する。さらに本例では、保存された非零な横断二次係数と滑らかな主曲線のパラメータ条件も非空開上で保たれるため、横断長≤2と同じ下界2から第4節の自由階数2の論法を一般点で繰り返せる。この追加の開条件によりt=0も得られる。いずれにせよ、飽和除去に必要な冪零性はある非空開上で成立する。
その補集合は次元高々15であり、proper像を除くとZの全一般βファイバーは
t飽和後の閉包から除かれる。

これはM1の階数一における唯一の点の族についての結論である。
M0の階数一A1族、主曲線接続点、その射影端点、他の17次元曲線族の非一様例外には及ばない。
