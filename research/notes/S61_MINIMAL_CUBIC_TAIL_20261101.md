# M1 共鳴曲線の三重構造と斉次化変数の消滅

2026年11月1日。固定βの全135式の共通二次斉次化を扱う。
以下の指定点で、完成局所環は

\[
S\simeq \mathbb C[[u,e]]/(e^3),\qquad t=0
\]

である。同じ証明の開条件を満たす部分にも延びる。
曲線の交点・端点・全一般βファイバーをこの結論へ含めない。

## 1. 指定点と実在する曲線

保存順の16一次座標は

```
(0,0,0,0,-1/3,2,2,3,5,3,7,11,13,1/3,4,5).
```

M1の規約で

\[
Q_{xy}=Q_{zw}=x^2/2,\quad Q_{yz}=-xz-bx^2,
\quad Q_{yw}=ax^2+2d xz
\]

とする。指定点は (a,b,d)=(16,3,1)。同じβのまま

\[
(a,b,d)=(3+13z,3,z)
\]

を動かした曲線 C は、全135最高式を恒等的に満たす。
これは既存の M1, k=-1/3, g2=z の共鳴曲線である。
射影chartにおける微分は非零なので、z=1の近傍で滑らかな埋込み曲線を与える。
全斉次化に対して C は t=0 に含まれる。

元の135式から再計算した最高q-Jacobianの階数は42、
t列を加えた全chart Jacobianの階数は43。
形式的陰関数消去後の接変数は二つで、二次障害はすべて零となる。

## 2. 同じ曲線に沿う標準形

一般の (a,b,d) に対し、symplectic shear w↦w−2dz は
dを零にし、aをa−2bdへ変える。続いて
z↦z−bx, y↦y+bw によりbを消す。
最後に (z,w)↦((a−2bd)^{-1}z,(a−2bd)w) とすると、
a−2bd≠0上で標準点

\[
Q^*_{xy}=Q^*_{zw}=x^2/2,\quad Q^*_{yz}=-xz,\quad Q^*_{yw}=x^2
\]

に移る。行列のsymplectic恒等式と双ベクトルの有限変換を、
全a,b,d上で厳密に確認した。
指定曲線では a−2bd=3+7z、指定点で10である。
従ってCの同じ開近傍全体がこの標準形へ移る。
全135斉次化の同変性は既証明の
`S61_HOMOGENIZED_EQUIVARIANCE_20261101` を用いる。

## 3. 全十変数上の二次障害消滅

Q*における元134最高式のβ線形条件の核は正確に十次元。
その全核をβ=K(b0,…,b9)と置く。追加G6の最高式も全核上で零である。
44個の射影chart変数に関する135×44 Jacobian D をこの全十変数上で計算した。

最初の70行の階数は25、核次元19。残余65×19行列の階数は17で、
独立な有理核二本を保存し全積零を検証した。
従って一般最高chart階数は42である。
接基底 T は44×2。最高二次式をTに代入した三つの二次単項式の係数を
135×3行列 H とする。
証明書は44×3行列 L を保存し、全十変数上で

\[
D T=0,\qquad D L=H
\]

を厳密に確認する。したがって**無限遠スキームS/(t)自体の二次障害が零**である。
全斉次化の障害だけを計算して t=0 の追加障害を見落としたものではない。

この主張は階数42の開集合上の束写像の零として解釈できるため、
特定の有理接基底の分母に依存しない。
全核の一般点で恒等的に零であることから、その階数一定開集合全体で零となる。
第2節の標準化により、同じCの一般点でも適用できる。

## 4. 横断長さは三

指定点の接変数を二つ取り、Cの接線で非零になる一つをuとする。
u=0に制限し、残る一変数をvと書く。
独立な43本の線形関係を形式的に解くと、残りの全関係の二次項は零。
三次項には非零係数が現れる。保存基底の元の第66行（零始まり）では

\[
\frac{84035}{389017}v^3
\]

である。よって S/(u) は長さちょうど3。
コードは43次可逆小行列、二次・三次の消去補正、および全135残余係数を保存する。
三次までのt係数も零だが、それだけから全環でt=0とは推論しない。

一方、第3節から、Cの一般点における無限遠局所因子の相対埋込み次元は1で、
二次関係がない。従ってそのArtin局所因子の長さは少なくとも3である。
これは一標本からの長さ推測ではなく、同じ実在曲線に沿う普遍的な二次消滅に基づく。

## 5. 有限自由性と環の決定

R=C[[u]]とする。第4節よりSはR上高々3生成の有限加群。
S∞=S/(t)の一般ファイバーはCに対応する長さ3以上の因子を持つので、

\[
3\geq \operatorname{rank}_R S\geq
\operatorname{rank}_R S_\infty\geq3.
\]

全射R³→Sの核は階数零のtorsion-free加群だから零。従ってSはR上自由階数3。
さらに(t)⊂Sも階数零なので零となり、t=0を得る。

Cは滑らかであり、Sの埋込み次元は2。Cへの制限で零となる法線変数eを選ぶと、
R[[e]]→Sは全射である。Cの一般因子が長さ3を使い切るため、他の一般台はない。
この一般局所因子は埋込み次元1、長さ3なのでe³=0。
SはR-torsion-freeだからe³=0は全環に延びる。
従ってR[e]/(e³)→Sは自由階数3のR加群間の全射となり、同型である。
これは単に自由階数3から下位係数を消去したのではなく、
唯一の滑らかな被約枝と一般因子の長さを使った議論である。

完備化の忠実平坦性からt=0は元の局所環にも降り、指定点はtによる飽和後の閉包に残らない。
同じ階数・三次係数・曲線微分の開条件を満たす近傍に同じ証明が適用できる。
曲線族の例外点は依然として別に扱う必要があり、全アフィンファイバーの有限性は結論しない。
