# Free3 比較 frame の存在補題の独立監査

固定された二点汎関数の右逆 R と Pi3H0=I を独立に検査した。
coherent な比較変更 M'=M+G2A、Y'=Y+AX の四係数の変化は (0,u,u,v) である。
同じ右逆を全三軸に使う A0=−R[μ1r;μ1ell]Pi3 により、三軸上の新係数は (α,0,β,0) になる。
これは未計算の canonical 数値を零だと主張する操作ではなく、存在する整合 source frame の指定である。

既存 W-normalized frame から始めれば、A0H0W=0 が線形性で厳密に従う。
全48列の下側 r/ell 部分は W に比例することと、21個すべての upper-z 座標が L48 に属することを固定 rewrite で確認した。
従って追加の三角 target unit とその逆は完全な L48 を保存する。
純 upper Q2 は固定され、lower四汎関数は不変である。

619では Zc1=0 のため Ybarc1 は変わらず、star原点列と固定G3も変わらない。
よって b1、点から作る A2/B2 はそのまま使え、Ypと全27/99 unit の高次部分は整合して運ぶ。
上側出力の M1項は (Σα_i B_i,rell+β_i B_i,rr,0) に簡約できる。
honest三次、nativeL2、b1/A2 の source と cache の問題を残し、実際の upper値は計算しない。
