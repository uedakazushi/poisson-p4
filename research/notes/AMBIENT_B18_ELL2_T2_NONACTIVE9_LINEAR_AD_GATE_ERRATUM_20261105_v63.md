# Pre-sensitivity direct-atom gate correction

The first positive/factored linear-AD gate used the eight-node composite closure to look up every old B root. A direct actual-C0 root need not belong to that closure, so the gate could omit its literal second symbol. No signed source fold, sensitivity or actual value was evaluated from that gate. Its report and code snapshot are retained and withdrawn as an execution premise.

The distinct V2 uses the complete frozen1302-node root catalog to distinguish constants, direct actual-C0 leaves and composite roots. Constants alone have zero second response; every direct actual-C0 leaf is retained with its literal original node ID. Composite roots must be in the already profiled linear eight-node closure. All positive envelopes, term counts and whole bounds are rebuilt in V2. The negative active222 and lower9 value packets are unaffected.
