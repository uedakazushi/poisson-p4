# AB の incidence と特異点集合：独立した幾何学的点検

2026年11月1日。[AB_INCIDENCE](AB_INCIDENCE_20261101.md) の証明を、
構成担当とは別の agent が点検した。以下は幾何学的議論の review であり、
線形 intertwiner と Jacobi 係数の独立再計算は統合担当の点検に依存する。

固定 L での八次元線形同型と GL2 同変性が与えられると、rank 一・trace 零の
行列錐 Y と任意の磁気二次式との積が固定 L の AB 閉包である。
対角代表の GL2 軌道微分 rank 四は Y の次元四と一致するため、
その軌道は既約 Y に稠密である。Y の表示 u⊗v、v(u)=0 は全非零点を覆う。
五次元二次超曲面の不変部分環による正規性の証明は正当であり、
非零部分が滑らかな旗多様体の線束から零切断を除いたものになることから、
Y の特異点は原点だけである。

Lagrangian Grassmannian 上の局所自明化は、incidence の局所模型を
Y×A6 とする。補 Lagrangian の変更が磁気項だけを変えるため、rank 条件は
大域的に貼り合わさる。閉 incidence から Q45 への射影は projective であり、
稠密な既知 AB 族の像の閉包と一致する。dim K(Q)=2 の領域では、
係数微分行列の核を取る操作が代数的な逆写像となるので、そこで同型である。

全ファイバーの点集合だけでなく被約性も確認した。L⊂K(Q) は通常の
Gr(2,K(Q)) を定める。K が二次元なら被約な一点、三次元なら isotropic 条件が
P2 内の非零線形方程式なので被約な P1、Q=0 なら LG そのものである。
追加の rank 一条件はそれぞれの被約スキーム上で恒等的に零になるため、
追加の厚みを作らない。三次元核の場合の普遍的 rank 一恒等式がこの点で必要である。

特異点集合に関する最後の議論も正しい。dim K=2 の同型領域では、
特異点は N=0 の平面因子型だけである。一変数型の trace 非零点の近傍では
incidence の全逆像は滑らかである。もし像もその点で滑らかなら、
滑らかな同次元多様体間の birational 射の det(df) は、非零の直線束切断となる。
P1 ファイバーの接方向を殺すので零点を持つが、その零集合は同型でない集合、
すなわち余次元三の例外集合にしか存在できない。正則な非零切断の零集合は
空でなければ余次元一なので矛盾する。像の全域正規性を仮定していない点も適切である。

一変数型の trace 非零開部分は稠密なので、特異集合の閉性により一変数型全体が
特異になる。二つの候補以外は上記同型と Y の非零部分の滑らかさで除外される。
従って特異集合の被約台は正確に二つの六次元既約閉集合の和である。
その交叉での条件 ell(w)=0 は span(J ell,w) が isotropic であることと一致し、
P(V*) 上の rank 二族の像なので既約五次元になる。

平面因子型のパラメータ束を厳密に書くなら
Sym²(V/L)*⊗Λ²L という rank 三束である。元の集合表示はこの線の因子を
u∧v に含めており、結論に影響しない。

以上より、記載された係数証明書を前提に、proper normal incidence、
全被約幾何学的ファイバー、特異点集合の決定を受け入れる。
incidence が正規化射ではないこと、B 自身の正規性やスキーム論的零ファイバーの
厚みを決定していないことも、主張の範囲として正しく区別されている。
