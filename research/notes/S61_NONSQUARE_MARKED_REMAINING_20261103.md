# a=0 と d=0 の除去後にも残る非平方 marked 問題

2026-11-03。本稿の結論は、既存の a=0 と d=0 の全一般 β 除去だけから、非平方 marked 因子 D の全除去を結論することはできない、という**推論上の障害の特定**である。以下の明示族は係数と incidence の模型であり、元 Jacobi 式の解でも、実際に残る境界点の構成でもない。

## 1. a=0 と d=0 が内在的に意味する条件

[支持面の三次式と一次式](S61_AFFINE_ANCHOR_RESIDUE_DEGREE_20261102.md)を

    P=A r³+B r²t+C rt²+D₀ t³,    l=h r+k t

と書く。ここで D₀ は三次式の係数であり、marked 因子 D の記号とは区別する。l≠0 の所で marked 線は v₀=ker l である。非平方 marked 二次形式のもう一方の因子を v₁ とすると v₁≠v₀。根を順序づけて従来の Q₀ の枠へ移したとき、

    d=0 ⇔ P(v₀)=0,       a=0 ⇔ P(v₁)=0.

従って固定した (P,l) で d≠0 なら、v₁ の候補は P¹\{v₀} の中にあり、a=0 の除去はそこから P の高々三つの根を除く。既に分かっている「真の marked 残余は有限」という事実は、その有限集合がこの開集合に入る可能性を除かない。有限集合が P¹ の全ファイバーを含むと推論してはならない。

下の模型は、既存の c=f=0 の零対除去も避けるように作る。単純な polar 点だけを使うと c=f=0 に入ってしまうため、それを反例模型として採用しない。

## 2. 三つの四次不変量と一つの六次不変量

代表ベクトル v₀=(-k,h) を取り、

    R=P(v₀),   H=−det(Hess P)(v₀)/4,   Δ=disc(P)

と置く。R,H,Δ はそれぞれ係数 (A,B,C,D₀,h,k) の次数4の SL₂ 不変量であり、既存の三次元不変式空間の基底と一致する。m=∇P(v₀)、w=(m_t,−m_r) と置くと、

    det(v₀,w)=−3R,       P(w)=R S,
    S²=4H³−27R²Δ                                             (3)

が恒等的に成立する。S は次数6の唯一の SL₂ 不変量である。これらは保存された不変式を単に読み替えず、P の微分・Hessian・多項式除算から再構成し、全係数で検算した。

SL₂ の g で P,l を pullback すると v₀ と w は共に g⁻¹ で移る。これは Jgᵀ=adj(g)J と連鎖律から従う。平面の中心スカラーで全六係数を s 倍すると、v₀,w はそれぞれ s,s³ 倍され、R,H,S は s⁴,s⁴,s⁶ 倍される。従って以下の射影点の定義は、SL₂ の枠と中心スカラーの双方に対して整合し、複素数体上で GL₂ の枠変更に降下する。

## 3. 零対も避ける shifted polar 模型

単純な w は ∇P(v₀)·w=0 を満たす。v₀,v₁=w の枠では三次式の rt² 係数が零なので、これは K=0 の c=f=0 の零対に入る。既に除去した層を見落とさないため、代わりに

    v₁=S w−R²v₀                                             (4)

を取る。二項はともに中心重み9であり、射影点として同変である。直接計算により

    det(v₀,v₁)=−3RS,
    ∇P(v₀)·v₁=−3R³,
    P(v₁)=R(S⁴+3R²H S²−R⁶)                                 (5)

となる。従って R S P(v₁)≠0 の開では v₁ は well-defined で、v₀ と異なり、P の根でもなく、さらに c=f=0 にも入らない。

水平な支持面因子の模型として

    f(P,l)=H−R=0                                             (6)

を取る。f は次数4の SL₂ 不変量で、複素数体上既約である。確認には f を A の一次式として見る。その A 係数は

    k(−3Ck+9D₀h+k²)

で、後者の第二因子は任意の標数零定数体上で primitive な C の一次式である。A を含まない項は k でもこの第二因子でも割れない。従って Gauss の補題で絶対既約性が従う。

非空性と全ての開条件を同時に満たす厳密な例は

    P=r³+rt²+t³, l=r,
    R=H=1, Δ=−31, S=29,
    v₀=(0,1), w=(3,−1), v₁=(87,−30), P(v₁)=709803.

この ordered pair の determinant-one 枠へ移した従来の六 core は

    a=26289/24389, b=−218/841, c=1/174,
    d=−1, e=−249/841, f=−5/174.

従って K=0、L=5b−e=−1、a c d L≠0 である。深部条件も

    Q*=600b²−255be−63e²+100af=10197/841≠0

であり、単に零対や深部の既除去層を再利用した模型ではない。

## 4. なぜ一般 β 上で有限な次数10の模型になるか

固定標準面で六 core の変換は可逆で、残る八 nuisance は自由である。f=0 はこの H14 の既約な13次元超曲面を定める。支持面を LG(2,4) 上で動かすと、全 incidence I の水平な既約因子 Y が得られ、次元は16となる。

f の係数次数4と平面中心の指標から、その一般標準曲線 Cβ 上の因子類は O_C(2) である。f は I 上恒等零でないので、一般 β の Cβ 全体を含まない。従って一般 Cβ での零因子の次数は10で、Y→W16 は優越かつ一般有限である。全空間の既約性と標数零での分離性により、一般底の一つの次数10の閉点を与える。

f は R、S、P(v₁) のいずれも割らない。上の一点でこれらが全て非零であることと f の絶対既約性から従う。従って Y における各零集合は次元15以下であり、その β 像の閉包も次元15以下である。これらの像を避ける一般 β では、Y の全ての点で (4) は正則で、(5) の開条件を満たす。

よって v₀v₁ が与える D の模型は、一般 β 上で有限な次数10の一閉点を持ち、Σ、a=0、d=0、c=f=0 を同時に避ける。これは [有限 anchor の次数下界10](S61_AFFINE_ANCHOR_RESIDUE_DEGREE_20261102.md) や八 nuisance への非依存性とも整合する。

**この模型について元135式の t 飽和条件は検証していない。** 実際の残余 weighted-rank 欠損集合に含まれるとも主張しない。その条件を追加せず、内在的な係数・同変性・有限性・剰余次数だけで全 marked 非平方点の空性を推論することが不十分だと分かる。

## 5. 残る実際の有限課題

c=L=1 の H11 正規化では core は (a,e,d)、八 nuisance を全て保持する。既存の横断長65の適格開 U の補集合は core 内で次元1以下である。したがって残る主な問題は、a d≠0 上に残る core 曲線の一般点を元 Jacobi 式から除くことである。

一つの有効な完了基準は、元式の相対 t 飽和支持を零 nuisance section に引き戻した bad core B について、

    dim(B∩{ad≠0})≤0

を証明することである。全零次元 core は有限個なので、八 nuisance と Sp4 を戻し、core を固定する三次元加法群の自由な source 作用を引くと、joint 像の次元は高々

    0+8+10−3=15

になる。a=0,d=0 は既証明の全一般 β 除去を使えるため、この基準で非平方 marked 残余全体を一般底から除ける。孤立した各 core で周囲の t 冪零性まで同定する必要はない。

計算的には、既存の正確な重み付き行列の rank 欠損集合に残る各曲線を、代替切断の小行列式、局所有限加群、または明示的な局所化恒等式で除く。単に core 曲線と a=0,d=0 の交点が有限だという理由では不十分であり、アフィン曲線は両座標超平面を避けることもある。

別の十分条件は、実際の bad core を保つ**固有な** compactification と ample な試験因子を構成し、その因子の全点で全周囲の飽和除去を確認することである。現在の a=0,d=0 の一般 β 定理だけを、その compactification 上の全特殊点での冪零性と読み替えることはできない。
