# u4=0 の二平面型端点を一般一次部分上で除く

2026年11月1日。対象は全135式の同次数二次斉次化であり、飽和前の射影 chart を用いる。
二平面型 Q=xw∂y∧∂z と

    H_e={u12=u13=u35=u50=u4=0}⊂W16

の Sp4 飽和像の閉包 Γ_e を考える。この既約十六次元族は W16 を優越する。
Γ_e の全一般 β ファイバーは t による飽和で除去される。
[先の二端点](S61_BINARY_ENDPOINTS_20261101.md)と合わせ、元の十七次元階数降下族の
u4=0、u14=0、u49=0 という三つの十六次元部分が処理された。
全階数降下 locus の尽くしは主張しない。

## 1. 非共鳴の検証点と横断長さ

重み一の保存順 (2,3,…,17) に H_e の条件を課し、さらに u49 の値だけを15から16へ変更する。
全値は report の `endpoint.sample` に保存した。この変更の理由は第4節で示す。

指定点で、全135式 chart Jacobian の階数は34、接次元は11である。
固定 β の実際の二平面型三次元部分を、Lagrangian 平面上の標準曲線と二次式の二変数から構成した。
標準曲線の二方程式の微分階数は2であり、この三次元部分は滑らかである。
その接写像上で v0,v2,v3 が独立なので、これらをパラメータとし、八変数の横断商 A を取る。

計算は元の135式から改めて再構成し、次を検証した。

| 証明書 | 結果 |
|---|---:|
| QQ 上の横断二次障害階数 | 14 |
| 五次初期関係の792次 minor、mod32003 | 24773 |
| 非斉次 A2+A3+A4 関係の430次 minor、mod32003 | 20914 |
| t の係数行を追加した431次 minor、mod32003 | 25835 |

全ての陰関数消去 pivot と分母は32003で可逆である。
厳密な QQ 二次階数14は modular な二次消去を QQ へ持ち上げ、真の三次初期式を与える。
五次 minor は横断環で m_A⁵=0 を保証する。従って四次までの非斉次残余式が A 自体を決定し、
430次 minor から特性零の長さ上界65を得る。有限体の階数を QQ の階数上界として用いていない。

同じ β、同じ支持平面で Q1=(xw+x²+w²)∂y∧∂z を取ると、
全 Jacobian 階数35、二次障害階数5、共通 Hessian radical 次元3である。
従って同じ滑らかな二平面型三次元部分の一般点には、既証明の普遍三次下界65が適用できる。
特殊横断上界65との比較により、完成局所環 S は

    R=C[[v0,v2,v3]] 上自由階数65、S_red=R

である。I=ker(S→R) は自由階数64で I⁴=0。
一般点での It=0 と t²=0 は R 上の torsion-freeness により S 全体へ降下する。
自由階数65から関係階数が正確に430と確定した後、431次 minor により t≠0 を得る。
さらに t は R 上の直和因子を生成し、S/(t) は自由階数64である。
横断 Hilbert 関数は (1,8,22,34) だが、各 graded piece の自由性は主張しない。

## 2. 相対族から ambient への降下

固定 β の一点だけでの消滅から、β を動かす開性を推論してはならない。
H_e の11変数と二平面型部分の3変数を動かす。標準曲線の微分階数2により、
その相対既知部分は指定点で滑らかな14次元部分である。
その14パラメータ環上で完成有限加群の議論を行うと、特殊横断長さ65と一般下界65から
相対完成局所環も自由階数65となり、t²=0を得る。

射影 Q の安定化群の連結成分は5次元であり、その Lie 代数が H_e を保つことを
全自由変数について検算した。一方、H_e の五つの制約方向への群作用の微分は、
指定点で五次 minor 1787632 を持つ。従って Sp4×H_e→W はこの点で smooth である。
全135同次数斉次化の Sp4 同変性により、H_e 上の相対 full135 と Sp4 の積は
全 ambient full135 をこの smooth 写像で base change したものと同型である。
従って相対環での t²=0 は局所的な忠実平坦性により ambient 局所環へ降下する。
coherent annihilator を取ると、ambient のある Zariski 開近傍で t²=0 となる。

この議論は、端点で二次障害階数14が全パラメータで一定という未検証の仮定を必要としない。

## 3. 十六次元像の全一般ファイバー

5次元安定化群により joint image の次元は高々10+11−5=16。
上の非零 minor は β 像の次元16を保証するので、Γ_e は既約十六次元で W16 を優越する。
第2節の非空開部分の補集合は Γ_e の中で次元高々15である。
その β 像の閉包を除けば、Γ_e のファイバー全体が飽和除去済み開部分に入る。
従って一点だけでなく、Γ_e の全一般 β ファイバーが除かれる。
十七次元の元の階数降下族全体について同じ結論を出してはいない。

## 4. 元の検証点にある実在の無限遠交差

u49 を変更する前の等差数列点は u14=6,u49=15 であり、追加の共鳴条件

    5u14−2u49=0

を満たしていた。これは u4=0 の一般点を代表しない。
全11自由変数を残した H_e 上で、三次 potential と双ベクトルを

    G_a=xw²/2+a x²z,
    Q_a=xw∂y∧∂z−a x²∂y∧∂w

と置く。全135 leading 式へ代入すると、非零になり得る式は零始まりの70番だけで、
その値は正確に −3a(5u14−2u49)/10 である。
よって共鳴上では Q_a が実在の無限遠直線を与える。
a≠0 では係数双ベクトルの二次 minor が −a なので、固定二平面の一つの双ベクトルに
二次式を掛けた binary 型ではなく、R0 の別の非二元枝である。

古い点の chart で、前に選んだ三つのパラメータはこの直線上で全て零となることも検算した。
従って古い点の横断商は実際に正次元であり、探索に出た69は A/m_A⁵ の長さでしかない。
古い点で有限自由階数65の議論を使うことはできない。

さらに射影 Q 安定化群は H_e 内の上記共鳴超平面も保つ。
従ってこの特殊交差の joint image の次元は高々10+10−5=15であり、
その β 像は真の閉部分に入る。この明示的交差から一般 β 上の別枝を推論してはならない。
交差そのものの飽和除去や全局所環は、本証明書の対象ではない。
