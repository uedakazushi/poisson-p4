# S61 の重み1空間：係数階数による層別と階数1の固定 fibre

2026-10-30（Asia/Tokyo）。研究ノート。公表用原稿ではなく、文献上の新規性は未調査。

## 結果と範囲

S61 の16個の重み1方向を、閉じた primitive な一次係数2形式の空間
\(W\) として扱う。この空間には、係数写像
\(B_\beta:U\to\wedge^2_0U^*\) の階数 \(0,1,2,3,4\) による
\(\mathrm{Sp}_4\)-不変な層別がある。階数1の非零部分の被約な locus は一つの軌道で、
次元5、その射影化は4次元の isotropic flag variety である。

階数1層の全 Poisson 解を扱うための固定 fibre を、保存済み S61 の
**45変数・134個の二次式**として明示した。134式は定数係数線形独立で、
その線形包には非零の一次以下の多項式がない。したがってこの直接の
定数係数操作だけでは変数削減できない。固定 fibre の分解・次元は未決である。

また W の一般点で Sp4 軌道次元は10、スカラーも加えれば11であることを
有理数体上の非零 minor で確認した。このノートの任意に選んだ witness 自体が
実際の Poisson 構造へ延長するかは未判定である。
一方、同日の独立な[toric 族の検証](TORIC_WEIGHT1_DOMINANCE_20261030.md)により、
既知 T01 から W への射影は優越的で、W の非空開部分の全点が実際に延長できる。

## 1. 一次項の内在的な模型

\(U=\mathbb C^4\)、座標 \(y_1,\ldots,y_4\)、
\(\omega=dy_1\wedge dy_2+dy_3\wedge dy_4\)、
\(J=\partial_1\wedge\partial_2+\partial_3\wedge\partial_4\) とする。
一次 bivector \(L\) を symplectic lowering で一次2形式 \(\beta\) に移す。
行列表記では \(\beta=-JLJ\)、逆にも \(L=-J\beta J\) である。
\([J,L]=0\) は \(d\beta=0\) と同値である。

\(\Lambda\beta=\beta_{12}+\beta_{34}\) と置く。
一次形式 \(\ell\) に対し

\[
 P_\ell=2\ell\omega+d\ell\wedge\iota_E\omega,
 \qquad E=\sum y_i\partial_i
\]

は閉じ、\(\Lambda P_\ell=5\ell\) である。
これは perspective 変換の一次方向（符号は pushforward/pullback 規約による）である。
よって閉一次形式は一意に

\[
 \beta=\left(\beta-\frac15P_{\Lambda\beta}\right)
          +\frac15P_{\Lambda\beta}
\]

と分解する。従って perspective 商は

\[
 W=\{\beta\in U^*\otimes\wedge^2_0U^*:d\beta=0\}
\]

と同一視される。24係数に対して閉性4条件、primitive 性4条件は独立で、
\(\dim W=16\)。この座標・perspective についての独立確認は
`S61_MODEL_AUDIT_20261030.md` も参照する。

これは標準的には最高重み \(\omega_1+\omega_2\) の Sp4 表現であるが、
以下の層別・軌道・計算には表現の名称や既約性を仮定する必要はない。
保存済み S61 の零座標による gauge は primitive gauge と異なるため、
一般の点で raw 一次係数をそのまま \(B_\beta\) に入れてはならない。
まず上の射影により perspective 成分を除く。

## 2. 係数階数1の完全な記述

\(\beta=\sum y_i\theta_i\) を
\(B_\beta(e_i)=\theta_i\) と解釈する。primitive 性により値域は5次元。
行列は行 \((12),(13),(14),(23),(24)\)、列 \(y_1,y_2,y_3,y_4\) の5×4行列で、
残る行 \((34)\) は \(-(12)\) である。階数条件は通常の minors で与えられる。

**補題。** 非零 \(\beta\in W\) の係数階数が1であることと、

\[
 \beta=\ell(y)\,d\ell\wedge dm,
 \qquad \ell,m\in U^*,\quad
 d\ell\wedge dm\ne0,\quad \langle\ell,m\rangle_J=0
\]

と書けることは同値である。

**証明。** 階数1なら \(\beta=\ell\theta\)。閉性は
\(d\ell\wedge\theta=0\) である。\(d\ell\) を基底の第一要素に選べば、
この核は \(d\ell\wedge U^*\) だから \(\theta=d\ell\wedge dm\) と書ける。
primitive 性は \(\langle\ell,m\rangle_J=0\) と同値。逆は直接従う。□

\([\beta]\) は isotropic 二平面 \(\langle\ell,m\rangle\) とその内部の直線
\(\langle\ell\rangle\) を一意に定める。逆にこの flag は
\([\ell\otimes(d\ell\wedge dm)]\) を定める。従って階数1 locus の射影化は
\(F(1,2;4)\)。Lagrangian 二平面の空間は3次元、その中の直線は1次元なので
射影次元4、非零 affine cone の次元5である。
Sp4 は isotropic flags に推移的であり、flag を保つ対角元の係数作用
\((t_1,t_2)\mapsto t_1^2t_2\) は \(\mathbb C^*\) に全射なので、
cone の非零部分も一軌道となる。

ここでの同定は被約な locus の主張であり、minors と線形条件で定めたイデアルの
根基性や非被約構造については主張しない。

固定代表を

\[
 \beta_0=y_1dy_1\wedge dy_3,\qquad
 L_0=y_1\partial_2\wedge\partial_4
\]

と取れる。\(J+L_0\) は Jacobi を満たし Pfaffian は1である。
実際、係数の微分方向 \(y_1\) は \(L_0\) の二つのベクトル場により消される。
斉次持ち上げは

\[
 x_0^2(\partial_{12}+\partial_{34})+x_0x_1\partial_{24}.
\]

したがって階数1層は実際の解を持つ。ただし、これだけで同じ一次項を持つ
全解がこの affine-linear 族に属するとは言えない。

## 3. 固定一次項への帰着と厳密な残余問題

primitive gauge での S61 を \(\widetilde S_{61}\) と書き、
\(F\) を一次項が \(L_0\) に等しい fibre とする。\(H=\operatorname{Stab}_{Sp4}(\beta_0)\)
に対して、W 内の被約な階数1軌道への制限は associated bundle

\[
 \widetilde S_{61}|_{\operatorname{rank}B=1}
       \simeq Sp4\times^H F
\]

となる。\(L_0\) は二つの gauge の両方に入り、一次項の補正は高次係数に依存しないため、
この固定 fibre は保存済み gauge の fibre と同じである。
これは equivariant morphism の一軌道上の逆像に対する一般的な記述であり、
rank2〜4の層を分類したことにはならない。\(H\) は flag の Borel 安定化群での
原始 character \(t_1^2t_2\) の核なので連結で、次元5である。
従ってこの層の成分研究は固定 fibre の成分研究に帰着する。
層の閉包が全 Poisson 空間の成分かどうかは別途判定する必要がある。

上の \(L_0\) は保存済み gauge でも perspective 補正が零であり、
S61 では **\(u_{34}=1\)、他の15個の重み1変数は零**となる。
重み2変数45個を全て残して134式に代入した結果は
`reports/weight1_rank_one_fiber_20261030_final.json` に格納した。
添字は JSON 内では0始まり、`variable_names` が元の \(u_i\) と対応する。

- 134式はすべて通常次数2で、定数係数線形包の次元も134。
- その線形包と一次以下の多項式空間の共通部分は零。
- 重み2座標が全て零の既知点で Jacobian の階数は7、固定 fibre の接空間次元は38。
- 接空間次元38を fibre 次元、成分次元、あるいは全 S61 の接空間次元とは呼ばない。

式には一次項も含まれる。「一次以下の式を定数係数結合で得られない」ことと
「一次化が零」は異なる。7本の一次化方向を局所的に解くには単元 minor を局所化して
残余方程式を導く必要があり、ここではまだ行っていない。

## 4. 一般一次項の軌道数に関する制約

`weight1_structure.py` は16次元核基底を有理数体上で作り、基底係数
\((1,2,\ldots,16)\) の一点を固定する。この点で係数写像階数4、
Sp4 Lie 作用の階数10、スカラー方向を加えた階数11を厳密に計算した。
証明書に元の小行列と非零行列式を保存した。

階数の半連続性と \(\dim Sp4=10\) より、W の稠密開集合で安定化群は有限、
軌道は10次元である。従って W 全体は有限個の Sp4 軌道に分かれない。
一般軌道の余次元は6、スカラー込みでは5。ここで「余次元」は軌道次元との差で、
具体的な商や生成不変式を構成したという意味ではない。
同日の `TORIC_WEIGHT1_DOMINANCE_20261030.md` は、六つの toric パラメータと
十の Sp4 方向からなる16×16微分 minor が
\(258241/10504375\ne0\) となることを証明した。このため実際の S61 像は
W の非空開集合を含み、上の一般軌道の次元は実際に延長可能な jet の稠密部分にも
当てはまる。その証明書には、係数階数4・軌道次元10/11を持つ延長可能な有理 jet もある。
本ノートで先に選んだ別の witness 個体の延長を示したという意味ではない。
