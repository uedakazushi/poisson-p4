# 固定 row6・col53 の完全 H 端面と非零係数

既存係数側 SOURCE の1203ノード SSA を用い、固定 row6・col53 分子の H=-3 面と H=21 面だけを一度評価した。新しい SOURCE ゲート・VALUE コード・896個のモード依存ノードについて、Mark の独立レビュー（SOURCE_CODE_REVIEW、7c6e2587…）が PASS してから、ROOT の条件付き一回実行を行った。ほかの H 係数や別の entry は評価していない。

主計算の report は b8d4309e…、実行時間0.766秒である。H=-3 の完全な面には411個の非零係数があり、H=21 の完全な面は零となった。元の正の支持上界はそれぞれ766点・214点であり、相殺された係数を含めて完全な面を計算した。最大所有数124,092、全RAW14,990,365バイトで、事前上限126,262／17,661,238バイト内に収まった。全5座標と係数の7数値課金、整数幅640／一時1921／既存VALUE2048を維持した。

明示的な非零係数は、変数順 (H,L,s0,q0,t0) で

    exponent = (-3,0,6,-1,10)
    coefficient = 241815/134217728

である。したがって固定の係数側分子は QQ 上で零多項式ではない。以前得た10個の正の支持頂点の係数がすべて零だったことから、この結論を得ることはできなかった。今回の面計算はそれらの頂点零を使って枝を省略していない。

非圧縮 binary の各面を全係数で読み戻し、別実装の stream decoder でも411個と0個を照合した。独立 decoder の report は c38b8696…で、primitive content、GCD、全5座標、SOURCE支持への所属、順序・一意性、値ハッシュを確認している。この decoder は保存値の検証であり、元の係数演算の独立再計算とは区別する。元 SOURCE からの独立 VALUE 再計算レビューは別 packet として待つ。

対象は既存第10段の full167×14 callback に対応する固定分子であり、既存の係数側恒等式と prefactor P7/(U²F10) は変更しない。全87追加RHS・66制約・P290一回・F9/F10とすべての補集合を保持する。この結果だけで全行列の逆、全列応答、補集合上の挙動、exhaustion は主張しない。新しい Schur 行列の係数更新もまだ行っていない。
