# a-only 十変数部分模型に省略されていた G6 を戻す

2026-11-03 / v62。全非平方 marked 問題の後続計算のため、11月2日の候補模型を元135式へ戻して厳密に補完した。

## 以前の入力の問題と修復

保存された a-only partial model は、元134式のうち正重み4以下の式だけを使い、追加の普遍式 G6 を含めていなかった。33個の線形置換はすべて有理定数×aの冪を pivot とし、行の正規化でも a の冪だけを除いている。元 q chart の q19=q23=0 に q5=0 を加える三切断で、残る変数は

    (q3,q4,q8,q12,q20,q22,q24,q35,q37,q43),
    重み (1,2,1,2,1,1,1,2,1,1)

である。

今回、凍結候補 JSON のハッシュを照合し、**元135式から**重み4以下の全行を再構成した。記録されている33 pivot、分母の a 冪、各行正規化を一段ずつ exact に再実行した。元134式に属する全ての最終係数が凍結候補と一致することを確認し、元 t の追跡式も

    t = a^(−9) T(q;a,e,d)

という保存された分子と完全に一致した。

G6 は重み3なので、重み4の選択変数には依存せず、同じ置換を通せる。新しい残余は重み3の105単項式に3747個の core 係数項を持つ。各段で G6 自身の a-content を除いているが、未知の core 因子は除かない。この追加式と t 分子を [追加データ](../../reports/S61_BINARY_NONSQUARE_PARTIAL135_20261103_v62/additional-G6.json) に保存した。

## 何を計算できるようになったか

固定 β、三つの実在 binary 接方向を切った商の**重み4以下の帰結**を、B や D0 で局所化せず a≠0 だけで扱える。これにより B=0 などの frame artifact を含む bounded weighted matrix と t-target の検算を、元135式の G6 を保って進められる。

この模型は、重み5・6の元の行をすべて再展開したものではない。従って全135式との ideal 等号を主張しない。ただし、この帰結 ideal だけで t を逆にして単位 ideal が得られれば、元の全 ideal についても同じ排除が従う。空でない場合は、高重みの追加条件も調べる必要がある。

これは nuisance 零・固定 β の部分模型であり、それだけで全相対の周囲 t 冪零性を推論しない。全 H11 への橋には、同じ実在 incidence の一般長、正重み有限性、または実際の相対加群の証明が別途必要である。
