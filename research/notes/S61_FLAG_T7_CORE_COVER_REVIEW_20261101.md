## 四次の残りの source

既存の有限正常化は ordinary core の全点を七変数 chart と Sp4 の像で覆う。
その chart 上の b8=0 と L=−200b10−91b11+200b9=0 は独立な線形条件であり、
残りは五次元である。Sp4 は十次元なので、この残りの全像の次元は高々15である。
悪い集合が安定化群不変である必要はない。
十分一般の W16 の点はその像閉包を避ける。

b8≠0 の既証明と b8=0,L≠0 の新証明を合わせた全点被覆を受理する。
ここで受理する係数計算の使用範囲は、定数 minor と L² minor および
全分母の L 冪監査が与える「指定開の全点への特殊化」である。
この四次結果だけで高次初期イデアルや t 冪零性を結論していない。

## 閉 flat4 商の全点被覆

新しい三つ目の nil 基底 q10 による正則化後の開条件は
a0*a8*a9*P≠0 であり、旧人工因子 Q を含まない。
全座標・積が正則なら、一般 ε で成立する代数恒等式と元135式は
ε-torsion-free な自由4 lattice に降りる。
実座標が nil 基底を生成し、q24=3ε と独立な shear 方向があることから、
既存 flat4 証明の閉商・曲面化の議論が適用できる。

有限 word は b0,b12 を保持するので、ordinary core の像で a0,a8 は非零である。
同じ H11 の a9=0 および P=0 の全 Sp4 β像が15次元であるという既存結果は、
βだけについての命題であり、ε≠0 に限定されない。
従って一般 β 上では旗端点 ε=0 でも残りの二条件は自動的に避けられる。
ε に依存しない word の逆作用により、閉商を元の同じβの旗点へ戻せる。

以上の全 ordinary core 被覆を受理する。
閉商における t=0 は ambient 局所環の t 冪零性を意味しない。
b0=0、b12=0、他の core、旗三次元族との scheme 的接続は対象外である。
