# 指定zero12点の実kernelは二変数底上有限である

2026年11月2日。Sを指定zero12固定β点の全完成局所環とし、
[実在の閉平方零商](S61_FLAG_BOUNDARY_SQUAREZERO_QUOTIENT_20261101.md)を
S→D、M=ker(S→D)と書く。
R=QQ[[v0,v1,v3]]上でDは自由rank5、Mは有限R-torsionである。

本結果はさらに

    M は R2=QQ[[v0,v1]] 上の有限加群で、111生成以下

を証明する。初期差加群E111との一致やMの自由性を仮定しない。
t作用はこの実際の有限R2加群のR2線形作用として扱えるが、冪零性はまだ結論しない。

## 1. 実在商Dのassociated graded

Sの九接座標をv0,...,v8とし、元45局所座標への接枠をTとする。
実在旗C3の三接方向と閉平方零商の四nilpotent方向を、Tの座標に厳密に戻す。
前者をC、後者をXという9×3、9×4行列で表す。

全七方向でv4=v7=0となる。また四つの線形形式

    ℓ=(v2,v3+2v6,v5,v8)

はCの三方向を殺し、Xの四方向に制限した行列の行列式は4/63である。
CとXを並べた行列は階数7である。これらは元の接枠と保存された正確な平方零方向から
有理数で再計算する。

Dは滑らかな三変数底上の四方向平方零代数なので、その極大idealによるassociated gradedは
三つの一次底変数と四つの一次nilpotent変数で生成され、後者の全二次積が零である。
上の接写像の線形条件と非零行列式により、vからの射のkernelは正確に

    B=(v4,v7)+(v2,v3+2v6,v5,v8)².

従ってgr D=QQ[v]/Bである。これはDの高次embeddingを無視した推測ではなく、
標準次数で生成されるgr Dへの全射を接写像で同定したものである。

## 2. 初期加群から実kernelへの全射

[保存済みQQ証明](S61_FLAG_ZERO12_RATIONAL_INITIAL_20261101.md)は
J6⊂in(I_S)と、E=B/J6がP2=QQ[v0,v1]上自由rank111であることを証明している。
生成元の次数は1から6までで、その個数は2,15,28,38,18,10である。
producerはこの小さい加群証明書を再実行する。

S→Dは局所全射なので、全nについてm_S^n→m_D^nも全射である。
Mには誘導filtration F^nM=M∩m_S^nを入れる。
このfiltrationについてassociated gradedの列は正確であり、

    0 → gr_F M → gr S → gr D → 0.

J6の包含と§1から、G=QQ[v]/J6→gr S→gr Dという可換な全射がある。
従ってそのkernel Eからgr_F Mへの全射が得られる。
特にgr_F MはP2上111生成以下で、生成元の次数は6以下である。
追加の未知初期関係はEの中のkernelに残しており、零とは仮定しない。

## 3. 完備性による実際の有限生成

gr_F Mの上記生成元を、対応するfiltration次数を持つm_i∈Mへ持ち上げる。
任意のm∈Mの最初の非零graded項を、v0,v1の斉次多項式とgr(m_i)の和で表し、
同じ多項式とm_iの和を引くとfiltration次数が一つ以上上がる。
これを反復する。

生成元の次数は6以下で固定されているため、反復のfiltration次数がnへ上がると、
新たな係数の(v0,v1)次数は少なくともn−6となる。
従って各生成元の係数はR2の形式冪級数へ収束する。
Mは完備Noether局所環Sの閉idealであり、誘導filtrationで完備かつ分離している。
余りは零へ収束するので、元mはこの有限個のm_iのR2線形結合となる。

これはR2有限性を最初に仮定するNakayamaの循環ではない。
111個以下のliftからR2^111→Mの全射を直接構成している。
よってMはR2有限である。

## 4. 正確な帰結と限界

t∈Mなので、tによる乗法は有限R2加群Mの線形自己準同型である。
Mには有限R2表示が存在し、その上でt作用を有限行列として扱える。
R2上のtorsionや自由性、必要な生成元の最小個数はまだ同定していない。
