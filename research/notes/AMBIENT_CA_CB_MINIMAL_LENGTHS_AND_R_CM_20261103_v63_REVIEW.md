# CA/CB minimal 一般長と R 上の CM・normal locus の独立監査

2026-11-03。全依存 hash を照合した。新 CAS は不要な exact-scope theorem の帰結である。
被約 CA/CB の両 ideal は共通 reduced first-jet image Z の ideal を含む。
従って generic Z の函数体への平坦な底変換は、法線底方向の nilpotent を仮定で捨てず、
実際の component ideal の和と可換する。既監査の全 fiber A10 とその exact intersection A9 を
使うと、Z を優越する N の generic 局所長は1である。
R の generic 長は、全 R\\N の actual ordinary double 完成環から2である。
通常の proper intersection Chow 積や embedded primary の数と同一視しない。

R\\B18=R\\N では D は smooth19 上の ordinary double なので CM、Dred は smooth19なので CMかつ normal。
B18 の各閉点では N27 と R19 という異なる minimal 次元が D と Dred の両方に残る。
優秀性と忠実平坦な完成によりこの二次元は completion でも残り、CM unmixedness に反する。
よって両 scheme の R 上の CM locus は正確に R\\B18である。
B18 の Dred 局所環は二つの minimal primes を持つ局所環で、normal local domain になれない。
D 自体は開側でも非被約なので、R 上に normal な点はない。

R 単体の CM 性、N\\R の全 locus、embedded primes や global primary decomposition は結論しない。
