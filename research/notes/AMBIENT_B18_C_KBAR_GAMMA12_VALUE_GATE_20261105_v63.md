# 確定済み t37 を再利用する二つの gamma の値計算ゲート

mu_R0(K)=3 の独立整数 postpeer が照合した phase1 の三十七係数を、そのまま入力として再利用する。C0 二十一 root の rr 値や IFT・gauge を再計算しない。二つの係数は、受理済み linear reduction `rh1-alpha1*v`, `rh2-rh3/4-alpha2*v` の true actual37 lift に対する `-pi_q2 M2` である。既存 gamma12 SOURCE はこの二つの weight を固定している。

新 worker の signed scope はこの二つの dot だけとし、C,F,Delta、残る G38 三次係数 H は計算しない。H を得る source inventory は別に行う。本ゲートは実値を対にせず、既存入力と weight の正の共通分母上界、全 partial prefix 保存、所有数・RAW・bit 上限を先に固定する。独立 source/code peer と ROOT の一回許可が必要である。
