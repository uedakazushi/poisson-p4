# M0/M1有限主曲線の全除去：独立レビュー

2026年11月1日。対象は `S61_MINIMAL_MAIN_REMOVAL_20261101` の凍結済み
コード・証明書・証明ノートである。結論を受理する。
十分一般の一次項βについて、非退化頂点二次式を持つM0/M1主曲線の
**全有限部分**が、全135式の同次数斉次化のt飽和で除かれる。
階数一頂点と射影分母極は、対象定理が明記した別の既存定理・残件のままである。

## 1. 独立計算の範囲

元134式と保存された普遍G6の単項式データから、βを全九係数で置き、
標準Q(c)での全135行・45列のJacobian Jを再構成した。
対象コードの `specialize`、`uniform`、局所初期idealの生成関数は呼び出していない。
有理核を列ごと、余核を行ごとに分母を払い、別実装の多項式環
QQ[c,b0,…,b8]で次を照合した。

- 全135個の最高式の恒等的消滅。
- 保存された全核Tについて J T=0、および指定自由座標部分行列が単位行列。
- 疎な余核Lについて L J=0。
- 元135式の二次部分を法線列に代入した L Q2 の全係数。
  M0の3×3行列の9係数、M1の1係数が全変数の恒等式として一致する。
- 上の行列式が対象証明書の法線minorに一致する。

M0の一般全階数42、M1の一般全階数43は別の有理標本でも確認した。
このレビューでは、対象コードの重い普遍Schur消去と17次残余minorの
記号的行列式計算そのものは再実行していない。
その非零minorによる全指定開の階数下界、最初70行とt列を含むSchur補の
正確な構成はコードを読み、既存の形式階数証明書とともに依存として保持する。
普遍J T=0による上界と余核・法線障害は今回独立に再計算した。

M1の普遍局所表のQは、幾何的主枝公式の代表の二倍である。
比較時にはこの定数倍を明示的に揃えた。半トレース規約との差を
β係数や主枝の座標変換に混入させていない。

## 2. β核・有限正規化・因子被覆

元134最高式のβ線形行列を別途再構成し、保存された七次minorとその
**全ての根での正確な階数**を検算した。
通常核は九次元であり、真の十次元への跳躍は次の通りである。

| 型 | 真の核跳躍 |
|---|---|
| M0 | c=±2、±4/5、±1/2 |
| M1 | c=±3、±1、±2/5 |

M0の±6/5、M1の±3/5は核次元の跳躍ではない。
跳躍値を九係数の核だけで代表させず、既レビュー済みの全十係数の
基線・半単純尾・三重尾の定理へ渡す点を確認した。

有限symplectic translationの全4×4 pullbackを、a,b,cを残して検算した。
さらに有限交換(z,w)→(−w,z)についてQ(c)→Q(−c)と、
全16個のβ座標の三共変添字pullbackを検算した。
b7=0がb8=0へ写ることも含む。
c=±1でtranslationが使えないことを隠さず、M0では既レビュー済みJordan、
M1では全三重尾へ移す被覆を確認した。

第一minor、残余Jacobian minor、全枠分母、法線minorの分子・分母を
独立に因数分解した。M0/M1それぞれ18個の異なる因子が、対象表と完全一致する。
b6=0、c=0および偽のrref極のproper像は、全Sp4方向を含むβ微分行列に
保存左核を掛けて恒等的に零となることと、その左核の独立性を検算した。
像上界はそれぞれ13、14、15である。

## 3. 非不変な35項因子P

M0のPについて、b4次数が1で、b4の係数と定数項のgcdが1であることを
独立に確認した。係数はcの多項式とb6,b8の単項式の積であるため、
このprimitive性は複素数への係数拡大後も成立する。
従ってPは幾何学的に既約である。

Qから直接作り直したprojective Sp4作用に、保存された三次元安定化を掛けて
零になることを確認した。そのβ作用も独立に照合し、
b6,b7,b8への作用が対象ノートの対角形になることを検算した。
第一Lie方向DによるD(P)は保存式と完全一致し、gcd(P,D(P))=1である。

ここでP=0全体のβ像を小さいと主張してはいけない。
対象証明はt飽和後の**内在的な残存支持**のsource逆像Sを用いている。
他の因子を既に処理した通常開は連結安定化で保たれ、その開上でS⊂V(P)である。
安定化不変性により各軌道上でPが消えるので、D(P)もS上で消える。
PとD(P)が互いに素であることから、十次元source底でdim S≤8となる。
Sp4×Sから(β,[Q])への写像には右安定化の三次元ファイバーがあり、
像次元は高々10+8−3=15である。
この議論は非不変超曲面自体の像に関する誤った推論を含まない。
固定cや分母の零は、別の有限表で処理される。

## 4. 新しい小例外層

五つの有理例外について、元135式から局所Jacobian、全二次残余、
二次の定数線形従属を消した全三次残余を再構成した。
保存された全初期多項式と一致し、u=0で有限、u=1での初期環の長さも一致する。
同じβの主枝については、非対角十四変数公式の微分とSp4作用を独立に作り、
β微分の核方向が保存された非零主接線に写ることを確認した。
主枝sourceのβ階数16・同時階数17、および例外層sourceのβ・同時階数16も検算した。

| 型・条件 | 全Jacobian階数 | 一般初期長の上界 |
|---|---:|---:|
| M0、b7=0 | 41 | 3 |
| M0、c=2/5 | 42 | 3 |
| M1、b7=0 | 42 | 2 |
| M1、c=1/5 | 43 | 2 |

7c²=1の例外は、QQ[a]/(7a²−1)をQQ(√7)で厳密に実現して検算した。
保存Jacobianの階数42、保存核との積、固定cおよび主枝のβ階数16を再確認した。

u=0切断長3、u=1局所化長2となる。
この体上の非零minorと恒等式は両複素埋込みで保たれる。
この例外の高次縮約を元135から再生成する計算は繰り返しておらず、
その生成コードを読み、保存初期形式を入力とする範囲を明示する。

## 5. 局所環と全一般βへの移送

通常開での滑らかな実在主曲線は、単独のsource微分標本から外挿されていない。
十分一般βでは頂点曲線Eτが滑らかであり、BE≠0上の非対角主枝公式が
正則graphを与える。Qの非零modular像から頂点が正則に復元できるため、
固定βで同じ滑らかな曲線Cが局所的に埋め込まれている。
普遍枠のminorが非零なら、その接線と選んだ法線方向は補空間をなす。
法線二次障害の非零minorからC方向のパラメータで切った長さ上界3/2を得る。
同じCに沿う普遍階数上界の下界と一致するので、有限加群の生成数と階数が一致する。
これにより指定通常開の全点でM0自由3、M1自由2が従う。

長さ下界の環を区別する必要がある。
M0の下界3は全Sの下界であり、S/(t)の下界ではない。
M1の下界2はS/(t)でも成立する。
従ってM0では一般平方零構造からt²=0、M1ではt=0となる。
自由性を得ていない例外層の指定点では、この結論をそのまま移さない。
初期多重度上界と同じ主枝の下界により一般因子を尽くし、
M0では(t²)、M1では(t)が有限長DVR-torsionへ入るのでtの冪零性を得る。
全環のt²=0や平坦性を新しい例外全体には主張しない。

各新例外の像閉包Zは、安定化による上界と実際のβ階数16により既約十六次元である。
有限jet行列の特殊化は全Sp4×sourceの関数体上で行い、
k(Z)/k(W16)の有限可分性と忠実な体拡大を使って一般固定βへ降下する。
標準九係数のHだけをW16に対して忠実と扱わない点を確認した。
一般点のt冪零性はZの非空開へ広がり、補集合は次元高々15である。
そのβ像閉包を避けることで、Zの全一般βファイバーが除かれる。

既レビュー済み基線・尾・Jordan・接続層の定理、全135斉次化のSp4同変性、
非対角主枝公式と頂点曲線の滑らかさは明示的依存である。
今回の結果は主曲線の射影端点、T5、旗・二平面の未処理層、
全S61アフィン一般五点の尽くしを結論しない。
