## 1. 実入力と二つのモニック消去

E4 は同じ物理 R0 上の二つの実正規化を、十二の残り物理出力で比較する環である。
自由四加群・四十八列の表示とは同じ環を扱うが、ここでは代数の表示

    R0[[tauA,tauB]] /
    (tauA^2-nuA, tauB^2-nuB, F18,F19,F28,F29,F60,F67,F72,F63,F64,F68,F73,F74)

を用いる。Fj=(aAj+bAj*tauA)-(aBj+bBj*tauB) であり、a,b,nu は
既存 `ACTUAL_TOP_COEFFICIENT_PREFLIGHT` の二つの実48係数 unit 系そのものである。
十二出力の元ノードと全96係数方程式を `typed-core4-input.json` に literal に保存する。

二つのモニック関係の実 R0 に関する微分は rho27,rho61 で minor -20/9 を持つ。
従って全96係数未知数とこの二座標を合わせた98未知数は unit Hensel 系で消せる。
既存の二つの48 unit 行列と Schur minor がその単位性を与える。
消去後の正則九次元環を

    S=QQ[[x108,x109,x112,x113,x117,x118,x119,tauA,tauB]]

とする。十二 F はこの環の具体的な代数的正則関数であり、任意の未指定関数ではない。

## 2. 実 N-pair からの全次数除法

前提 packet は同じ N 正規化 B_N から S への rank8 閉埋込みを証明する。
特に (X,tauA) が B_N の座標で、その上の実第二根を beta(X,tauA) と書ける。
beta は元 source28・20切断と二つの48係数 unit 系、および
非零 conductor 係数から整閉性で証明した一意な正則商により有限に指定される。
中心の消える conductor 係数を単位反転しない。

    L=6*(tauB-beta(X,tauA))

と規格化する。L の一次項は

    5*x112-20*x117+24*tauA+6*tauB

であり、S/(L)=B_N は正則八次元。十二の実物理出力は B_N 上で一致するので

    Fj=L*Gj   (j=18,19,28,29,60,67,72,63,64,68,73,74)

が全次数で成り立つ。Gj は座標 ell=L による一意な正則 Hadamard 商である。
`tauB=beta+ell/6` として Fj を評価し ell で正則除法することが、その具体的有限入力。
L を反転する操作ではない。ここまでの正則商を全て多項式だけの unit 系へ
展開したとは主張せず、型付き代数的正則関数 operator として保存する。

## 3. 五つの単位微分と七つの core 関数

既存の全二次キャッシュは、全 F の二次項が同じ規格化 L の一次項で割れることを示す。
従って次の五つの実 Gj の一次ヤコビ行列は、記載した五座標について対角である。

| 関数 | 対応する座標 | 微分 |
|---|---|---|
| G18 | x108 | 1/12 |
| G19 | x109 | 1/12 |
| G60 | x113 | 1/24 |
| G28 | x118 | 1/12 |
| G29 | x119 | 1/12 |

他の一次係数は零。minor は 1/497664。
形式逆関数定理でこの五関数を正則座標として消す。残る座標は

    C=(x112,x117,tauA,tauB)

である。残る七つの Gj、すなわち物理 rows 67,72,63,64,68,73,74 をこの五関数零の
unit 解へ代入したものを K1,...,K7 とする。これは実関数の有限代数的な代入であり、
新しい係数推定ではない。J=(全十二 Gj) とすれば厳密に

    S/J = QQ[[C]]/(K1,...,K7)

となる。S の新しい五座標を U と書くと、元 E4 の ideal は

    L'(U,C)*(U1,...,U5,K1(C),...,K7(C))

と書ける。七関数から U の倍を引く操作は同じ ideal を与える。
五つの L'*Ui 関係を捨てない。E4 全体を四変数商と同一視しない。
L' の tauB 微分はなお6であり、元の hypersurface 因子は正則である。

## 4. socle 計算の正しい移行

S は整域、L は非零なので、任意の J に対し

    0 -> S/J --L--> S/(LJ) -> S/(L) -> 0

は完全である。実際、La が LJ に入れば整域で L を消去して a は J に入る。
S/(L) は正則八次元なので H0 と H1 が零。局所コホモロジー完全列から

    H0_m(E4) = H0_m(S/J)
              = H0_m(QQ[[C]]/(K1,...,K7))

を得る。これが次の実四変数計算の正確な目標である。
ここでは K の高次係数・零性・有限 socle をまだ計算していない。
また D0→E4 の比較 kernel を消してはいないため、H0(D0) をこの H0 と同一視しない。
I_A I_B による比較 kernel の零化は別の既証明であり、T0 全体の零化ではない。
