# 一つの既存 genuine edge 値と normalized nil の fiber 像

SOURCE packet に固定した old generator4 の像を、五つの既存 scalar product だけで評価する。自然写像の全原点列の head0 成分は0なので像は genuine G3 の socle QQ Q1 に入る。必要な一つの r 微分 Jr は HEAD4_Z5_VALUES の保存値そのもので、新しい微分・source・gauge・jet は計算しない。

値が非零なら δ′|Told の像の k 次元は1、Told∩Nbar の長さは11-1=10である。実比較図式の可換性と ker(Tnil→NEbar)=Told によって Nbar→NEbar の実像は14-10=4次元となる。

I=image(N→NE)=N/K は既受理の D-free7、NE は D-free9。Nbar→Ibar は全射なので Ibar→NEbar の rank は4。L=coker(I→NE) は D generic rank2 で、Tor1^D(L,QQ) の次元は7-4=3、従って L の D-torsion の最小生成数は3である。その長さ・指数は決めない。

Q=Tnil/Told は NEbar の長さ5の部分加群である。一方、Lbar は同じ NEbar の長さ5の商加群であり、両者を同一視しない。全 S-module splitting や全 z 作用を0とする仮定も使わない。元 H0 の長さ・指数、元 nilcube の消滅を推論しない。

値が0ならこの一列だけの partial negative とし、rank0とは結論しない。
