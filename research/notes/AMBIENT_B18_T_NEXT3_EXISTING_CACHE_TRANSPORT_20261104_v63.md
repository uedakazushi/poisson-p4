# 既存キャッシュへの明示節点輸送

残った108個の C0 複合根を対象にする。元の凍結パケットは変更しない。元 actual-source DAG が C0 DAG の文字どおりの prefix であることを検算し、FULL_RELATIVE_INPUT の第15 inverse instance の **57個の明示的な original/copied 節点対** を使う。名前の似かよりによる対応付けはしない。

この instance は CB の自身の YB 九座標のうち `[7,8]` だけを保持する。保存 CB57 source2 逆写像と同じ57未知・同じ48式とYB九式である。全57式の複写を、保存 DAG 上の定数・加法・積・負号・単位逆元の規則だけで再構成し、保存された57式の節点番号と一致することを検算する。従って、その48個の group/source/trace/norm 変数の二次値は、保存された CB57 自身の YB 座標での二次逆写像に、実際の YB7/8 を代入して得られる。新しい陰函数解は不要である。

`CA_trace_p` は original node 11、元の Quadratic.S であり `p²=S*p+T` の trace 係数である。同じ node11 は105未知の保存値に含まれる。別の基底母数を推測して代入しない。

有限環は `B11=QQ[r,z0,z1,z4,z5]/(r³,zi*zj,zi*r²)`、基底順は `[1,r,r²,z0,z1,z4,z5,z0r,z1r,z4r,z5r]`。H20 の全8座標作用×20基底の160恒等式を照合し、保存105値の読み戻しがこの商で正当な環写像であることを確認する。実 YB7/8 は保存された105解の入力だけで元の有限式を評価する。コピー57変数を既存 source2 で合成し、その全57式も B11 で零と確認する。これは源 jet 求解や新しい函数値の追加ではない。

一方、正直な Hadamard 除算や g 除算の二次係数を H20 の任意の代表で置き換えない。それらは既存の定数・一次キャッシュだけを使い、二次を記号のまま残す。全108複合根の多項式・単位逆元をこの既知部分と記号的二次感度に分け、元の620三成分機能へ戻して集約する。既知部分を作るため二次記号を零にする操作は、実二次係数が零という仮定ではない。

この段階で未知除算係数が全て消えれば既存値で古い B/P 部分を確定できる。残れば、その正確な node/pair を次の源 gate として保存する。native128 の有効 S2 は別パケットであり、ここでは型付き項のまま保持する。T の全長・深さ・全 nil に関する推論は行わない。

実行は60秒、2GB、32MiB、展開 QQ 支持150000未満。源ラベル輸送を先に保存し、未知節点または上限に達した場合はその境界で停止する。
