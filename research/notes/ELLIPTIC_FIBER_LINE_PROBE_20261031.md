# 楕円五変数模型の計算可能性：厳密な一変数制限

2026-10-31。五変数模型の一般次数を計算したものではない。
T39/T40 の両方について、一つの明示的な直線制限の固定一次部分 fiber が
一つの被約点になることを有理関数の gcd で確認した。
同時に、多変数に進む前の式の保持方法を比較した。

## 1. 制限と結果

既存 `ELLIPTIC_SIX_VARIABLE_FIBER_20261031.md` の共変量を用いる。

    λ=2, p=(t,2,3,4), b(t)=b_k(2,(t,2,3,4),1), target β=b(1).

スカラーは五変数模型と同じ c(t)=h(β)/h(b(t)) で復元する。
以下の表は約分後の有理関数についての「分子次数,分母次数」である。
両族とも同じ次数になる。

| 不変量 | T39 | T40 |
|---|---:|---:|
| I4=tr(A²) | (5,5) | (5,5) |
| I14=T(Av,v,Av) | (12,15) | (12,15) |
| h=I14/I4³ | (12,15) | (12,15) |
| G8=vᵀJAv | (8,10) | (8,10) |

全30等式から必要条件として従う二式

    f4(t)=c(t)² I4(b(t))−I4(β),
    f8(t)=c(t)⁴ G8(b(t))−G8(β)

を約分し、それぞれの分子を n4,n8 とする。
両族とも分子次数は35,68であり、QQ[t] でのモニック gcd は厳密に t−1 である。
全係数を `reports/ELLIPTIC_FIBER_LINE_PROBE_20261031.json` に保存した。

## 2. 一つの被約点であることの範囲

共変 frame が可逆な開集合では、全30等式は同じ Sp4 軌道をスキームとして表す。
従って I4 の一致もその等式イデアルの局所化内で従う。G8 は signature の成分自体である。
このため二つの必要条件から、全等式イデアルは局所化後に (t−1) を含む。
一方 t=1,c=1 は元の target 自身であり、全30等式を満たす。
その点で frame の determinant、I4,I14、および二式の分母が非零であることも確認する。
従ってこの開直線上の固定一次部分 fiber は Spec QQ、すなわち一つの被約点である。

この直線は五変数空間の特別な一次元部分である。
その外の解、異なる λ、有限群による他の表示を数えた結果ではなく、
五変数模型の一般長さ N_k や成分の一般次数 d_k への上界・下界は与えない。

## 3. Pfaffian の分母との一致――この直線上のみ

元の affine bivector P の Pfaffian は、この直線上でそれぞれ

    T39: −(8t⁵−1585t³+1070t²−37960t+35200)/16,
    T40: (16t⁵+1180t³+7715t²+16980t+29700)/32.

I4,I14,G8 の約分後の分母は、非零定数倍を除き、それぞれこの Pfaffian の1,3,2乗である。
コードは比が非零定数であることを検証し、定数を報告書に保存する。
従って初期の有理 frame が持つ余分な pivot 分母は、これらの不変量では消えている。
全 λ,p に同じ分母表示が成立すると外挿していない。
これは今後低次数の分子を復元する際の具体的な候補である。

## 4. 算術の保持方法と残る障害

通常の SymPy Expr のまま I14 の大きな縮約を最後に一括 cancel する方法は、
中間の展開に時間を費やしたため中断した。
代わりに、24個の正規化済み一次係数を先に QQ(t) の元へ移し、
各加減乗除を約分済み有理関数として行うと、両族とも一件約3秒で
不変量、二式、gcd、非消失条件まで確認できた。
所要時間は証明の一部ではなく、使用環境の参考値である。

```sh
.venv/bin/python code/elliptic_fiber_line_probe.py \
  --output reports/new-run/elliptic-line.json
```

実装には一件60秒の上限を置き、出力は排他的に新規作成する。
この一変数計算が軽いことは、多変数分子の項数や Gröbner 消去の小ささを保証しない。
次の具体的な課題は、低次数不変量の多変数分母・分子を数学的に制御し、
五変数模型の有限生成と全解の長さを証明すること。
その後も、位数50より大きい全パラメータ表示重複 ρ_k の決定が別に必要である。
直線の解数を N_k または d_k と読み替えてこの障害を省かない。
