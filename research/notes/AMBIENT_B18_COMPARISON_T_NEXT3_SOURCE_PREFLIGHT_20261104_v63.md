# 実比較 T の残る三二次類：固定証明書からの源前処理

このパケットは、受理済みの一次階数37・既知二次階数177の証明書から、二次商への厳密な三双対と、一次関係が零になる620本の定数結合を抽出する。新しい源係数、jet、階数探索、Gröbner 計算は行わない。T の全長・深さは未決のままである。

五標的の順序は fullV source `[22,23,29,30,55]`、変数は `(zA0,...,zA6,rA)`、二次単項式は `combinations_with_replacement(range(8),2)` とする。177本の固定正規化列を消去すると残る座標は `[143,176,179]`。双対の実際の支持は保存 JSON に記録し、これら三つの代表単項式だけから推測しない。全177基底列・全464既知関係を双対が消すことと、三代表への値が単位行列であることを検算する。

一次証明書の657列から37本の正規化列を固定手順で消すと620個の零結合が得られる。84単位 wedge の既存消去、次に27単位源列の既存消去を逆追跡し、各結合を元の768源列まで保存する。各結合 c について `Xc(0)=0`、全56行の一次係数 `Xc_1=Xp_0 alpha_1` を、各変数で厳密に検算する。従って補正 `Z=Xc-Xp alpha_1` は二次から始まる。

## m の一次係数を必要としない射影公式

`Z_0=Z_1=0` より `(mZ)_2=m_0 Z_2` である。未知の二次 alpha の寄与 `Xp_0 alpha_2` は `m_0` と五標的射影 pi の双方で消える。ゆえに必要な二次入力は

`Z_2 = sum(c_j Xj_2) - sum(alpha_p,1 Xp_1)`

だけであり、比較 m の一次係数は不要である。ただし Euler lift は係数環上線形ではないので、この式を元の文字どおりの圧縮二次係数と無条件に同一視しない。両 lift の差の一次部は `ker(d2_linear)` に属する。七変数が正則列である Koszul `(zA0,...,zA6,0)` の H2 は零なので、その差は `im(d3_linear)` にある。その下位五成分への補正は既に保存した168本の d3 二次関係に属し、三双対では消える。従って成立するのは **三類への射影公式** である。

二次 cycle `a=m0 Z2` の Koszul lift は z 次数 k で分けて取る。i<j<7 には `(partial_i a_j-partial_j a_i)/(k+1)`、最後の成分には `partial_i a_7/k` (k>0) を用いる。r は z 次数零。実 cycle では純 r² の障害係数は零である。保存した随伴感度はこの線形演算を全二次入力へ拡張したものなので、実 cycle 上に制限して初めて射影公式として使う。支持は安全な上限であり、cycle 制約でさらに縮む可能性を否定しない。

## 次の実係数 gate

三残余双対の支持だけでは元 X2 の必要変数は決まらない。Koszul lift の微分が外の z_i を含む係数を参照し得るため、保存した `projected-source-X2-sensitivity.json` は随伴を実56源行の二次係数まで合成する。これも新しい X2 値を評価しない。

旧 B の scalar-atom DAG 二次係数、r/g の原始分子高次係数、native N の二次係数は未入力である。g 型 quotient の二次読戻しは最大五次分子を要求し得るが、原子への随伴感度を合成して消失を証明する前には、その高次入力を必要と断言しない。native N の単位基底変更も全列を同時に運ぶ共通行変換なら `Z0=Z1=0` により二次に定数部分しか寄与しない。ただし実源 operator 中の N2 を一律零にする理由にはならない。各残る依存は別の源 gate として保持する。
