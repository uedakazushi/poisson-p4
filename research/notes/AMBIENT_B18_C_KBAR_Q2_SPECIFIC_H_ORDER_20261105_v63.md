# q2 零積で使う H の literal ordinary-order 証明

ここでの H は HONEST_NIL_T_OPERATOR の `shared_homotopy_template_v1` であり、同じ S=QQ[[zA0,…,zA6,rA]] の三 sector `(zA7,r),(zA7,r),(zA7,r²)` に一回ずつ作用する。periodic な抽象 H や jet-query の保守的 loss を使っていない。

実 cycle v∈m^d では、z=0 の cycle 恒等式から v7(0,r)=0。ordered Hadamard による Hi は zi を一回だけ割るため m^(d−1)。wi=vi+r^nHi は n≥1 より m^d に残る。次の Koszul-Euler 式は zi 微分一回と正整数 dz+2 による除算だけなので、出力は m^(d−1) に入る。これは全 formal cycle に対する式である。

実 matrix m は既に regular Rbar entry を持ち、その係数の元 source jet を得るために必要な高次数と、入力 vector の ordinary order を混同しない。積 cycle の全 v=mc を有限 NF より前にこの template へ入れる。h84×780 を Rbar 線形に延長したものを任意の積に適用したり、H から係数を外へ出したりしない。
