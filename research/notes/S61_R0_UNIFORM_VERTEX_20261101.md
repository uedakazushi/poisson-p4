# R0 頂点模型の全 k にわたる根基と例外ファイバー

2026-11-01。コード `code/s61_r0_uniform_vertex_20261101.py`、証明書
`reports/S61_R0_UNIFORM_VERTEX_20261101.json`。

前ノートの一般関数体計算を、K=L=0 の模型について QQ[k,h0,…,h8] 上の
**特殊化前の計算**に強化する。さらに (3k−1)(3k+4)≠0 なら、任意の K,L を
除けることを実際の symplectic 座標変換で証明する。
一般 S61 や全無限遠の成分数に関する主張ではない。

## 1. 相対根基の29生成元

一般頂点模型で禁止された29組 (i,j) に対して、原則 p_ij(k)=1 とする。
次の表の組についてだけ p_ij(k)=k−a と置く。

| a | (i,j) |
|---|---|
| −1/2 | (0,6), (1,7) |
| 1/3 | (0,3), (0,7), (2,6), (3,7) |
| −4/3 | (1,3), (1,6), (3,6), (4,7) |
| 2 | (0,4), (2,7), (3,8) |
| −3 | (1,2), (3,5), (4,6) |
| 11/3 | (2,8) |
| −14/3 | (4,5) |
| 7/6 | (0,8) |
| −13/6 | (1,5) |

この模型の65式が生成するイデアルを I とすると、

    √I = J = (p_ij(k) hi hj : 上記29組)

が QQ[k,h] 上で成立する。

証明は次の二方向からなる。各 I の生成式の hi hj 係数が p_ij(k) で
割り切れることを検算し、I⊂J を得る。次に、65式から QQ 上で計算した
125要素の grevlex Gröbner 基底を使い、各 p_ij hi hj の5乗以下が I に
入ることを示す。冪と全表示係数を保存し、恒等式を再検算する。
有限個の k の値における点検からの補間ではない。

J が根基であることは、次節の座標素イデアルの共通部分として直接証明する。
h の各単項式の台 S ごとに、その係数イデアルは S 内の禁止組についての
p_ij の gcd である。一方、素イデアルの共通部分から得る係数は、S が
許される特殊ファイバーの k−a の積である。512個の平方自由な台全てで
この一致を検証する。h の生成元が平方自由なので、この有限検証で任意の
単項式にも一致する。よって I⊂J⊂√I と J=√J から結論を得る。

## 2. 特殊ファイバーの追加座標面

一般ファイバーの最大座標面は

    {0,2,5}, {1,4,8}, {0,1}, {3}, {6}, {7}

である。添字集合 F は、F 以外の hi を零とするアフィン座標空間を表す。
各特殊値で次の座標面を加えると、そのファイバーの被約台を正確に得る。
既存の面が新しい面に含まれるときは、既存の面は既約成分でなくなる。

| k | 追加される最大面 |
|---|---|
| −1/2 | {0,6}, {1,7} |
| 1/3 | {2,6}, {0,3,7} |
| −4/3 | {4,7}, {1,3,6} |
| 2 | {2,7}, {3,8}, {0,1,4} |
| −3 | {3,5}, {4,6}, {0,1,2} |
| 11/3 | {2,8} |
| −14/3 | {4,5} |
| 7/6 | {0,1,8} |
| −13/6 | {0,1,5} |

従って相対被約スキームは、一般 k まで動く六つの座標成分と、k を特定値に
固定した16個の座標成分の和である。ここでの22個という数は、この固定因子・
特定正常形模型の相対素イデアル数であり、S61 や Q45 の大域成分数ではない。

## 3. 非共鳴の場合の一様な座標変換

K=5k2+k3、L=5k1−k4、A=−K/(3k−1)、B=−L/(3k+4) とし、

    T = [1 0 0 0; 0 1 A −B; B 0 1 0; A 0 0 1]

と置く。TᵀJT=J を恒等的に検算する。これは

    (x,y,z,w) ↦ (x, y+A z−B w, z+B x, w+A x)

という変換で、v=∂y を固定する。

β を T の逆で引き戻すと、正規化された五条件

    u4=u12=u5=u13=0, u14=k, u49=2k+1

を保ち、K′=L′=0 となる。証明書は全16個の新しい primitive β 座標を
記号式として保存する。六つの制限式に現れない β 係数も自由に保つ。
制限式が K,L だけに依存することは前ノートで恒等的に確認しているため、
計算では k1=k2=0,u50=K,u51=−L という代表を選んでよい。

Q=∂y∧X_G の引き戻しは ∂y∧X_(G∘T) である。G は y に依存せず、
Hamilton ベクトル場の ∂y 成分は外積で消えるので、これはまさに
Z=z+B x,W=w+A x という前ノートの係数変換になる。
全135先頭イデアルの Sp4 不変性は既存の G6 査読ノートで証明されている。
従って、この節は関数体上の一般行空間一致だけでなく、
(3k−1)(3k+4)≠0 の**全ての k,K,L** に対するイデアルの同型を与える。

## 4. 残る範囲

k=1/3 または −4/3 では座標変換が使えない。この場合、K=L=0 の模型は
上表で完全に扱ったが、非零の共鳴パラメータを持つ模型は別途扱う必要がある。
また誘導二次形式が退化する頂点も別の正常形に属する。

これらの特殊層を一般 β に対して排除または分類するには、普遍 incidence の
次元と評価写像を確認する必要がある。相対模型の表だけから、全 R0 や
アフィン S61 の一般ファイバーを尽くしたと結論しない。

    .venv/bin/python code/s61_r0_uniform_vertex_20261101.py --output work/r0-uniform.json

約3秒。全125 GB 要素、29個の冪の帰属証明、512個の台の交叉検証と
symplectic 座標変換を再計算する。
