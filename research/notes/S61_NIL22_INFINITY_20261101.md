# モジュラー Jordan 型 (2,2) の一般一次データからの排除

2026-11-01。コード `code/s61_nil22_infinity_20261101.py`、証明書
`reports/S61_NIL22_INFINITY_20261101.json`。

十分一般の β∈W16 に対して、非零モジュラー場の Jordan 型が (2,2) の Q は
元の134先頭式を満たさない。ここで一般 β という条件は不可欠である。
`S61_MODULAR_INFINITY_COUNTEREXAMPLE_20261101` は Δ≠0 でもこの型の
無限遠点が存在することを示している。本結果は、例外的な β 像の次元を15以下と
評価するものであり、全 Δ≠0 上の排除ではない。

## 1. 使用する固定トレース分類と次元

依存する既存結果は v06 の固定トレース s=xz の17枝の被約な尽くし
（`legacy/v06/code/certify_nilpotent22.py` と同証明書）である。
二つの開チャート A≠0、B≠0 と、A=B=0 の15本の既約曲線×A³ が全点を覆う。
三つの自由座標 p=(p3,p4,p5) は Qyw に p3 x²+p4 xz+p5 z² を加える。
中心化群の成分群による交換を用いると、開型一つと閉型十個を調べればよい。
本コードは中心化群の交換を全11係数の正常形について再検算する。

非零 rank2 平方零モジュラー行列の Sp4 軌道は六次元である。
固定トレースファイバーは四次元なので、全 (2,2) 型 Q の次元は高々10、
射影化した次元は高々9となる。モジュラー行列の共役軌道次元6も厳密な階数で
再検算する。

各枝の Sp4 飽和は Q の非零スカラー倍で保たれる。実際、Q を c 倍した後、
diag(r,r⁻¹,r,r⁻¹) の引き戻しで r²=c⁻¹ とすれば、トレース xz を戻せる。
閉枝ではコア係数が保たれ、p は c⁻¹p へ移る。開枝も開条件を保つ。
従って後で使う錐の次元から射影次元への1の減少は正当である。

## 2. 開二枝の全パラメータ

v06 の A≠0 チャートは (A,b,v,d) の四つを自由座標とする。symplectic
変換 y↦y+r x、w↦w+h z による Q の引き戻しは

    b↦b+4Ar, d↦d+Ah, A↦A, v↦v.

この全係数恒等式を記号的に検証する。従って A≠0 なら b=d=0 にできる。
diag(ρ,ρ⁻¹,ρ⁻¹,ρ) の引き戻しは

    A↦Aρ², b↦bρ⁴, v↦vρ², d↦d

なので、ρ²=A⁻¹ と取れば A=1、自由パラメータは ν=v/A の一つになる。
正常形の成分は

    Qxy=−νx²−xw+xz, Qxz=−x², Qxw=0,
    Qyz=z²−4νxz+3xy−3zw,
    Qyw=ν²x²−2νxz+z²/2+xy−2zw+2νxw+w²,
    Qzw=νx²+xw.

その β 係数行列には、ν に依存しない12次小行列式 2116013625/512 がある。
従って開型の全点で rank B(Q)≥12。もう一つの開枝は検証済みの中心化群交換で
同じ結論を得る。開型の特別な ν を捨てていない。

## 3. 閉枝の非零コア係数の正常化

閉枝の共通正常形で、コア係数を (a,b,u,v,c,d) とすると、同じ対角トーラスは

    (a,b,u,v,c,d,p3,p4,p5)
     ↦(aρ⁻⁴,bρ⁴,uρ⁻²,vρ²,c,d,p3ρ²,p4,p5ρ⁻²)

を与える。全 Q 係数について恒等式を確認する。
v06 の曲線表示から、C±、D±、U、V の非零パラメータは ρ² により、
A、B、AB の非零パラメータは ρ⁴ により、任意の固定された非零値へ移せる。
必要な平方根・四乗根は複素数体で存在し、p は依然任意に保たれる。

パラメータが零の A¹ 枝の端点は L0 または L1 の点であり、次節で残す。
C、D、AB は Gm 型である。交換される枝をまとめた代表について、三つの p を
記号変数のまま保存した小行列式により次の一様な下界を得る。

| 閉コア | 全 p における rank B(Q) の下界 |
|---|---:|
| Cplus | 10 |
| Cminus | 11 |
| Dplus と Dminus | 12 |
| U0 と V1 | 9 |
| U1 と V0 | 10 |
| A0 と B0 | 12 |
| A1 と B1 | 12 |
| AB | 10 |

各小行列式は p に依存しない非零定数である。Dplus だけは QQ(√3) 上で
計算する。U0 も p=(1,2,3) では階数10であることを別の小行列式で確認する。
従って U0 飽和内の rank≤9 locus は真の閉部分集合となる。

## 4. 閉二直線 L0、L1 の特別な値を全て保持する

ここでの L0、L1 は nil22 の閉曲線の名称であり、零モジュラー成分 L0 と
混同しない。共通正常形で a=b=u=v=0 とし、

    L0: c=d,  L1: c=d−1

と置く。d と三つの p を全て記号変数として、β 行列の12次小行列式を四つずつ
保存する。いずれも p に依存しない。その gcd の零点を全部調べると、例外候補は
有理数だけであり、各候補 d について再び p に依存しない小行列式が得られる。
従って結論は全ての p と全ての d に対するものである。

* nil22-L0 は d=0,1 で rank B(Q)≥9、それ以外では rank B(Q)≥10。
* nil22-L1 は全ての d で rank B(Q)≥10。

一般 d ではどちらも階数12である。保存した gcd に含まれる一部の根は、単に
選んだ小行列式の都合による候補にすぎず、再計算では階数12のままである。
根を除外するのではなく、全候補に対する小行列式を証明書に保存している。

## 5. rank9 locus の次元と β 像の上界

以上の有限場合分けにより、全非零 (2,2) 型で rank B(Q)≥9。
rank9 が残り得る部分は、次の二種類に限られる。

* U0/V1 の飽和内の真の閉部分集合：飽和は既約で次元≤10、階数10の点を
  含むので、この部分のアフィン次元は≤9、射影次元は≤8。
* nil22-L0 の d=0,1：固定トレースで残るのは p の三次元だけなので、
  モジュラー軌道六次元を加えてもアフィン次元≤9、射影次元≤8。

それ以外の部分では rank B(Q)≥10、射影 Q 次元≤9。従ってどちらの場合も
許される β を加えた incidence の次元は

    9+(16−10)=15, または 8+(16−9)=15

以下である。この像の閉包を避ける一般 β には、非零 (2,2) 型の無限遠点はない。
階数が落ちる locus の次元を無視した一般点計算ではない。
