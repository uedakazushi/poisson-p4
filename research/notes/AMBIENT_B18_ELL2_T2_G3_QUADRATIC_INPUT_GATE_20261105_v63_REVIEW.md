# 全一次 kernel に対する G3 二次 transport の独立監査

二番目の source 基底は `[E56,D3sel126,Efree42−E56K]` である。最後42列に最初56列の倍を加えても、逆行列の最後42行 P は変わらない。よって P は `[E56,D3sel126,Efree42]` の逆行列の最後42行に等しく、第一 source 基底の微分を零と仮定する必要はない。

第三 source の unit 消去は選択 D3 列の倍を引く操作なので、P がそれらを消すことから、実 reduced G3 は厳密に `P D3 I3(0)` と表せる。固定 I3(0) は D30 により零となり、元の periodic/Koszul D3 は定数と一次部分しか持たない。したがって実 G3 は `P D31 I3(0)` そのものである。逆行列の微分式から、二次部分は `−Pi42 D31sel A126(D31 I3(0)c)` となる。

全 G3 一次写像の kernel176本に対して、D31 I3(0)c の六変数各係数が固定182列の span に入ることを、元の固定 receipts のみで独立再生した。選択126係数、Pi42 D31sel、最終 PiY と既知 L48/ell² による840個の二次単項式 normal form を全て別の Fraction 算術で照合した。合成可能な各項の normal form はそれぞれ零であり、符号付き値を新規評価する必要はない。

最初27消去に対して G3 の bottom は全次数零である。最後99消去に対しては **全** G3 一次 kernel 条件により unit 射影の一次微分項が零となる。過去の投影後393 kernel はこの議論に使用しない。以上から176本の実二次関係は既知 L48/ell² に属すると受理する。

これは当該 family の否定的結果である。実HF2、実全長、H0指数、全二次初期関係の完全性は結論しない。元 source の新しい係数、陰関数、physical jet は求めていない。
