# 深部二平面型の全 core における一般一次部分上の除去

2026-11-02。水平・垂直 SUPPORT の最終証明書への依存を固定した結果。
係数計算の追加ではなく、有限行加群の支持と既証明の相対幾何を接続する論証である。

## 1. 対象と主張

標準無限遠点を Q0=xw∂y∧∂z とし、

    (a,b,c,d,e,f)=(u4,u14,u35,u36,u49,u50),
    K=5c+f,  Q*=600b²−255be−63e²+100af

とする。対象は u12=u13=K=Q*=0 の深部二平面型層である。
十分一般の一次部分 β 上では、この層に属する全点が全135式の t-飽和で除かれる。
その軌道閉包の全ての他の型、旗、全アフィン S61 の尽くしを含む主張ではない。

既存の DEEPER_REDUCTION、BOUNDARY_REMOVAL、PIVOT_DIVISORS、SEVEN_SLICE により、
一般 β 上の未処理点は七変数切断 H=A²_(e,d)×A5_(p,q,r,h,k) へ正規化できる。
その式は SEVEN_SLICE §2 に固定されている。既知十三因子の積を D とする。
これら十三曲線は CORE_ARTIFACTS とその先行結果で一般 β 上の全点が除去済みである。
以下では D≠0 の切断だけを扱う。

## 2. 重み四次の支持に曲線はない

nuisance を零にした正確な重み有限模型の390×269行列を A(e,d) とする。
U=Spec QQ[e,d,D⁻¹] とし、その最大 minor ideal の被約零点を Z⊂U とする。
HORIZONTAL_SUPPORT は A が QQ(e)[d,D⁻¹] 上で全射であることを示す。
したがって有限表示加群 coker A^t は非零の e 多項式を逆にすれば零となる。
Z の曲線成分があれば、それは e=α という縦直線の開部分である。

VERTICAL_SUPPORT は d=3 の断面で coker の支持が

    (24e−7)(10e−1)(2e−1)(15e+8)(270e²+321e−388)=0

に含まれることを、QQ 上の完全因子次数と有限 DVR 加群の CRT から示す。
最初の四つの縦直線は D=0 に含まれるので U にはない。
残る二次因子 f3 は QQ 上既約である。仮にそのいずれかの幾何的縦直線が Z に含まれれば、
QQ 定義性と共役作用により f3 が d=4 の全最大 minor を割る。
原係数は32003で整であり、f3 の先頭係数も単元なので、この完全整除は有限体へ還元する。
しかし d=4 の元行 span に属する269行の determinant は四つの既知一次因子と
別の二次因子 f4 だけを持ち、f3 とそれらは互いに素である。
従ってその整除は不可能である。

よって Z に曲線成分はなく、有限型の零次元閉部分として有限集合である。
その点の座標・長さ・被約性は計算していない。特に「U の全点で行列が全射」とは主張しない。

## 3. 未処理集合を有限個の十六次元層へ減らす

旧 QUARTIC_NUISANCE と CORE_OPEN_FORMAL は、ある非空 core 開 U0⊂U 上で、
全 nuisance 値の全一般 β 点を除く。従って残る点は (U∖U0)×A5 の Sp4 像に含まれる。
U∖U0 は有限個の既約曲線と孤立点の和である。特異点と成分の交点も孤立点へ移し、
各曲線の滑らかな開だけを考えてよい。

重み二次・三次の階数は DF≠0 上で7・64である。ここで F は別証明書
SEVENTEEN_CURVES に定義された十七因子の積であり、その曲線上の全一般 β 点は既に除去済みである。
したがって、残る幾何的既約曲線 C は DF=0 に含まれないとしてよい。
§2から C は Z にも含まれない。C の一般点の nuisance=0 で重み四次は全射であり、
WEIGHTED_FINITE_MODEL によって実際の横断商は長さ65となる。

この横断長さ上界は C×A5 の非空開へ延びる。根拠は実際の多項式の implicit 解と
有限個の係数 minor の非零性であり、切断ν=0から全νの同一点上界を主張するものではない。

## 4. 同じ実在三次元部分の下界

H_C=C×A5、B=Sp4×H_C と置く。B は滑らかな既約十六次元 source である。
β:B→W16 が非優越なら、その像閉包は次元15以下なので一般 β には出現しない。
以下は優越する場合であり、標数零から B→W16 は非空開上で étale となる。

ここで base を H_C に制限しただけで旧 C_rel の既約性が自動的に保たれるとは仮定しない。
先に B を底に取る。十分一般の β について、実在する nonsquare binary 三次元族は、
滑らかな標準楕円曲線 Cβ⊂LG(2,4) 上の二元二次形式の P² 束の開である。
従って幾何的に既約である。これは PRIMITIVE_JET_ELLIPTIC_CURVE と実在 binary 族の構成による。
B が W16 を優越するため、その pullback の一般 fiber もこの同じ幾何的既約三次元族である。

D≠0 では Q0-section を通る実在三次元族は B 上相対的に滑らかである。
CORE_OPEN_FORMAL の元式からの検査によれば、三つの切断座標への射影 minor は
2(24e−7)/125 であり、これは D 開で可逆である。
よって section を含む相対 smooth 成分は B を優越し、上の一意の一般 fiber へつながる。
通常 binary の65下界開はこの同じ成分上で稠密であり、各 section の形式的一般点にも適用できる。
この下界は普遍三次証明の通常法線 Hilbert 下界 (1,7,23,34) である。

## 5. 非空 ambient 除去開と全一般 β 点

§3の横断上界開と B→W16 の étale 開を交差させる。
そこで実在三次元族の完成局所環 R は正則な十九変数環であり、全相対135式の完成環 S には
R→S→R という分裂がある。横断上界から R^65→S が全射となる。
§4の同じ成分の一般長さ下界65が全 rank を使い切るため、この写像の核は rank 零である。
自由 R 加群の部分加群にはそのような非零核はないので S は R 上自由65となる。

I=ker(S→R) とすると、一般点で I⁴=It=t²=0 である。
S の R-torsion-freeness によりこの三恒等式は S 全体へ降りる。
全135同次数斉次化の Sp4 同変性と B→W16 の étale 性から、この相対 scheme は
ambient scheme の忠実平坦 base change である。完備化も忠実平坦なので ambient でも t²=0 となる。

ambient の t-飽和支持の補集合は開である。上の構成は source 像閉包 Z_C とこの除去開が
非空に交わることを示す。βを優越する場合 dim Z_C=16 だから、除去開の補集合は15次元以下。
十分一般の β はその像を避け、C の全 nuisance 値の点が除かれる。
曲線が QQ 上の既約因子から幾何的に分裂する場合も、各幾何成分に上の同じ論証を適用できる。
除去開自体は QQ 定義であり、共役作用で不変でもある。

残る core の有限個の孤立点の Sp4×A5 像は次元高々15で、一般 β には現れない。
有限個の曲線・点について得た W16 の開を交差し、§1の深部層の全一般 β 除去を得る。

## 制限

全 core の各特殊点の完成局所環、特殊 β の t 冪零性、Z の明示的列挙は結論しない。
他の binary 層、旗、全 S61 アフィン fiber の尽くしは別課題である。
横断ν=0の階数被覆だけから ambient を除く飛躍はせず、旧全ν共通開・有限曲線・
相対自由性・étale 降下・次元15という順序を用いている。
