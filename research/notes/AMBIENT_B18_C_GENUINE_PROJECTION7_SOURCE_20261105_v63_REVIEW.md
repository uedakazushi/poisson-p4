# 真正接続写像用 q7 の独立 SOURCE 検証

独立検証は PASS した。既存の実加群 C の商 C/m⁴C から
T7=C4/F16 への D=QQ[[ell]] 線形射影を、三 target と九変数の
次数三以下の660列について再構成した。非零列は25列である。
係数は既存 C2 cache 葉の affine operator のまま保持し、新しい応答や
接続写像の値は評価していない。

原資料は `AMBIENT_B18_C_GENUINE_PROJECTION7_SOURCE_20261105_v63`、
原報告の SHA256 は
`de02c3e5fc8b542298127b208099e9513a91def5ade9e5f3db79359416b01341`。
独立報告は同名の `_REVIEW/report.json` である。

独立コードは producer を import せず、Fraction と疎な記号係数を用いた。
RA, RB, RH による局所的な実関係の書換えを再帰的に行う。
RB の全二次平面項と三次平面項を使って z_i B を消去し、その規則を
RH の混合二次項に適用する。このため RH の有効三次 B 係数は
delta_i3−delta_i2,mixed beta2 となり、負の carry を省かない。
得られた全660列が保存済み射影と一致した。

実 source 正規化の根拠は、全次数の ordered-prefix 恒等式
z_B=A z+b と det A(0)=−1/1024 である。最初の七生成元を
A⁻¹z_B に替えることは実 ideal の可逆な生成元変換であり、
beta2=A0⁻¹b2、beta3=A0⁻¹(b3−A1 A0⁻¹b2) を与える。
beta2 が平面にあることを確認した。beta3 の z を含む項は未知値を
零としたのではなく、三次 z 項が実 m⁴C に入るため射影で消える。

第一フレームから z_i target は m²C に入る。RH と既知の平面二次零を
使うと z_i H は m³C に入り、さらに P0,P1,P2 から平面三次 H は
m⁴C に入る。二つの z を含む B 項も RB から m⁴C に入る。
したがって省略された項の像は次数と実 source 関係により零である。
P3_B の負の beta carry は既存の独立検証済み演算子と係数ごとに一致した。

26正規化 source の許される全1187倍、全660個の
q(ell x)=E7 q(x)、実21基底の像も確認した。
正当性は単に26関係の像が零という条件だけには依存しない。
上記の局所規則は各660列を、実 C/m⁴C の既知21基底へ書き換える。
実 HF=(3,6,6,6) とその基底の既存証明を合わせることで、抽象的な上界模型ではなく
既存の実射影そのものと分かる。

F=<A,B,rA,rB>_D は原始的 D 自由因子だが R0 部分加群ではない。
従って q は D 線形としてのみ扱う。真正 eta∈C[ell] に対して初めて
q(eta)∈ker E7 となり、自由行1,2,5,6と既存 Jordan 基底変換を使える。
任意の有限商ベクトルに同じ行 selector を適用して真正 torsion と呼ぶことはできない。

五 head の接続写像では、FULL_R0 の分子を形成し ell=0 で零であることを示してから、
形式環で ell を割り、その後に有限射影 q を適用する必要がある。
分子の最高必要単項式 A/B の r³ell と r²ell²、および
V4 sigma0、V3 sigma1、V2 sigma2、V1 sigma3 は未計算のままである。
この検証から元 H0、K torsion、nil 三乗について新しい値の結論は得ない。

原 V1 の一フィールド名訂正も旧 snapshot と比較した。
