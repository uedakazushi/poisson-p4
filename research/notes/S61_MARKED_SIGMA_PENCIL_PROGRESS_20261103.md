# 指定平方の試験直線：有限性判定の例外と厳密な中央支持

2026年11月3日（Asia/Tokyo）。既存の全有限 h 模型
[S61_MARKED_SIGMA_PENCIL_MODEL](S61_MARKED_SIGMA_PENCIL_MODEL_20261102.md)を用いる。
対象は a=1,c=2 の零 nuisance 中央環 S であり、ρ=u5 を保持した
14変数の全135残余式の環である。既存の原資料・モデル・証明書は変更していない。

今回、次の二つの**標数零の中央支持**を厳密に求めた。一方、試験直線の全点での
**周囲** t 冪零性や、指定平方全層の一般 β 上での除去は証明していない。

## 1. 変数と出力の来歴

凍結した Smith 模型の変数を

    (v0,…,v6 ; v7,…,v10 ; v11,v12 ; ρ)
    重み (1^7 ; 2^4 ; 3^2 ; 1)

と書く。元の第136出力行は t の表示であり、追加方程式としては使わない。
今回の6変数の環は

    H = S/(ρ,v0,…,v6),
    (x0,x1,x2,x3,x4,x5)=(v7,v8,v9,v10,v11,v12)

である。この制限で t=x4 となることを、元の第136行から検査した。
H は S の閉部分スキームを定める商である。H の支持を尽くしても S の支持全体は
尽くさず、H での t²=0 を S または周囲の局所環へ移すことはできない。

引継ぎの `marked_sigma_pencil_wip.tar.gz` にある `global-rows` の SHA256 を、
凍結済みモデル報告の `row_output_sha256` と照合した。全係数はその厳密な有理係数から
読む。旧 generic GB と QQ(h) 大行列の停止試行は同条件で繰り返していない。

## 2. 新しい二次因子の標数零での実支持

K=QQ[h]/(1000h²+1127) の商体上の H の定義イデアル I_H について

    sqrt(I_H) =
      (x0−(100/161)h x3, x1+x3, x2−(10/7)h x3, x4, x5).

従って被約支持は重み2の一本の軸であり、次元は1である。正確な Hilbert 級数は

    (1+3T²+2T³−2T⁴−2T⁵−T⁶)/(1−T²).

また I_H 自体を法として t=x4、t²=0 である。これは**標数零での実際の中央計算**であり、
有限体の因子 h²+9314 を数値的に持ち上げた推測ではない。

証明書ではまず全140行23列の重み6行列から一つの23次小行列式を QQ[h] 上で計算した。
その次数は26で、定数を除いた因数分解は

    (1000h²+1127)(1000h²+5313)(h²+2)²
    ·(329h⁴+474h²+64)(5000h⁴+104305h²+138138)
    ·(8h¹⁰−230h⁸+2577h⁶−21767h⁴+115550h²−7200).

これは一つの非零小行列式であり、全最大小行列式の gcd とは主張しない。
続いて上記の二次数体上で**全135式由来の H**を計算し、表示した素イデアル J に対し
I_H⊂J と、J の各生成元のある冪（8以下）が I_H に入ることを検査した。
J は明示的な多項式直線のイデアルなので、この二包含が根基等式を証明する。
Macaulay2 の `radical` がこの数体表現に対応するという仮定は不要である。

## 3. h²+2=0 の二次因子での中央平面

K=QQ[h]/(h²+2) の商体上では

    sqrt(I_H)=(x0,x1,x2−h x3,x4).

従って被約支持は重み(2,3)の二変数平面で、次元は2である。Hilbert 級数は

    (1+3T²+T³−3T⁴−4T⁵−T⁶+3T⁷+T⁸)/((1−T³)(1−T²)).

ここでも t=x4、t²=0 を I_H を法として厳密に確認した。同じ二包含による根基証明を使う。
標数32003でも同じ支持式・Hilbert 級数を再確認した。h²+2 はこの有限体上では分解するので、
この場合は根 h=3083 と h=28920 を別々の実際の有限体として検査する。分解する二次式の商を
`toField` で体と宣言して使わない。新しい二次式の有限体版は既約な二次拡大体である。

これらの正次元の中央支持の存在から、ρ=0 商が全 h で有限であるという単純な判定経路は
使えない。特に h²+2=0 は、以前の重み5行加群の不全射性が単なる未知の pivot 因子では
済まないことを示す。ただし t が支持上で零なので、これはアフィン枝の存在証明ではない。

## 4. F32003[h] 上の有限行加群

ρ と七lightを零にした H の行と単項式倍から作った行加群を計算した。
多項式の行減算と非零の体定数の逆だけを用いる weak Popov 計算であり、h の因子は
逆にしていない。以下はその行加群の行列式因子である。

|重み|行数×列数|行列式次数|定数を除いた因子|
|---|---:|---:|---|
|6|140×23|6|(h²+2)²(h²+9314)|
|8|426×47|6|(h²+2)²(h²+9314)|
|9|570×44|4|(h²+2)²|
|10|1088×86|6|(h²+2)²(h²+9314)|

9314≡1127/1000 mod32003 である。h²+9314 は F32003 上で既約であり、
有理点だけの標本ではこの例外を検出できない。これらの結果は上記 QQ の支持計算と
整合するが、有限体行列式だけで QQ の全例外を同定したとは主張しない。

また Z=S/(ρ) の重み5を再計算し、2022×932行加群の行列式は定数を除き h²+2、
次数2であることを再現した。旧出力とは行列の列順・行順が異なるが、因子と次数が一致した。

## 5. S の重み5の上界と、その実際の跳び

S5 の元の関係行列は2599×1432である。h=0 の有限体行簡約で残る四列

    0,204,354,586（零始まり、指数順は再現コードに固定）

の単項式を四本加えた2603×1432行加群は全階数となった。重み5の行列式次数は22、
因子は定数を除いて

    (h²+9314)(h²+2)²(h²−16)²(h²−15105)²(h²−12033)⁴.

この主張は F32003[h] 上である。元の2599行だけについても次の厳密な有限体階数を
別プログラムで計算した。追加した四行の選択による不全射と区別するためである。

|h|元関係行列の階数|dim S5|
|---|---:|---:|
|0|1428|4|
|4499,27504|1427|5|
|15938,16065|1427|5|
|4,31999|1426|6|

h=±4 の6は既存の三枝4+1+1と整合する。他の四点も重み5では実際の次元跳びであり、
四単項式の選択の人工例外と断言できない。ただし有限重みでの次元跳びから、
QQ 上の例外因子、最終的な k[ρ] 階数、無限長、周囲の残存枝は推論しない。

## 6. 残る数学的な橋と次の実行

第一の障害は、§2の中央軸および§3の中央平面の非零点を元の (β,[q]) 座標へ戻し、
同じ実入射族を識別することである。現在の証明書は重み付き Smith 法線座標である。
周囲冪零性を得るには、元135式の全周囲において同じ軌道・一次核の滑らかな入射を作り、
既知の一般重複度下界と新しい横断長上界を照合する必要がある。
固定中央の t²=0、あるいは商の支持式だけでは足りない。

具体的には `new-QQ.log` の x3=1 の軸点、および `old-QQ.log` の
(x3,x5)=(1,0),(0,1),(1,s) を凍結模型の陰関数多項式へ後代入する。
第136行の t=0 と全135式を元座標で確認し、q 軌道次元・全一次核・一般 β 優越性を求める。
平面側は重み(2,3)の射影直線全体を覆う必要があり、二つの端点だけの検査で済ませない。

第二の障害は§5の重み5次元跳びである。まず零 nuisance の ρ=1 ファイバーを新しく
縮約して調べ、有限埋込 torsion と一般階数の変化を区別する。汎用 QQ(h) GB を同条件で
再起動するのでなく、既に得た低次因子と小さい閉部分を使う。
