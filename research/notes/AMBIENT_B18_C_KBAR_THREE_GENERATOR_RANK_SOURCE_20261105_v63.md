# 元 K の三生成上界と Kbar の r 階数

honest 七基底を `(v,q1,q2,g,w,U,S)` とする。ITold の四基底では `rv=q1,rq2=g,rq1=rg=0`。G38 と旧 m³Told=QQg から `rw=−c q1+H g` であり、H は未取得の真の係数として残す。

M7 の正確な関係から `rU=w+A v+Bq1+Cq2+Dg`、`rS=lambdaS v+Eq1+Fq2+Gg`。ここで B,…,H を全て独立記号に保つ。取得済み initial reduction により `lambdaS=−6957653957/295294329` は非零、A=lambdaU+c である。従って r作用の全七列は rv,rq2,rU,rS の span に入り、行(q1,g,w,v)の minor は lambdaS。よって **rank(r:Kbar→Kbar)=4** である。

三候補 U,S,q2 とその r倍を並べた `(U,S,q2,rU,rS,rq2,r²S)` の七行列は、未知の深い係数すべてに無関係に行列式 lambdaS² を持つ。従ってこの七列はQQ基底で、Kbar は U,S,q2 の三元で QQ[[r]] 上生成される。原 K の有限性と ell-Nakayama により **2≤μ_R0 K≤3**。下界二は U,S の独立な constant-head 像から従う。三つの full R0 K lift は存在するが、その展開係数や最小性は求めない。

独立に受理済みの r³Kbar=0 と射影 r²階数一を合わせると、r-Jordan partition は **(3,3,1) 又は (3,2,2)** の二つに限られる。残る判定は `lambdaU F−lambdaS(H+C)` の一つの真の未取得係数である。ここではその値を評価せず、元 m³の補正を消去しない。

この r は切断変数で、DVR の ell と区別する。元 H0 の長さ・ell torsion 指数、nil 三乗・正確な nil 指数の結論はない。以前の四生成上界の packet は履歴として保持する。
