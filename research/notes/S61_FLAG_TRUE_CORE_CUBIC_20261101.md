## 2. 原式からの再構成と二次補正

`parametric_implicit_jets_20261101.cpp` に原135式と多項式 frame を渡し、

## 3. 二次一次倍の全域基底

Q の有理関数体上 rref に含まれる13本の定数二次式 C を取る。
既存の二次恒等式と多項式 Q の単位小行列式により、C は全七変数で Q の張る空間に入る。
C の一次倍130行の階数は100である。定数 rref を RC、pivot を PC とする。
全15本の Q の一次倍150行から RC の成分を引き、120個の自由列に射影する。
零でない54行のうち、パラメータ全零で選んだ14行・14列の小行列式が、
七変数多項式として非零定数であることを厳密に検査した。

この14行を小行列式の逆で正規化した RE は全係数が多項式である。
全54行がその pivot 成分によって RE の一次結合に一致することを検査する。
従って二次一次倍の階数は全域で100+14=114、三次商の次元は220−114=106である。
従来の辞書式 rref の b8 分母や、b8=0 で現れる線形因子はこの基底には存在しない。

## 4. 真正三次と観測量

H3 の全135行を RC,RE で106次元商に射影する。
パラメータ全零で独立行・列を選び、その5次小行列式を七変数体上で計算すると、
やはり非零有理数である。逆行列で正規化した5行 RR は多項式であり、
全135行が pivot 成分を係数として RR の一次結合に一致する。

同じ射影を T3corr に施すと、同じ5行の張る空間に入ることも厳密に一致する。
