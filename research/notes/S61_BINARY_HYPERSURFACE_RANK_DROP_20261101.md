# 十八次元の二平面型階数降下族と自由階数65の局所開部分

2026年11月1日。全135式の共通二次斉次化を扱う。
二平面型 Q=xw∂y∧∂z の許される一次部分は H={u12=u13=0} である。
その中の十三次元超平面

    H_+={u12=u13=0, 5u35+u50=0}

の Sp4 飽和像の閉包 Γ_+ は既約十八次元で W16 を優越する。
その一般 β ファイバーは二次元であり、一般点で最高/全 Jacobian 階数は33/34へ下がる。
以前の十七次元族 {u35=u50=0} はこの族のさらに特殊な部分であった。

指定点では全完成局所環が三パラメータ環上自由階数65で、非零 t は平方零となる。
この性質は Γ_+ の非空な ambient 開近傍で成立する。
**十八次元族の全一般 β ファイバーを除いたとは主張しない。**
開補集合は十七次元で W16 を優越し得るため、その処理が残る。

## 1. 普遍行列の三つのブロック

135式の最高 q-Jacobian の最初の70行は定数階数16で、45×29の核行列 K を持つ。
残る65行に K を掛けた E は、行・列を保存された順序に並べ替えると

    [ A  P  0  0 ]
    [ 0  B  R  0 ]
    [ 0  0  C  0 ]
    [ 0  0  0  0 ]

となる。A は4×12、B は12×9、C は17×5。
対角ブロックは六変数 (u4,u14,u35,u36,u49,u50) のみに依存し、
残る八個の自由一次座標は上三角の P,R にしか現れない。
この支えの恒等式は全十四変数上で検証した。

H_+ 上では B に保存された非零の九成分三次多項式右核がある。
B とそのベクトルとの積は全変数で恒等的に零。
従って B の階数は高々8であり、上三角構造から E の階数は高々4+8+5=17。
多項式核が特殊点で零になり得ても、九次 minor の恒等的消滅により上界は全 H_+ へ延長する。
よって最高 Jacobian は全 H_+ で階数高々33、t列を加えた全 chart Jacobian は高々34となる。

以下の有理点で等号33/34を確認した。
重み一の保存順 (2,3,…,17) を使い、u12=u13=0、u35=11、u50=−55とする。
他の値は保存順のまま保つ。全値・三ブロック・核・minor は report に保存した。

## 2. 十八次元と β 優越性

射影 Q の安定化群の連結成分は五次元で、H_+ を保つ。
後者は五つの Lie 作用について全自由変数上で検証した。
Sp4×H_+→(β,[Q]) のファイバーは射影 Q の安定化群内にあり、
その単位成分が H_+ を保つので、一般ファイバー次元は正確に5である。
従って Γ_+ の次元は10+13−5=18。

H_+ の三つの制約方向への十個の群接方向は、指定点で三次 minor −18300を持つ。
従って β への微分は階数16、Γ_+ は W16 を優越し、一般 β ファイバー次元は2である。
最高/全階数33/34が一般 β 上にも残ることを示す、実際の優越族である。

## 3. 指定点での自由階数65

同じ固定 β の二平面型三次元部分 C を標準曲線と二次形式から再構成した。
C は指定点で滑らかであり、v0,v1,v3 の制限が独立である。
八変数の横断商について、元の135式を用い次を新たに計算した。

| 検証 | 値 |
|---|---:|
| QQ 上の二次障害階数 | 14 |
| 五次初期関係792次 minor、mod32003 | 13761 |
| 実際の A2+A3+A4 関係430次 minor、mod32003 | 12091 |
| t の係数行を追加した431次 minor、mod32003 | 30652 |

全分母と pivot は32003で可逆。
厳密な二次階数により三次初期式の modular 消去を QQ へ持ち上げる。
五次 minor は m_A⁵=0、430次 minor は特性零の実際の横断長さ上界65を与える。
同じ β で Q1=(xw+x²+w²)∂y∧∂z とすると全階数35、二次障害階数5、
共通 Hessian radical 次元3となり、同じ C の一般点に普遍下界65が適用できる。

従って既存の有限自由加群の議論により、指定点の完成局所環 S は

    R=C[[v0,v1,v3]] 上自由階数65、S_red=R、
    I=ker(S→R) は自由階数64、I⁴=0、0≠t、I t=0、t²=0

となる。S/(t) は自由階数64、横断 Hilbert 関数は (1,8,22,34)。
431次 minor の使用は、元の関係階数が65の下界により正確に430と分かった後である。

## 4. 相対開部分と適用範囲

H_+ の13変数も動かすと、既知の相対二平面型部分は指定点で滑らかな16次元部分となる。
そのパラメータ環上の特殊横断商は65、一般点の長さ下界も65なので、
相対完成局所環は自由階数65となり t²=0である。
Sp4×H_+→W は上の三次 minor により smooth。
全135同次数斉次化の Sp4 同変性により、この相対環の群との積は ambient の smooth base change となる。
忠実平坦性から t²=0 が ambient 局所環へ降下し、coherent annihilator により開近傍を得る。

ただし Γ_+ は十八次元である。
その非空開部分の補集合は次元十七まであり、一般 β 上に曲線を残し得る。
十六次元端点に用いた「補集合の β 像は次元高々15」という議論はここでは使えない。
全 Γ_+ の例外集合を処理するには、局所計算に使う全非零条件を追い、その因子ごとに検証する必要がある。

既存の十七次元部分は Γ_+ の中で u35=0 と書ける。
その u4=0、u14=0、u49=0 の三つの十六次元部分は別証明書で全一般 β 上除去済み。
これらが Γ_+ の全例外集合を尽くすとは述べていない。

## 5. 二つの超平面表示の同一視

有限 symplectic 変換 S(x,y,z,w)=(w,−z,−y,x) は Q を −Q へ送る。
primitive β の有限 pullback によって

    (u12,u13)→(u13,u12),
    5u35+u50→5u14−u49

が正確に成り立つ。
従って {u12=u13=0,5u14−u49=0} から得る十八次元族も Γ_+ と同じである。
二つの表示を別の成分として数えない。
