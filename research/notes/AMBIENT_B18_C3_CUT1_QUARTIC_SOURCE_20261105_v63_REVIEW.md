# 文字通りの ell³ 切断から生じる四次源の独立監査

同じ実際の正規化二次源 P2 は、全二次項が ell²eH である。拡大した C3=C/ell³C の表示には、文字通りの ell³eH 列があり、高次の尾を持たない。したがって `ell*P2−ell³eH` は全ての三次項が消え、四次から始まる。この差を零と見なしてはいけない。

全ての平面三次係数を形式変数として P2 を作り直し、ell 倍と単項式 NF4 書換えから、A4、B4、残余 B4−121A4/48 の全重みを独立に再構成した。負の RB β2 補正と、その r³ 成分も保持する。λ の r ell² 項と未知 ell³ 項は ell/NF 操作で消えるのであって、値を零に置かない。第三次の z 項と H 項の消去、P2 の四次以降の項は A/B に五次以前の追加項を生じない。

使う全ての旧 C2 葉に対して74個の raw 正規形の Taylor 双対を確認した。六項の A、24項の B と残余は値を対合せず、正の上界だけを検証した。保存係数上界34/43/42 bit、全後段演算519 bitは厳密上限2048 bit内である。

固定ワーカーは24項の残余だけを計算し、A4=t は未計算の実際の座標を表す形式変数のまま保つ。座標 (A,L) で二源の行列は `[[-3/5,t],[0,d]]` となる。QQ[t,d^-1] 上の逆行列を独立に検査し、両方向積が恒等行列になることを確認した。実装の長さ3の多項式は全ての積の次数2までを保持するため、t の冪零性を仮定していない。

分数の和・積・構築・逆数は演算前の検査を通る。全10,040セルは静的18,000、絶対30,000以内で、RAW 145,426 bytesと保存予約は400,000 bytes以内である。60秒・2GBの枠を変更しない。この PASS は親が条件付きで認めた同じ一回の残余計算を実行可能にするが、監査自身は値を計算していない。

残余が非零なら既知 HB の四次線と独立なので C3 長さ19・HF36640が得られる。零ならこの源だけの従属性であり、長さ20や全四次階数は導けない。長い DVR 指数、H0、元の nil ideal の結論は含まない。
