# 全Q模型内のRat(1,1,3)：二Casimir schemeの正確なA20表示

2026年11月3日。全aで定義されたSmith37模型R37について、
canonical二ベクトルが二つの独立な定covector Casimirを持つschemeを構成した。
このschemeの実際の商は

    R37/(二Casimir条件) ≅ QQ[20変数],    a=0

である。全350 Jacobi式と全150 Schur条件は20変数への代入で厳密に恒等零となる。
これは既知Rat(1,1,3)の滑らかな横断枝であり、新しい全Poisson成分ではない。
Q_0の全Poisson局所環がこの枝だけだとは主張しない。

## 1. 全切断上で単元となるcontraction minor

生150係数から、定covectorを二次ベクトル場へ送るcontraction行列M(P)を作る。
行は五つのベクトル成分と15二次単項式、列は五つのcovector成分で、サイズは75×5である。
次の三行と列2,3,4を選ぶ。

    (成分3,x0²), (成分2,x0²), (成分3,x1²).

Smith37の固定非正重み係数により、この3×3行列は恒等的に

    [ 2/9    0    0 ]
    [  0   −2/9   0 ]
    [  c     0    1 ]

であり、cは生係数の一つである。行列式は定数−4/81である。
その逆行列を多項式で保存し、積が単位行列であることを確認した。
特定のaやPoisson点でしか可逆でないminorではない。

残るcovector列0,1を自由にして、上の三行を解くと、
先頭二行がI2である5×2 kernel候補K(P)を得る。
全75行についてM(P)K(P)=0と置いた150本がSchur条件である。
単元minorのため、これはcontraction行列のrank≤3条件とschemeとして同値であり、
成立する点のkernelは正確にrank2の直和因子となる。
Schur条件の121番目（零始まり）は文字通り−aである。

## 2. nilpotent基底も含む二Casimir認識

任意のQQ代数上でSchur条件が成立すると、Kの二列は

    ell0=dx0+Σ_{i=2}^4 alpha_i dxi,
    ell1=dx1+Σ_{i=2}^4 beta_i dxi

という独立な二つの定covectorを与える。
この二一次式とx2,x3,x4を新しい座標に取る線形変換の行列式は1であり、
nilpotentを持つ係数環でも可逆である。
新座標ではPの成分は23,24,34だけとなる。
canonicalなdivergence零条件は、この三成分が作る三変数方向の一形式の相対的閉性に等しい。

固定したCasimir平面W=span(dx0,dx1)で、三次式Hをx0,x1だけの三次式で割ると31次元となる。
写像

    H ↦ P23=∂4H, P24=−∂3H, P34=∂2H

の150×31行列Tを構成した。
また、各二次単項式のactive次数kに対して1/(k+1)を掛ける相対Euler積分により、
逆向きの31×150行列Lを作った。
厳密にLT=I31である。
三つのactive成分の45係数に対するdivergence行列の階数は14であり、kernelの31次元とTの像が等しい。
従ってこの線形同型は任意のQQ代数へtensorしても保たれ、nilpotent方向を捨てていない。
さらにTへ元の物理的350 Jacobi二次式を代入し、全式の全係数が恒等零となることも確認した。

従って二Casimir locusは、rankが正確に3のcontraction開集合で、
Gr(2,V*)上のrank31束Sym³V*/Sym³Wの対応する開集合と**schemeとして**同型となる。
Wはkernelとして一意に復元でき、Hは純Casimir三次式を除いて一意に復元できる。
これは既知Rat(1,1,3)の実際のJacobian族である。
そのcontraction rank<3の境界まで、この逆写像を拡張したとは主張しない。

## 3. 正確な20変数多項式商

Q_0で150 Schur条件の37方向Jacobianは階数17であり、保存小行列式は

    −7334/23914845

である。
−aを一式として使い、残る16式を正重み順に選ぶと、
重み1,…,6のblockの大きさは1,2,3,4,4,2となる。
全逆行列は有理定数であり、正重みによる三角消去で残りの20正入力の有限多項式として解ける。
これは形式的な次数打切りではない。

得た代入を元の全350残差と全150 Schur条件へ合成し、QQ[20変数]の指数辞書上で全500式の恒等零を確認した。
生150係数の復元の非零単項式は合計69個である。
選んだ17式のidealの商が20変数多項式環であり、その代入kernelに残る全式も入るため、
全Schur idealも同じ17式で生成される。
従って元の全Poisson idealを含めても、実際の商はQQ[20変数]となる。
明示的な親37入力の多項式表示、全150係数、kernel二列を保存する。

これは二Casimir枝自体がQ_0を含めて滑らかであることを示す。
親の17群方向を戻すと、この既知枝はcanonical affine次元37、射影次元36となる。
この枝と別の枝の交叉・全Poisson schemeの厚みは別問題である。

## 4. 実際の全Poisson idealの最小素成分とa非平坦性

20自由入力をすべて1とした点で、親R37の**元の全350式**の37方向Jacobianを直接構成した。
階数は17であり、17個の従属入力方向から選んだ小行列式も非零となる。
全行列、点、非零有理値を証明書に保存した。
この点では全R37の局所次元は既知商から20以上、埋込み次元は37−17=20以下であり、
全局所環が20次元で正則となる。
従ってこの20次元の素graphは、元の全I350の実際の最小素成分である。
既知Rat(1,1,3)の成分数を新しく加えるものではない。

この最小素idealはaを含み、Q_0を通る。
Noether環の最小素idealは関連素idealなので、Q_0での全R37局所環でaは零因子となる。
従って全R37の局所環および完成はaに関して非平坦である。
完成は忠実平坦なので、局所環の非零a-torsionは完成でも非零のまま残る。
この結論は**全20次元枝と元350式のgeneric階数**から得たものであり、
先の閉二平面だけの非平坦性を親へ読み替えたものではない。
Q_0での全R37の正則性や、他の局所枝の尽くしは主張しない。
