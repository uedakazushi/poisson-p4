# 楕円二成分の一次部分：五変数模型と有限表示重複

2026-10-31。対象は T39=q(5,1), T40=q(5,2)。本ノートは楕円二成分の一般次数を
決定しない。Sp4 の十変数およびスカラーを厳密に消去する開模型と、表示の重複を与える位数50の
部分群を記録する。全S61の一般ファイバーの尽くし・有限性は扱わない。

## 1. 結論と計算範囲

primitive な閉一次二形式の空間 W（次元16）には、具体的な多項式 d(β) で定義される
非空開集合 W°={d≠0} があり、Sp4 は W° 上で自由に作用する。
各 β∈W° の楕円パラメータ表示による逆像は、

- 六変数 (λ,p1,p2,p3,p4,c)、さらに明示した開集合上では五変数 (λ,p1,p2,p3,p4)、
- 30本の明示的な有理等式、
- λc と指定した正規化の分母・d の非消失条件

による模型とスキームとして同型である。十変数の symplectic frame とスカラー c は各解から一意に復元される。
この模型は一般 β で零次元である。全解の長さは未計算である。

さらに、λ を固定したまま表示を保つ位数50の群を明示する。一般の一つの正規化済み
Poisson tensor は少なくとも50個のパラメータ表示を持つ。従って六変数模型の解数を
そのまま成分の次数にしてはいけない。50が全表示重複かも未決である。

再現：

```sh
.venv/bin/python code/elliptic_six_variable_fiber.py --output reports/ELLIPTIC_SIX_VARIABLE_FIBER_recheck.json
```

証拠は `reports/ELLIPTIC_SIX_VARIABLE_FIBER_20261031.json`。
計算は両族の有理点での非消失、共変性・逆構成の点検、および一般 λ での群生成元の
恒等式を確認する。以下の普遍的なテンソル証明と、有限次元の数値観察を区別する。

## 2. 共変 frame の構成

J は従来通り diag(J2,J2), J2=[[0,1],[-1,0]] とする。
β_bc(y)=Σ_a T_abc y_a と書く。T は後二添字で反対称であり、閉性および
primitive 条件を満たす。Sp4 の pushforward S に対し、下げた三添字の変換は

    T'_{abc}=Σ_{ijk}(S^{-1})_{ia}(S^{-1})_{jb}(S^{-1})_{kc} T_{ijk}.

次を定義する。和は全て0,…,3の添字について取る。

    M_ia = Σ_{j,k,b,c} T_ijk T_abc J_jb J_kc,
    A = J M,
    H = J M Jᵀ,
    u_i = Σ_{a,b} T_abi H_ab,
    v = J u,
    R = [ v | Av | A²v | A³v ],
    d(β) = det R.

M は対称である。実際、二つの T の交換時に J の反対称性から二回符号が変わる。
従って A は Hamiltonian、すなわち AJ+JAᵀ=0 である。
各添字の変換を縮約すると、

    M' = S^{-T} M S^{-1},     A' = S A S^{-1},
    u' = S^{-T}u,            v' = Sv,          R' = SR.

ここでは SJSᵀ=J を用いた。この証明は任意の係数環で成立し、数値標本に依存しない。
R の列の次数は順に3,5,7,9、d の次数は24である。
Sp4 は行列式1なので d は不変量である。

もし Sβ=β かつ d(β)≠0 なら SR=R から S=I。
これは W° 上の安定化群がスキームとして自明であることも示す。

### 非空性と両楕円族への適用

既存 `elliptic_weight1_dominance.py` の正規化を使い、λ=2、p=(1,2,3,4)、c=1
で計算すると、

    q(5,1): d = -22424316787704798313221875000 / 129140163,
    q(5,2): d = -22874904216621589416199115134751991796875
                  / 7736897450643967348366687611387904.

いずれも非零である。従ってこの開集合は空でなく、両族のパラメータ空間とも稠密開で交わる。
以前の優越性証明に用いた p=0 は d=0 である。この点で frame が退化することは
優越性証明を否定しない。今回の逆構成では上記の別の点を使用する。

## 3. 30個の不変量による軌道の厳密な分離

R の列を R_0,…,R_3 とする。次の30個をまとめて I(β) と書く。

1. G_ij = R_iᵀ J R_j（i<j の6個）。
2. U_dij = T(R_d,R_i,R_j)（i<j、d=0,…,3 の24個）。

これらは多項式不変量である。24個の間には閉性等の従属があるが、全て残す。

**補題。** b,β∈W° に対し、I(b)=I(β) と、
S∈Sp4 で S·b=β が存在することは同値である。その S は一意で、

    S = R(β) R(b)^{-1}

である。

**証明。** 必要性と一意性は共変性から従う。
逆に G の一致は SᵀJS=J を与える。U の一致と R(b),R(β) の可逆性は、
全ての三添字にわたるテンソルの一致 Tβ=(S^{-1})^{⊗3}Tb を与える。
24個で足りるのは後二添字が反対称だからである。
この議論は d(b)d(β) を可逆にした任意の係数環で成立する。
従って単なる閉点の全単射ではなく、対応する局所化された等式スキームの同型である。□

これは不変式環全体の生成系を主張しない。非空開 W° 上の完全な軌道判定に必要な
明示的な不変量を与えるだけであり、境界 d=0 は別に残る。

## 4. 六変数の固定一次部分模型

Ortenzi–Rubtsov–Tagne Pelap の一般族 B_k(λ) を用いる。
出典は [arXiv:1001.4422v2, equations (16), (18), (19)](https://arxiv.org/pdf/1001.4422v2)。
q(5,1) の符号は equation (18) の +λ を用いる。後の equation (21) の符号との不整合は
既存の優越性ノートとコードで Jacobi 恒等式により監査済みである。

x0=1 の affine bivector を P_k(λ,z) とし、六変数
q=(λ,p1,p2,p3,p4,c) に対して K=cP_k(λ,p) と置く。
従来の有理 frame F(K) は F K Fᵀ=J を満たす。
その非消失条件は λc aΔ≠0 であり、a と Δ は同じ固定順序 [0,3,1,2] による
2×2 pivot と Pfaffian である。

    D_h = c (∂P_k/∂z_h)(λ,p),
    L_j = F (Σ_h (F^{-1})_hj D_h) Fᵀ,
    b_k(q) = primitive_vector(L_0,…,L_3).

F^{-1}=-KFᵀJ なので逆行列の追加消去変数は不要である。
この式は既存の perspective 正規化を含む、有理関数としての明示的処方である。
`normalized_jet` と `fixed_jet_equations` が実装する。
大きな分子を展開する代わりに、この有限個の加減乗除からなる処方を保持する。

固定 β∈W° に対する六変数模型は

    I(b_k(q)) = I(β),
    λ c a Δ d(b_k(q)) != 0.                           (★)

すなわち30本の有理等式である。分母を払うときは、列挙した分母による局所化を維持する。
R(b_k(q)) の可逆性から、解 q ごとに

    S(q,β)=R(β)R(b_k(q))^{-1}

が唯一の symplectic frame として復元される。前節により、(★) は

    {(S,q)∈Sp4×U6 : S·b_k(q)=β}

とスキームとして同型である。ここで U6 は指定したパラメータ開集合である。
従って Sp4 の十変数を消したことで解や冪零構造を失っていない。

両族の既証明の16×16非零微分小行列式により Sp4×U6→W は優越的で一般に有限である。
今回の d≠0 は非空開なので、(★) も一般 β において零次元である。
一般 β から除いたパラメータの真の閉部分の像は次元高々15であり、一般次数を変えない。
ただしこれは d=0 上の個々の特殊 β にこの模型が完全であるという主張ではない。

一般の零次元性は既知の優越性から従う。今回の30本について Gröbner 基底、
特殊ファイバーの全長さ、明示的な有限étale近傍を得たという意味ではない。
数値ホモトピーの根数が得られても、非消失条件、全解、有限な近傍を別に確認する必要がある。

## 5. スカラーも消去する五変数模型

さらに次の多項式不変量を用いる。

    I4(β)=tr(A²),
    I14(β)=T(Av,v,Av),
    h(β)=I14(β)/I4(β)³.

I4 と I14 の次数はそれぞれ4,14であり、h は次数2の有理不変量である。
上記の共変 frame の有理点では、

    q(5,1): I4=-207550/9, I14=-1364884028921875/13122,
    q(5,2): I4=-34396225/444728,
             I14=-12824353234395624109375/2814708331152523264.

従って d I4 I14≠0 は W および両族における非空開条件である。

正規化前の bivector を c 倍すると、正規化後の一次部分は Sp4 を除いて
sqrt(c) 倍になる。実際、c=1 の frame F に対し F/sqrt(c) を使えば
定数部分は J であり、一次部分は sqrt(c)L となる。primitive 射影は一次なので
同じ変換則を持つ。コードの有理 frame とこの frame の差は Sp4 である。
従って

    I4(b_k(λ,p,c)) = c² I4(b_k(λ,p,1)),
    I14(b_k(λ,p,c)) = c⁷ I14(b_k(λ,p,1)),
    h(b_k(λ,p,c)) = c h(b_k(λ,p,1)).

この恒等式を平方根の付加上で証明したが、両辺は元の係数環上の有理関数であり、
c を可逆にした忠実平坦な二重被覆から降下する。解に平方根の選択を追加しない。

固定 target β と b0=b_k(λ,p,1) に対し、スカラーは一意に

    c(λ,p;β) = h(β)/h(b0)

と復元される。この有理式を (★) の30等式全てに代入したものが五変数模型である。
新しい開条件は target と b0 の d I4 I14 の非消失、および λaΔ≠0。
c は上の式から非零となる。

前節の軌道分離により30等式のスキーム上で全ての不変量が一致するため、h の一致も
スキームとして従う。c h(b0)=h(β) は h(b0) を可逆にした一次式なので c を消去できる。
従って五変数模型も元の固定一次部分のパラメータ fiber とスキームとして同型である。
これは30等式を任意に選んだ五本に置き換える主張ではない。
実装は `fixed_jet_five_variable_equations`。実装上は c を代入した jet を作り直さず、
各 signature 成分 I_j の偶数次数 w_j を用いて

    c(λ,p;β)^(w_j/2) I_j(b0) - I_j(β) = 0

を使う。R の列次数を d_i=3+2i とすると、Gram 成分の次数は d_i+d_j、
三添字成分の次数は 1+d_d+d_i+d_j であり、全て偶数である。
従って平方根を導入しない30本の有理等式として直接評価できる。
c=3 の厳密有理点で、直接正規化とこの重み付き表示の一致、全等式、c の復元も確認する。

## 6. 位数50の表示重複

ζ を原始五乗根とし、添字を mod5 とする。PGL5 の元

    C: (x_i) -> (x_{i+1}),
    D: (x_i) -> (ζ^i x_i),
    H: (x_i) -> (x_{-i})

について、両族とも一般 λ で

    C_* B_k(λ)=B_k(λ),  D_* B_k(λ)=B_k(λ),
    H_* B_k(λ)=-B_k(λ).

C,D の projective 交換子は自明で、生成する群は (Z/5)^2。
H は C,D をそれぞれ逆元に共役する。従って
G=(Z/5)^2⋊{±1} は位数50である。
その50元が異なることは、10種の置換 i↦±i+a と、各置換での5種の
非 projectively equivalent な対角位相で直接確認できる。
C,H の恒等式はコードが一般 λ の有理式として検証する。
D は各 B_ij の単項式の添字重みが i+j mod5 であることから従う。

character χ:G→{±1} を χ(C)=χ(D)=1, χ(H)=-1 とする。
パラメータ変換は

    λ'=λ,       p'=h(p),       c'=χ(h)c.

p'=h(p) は x0=1 chart への projective 座標変換である。
これに伴う正規化 frame の変換も一意に存在する。
実際 h_*B=χB より、微分 Dh_p を用いて

    Dh_p K(p,c) Dh_pᵀ = K(p',c')

となる。旧 frame が F なら、新 frame は F(Dh_p)^{-1} である。
原点を固定し微分が同一である二つの projective 座標変換の差は perspective であり、
primitive gauge の一意性により最終的な正規化済み Poisson tensor は同じになる。
従って I(b_k(q'))=I(b_k(q)) であり、この有限群は (★) の表示重複を与える。

各非自明な projective 線形変換の固定 locus は P4 の真の閉部分であるから、
有限個のその和を除くと G は自由に作用する。必要な全 chart の交わりも稠密開である。
ゆえに一般の一つの正規化済み tensor は、六変数模型内で少なくとも50個の異なる q
によって表示される。反転 H で c が符号変化することは必要である。
一方、Sp4 の中心 -I は frame 復元で既に扱われており、これを別の係数2として加算しない。

## 7. 次数の正しい分離と残る障害

d_k を T39 または T40 の W への一般次数、ρ_k を
Sp4×U6 から対応する正規化済み成分への一般表示次数、N_k を (★)、同値に五変数模型の一般長さとする。
関数体拡大の次数乗法性により

    N_k = ρ_k d_k = 50 e_k d_k,       e_k∈Z_{>0}.

位数50の自由な作用から 50|ρ_k が従う。ρ_k=50 も e_k=1 も証明していない。
λ の異なる値を結ぶ projective 同型、特殊な λ による分岐、一般の全安定化群を
同定する必要がある。楕円曲線の j 不変量のみに頼る場合にも、Poisson tensor の
同型との同値、使用する λ 座標、スカラー作用を一次資料または直接証明で監査する。
今回はその未監査の同定を次数計算に使用しない。

次の有限課題は五変数模型の算術回路を保ったまま分母を局所化し、一般 target の有理点で
消去・有限生成の証明書を作ること。その際には N_k の計算と ρ_k の決定を分ける。
30式は高次数で従属も多く、単に未知数が五つになったことだけで計算可能性や
明示的な有限近傍が得られたとはしない。
