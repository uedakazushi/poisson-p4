# C/ell四乗の実 HF と、二つの HB residual 座標による指数三判定

全 C の実 HF 次数零〜三は(3,6,6,6)。また C3 の m⁴ は零なので、
m⁴C⊂ell³C。全 C の reduction m⁵C=ell*m⁴C から m⁵C⊂ell⁴C、
従って C4=C/ell⁴C の m⁵ は追加の jet なしで零である。
既知 D 型 D⁴⊕tors(1,1,2,e),e>=3 により C4 長は二十三又は二十四。
ell⁴C は m⁴ 内なので次数零〜三は変わらず、実 HF は厳密に
(3,6,6,6,2,0)又は(3,6,6,6,3,0)となる。

全六 quartic NF は A r²ell²,A r ell³,A ell⁴,B r²ell²,B r ell³,B ell⁴。
既知の二つの真正 HB source と literal ell⁴A,ell⁴B を C4 で使う。
w=HB1+10HB0 とし、w の第二又は第五座標が非零なら、
行[0,j,2,5]・列[HB0,HB1,ell⁴A,ell⁴B]の minor は(-3/5)w_jで非零。
下二行の HB 係数 p,q,s,t は任意のまま determinant を普遍的に検証する。
従って四次 NF 六次元から四関係が落ち、C4 の HF4<=2、長<=23。
既知下界二十三と合わせ長二十三、e=3 が従う。

この条件付き判定に追加の値は要らず、準備した全 HB 行列の二座標を読むだけでよい。
両座標が零ならこの既知部分の陰性に留め、e>=4や全四次階数を断定しない。
比較 C の torsion長を元 H0(D0) や nil 三乗へ移送しない。
