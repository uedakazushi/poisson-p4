# B18：第4の埋め込み随伴閉包の独立幾何監査

2026-11-04。対象は actual `D=CA∩CB`。新しい点・jet・CAS・群行列を計算せず、
既受理の source/深さ/軌道積/全被約境界の証明を hash で固定して幾何を監査した。

## 同じ B18 軌道の同定

旧 proper boundary theorem は、全被約交叉 `(R∩N)_red` が既約な射影18次元の
B18であり、その全像が9係数 chain 族の群飽和であることを証明済みである。
独立 checker は literal `a=b=1,c=0,G2=h²+z²` を使い、標準150係数の P0 が
旧軌道証明書の P0 と一致することを確認する。単なる形式型の類似ではない。

連結群 GL5×Gm の P0 軌道は滑らかな既約19次元。B18 は群不変な既約19次元の
錐なので、その軌道閉包は B18 全体である。軌道は閉包内で局所閉、従って
この場合は稠密開である。B18 は P0 において滑らかな19次元軌道そのものである。

## 深さ0から具体的な形式的随伴素イデアルへ

受理済み全 Artin 点における actual 群作用と minor −32 は
`Dhat_P0 = A_perp[[g19]]` を与え、冪零構造も保持する。
確定した錐深さ19より `depth(A_perp)=0`。有限長非零 `H0(A_perp)` の socle から
非零 z を取れば `Ann_Aperp(z)=m_perp`。これを定数級数として群積に入れると、
係数ごとの積によって厳密に

`Ann_Dhat(z)=m_perp[[g19]]`

となる。商は `k[[g19]]` なのでこれは随伴素イデアルである。非零の群変数級数が
z を殺すことはない。z の具体式や長さは求める必要がない。

## 完備化から降ろす素イデアルを明示する

ここで得た形式的素イデアルを、任意の formal fibre prime として扱ってはならない。
既存の同型は、canonical126内の実作用写像
`Gamma19 × (P0+H107) → V126` の形式的逆関数定理そのものである。
`Gamma19 × {P0}` の像は P0 の実軌道の形式近傍であり、軌道の接写像は19次元で
可逆なので、その形式近傍は B18 の形式近傍と一致する。

従って上の `m_perp[[g19]]` は、具体的な代数的イデアル
`I_(B18,P0)` の完備化に等しい。flat completion の随伴素イデアル収縮と
localization の定理を適用すると、global cone D における随伴素イデアルは
まさに `I_B18` である。任意の形式的素イデアルの収縮が次元を保つ、という
不正な仮定は要らない。B18 は極小成分 N28 と R20 の真の部分集合なので embedded。

## 相異性と射影版

既存の Pa・Qb・CA-critical V の3閉包は互いに相異なる錐20次元である。
B18 は錐19次元なので、そのいずれとも異なる第4の閉包である。
`q106(P0)=1`、全イデアルは homogeneous なので、この非零チャートでは錐環は
射影チャート環の Laurent スカラー拡大に一致する。同じ随伴素イデアルが射影版へ
降り、次元は18になる。

結論は actual CA/CB 交叉の global embedded associated closure が少なくとも4個。
全 Ass の尽くし、primary 分解、socle 長、nil指数、nil三乗の非零性、Poisson の
新既約成分は主張しない。Poisson 成分下界58は変更しない。
