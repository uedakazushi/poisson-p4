## 結論

両指定点の完成局所環 S は一次元の完全交叉である。

となる。冪零部分の平方は零で、二つの枝の一般長さはともに二。
さらに **t=0 in S**。従って両点は t による飽和後の閉包から除かれる。
この結論は証明中の開条件が成立する同じ交点族へ延びる。
全 R0 の端点・例外点や全アフィンファイバーを尽くす主張ではない。

## 2. 二つの滑らかな無限遠枝

主枝 C0 は Sp4 が Q の射影軌道を動かす既存の非二元曲線である。
Q に対する β の全線形条件の核は十次元。
その十方向と Sp4 の十方向を合わせた β 微分の階数は、両指定点で16となる。

全135最高式の同変性により、この枝は t=0 の中にある。

もう一つの枝 C1 は、それぞれ

    G=xzw+c z³, または G=xzw+c w³,
    Q(c)=dy∧(G_w dz−G_z dw)

という明示的な射影直線の c=0 近傍である。
固定した β のまま、全135最高式が c の恒等式として零になることを確認した。

元の全 Jacobian がこれらの接ベクトルを殺すことも直接確認した。

## 3. 同じ二枝に沿う長さの下界

C0 の一般点では、既証明の全十個の独立一次係数を保つ普遍階数上界により、
最高 q-Jacobian の階数は42以下である。
ここで使う正確な独立 β 核の次元は十であり、座標自由度の数え直しで上界を推測していない。
具体的な既存証明書は `S61_NONBINARY_FORMAL_RING_20261101` の135式部分である。

C1 の c≠0 部分について新たに普遍計算を行った。

従って全最高階数は42以下。この上界は過大な小行列式の恒等的消滅として全核に延びる。
非零 c は symplectic 対角変換で一にできる。
z,w の symplectic 交換と射影スカラーによる w³ 型への移送も有限変換で検証した。
従って同じ上界が両方の C1 の一般点で成り立つ。

S は R 上有限なので、S∞=S/(t) も有限である。

    44−1−42=1

よって rank_R S∞≥4 である。

## 4. 有限自由性、t の消滅、完全交叉

第1節の上界と合わせて

    4≥rank_R S≥rank_R S∞≥4

となる。高々四生成元の全射 R⁴→S の核は階数零の自由加群の部分加群なので零。
従って S は自由階数四である。
全射 S→S∞ の核である ideal(t) も階数零の torsion-free 部分加群だから零、すなわち t=0。

形式的陰関数消去後の全イデアルから、第1節の二次初期式を持つ二つの関係を選ぶ。
それらだけの商 T は、二次初期式が正則列であるため一次元完全交叉であり、
u を除いた長さは正確に四となる。
T は Cohen–Macaulay で u はパラメータなので、R 上自由階数四である。
全射 T→S は同階数の自由 R 加群間の全射で、核は零。従って S=T は完全交叉である。

二つの一般局所因子の長さが二ずつで総階数を使い切るため、他の一般的な台はない。
S は R-torsion-free なので原点だけに支持された追加部分もなく、被約台は C0∪C1 だけである。
二枝は滑らかで接線が異なるので、この被約完成環は通常二重点である。
一般因子はいずれも双数環で、冪零部分の平方は一般点で零。
torsion-free 性によりその平方は全環で零となる。
完備化の忠実平坦性により t=0 は元の局所環にも降り、飽和からの除去が従う。
