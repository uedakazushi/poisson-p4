# 既存の二平面型探索パッケージ

停止前に work/ に選別されていた37個の研究パッケージから、異なるファイル内容を一度ずつ保存した。現在の四作業台の再開にはこの過去資料の一括展開は不要である。`index.json` の `original_files` が元のパッケージと内部パスを内容の SHA-256 に対応させ、`stored` がその内容の実際のアーカイブ・内部パスを示す。内容のない重複パッケージは索引のみに現れる。`excluded_platform_binaries` はローカル用実行ファイルの一覧。正規の最新証明は research/CLAIMS.json を参照する。
