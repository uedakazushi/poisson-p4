# 滑らかな二次因子・正則半単純正規場の全支持：独立検証

2026-11-07。`SMOOTH_QUADRIC_CUBIC_SUPPORT.md` 第2–3節を受理する。
q=x0²+x1x2+x3x4、正規 Hamiltonian 場の固有値 `(0,1,−1,2,−2)` を固定した
全 canonical lift の支持は、六つの全パラメータ源で尽くされ、全て MPS40 の和に入る。
他の Jordan 型や q の階数3/4をこの結論に含めない。

独立実装は producer、SymPy、既存の多項式演算 engine を import しない。
保存した括弧をデータとして読み、標準ライブラリ Fraction による疎多項式、
微分、Jacobi、Pfaffian、Gaussian elimination を別に構成した。

## 全源の確認

全150係数中の重み不変な単項式を独立な指数順で列挙すると20個である。
発散零と `dq_i Πij=q Xj` を、零行を含む全200係数 slot で構成した。
この200×20行列と右辺付き行列の階数はともに15。
producer の25行表示は同じ写像の非零係数を抜き出したものである。

保存された五パラメータの括弧は、この全 affine 線形条件を恒等的に満たす。
五つのパラメータ微分は独立である。
したがって、20−15=5という解空間の次元と合わせて、表示が全 affine 解を尽くす。
線形方程式の一部を満たす五次元部分族だけを検証したわけではない。

その全テンソルから十個の strict Jacobi 多項式を直接微分した。
全350係数 slot の QQ 線形包と、ノートの五条件の線形包はともに階数5で、
両者を合わせても階数5である。
従って五条件は元の全 Jacobi と同じ ideal を生成する。

## 六源の全支持

s=u+v と置くと、最後の二条件は

\[
 t(s-1)=0,\qquad (8t+30)s+7t+20=0.
\]

前者の二枝を全て残すと、後者によって
`(t,s)=(0,−2/3)` または `(-10/3,1)` となる。
各々で `ab=0,a(u+1)=0,b(v+t+3)=0` を分けると、
a=b=0 の central line、a が自由な line、b が自由な line の三つを得る。
各 line の零パラメータや交点も含め、ノートの六本と一致する。
これは複素閉点の全支持を尽くす議論であり、全スキームの厚みを追加で主張しない。

## 全パラメータの軌道極限

六源の各々で、自由パラメータを残した全 Jacobi が恒等的に零であることを確認した。
実五次式も五つの符号付き Pfaffian から独立に再構成し、
保存した全 D と一致し、各 minor が対応する偏導関数に等しい。

対角 pushforward の指数は
`wi+wj−Σ mk wk` とする。保存された六組の重みに対し、
全源の全括弧項の指数は非負であり、零指数の全項は logcanonical である。
極限の全 Pfaffian を再構成すると、自由パラメータに依らず

\[
 D_{\mathrm{lim}}={10\over3}x_0x_1x_2x_3x_4
\]

となる。従って極限は非零な一般階数4の SNC 点である。
PGL5 は連結なので、元の点を含む各全空間成分はその軌道閉包も含む。
MPS の SNC 成分定理により、それらは既知40成分のいずれかである。
T01 単独への包含や、他の Jordan 型の被覆へ拡張していない。
