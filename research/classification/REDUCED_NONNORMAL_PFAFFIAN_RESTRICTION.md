# 被約非正規五次因子の Pfaffian–Jacobian 制約

2026-11-07。課題 E_reduced_nonnormal。
標数零の複素数体上で、全5×5行列と全Poisson条件を保持した構造補題を示す。
結論は条件付きの線形因子の存在であり、被約非正規因子の全支持分類ではない。

## 1. 正確に高さ二となる入口

R=C[x0,…,x4]、E=Σxi∂i とし、Πを射影Poisson構造の標準divergence-free二次liftとする。
ν=dx0∧…∧dx4 に関して

    E∧Π²/2=D ∂0∧…∧∂4

と書く。Dは実際の非零五次退化式であり、被約非正規と仮定する。

このliftは射影Jacobiだけでなくstrict Jacobiを満たす。
実際、JΠ=[Π,Π]は係数次数3の三ベクトルであり、divΠ=0からdiv JΠ=0。
射影Jacobi E∧JΠ=0にdivergenceを作用させると、Euler恒等式により5JΠ=0となる。
またBV恒等式から1形式 α=ι_(Π²/2)ν は閉じている。
ι_Eα=D、L_Eα=5α なのでCartan公式は

    ι_(Π²/2)ν=dD/5,          Π♯dD=0                         (1)

を与える。従ってΠの符号付き五つの4×4 Pfaffianが、Dの五つの偏微分の1/5倍である。

J=(∂0D,…,∂4D) と置くと、正確に ht J=2 である。
まずEuler公式からD∈J。偏微分全てを割る素因子pがあればp|Dである。
D=pg、p∤g と書き、偏微分をpで還元するとg∂ip=0となる。
標数零では少なくとも一つの∂ipが非零でpでは割れないので、これは矛盾する。
従って ht J≥2。

一方、被約hypersurfaceはS2条件を満たすため、非正規性はR1条件の失敗に等しい。
三次元射影hypersurfaceDの特異集合は曲面を含み、そのaffine coneの次元は3以上。
従って ht J≤2であり、等号が成立する。
この議論は可約Dも含む。高さ一の分岐を黙って除外していない。

## 2. Perfectなnon-cone枝には線形因子がある

**命題。** 上の仮定に加えて、

1. 五つの偏微分∂iDがC上一次独立である、すなわちDがlinear coneでない。
2. R/JがCohen–Macaulayである、すなわちJがgrade二のperfect idealである。

と仮定する。このときDは線形因子を持つ。

**証明。** Jの最小生成元は次数四の五つの偏微分である。
Hilbert–Burch分解を

    0 → ⊕_(j=1)^4 R(−4−d_j) → R(−4)^5 → J → 0

と書く。最小性からd_j≥1であり、四次生成元が極大minorであることからΣd_j=4。
従って全d_j=1であり、分解は

    0 → R(−5)^4 → R(−4)^5 → J → 0.                    (2)

よってgrad Dのsyzygy module Mは、四つの線形ベクトル場X1,…,X4で自由に生成される。
各XiはXi(D)=0を満たす。
Hilbert–Burchのcofactor恒等式とEuler公式から

    det(E,X1,X2,X3,X4)=cD,            c≠0.             (3)

が成り立つ。

(1)からΠの各列はMに属する。V(J)の外ではMは自由加群R⁵の直和因子であるため、
skew性からΠはΛ²Mの切断となる。
従ってその開集合上で

    Π=Σ_(i<j) c_ij Xi∧Xj

と書ける。補集合の余次元は二であり、Mが自由でRが正規なので、各c_ijはR上の多項式に延びる。
Πは二次、Xiは一次なのでc_ijの次数は零、すなわち定数である。
Πの一般階数四から、定数skew行列(c_ij)は非退化である。

g=span_C(X1,…,X4) は四次元Lie代数をなす。
実際、[Xi,Xj]は線形でDを消すので、(2)よりXiの定数係数結合となる。
四つのXiは函数体上も独立であるため、ΠのJacobiはg上の非退化な定数r-matrixのJacobiと同値。
その逆形式はg上の閉非退化二形式となる。

四次元の非可解複素Lie代数はsl2⊕Cであるが、これは閉非退化二形式を持たない。
中心元zに対し閉性はω([x,y],z)=0を与え、[sl2,sl2]=sl2だから中心がωの核に入るためである。
従ってgは可解である。

Euler場Eは線形場Xiと可換なので、CE⊕gも可解な線形Lie代数である。
Lieの定理を双対表現に用い、共通固有一次式ℓを取る。
超平面ℓ=0上ではE,X1,…,X4が全てその超平面に接する。
従って(3)の行列式はℓで割れ、ℓ|Dが従う。□

必要なのはR/JのCohen–Macaulay性である。
Sing Dの一般点での良い性質や、高さ二だけでこの仮定を置き換えていない。
また一次独立性を失うcone枝では、(2)の次数の議論をそのまま用いない。

**系。** 線形因子を持たない被約非正規D、特に既約五次型および既約二次×既約三次型について、
Dがnon-coneならR/Jは必ず非Cohen–Macaulayである。
従ってこの全分岐には、cone枝またはJacobianの非perfect枝が本質的に残る。

## 3. 高さ二からperfect性は従わない：実Poisson反例

座標を(h,u,v,z,w)とし、

    F=h²+u²+v²,       G=h²+z²+w²,
    P=F∂u∧∂v+G∂z∧∂w

と置く。hはCasimirであり、二つの項は互いに可換なのでPはstrict Poissonである。
実退化式は

    D=hFG.

これは相異なる三つの既約因子を持つ被約五次式であり、因子同士の交叉曲面で非正規である。
定数場がDを消せばh,F,Gをそれぞれ消すので、その定数場は零。
従ってDはnon-coneで、五つの偏微分は一次独立である。

divergenceは

    X=−2v∂u+2u∂v−2w∂z+2z∂w.

このXはPを保存し、Eとも可換である。
従ってΠ=P−E∧X/5はdivergence-freeなstrict Poisson liftであり、
元の射影構造と同じDを持ち、(1)の全Pfaffian–Jacobian条件を満たす。
単に任意のskew行列から作った反例ではない。

一方、Dを消す線形場Yについては、三つの因子の既約性から

    Y(h)=ah,       Y(F)=bF,       Y(G)=cG,       a+b+c=0

となる。二次係数を比較するとb=c=2a、従って5a=0。
残る自由度は正確に

    v∂u−u∂v,            w∂z−z∂w

の二つである。
もしR/JがCohen–Macaulayなら(2)から線形syzygyは四次元必要なので矛盾する。
従ってこの実Poisson例は ht J=2 かつR/J非Cohen–Macaulayである。

## 射程と独立確認

ここまでの証明は係数計算ジョブや有限体実験を使わない。
Hilbert–Burch、Hartogs延長、四次元Lie代数の短い議論、Lieの定理、および上の反例は、
別担当が全て読解確認した。

完全な被覆、Jacobian非perfect枝の分類、cone枝の分類は未証明である。
また、この補題で得た線形因子を持つ全点が既知成分へ入るとは主張しない。
その枝では実際の因子を使うh-Casimir affine模型へ移れるが、全Poisson条件の処理は別の義務である。
