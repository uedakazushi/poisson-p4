# 階数3・横断二重二次曲面層の支持被覆：独立査読

2026-11-07。退化因子が H+2Q_h で、Q_h が階数3の既約二次曲面、H がその頂点を含み、
商の滑らかな二次曲線に横断的な場合を扱う。この層を既知52個の rank4 成分閉包で
覆う証明を **受理する**。依存するのは既存の β=0 支持被覆と、その既知閉包の PGL5 不変性である。
階数3の接する場合、他の退化因子、全分類の完了は本稿の結論に含まない。

## 1. 逆二形式の全空間を独立に再構成した範囲

H の補集合の座標を (u,v,z,w) とし Q=1+u^2+v^2 と置く。
次数2以下の二形式 α は90係数を持つ。閉性は

    Q dα − 2 dQ∧α = 0

という140本の線形係数式である。独立な疎整数多項式・外積実装で140×90行列 D を再構成した。
また、全20係数のアフィン一次形式 θ に対する Q dθ−dQ∧θ の90×20行列 B と、
追加列 Q du∧dv を持つ90×21行列 E を再構成した。

全 D E=0 を整数で確認した。原証明書の70次、19次、20次小行列式を、
producer と SymPy を import しない整数 Bareiss 消去で再計算し、非零値が完全一致した。
三つの全行列の hash も一致した。さらに B(dQ)=0 の非零核を確認した。
従って rank D=70、rank B=19、rank E=20、ker D=im E が厳密に従う。
全ての閉形式は

    α = Q dθ − dQ∧θ + t Q du∧dv

で尽くされる。θ はアフィン一次、t は定数である。
ここで θ は原始形式の記号であり、S61 の一次 jet 座標 β とは別物である。

検証記録は `reports/CLASSIFICATION_RANK3_TRANSVERSE_REVIEW_20261107.json`。
0.1秒未満で完了し、検査コード全文と hash、三つの小行列式、全行列 hash を保存した。
入力は `reports/CLASSIFICATION_RANK3_QUADRIC_FORMS_20261107.json` の横断ケースである。
他の二ケースの線形空間は今回再計算していない。
初回producerの全bytesは`reports/CLASSIFICATION_DOUBLE_QUADRIC_SOURCE_20261107.json`の

## 2. Pfaffian 条件の正確な帰結

rank4 条件を Pf(α)=k Q^2、k≠0 と書く。
Ω=dθ+t du∧dv と置くと、Ω は定数二形式で

    α = Q Ω − dQ∧θ.

臨界アフィン平面 R={u=v=0} では Q=1、dQ=0 なので α=Ω。
従って Pf(Ω)=k≠0 であり、Ω はシンプレクティックである。
一意なアフィンベクトル場 Z を i_Z Ω=θ で定める。
四次元の外積恒等式

    dQ∧i_Z Ω∧Ω = (ZQ/2) Ω^2

から

    Pf(α) = Pf(Ω) Q(Q−ZQ)

を得る。Pf(α)=kQ^2 と Pf(Ω)=k を合わせると ZQ=0。
これは Q≠0 上の議論だけでなく多項式恒等式である。
また Cartan の公式から

    L_Z Ω = dθ = Ω−t du∧dv.

U=(u,v)、r=(z,w) と分けると、ZQ=0 は

    Z(U,r) = (A U, C U+D r+v_R),    A∈so(u^2+v^2)

と同値である。特に tr A=0 である。
Ω の行列を J、Z の線形部分を M=[[A,0],[C,D]] とすれば、残る条件は

    M^T J+J M = J−t diag(E,0),    E=[[0,1],[-1,0]].

## 3. Ω の R への制限が非退化な場合

R の Ω 直交補空間を選ぶ変更は、U を固定し r を r+K U に変える線形座標変更で実現できる。
これは Q を保つ。従って J=diag(a E,b E)、a b≠0 としてよい。
上の行列式の交差ブロックから C=0、R ブロックから tr D=1、U ブロックから t=a を得る。

Ω、A、t、v_R を固定し、

    D_s=(1−s)D+(s/2)I_2

と置く。全ての s で tr D_s=1 なので全条件を保ち、D_1=I_2/2 は可逆である。
従って D_s が可逆なパラメータは非空開集合をなす。

## 4. R が Ω に関して Lagrange 平面である場合

R は二次元なので、制限の退化は制限が零であることと同じであり、この二場合分けで尽くされる。
Ω の非退化性により U と R の交差行列は可逆である。
U を固定して R の基底だけを変更し、

    J=[[T,I_2],[-I_2,0]],    T^T=−T

としてよい。この変更も Q を保つ。条件の各ブロックは

    D=I_2−A^T,    C−C^T=T−t E

となる。二次元の恒等式 A^T T+T A=(tr A)T=0 を用いた。
従って Ω、C、t、v_R を固定して

    A_s=(1−s)A,    D_s=I_2−A_s^T

と置けば全条件を保ち、D_1=I_2 は可逆である。
この変形に t の調整や追加の仮定は要らない。

## 5. 既存の β=0 被覆への接続

どちらの場合も Z_s と θ_s=i_(Z_s)Ω は s の多項式族であり、
α_s=QΩ−dQ∧θ_s は全て閉性と Pf(α_s)=kQ^2 を満たす。
Ω と k は固定されている。四次元の逆行列公式により、
ω_s=α_s/Q^2 の逆 Poisson 二ベクトルは

    π_s = Q^2 α_s^(-1) = α_s^∨/k

となる。ここで α^∨ は符号規約を固定した、α の相補係数による線形反対称行列である。
従って π_s は s に多項式的で、アフィン座標次数2以下の大域射影 Poisson 族を与える。
Q=0 上の点を取り除いた族にしていない。

D_s が可逆なら、p_s=(0,−D_s^(-1)v_R)∈R は Z_s の零点である。
R に沿う平行移動で p_s を原点へ移す。この変換は Q と H を保つ射影変換である。
移動後は θ_s の定数項が零なので、α_s、従って π_s は定数項と二次項だけを持つ。
定数項は非退化であり、線形変換で J に正規化すると S61 の一次 jet β=0 に入る。

既知52閉包の有限和を C とする。既存の β=0 被覆と PGL5 不変性により、
D_s が可逆な非空開集合の全 π_s は C に属する。C は閉集合だから、その特殊化 π_0 も C に属する。
平行移動の係数が s=0 で発散しても、元の多項式族 π_s は全 A^1 上に定義されているため問題はない。
これでこの横断二重二次曲面層の全点が既知閉包で覆われる。

残る依存は既存の β=0 全支持被覆（Q45_22、MPS および既知成分の定理）と、
退化因子から上記逆二形式へ移る標準的な同定である。
本査読はその旧分類定理を再証明したものではなく、今回の全90係数計算と新しい変形の矢印を独立確認した。
