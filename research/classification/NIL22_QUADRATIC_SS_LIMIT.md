# nil22 image・quadratic_A の全磁気正規化と停止した SS20 接続

2026-11-07。対象は全十一源の独立確認済み分類の `quadratic_A` である。
本ノートは全七変数源の磁気正規化を証明し、一つの有限 SS20 接続法が
一般パラメータでは成立しないことを記録する。成分への非所属は主張しない。

## 1. 全七変数と正規化の補集合

座標を `(q1,q2,x,y)` とし、`a=λ−1/2`, `b=−λ−1/2` とおく。
`a+b=−1` であり、六磁気係数は独立な `m0,...,m5` である。

```
M = [[a*x², 1+b*x*y], [1+a*x*y, b*y²]],
{q1,q2} = F0+b*y*q1−a*x*q2,
F0 = m0+m1*x+m2*y+m3*x²+m4*x*y+m5*y²,
{qi,pj}=Mij,  {x,y}=0.
```

実 Pfaffian は `1−xy`、modular field は
`N=x∂q1+y∂q2` である。全七変数の Jacobi 恒等式は既存の全源検証で確定している。
`ab≠0` では次の可逆 affine 変換により、他の五磁気係数が消える。

```
q1' = q1+L1,  L1=m2/b−m4*x+m5*y/(2*b),
q2' = q2+L2,  L2=−m1/a−m3*x/(2*a),
x'=x, y'=y.
```

六括弧すべての変換恒等式を保ったまま、新しい磁気項は `I=m0+m4` となる。
さらに `I≠0` で `q'=q/I` と tensor の `I` 倍を行えば `F0=1` になる。
続いて `q1'=q1+x` とすると、磁気項は `xy` になる。この最後のテンソルを
`P0` と書く。その原点での定数交代形式は
`C=∂q1∧∂y+∂q2∧∂x`、Pfaffian は 1 である。

`I=0` を消去したとの解釈はしない。固定した一般の `λ` で `F0=t` は
すべての `t` に対する実 Poisson 曲線であり、`t=0` もその閉包に含まれる。
`λ=±1/2` を含む残りの補集合も、元の既約な `A7` 全源の稠密開集合の閉包に
入る。したがって、一般の `λ` に対し `P0` が既知の有限閉成分和に入ると
別途証明できれば全七変数源に拡張できる。この所属自体は未解決である。

## 2. 試した有限の実族

`H=diag(−1,−1,1,1)`、`N(q1,q2,x,y)=(x,y,0,0)` とし、

```
gτ=1+N/(2τ),   Pss=C+τ*A+τ²*B
```

を試した。`A,B` は全ての `H` 重み零の斉次二次 bivector とする。それぞれの
空間は厳密に 22 次元であり、未知係数は 44 個である。
`gτ` は symplectic で、`gτ*(τH)*gτ⁻¹=N+τH` を満たす。
この重みでは pushforward の Laurent 負次数は高々 `τ⁻1` なので、次を
有限個の係数条件として完全に課した。

- `div A=H`, `div B=0`、および `C` との compatibility。
- `gτ_*Pss` の全負冪の消滅と `τ=0` での全六括弧 `P0` との一致。
- `Pss` の全 `τ` に対する厳密な Jacobi 恒等式。

これは jet の有限次数だけを調べる方法ではない。成功すれば literal な
全 `τ` Poisson 多項式族になるように全条件を課したが、この指定した族は失敗した。
`τ` の次数は増やしていない。

## 3. 一般パラメータでの明示的な矛盾

最初の全線形条件は `76×44`、rank 34 であった。残る自由変数は十個だが、
`A` への射影は二変数 `r19,r21` のみで、全六括弧は計算報告に保存した。
全 Jacobi ideal の `QQ(λ)` 上の Gröbner 基底は `(1)` である。
この不整合は巨大な基底に依存せず、直接三係数で読める。

`J_A(q1,q2,x)` の係数のうち、

| 空間 monomial | 実際の係数 |
| --- | --- |
| `q1²*x` | `4λ*r19` |
| `q1*q2*y` | `−8λ*r21` |
| `q1²*y` | `−16*r19*r21−1` |

を別の小プログラムで六括弧から直接再構成した。一般の `λ≠0` なら前二式から
`r19=r21=0`、第三式から `−1=0` となる。正規化後の unit ideal 恒等式は

```
1=16*(r19*r21+1/16)−16*r21*r19.
```

`Jac(C+τA+τ²B)` の `τ²` における空間三次部分は `Jac(A)` であり、
空間一次の `[C,B]` では打ち消せない。従って上の矛盾は、保存した全線形解を
満たすどの `B` の選択に対しても有効である。
`λ=0` 等の特殊値だけにおけるこの ansatz の可否は今回の結論に含めない。

この結果が除外するのは、指定した `H`、重み、定数項、次数二、端点条件を持つ
一般パラメータの SS20 接続だけである。より一般の実族、他成分への所属、
quadratic_A の未解決性を解消したとは主張しない。このルートはここで停止する。
