# T(w)=0 の全源は、既知59個とは異なる成分に入る

2026-11-07。主課題 E_quadric3。
**全 Poisson 空間には、既に個別証明した59成分とは異なる既約成分が少なくとも一つ存在する。**
従って、この弱い存在論だけでも成分数下界60が従う。
本ノートの議論は、以下の閉既約族 Z 自身の成分性や正確な次元を前提としない。
それらは別の `RANK3_TWZERO_COMPONENT.md` で、三法線の支持計算により
**Z が24次元の全成分であることまで証明済み**である。
ここではその強い結果と独立な非包含の証明を保持する。全成分の網羅性は未証明である。

## 1. 実際の既約源と全周囲の次元評価

`RANK3_TANGENT_ZERO_TW_RESTRICTION.md` は、Q=w+u²、T(w)=0 の全逆形式支持を
`SL2×Gm×A7` という既約な源で覆う。
閉性、全六余剰クラスからの制約、全点への全射性は同ノートの証明を入力とする。
`classification_rank3_twzero_source.py` はその全パラメータで閉性と
`Pf(α)=−δQ²` を確認しており、δ≠0の全源が実際の一般 rank4 Poisson 構造を与える。
その PGL5 飽和の射影閉包を Z とする。Z は閉既約である。

SL2 の chart `d=(1+bc)/a` を用いて

\[
 a=b=c=1,\quad \delta=D=D_0=S=2,\quad C=g=T_0=T=1
\]

とした点を P* とする。これは以下の逆形式から得られる点である。

\[
\begin{aligned}
 r&=w(2v+z+w),\\
 \beta&=(1+u)du+(2u+3w)dv+(2u+w)dz
             +(2u+2v+z+w)dw,\\
 \alpha&=Qd(\beta+u\,dr-r\,du)
              -dQ\wedge(\beta+u\,dr-r\,du).
\end{aligned}
\]

全150係数・全350射影 Jacobi 式での検査は、次の QQ 階数を与える。

| 行列 | 階数 |
|---|---:|
| 全350×150微分 D | 98 |
| Euler-vertical | 24 |
| 鉛直・全GL・scalar | 47 |
| 上記と全11個の実源微分 | 49 |

`D F=0` は全係数の整数恒等式で確認し、微分列の分母払い尺度を記録した。
従って `dim Z≥49−24−1=24`。
全射影 Zariski 接空間次元は `150−98−24−1=27` である。
ここで接空間上界と族下界は一致しておらず、滑らかさは結論しない。

Z を含む全 Poisson 空間の既約成分 C を一つ選べば、P*∈C であるため

\[
 24\le\dim Z\le\dim C\le27.                   \tag{1}
\]

下の議論は、この C が既知59成分のどれとも一致しないことを示す。
C の一意性も、Z=C もここでは必要としない。

## 2. 全閉包に適用できる退化因子の条件

Z の稠密な実源では退化五次式は非零な `LQ²` であり、Q の階数は三である。
射影的な積写像

\[
 \mathbb P(V^*)\times
 \{[Q]\in\mathbb P(\operatorname{Sym}^2V^*):\operatorname{rank}Q\le3\}
 \longrightarrow \mathbb P(\operatorname{Sym}^5V^*),\quad(L,Q)\mapsto LQ^2
\]

の像は閉である。零を含む affine cone の逆像を取れば、
退化五次式が零になる rank2 境界も含めて、全 Poisson 係数空間で閉条件となる。
従って Z の**全閉包**はこの条件を満たす。特に rank4 の部分では退化因子は非被約である。

* 射影次元が24未満の既知成分は、(1)により Z を含めない。
  新たに個別証明された mixed 22次元成分もこの場合に含む。
* 次元24の既知成分は MPS の8成分と CPLUS_EXT である。
  もし Z がその一つに含まれれば、次元と閉既約性により Z はその成分そのものになる。
  MPS の各成分は被約 SNC 退化因子を持つ点を含み、CPLUS_EXT の一般元は
  相異なる因子を持つ `H+Q1+Q2` である。いずれも上の閉非被約条件に反する。

従って残る高次元 rank4 成分だけを調べればよい。
T01 は25次元で、退化五次式が五つの一次式の積であるという閉条件を全閉包で満たす。
CA と NEW25 は三乗の一次因子を持つという閉条件を満たし、
CB は `LL1²L2²` という全て一次因子の閉条件を満たす。
P* の退化式は `−2h(hw+u²)²` で、Q は既約、h と Q は異なる。
従って P* はこの四種類の閉条件のどれも満たさず、Z はこれらに含まれない。
NEW25 について必要なのは三乗一次因子条件であり、一般退化式が純五乗だとはしない。

残る既知の高次元 rank4 成分は T39,T40 であり、次節で排除する。
既知六 rank2 成分は全閉包が `π∧π=0` に含まれるので、P* の一般階数4から除外される。

## 3. T39 と T40 の全閉 graph からの厳密な排除

P* を S61 へ送る際、基点・評価値・有限 perspective を全て処理した。
まず affine 点 `(u,v,z,w)=(0,0,0,1)` を原点へ移す。
この点での交代値は

\[
 K=\begin{pmatrix}
 0&1&-2&0\\-1&0&6&-4\\2&-6&0&6\\0&4&-6&0
 \end{pmatrix},\quad\operatorname{Pf}(K)=-2.
\]

次の rational Darboux frame は `SKSᵗ=J` を満たす。

\[
 S=\begin{pmatrix}
 1&0&0&0\\0&1&0&0\\6&2&1&0\\2&0&0&-1/2
 \end{pmatrix}.
\]

その後の有限 perspective は `(7/3,0,0,−1)` である。
正規化した全150係数は元の S61 復元写像と quotient 内で一致し、元の全134式も零である。
従って接空間や一部 jet だけを既知認識式へ代入した結果ではない。

全45座標の多項式 graph に対して

\[
 (q-Q_{51})_{u_1}=-31/4,\qquad
 (q-Q_{52})_{u_6}=-1.                          \tag{2}
\]

が得られた。添字は S61 の1始まりの u 座標である。
T39 では12座標、T40 では6座標が非零であり、全45残差は report に保存した。

`Q51_UNIVERSAL_SECTION_REVIEW_20261101` と `Q52_UNIVERSAL_SECTION_REVIEW_20261101`
は、それぞれの graph が全 W16 上に定義された閉 graph であり、
**全被約 S61 成分** T39,T40 に等しいことを証明している。
前者は全パラメータ恒等式と既知滑らか点、後者は全域の一意な二次延長と既知の稠密開から
閉包の同定へ進んでいる。密な源 chart だけの認識式ではない。
固定非退化評価値・perspective の全域 S61 正規化と、連結安定化群による全成分の対応は
`C0_S61_SLICE_SCALAR_AUDIT_20261106.md` の依存を用いる。
従って(2)は P* が全射影 T39,T40 の両成分から外れることを意味する。

この診断は一点から**非包含**を示すために用いる。
仮に一点で graph 値が一致しても、全源の包含を推論することはできないが、
今回は両方が非零なので Z の非包含には十分である。

## 4. 独立な存在下界と成分定理への接続

以上で、Z を含む既約成分 C は既知59成分のどれでもない。
従って少なくとも60個の既約成分が存在する。
この節までの証拠だけなら C の次元評価は24から27の範囲である。

`RANK3_TWZERO_COMPONENT.md` は、P* における**真の49次元実族に横断する三変数形式切片**
を取り、全 D の98方向を形式陰関数で消去して、その支持が零次元であることを示した。
群方向47だけでなく実源の二方向も保持した切片であり、独立な有限係数再検証も完了した。
この追加証拠により Z 自身が24次元全成分と確定するが、
本ノートの存在下界の証明は、その追加証拠に依存しない。
