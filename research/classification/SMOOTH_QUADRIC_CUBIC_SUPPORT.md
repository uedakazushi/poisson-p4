# 滑らかな二次曲面と三次曲面：正規Hamiltonian場による全源

2026-11-07。課題 E_reduced_nonnormal。
実退化因子 D=q c、q は階数5の二次式、c は既約三次式とする。
このノートは全型の分類ではない。正則半単純な正規Hamiltonian場の全支持を
MPS40 の和へ覆い、それ以外の有限 Jordan 型を明示して保持する。

## 1. 全支持に適用する入口と固有値制限

P4 の構造の標準的な発散零二次 lift を Π とする。五次の実退化式 D は Π の Casimir。
q,c は互いに素なので `{D,f}=0` から `{q,f}=q X(f)` となる線形場 X が存在する。
反対称性から Xq=0、また `{q,D}=0` から Xc=0。
X=0 なら q,c は独立な二つの Casimir となり Π の階数4と矛盾する。
よって X は非零な so(q) の元である。Poisson 恒等式から `[X,Π]=0`。
この条件は特定の restriction fiber や最高部だけの仮定ではなく、全 Π に必要である。

X の半単純部の固有値を `(0,a,−a,b,−b)` とする。
ab≠0 で a≠±2b、b≠±2a なら、weight零の三次単項式はすべて
零固有座標 x0 で割り切れる。実際、x0 を含まない三つの非零重みの和が零になるには、
同じ重み二つと他方の反対符号の重みが必要で、ちょうど上の比2の条件となる。
a=±b≠0 の場合にも三つの重みの和は零にならない。
従って c の既約性から、非零半単純部は次の二型だけである。

1. 正則半単純型 `(0,1,−1,2,−2)`。X の冪零部は零。
2. 半単純部分の階数2。零固有空間は三次元で、その so3 冪零部は零または Jordan3。

純冪零の場合は so5 の非零型 `(5),(3,1,1),(2,2,1)` をすべて残す。
入口とこの固有値列挙は別担当が独立に読解した。

## 2. 正則半単純型の全二次 lift

q=x0²+x1x2+x3x4、X=diag(0,1,−1,2,−2) と正規化する。
全150係数のうち `[X,Π]=0` を満たす単項式は20個。
`div Π=0` と `dq_i Π^{ij}=q X^j` の全25係数式は階数15で、
全解を五変数 a,b,u,v,t で次のように書ける。

| ij | Πij |
|---|---|
| 01 | a x2 x3/2 − (u+v+1)x0 x1 |
| 02 | b x1 x4/2 + (u+v+1)x0 x2 |
| 03 | −b x1²/2 − (t+4)x0 x3 |
| 04 | −a x2²/2 + (t+4)x0 x4 |
| 12 | −(2u+2v+3)x0² − x1 x2 + (u+v−1)x3 x4 |
| 13 | (t−u+2)x1 x3 |
| 14 | a x0 x2 − (t+v+2)x1 x4 |
| 23 | b x0 x1 + u x2 x3 |
| 24 | v x2 x4 |
| 34 | −(2t+10)x0² + t x1 x2 − 2x3 x4 |

全十 Jacobi 多項式の係数の QQ 線形包は、次の五式の線形包と一致する。

    ab = 0,
    a(u+1) = 0,
    b(v+t+3) = 0,
    t(u+v−1) = 0,
    8t(u+v)+30(u+v)+7t+20 = 0.

特にこれは元方程式と同値な全支持条件である。
最後の二式により、(t,u+v) は (0,−2/3) または (−10/3,1)。
残る三式を分けると、全解は次の六本の affine line の和となる。z は任意。

| 枝 | (a,b,u,v,t) |
|---|---|
| I0 | (0,0,z,−z−2/3,0) |
| Ia | (z,0,−1,1/3,0) |
| Ib | (0,z,7/3,−3,0) |
| II0 | (0,0,z,1−z,−10/3) |
| IIa | (z,0,−1,2,−10/3) |
| IIb | (0,z,2/3,1/3,−10/3) |

全枝で全 Jacobi が恒等的に零である。
五つの符号付き Pfaffian minor が dD に等しい規約で、D=q c、c は順に

    (10/3)x0(x0²+x3x4),
    (20x0³+20x0x3x4−3z x2²x3)/6,
    (20x0³+20x0x3x4+3z x1²x4)/6,
    (10/3)x0(x0²+x1x2),
    (20x0³+20x0x1x2−3z x2²x3)/6,
    (20x0³+20x0x1x2+3z x1²x4)/6.

I0,II0 と各 z=0 の補集合も捨てていない。
既約三次を要求する元の型では四つの非零 arm だけが残るが、次の被覆は六源全部に成立する。

## 3. 六つの全源を既知 MPS 成分へ入れる実軌道極限

対角変換 `g_epsilon=diag(epsilon^w0,...,epsilon^w4)` を用いる。
Πij の単項式 x^m に付く指数は wi+wj−Σ mk wk である。
各源全体に対し次の重みを選ぶ。

| 枝 | 重み w |
|---|---|
| I0,Ia | (0,3,0,1,1) |
| Ib | (0,0,3,1,1) |
| II0,IIa | (0,2,0,1,2) |
| IIb | (0,0,2,2,1) |

上の全括弧を比較すると、全指数は非負であり、指数零の項は全て xixj の定数倍である。
従って epsilon=0 へ正則に延びる真の projective Poisson 軌道族が得られる。
どの源のどの z でも、極限の実退化式は

    D_limit = (10/3) x0 x1 x2 x3 x4

であり、五独立超平面の SNC 因子である。
元の点を通る全既約成分は、PGL5 の連結性によりその軌道と閉包を含む。
ゆえにその成分は SNC locus と交わり、MPS の全成分定理により既知40成分の一つである。
これで正則半単純型の全支持が覆われる。成分を新しく加える必要はない。

## 5. 外部文献との接続範囲

Loray–Pereira–Touzet, arXiv:1112.3871v3, Theorems 5.2 and 9.1
（本文 pp.14,22、一次資料を確認）は、滑らかな三次元 quadric 上の Poisson 空間を
Rat(1,2), Log(1,1,1), Aff の三成分に分類する。
この結果だけから P4 への全延長を覆うことはできないので、上では全 lift を直接保持した。
残る Jordan 型への別の入口として利用できるが、generic restriction のみの分類を
ambient 全支持へ無断に拡張しない。
