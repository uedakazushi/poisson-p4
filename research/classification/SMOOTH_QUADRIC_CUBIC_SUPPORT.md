# 滑らかな二次曲面と三次曲面：正規Hamiltonian場による全源

2026-11-07。課題 E_reduced_nonnormal。
実退化因子 D=q c、q は階数5の二次式、c は既約三次式とする。
正則半単純な正規Hamiltonian場の全支持をMPS40の和へ覆い、
他の全Jordan型を既約三次因子条件から除外する。
§7までの証明は全型を扱い、全線形源・必要Jacobi係数・除外の独立検証も完了した。
特異な二次因子、可約な三次因子、他の次数分割へこの結論を拡張しない。

## 1. 全支持に適用する入口と固有値制限

P4 の構造の標準的な発散零二次 lift を Π とする。五次の実退化式 D は Π の Casimir。
q,c は互いに素なので `{D,f}=0` から `{q,f}=q X(f)` となる線形場 X が存在する。
反対称性から Xq=0、また `{q,D}=0` から Xc=0。
X=0 なら q,c は独立な二つの Casimir となり Π の階数4と矛盾する。
よって X は非零な so(q) の元である。Poisson 恒等式から `[X,Π]=0`。
この条件は特定の restriction fiber や最高部だけの仮定ではなく、全 Π に必要である。

X の半単純部の固有値を `(0,a,−a,b,−b)` とする。
ab≠0 で a≠±2b、b≠±2a なら、weight零の三次単項式はすべて
零固有座標 x0 で割り切れる。実際、x0 を含まない三つの非零重みの和が零になるには、
同じ重み二つと他方の反対符号の重みが必要で、ちょうど上の比2の条件となる。
a=±b≠0 の場合にも三つの重みの和は零にならない。
従って c の既約性から、非零半単純部は次の二型だけである。

1. 正則半単純型 `(0,1,−1,2,−2)`。X の冪零部は零。
2. 半単純部分の階数2。零固有空間は三次元で、その so3 冪零部は零または Jordan3。

純冪零の場合は so5 の非零型 `(5),(3,1,1),(2,2,1)` をすべて残す。
入口とこの固有値列挙は別担当が独立に読解した。

## 2. 正則半単純型の全二次 lift

q=x0²+x1x2+x3x4、X=diag(0,1,−1,2,−2) と正規化する。
全150係数のうち `[X,Π]=0` を満たす単項式は20個。
`div Π=0` と `dq_i Π^{ij}=q X^j` の全25係数式は階数15で、
全解を五変数 a,b,u,v,t で次のように書ける。

| ij | Πij |
|---|---|
| 01 | a x2 x3/2 − (u+v+1)x0 x1 |
| 02 | b x1 x4/2 + (u+v+1)x0 x2 |
| 03 | −b x1²/2 − (t+4)x0 x3 |
| 04 | −a x2²/2 + (t+4)x0 x4 |
| 12 | −(2u+2v+3)x0² − x1 x2 + (u+v−1)x3 x4 |
| 13 | (t−u+2)x1 x3 |
| 14 | a x0 x2 − (t+v+2)x1 x4 |
| 23 | b x0 x1 + u x2 x3 |
| 24 | v x2 x4 |
| 34 | −(2t+10)x0² + t x1 x2 − 2x3 x4 |

全十 Jacobi 多項式の係数の QQ 線形包は、次の五式の線形包と一致する。

    ab = 0,
    a(u+1) = 0,
    b(v+t+3) = 0,
    t(u+v−1) = 0,
    8t(u+v)+30(u+v)+7t+20 = 0.

特にこれは元方程式と同値な全支持条件である。
最後の二式により、(t,u+v) は (0,−2/3) または (−10/3,1)。
残る三式を分けると、全解は次の六本の affine line の和となる。z は任意。

| 枝 | (a,b,u,v,t) |
|---|---|
| I0 | (0,0,z,−z−2/3,0) |
| Ia | (z,0,−1,1/3,0) |
| Ib | (0,z,7/3,−3,0) |
| II0 | (0,0,z,1−z,−10/3) |
| IIa | (z,0,−1,2,−10/3) |
| IIb | (0,z,2/3,1/3,−10/3) |

全枝で全 Jacobi が恒等的に零である。
五つの符号付き Pfaffian minor が dD に等しい規約で、D=q c、c は順に

    (10/3)x0(x0²+x3x4),
    (20x0³+20x0x3x4−3z x2²x3)/6,
    (20x0³+20x0x3x4+3z x1²x4)/6,
    (10/3)x0(x0²+x1x2),
    (20x0³+20x0x1x2−3z x2²x3)/6,
    (20x0³+20x0x1x2+3z x1²x4)/6.

I0,II0 と各 z=0 の補集合も捨てていない。
既約三次を要求する元の型では四つの非零 arm だけが残るが、次の被覆は六源全部に成立する。

## 3. 六つの全源を既知 MPS 成分へ入れる実軌道極限

対角変換 `g_epsilon=diag(epsilon^w0,...,epsilon^w4)` を用いる。
Πij の単項式 x^m に付く指数は wi+wj−Σ mk wk である。
各源全体に対し次の重みを選ぶ。

| 枝 | 重み w |
|---|---|
| I0,Ia | (0,3,0,1,1) |
| Ib | (0,0,3,1,1) |
| II0,IIa | (0,2,0,1,2) |
| IIb | (0,0,2,2,1) |

上の全括弧を比較すると、全指数は非負であり、指数零の項は全て xixj の定数倍である。
従って epsilon=0 へ正則に延びる真の projective Poisson 軌道族が得られる。
どの源のどの z でも、極限の実退化式は

    D_limit = (10/3) x0 x1 x2 x3 x4

であり、五独立超平面の SNC 因子である。
元の点を通る全既約成分は、PGL5 の連結性によりその軌道と閉包を含む。
ゆえにその成分は SNC locus と交わり、MPS の全成分定理により既知40成分の一つである。
これで正則半単純型の全支持が覆われる。成分を新しく加える必要はない。

## 6. 零固有空間が三次元の非冪零型

### 6.1 半単純場の全十一変数源

q=x0²+x1²+x2²+x3x4、S=diag(0,0,0,1,−1) とする。
U=(x0,x1,x2)、y=x3、z=x4、f=UᵗU と書く。
全46個の S 不変二次係数に発散零と q-normal 条件を課すと、
61係数式の階数は35。全解は ℓ=(l0,l1,l2) と tr A=−1 の3行列 A により

    Π_UU = (ℓ·U) J_U − yz K_ℓ/2,
    Π_Uy = y A U,
    Π_Uz = z(K_ℓ−A) U,
    Π_yz = 2 Uᵗ A U − f − yz,

となる。ここで J_U の上三角成分は `(x2,−x1,x0)`、
K_ℓ の上三角成分は `(l2,−l1,l0)`。
全線形条件を恒等的に満たし、十一個のsource方向は独立なので全解である。
残る全Jacobi係数は ℓ に一次、A にaffine一次である。

ℓ=0なら全Jacobiを満たすが、Πは AU,∂y,∂z の三場上の二ベクトルとなり階数2以下。
ℓ≠0 を SO3 で非等方・等方の二型へ移す。
非等方では ℓ=(a,0,0)、a≠0 とでき、Jacobi条件の二つは

    A00+2=0,  8A00+1=0

となって矛盾する。
等方では ℓ=(1,i,0) とできる。Aの独立座標をrunnerの m0,…,m7 で書けば、
次の五つの必要条件だけで矛盾する。

    m0+i*m3+2=0,       8m0+2i*m3+1=0,
    m1+i*m4+2i=0,      2m1+8i*m4+i=0,
    2m0+2m4+3=0.

最初の四式から m0=m4=1/2、最後の式は5=0を要求する。
したがって S のみを q-cofactor とする全Poisson sourceに rank4 は存在しない。

### 6.2 半単純場に非零冪零部がある場合

零三次元block上の非零冪零元は全て次の N と SO3 共役である。

    N = [[0,0,-i],[0,0,1],[i,-1,0]],  N³=0, N²≠0.

五次元へ零で延長する。EをEuler場として

    Π_N = −(5/6)q N − (1/3) E∧(Nx)

を取る。第1項ではNを定数反対称二ベクトルと見ている。
直接に div Π_N=0、Π_N♯dq=qNx、[N,Π_N]=0 が成り立つ。
従って S+N を q-cofactor とする全線形源は前節の Π+Π_N で尽くされる。
Poisson性から [S+N,Π]=0 であり、線形表現のJordan分解により [S,Π]=[N,Π]=0。
前節の十一変数に全[N,Π]=0を課す階数8の線形系を解くと

    l0=−i*l1, l2=0,
    m0=−m4−2/3, m1=m3=−i*m4−i/3,
    m2=i*m7, m5=−m7, m6=−i*m7

となり、全三変数 l1,m4,m7 が残る。
全Jacobiには `3*l1+5i` と `l1*(3*m4+1)` の非零定数倍が現れる。
従って全解は l1=−5i/3、m4=−1/3、m7任意であり、
これを代入すると他の全Jacobiも恒等的に零になる。
五つの Pfaffian minor の勾配から得る実退化式は、全m7で

    D=(5/6)(x0+i*x1)(x0²+x1²+x2²) q.

三次因子は必ず可約なので、D=q*c、c既約三次という今回の型には入らない。
この一変数族自体は H+Q_rank3+Q_rank5 の別次数型として保持し、その成分帰属は未主張。

## 7. 純冪零の全三型を既約三次因子条件から除外する

全150二次係数に `div Π=0, Π♯dq=qN, [N,Π]=0` を課す。
三型の全線形源を、他の自由係数を捨てずに構成した。

| Nの型 | q | N | 全線形源の次元 |
|---|---|---|---:|
| (5) | x0x4−4x1x3+3x2² | x0∂1+2x1∂2+3x2∂3+4x3∂4 | 5 |
| (3,1,1) | x0x2−x1²+x3²+x4² | x0∂1+2x1∂2 | 11 |
| (2,2,1) | x0x3−x1x2+x4² | x0∂1+x2∂3 | 15 |

全括弧と全Jacobi係数は `CLASSIFICATION_SMOOTH_QUADRIC_NIL5_LINEAR_20261107.json`、
`...NIL311_LINEAR_...json`、`...NIL221_LINEAR_...json` に保存する。
各producerは全150線形解を元条件へ代入して全恒等式を確認し、自由係数を保持する。
Eulerで収縮したPfaffianはPoisson条件を課す前にはactual divisorと呼ばず、
全Jacobiを満たすときに勾配の原始式となることを使う。

### 7.1 正則冪零型 (5)

五自由係数をn0,…,n4とすると、全Jacobi係数の線形包は次の四式の線形包である。

    (n4−12)(n4−4),
    n2(3n4+4),
    16n2²+9n3n4+12n3,
    15n0n4+20n0+8n1n2+16n3².

全解は n4=4 または12、n0=n2=n3=0、n1任意。
n4=4では D=−x0q²/2、n4=12では D=0。
前者は既に被覆済みの二重smooth quadric型、後者はrank2以下であり、
既約三次因子cを持つ今回の型には点がない。

### 7.2 型 (3,1,1)

全十一変数の**線形源全体**で、Euler収縮Pfaffianはx0*qで割り切れる。
従ってJacobiを満たしてrank4になる任意の点のcは一次因子x0を持つ。
残る十一変数の非線形支持を解き切ることを、この除外の前提に追加しない。

### 7.3 型 (2,2,1)

u=x0、v=x2、w=x4、a=x1、b=x3 と置くと

    q=ub−av+w²,   N=u∂a+v∂b.

全十五源のbase括弧は三変数Jacobian PoissonテンソルJ_Fであり、

    F=A(u,v)w+B(u,v),
    A=(n8*u²+2n12*uv−n1*v²)/2,
    B=(n5*u³+3n7*u²v+3n10*uv²−n0*v³)/3,

すなわち `{u,v}=F_w, {u,w}=−F_v, {v,w}=F_u` である。

F=0なら全base括弧が零。
q-normal条件から、任意のbase座標rについて
`v{r,a}−u{r,b}=0` となり、u,vが互いに素なので
`{r,a}=uK_r,{r,b}=vK_r` と書ける。
Πは一つのbase場Kと∂a,∂bの三場上の二ベクトルとなりrank2以下。
従ってrank4ではF≠0である。

N不変な斉次三次式はすべて

    c=C(u,v,w)+q ℓ(u,v,w)

の形である。ここでCは三次、ℓは一次。
これはdegree3で直接確認できる：a,b次数1の係数は
`u A2+v B2=0` から `(A2,B2)=(-vℓ,uℓ)`。
a,b次数2以上の不変項は次数条件と同じ互いに素性により零となる。
ub−avをq−w²へ置き換えれば上の表示を得る。

D=qcがCasimirで、qのbase括弧が零なので

    J_F♯dℓ=0,   J_F♯dC=0.

係数qとbase多項式の比較はu≠0の函数体上で行い、多項式恒等式へ戻る。
ℓ≠0ならdF∧dℓ=0からF=αℓ³、F≠0によりα≠0。
さらにdC∧dℓ=0よりC=βℓ³なのでc=ℓ(βℓ²+q)は可約。
従ってc既約ならℓ=0。
dC∧dF=0とEuler恒等式から `F dC=C dF`、従ってC/Fは定数であり、cはFに比例する。
求める構造には**Fが既約三次**であることが必要である。

一方、全Jacobiの必要条件として次の三式が実際の係数に現れる。

    J0=n1*n8+n12²,
    J1=n0*n8+n1*n7+2n10*n12,
    J2=n1*n5−n10*n8+2n12*n7.

SL2を(u,v)と(a,b)の両方へ同じ行列で作用させれば、q,Nを保つ。
従ってbinary quadratic Aは、非零αを用いてαuv、αu²、または0へ正規化できる。
この正規化後も全十五源と上の必要条件を使用できる。

* J0はAの判別式なのでrank A≤1。従ってA=αuvの枝は空である。
* A=αu²なら n1=n12=0、n8≠0。J1=J2=0よりn0=n10=0、
  F=u²(αw+n5u/3+n7v)となる。
* A=0ならFはbinary cubicなので複素数体上で一次式に分解する。

いずれもFの既約性に反する。これで型(2,2,1)も除外される。
十五源の残る全Jacobiを解く必要はなく、必要な三条件で十分である。
