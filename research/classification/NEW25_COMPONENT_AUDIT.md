# NEW25 の成分性・既知成分との相異性：依存の監査と八初期式による上界

2026-11-07 JST。分類課題 A。`R4_POSITIVE_WEIGHT6_25`（以下 NEW25）について、
全 Poisson 空間の成分性と既知57成分からの分離に至る論理を再点検した。
新しい数学的簡約は、全局所次元の上界に必要な支持の計算を、既存の21初期式のうち
**八式、二つの三次恒等式、6×6整数行列式**へ縮めたことである。
旧 M2 の Hilbert 関数・Gröbner 基底・四次初期空間の完全性をこの上界には必要としない。
八式が全350式の真正 ordinary initial ideal に入ることと、全周囲の形式模型は、
既存の独立監査済み証明書を引き続き使う。

この監査は新成分を追加しない。既知58成分の下界に使う一成分の証明を簡約する。
全成分の尽くし、NEW25 の一般被約性、局所枝の一意性を結論しない。

## 1. 同じ全周囲空間における下界と上界

`Q_POSITIVE_WEIGHT6_NEW_FAMILY_20261103_v63_REVIEW` は、三変数
`QQ[n0,n1,n2]` 上で、全140 affine Jacobi と全350 strict canonical Jacobi を検査している。
canonical150係数のパラメータ次数は高々二であり、350式の次数0–4の検査は
全多項式恒等式の検査である。旧補助式 `(4/3)n0²n2` は実 Jacobi 条件ではなく、
この三変数族へ課されていない。したがって切断 jet を実族とみなす問題はない。

全 GL25・scalar・三族微分の150×29行列は、パラメータ原点で26次小行列式

\[
 -\frac{21267647932558653966460912964485513216}{784526490225}\ne0
\]

を持つ。既約源 `GL5×Gm×A3` の像の affine 閉包を Y とすれば、Y は既約錐、
`dim Y≥26` である。その射影化 Z は既約閉集合、`dim Z≥25` であり、
同じ原点の像である正 weight6 軸 eta=1 の点 P+ を含む。

上界側の `Q_POSITIVE_WEIGHT6_SMALL_MODEL_20261103_v63_REVIEW` は、
canonical150係数中の divergence 核126方向と**全350 Jacobi式**から出発している。
actual GL と scalar の23方向を非零小行列式で切り、103変数の形式横断模型を得る。
そこで線形化の95可逆方向を形式陰関数定理で解くと、八変数環

\[
 A=\mathbb C[[z_0,\ldots,z_7]]/I
\]

と全 projective 局所環の完成の間に、22変数の形式的に滑らかな因子を戻す関係がある。
残る255方程式を捨てた模型ではない。四次までの有限計算は、全形式環の
ordinary initial ideal `in(I)` に入る斉次式を取り出すためだけに用いる。

以下の補題により `dim A≤3`。したがって P+ における**全 projective Poisson**
局所次元は高々25となる。Z を含む全 Poisson 空間の既約成分 C を選べば P+∈C。
有限型既約複素多様体の閉点の局所次元はその次元なので

\[
 25\le\dim Z\le\dim C\le25.
\]

同次元の閉既約部分集合 Z⊂C は C 自身であり、NEW25 は全空間の25次元既約成分となる。
これは接空間次元を成分次元と同一視する議論ではない。P+ での滑らかさや他成分の不存在も使わない。

## 2. 八初期式だけによる横断次元上界

凍結済み `Q_POSITIVE_WEIGHT6_INITIAL4_20261103_v63/certificate.json.gz` の
`quadratic_generators` 五本、`cubic_new_generators` 八本、`quartic_new_generators`
八本をこの順に連結し、0始まりで `f0,...,f20` と書く。
使うのは

\[
 f_0,f_2,f_3,f_4,f_8,f_{16},f_{17},f_{18}
\]

だけである。これらが `in(I)` に属すことは上記の全350式の独立検証が与える。
この八式の零点集合を S と置く。`Spec gr(A)⊂S` なので `dim S≤3` を示せばよい。

### 2.1 二次式で二つの閉枝へ分ける

`a=z1,b=z5,c=z7` と書く。次の厳密な多項式恒等式がある。

\[
\begin{aligned}
a^3={}&(40a/21+720b/7-268c/21)f_2\\
 &+(488a/21-1440b/7+232c/3)f_3\\
 &+(-152a/7+480b/7-536c/7)f_4,\\
c^3={}&(-11a/42+20b/7+5c/21)f_2\\
 &+(19a/21-40b/7+4c/3)f_3\\
 &+(-8a/21+40b/21-26c/21)f_4.
\end{aligned}
\]

従って S の被約支持では a=c=0 であり、さらに

\[
 f_0|_{a=c=0}=-64b(z_4+2z_6).
\]

よって `b=0` と `z4+2z6=0` の**両方の閉枝**を残せばよい。局所化や未知の分母は使わない。

### 2.2 b=0 の枝

`u=z3,v=z4,w=z6` と置き、次の整数係数四次式を用いる。

\[
 f=8224f_{16}|_{a=b=c=0},\qquad
 g=30840f_{18}|_{a=b=c=0}.
\]

これらは z0,z2 に依らない。全係数は新 report に保存している。
u の三次式として f の最高係数は `−3531600(v+2w)`。
その定数係数を v=−2w に制限すると `−194040w⁴` となる。
従って f の係数内容は `C[v,w]` で単元である。

(v,w)=(1,0) では

\[
\begin{aligned}
 f&=-3531600u^3-826470u^2-64737u-1632,\\
 g&=6277500u^3-12424050u^2-1322145u-32268.
\end{aligned}
\]

この二つの三次式の6×6 Sylvester行列の行列式は

\[
 -69250121673542498866103739000000\ne0.
\]

したがって `C(v,w)[u]` での resultant は非零であり、u の正次数を持つ共通因子はない。
f の係数内容が単元なので `C[u,v,w]` においても f,g は互いに素である。
ゆえに三次元 affine 空間内の V(f,g) の次元は高々一である。
自由な z0,z2 を戻して、この枝の次元は高々三となる。

### 2.3 z4+2z6=0 の枝

`a=c=0,z4=−2z6` の上で

\[
 f_8=-\frac83bz_6^2.
\]

b=0 なら既に扱った枝である。残る支持は z6=0、従って z4=0 に含まれる。
この上で

\[
 f_{17}=1433272320bz_2^3.
\]

再び b=0 なら既処理であり、残りは線形三平面

\[
 L=V(z_1,z_2,z_4,z_6,z_7)
\]

に含まれる。従ってこの枝も次元高々三。以上より `dim S≤3` が得られた。
八式が initial ideal を生成する必要はなく、零点集合が真の tangent cone より大きくても上界は有効である。

## 3. 五つの高次元既知閉成分からの分離

既知51個の一般 rank4 成分で次元25以上のものは、T01,T39,T40（各25）と
CA,CB（各28）である。他46個の次元上界24は、既存カタログ・元定理の依存である。
像微分の rank 下界だけからこの「他46個の上界」を取り出してはいない。
追加11個の元定理の監査は別 packet の対象であり、このノートではその結果を再証明しない。

| 閉成分 | P+ を除く証拠 | 全閉包への適用根拠 |
|---|---|---|
| T01 | 真の closed jet の403項関係式が `−1163264/135` | 全274式空間の Sp4 根作用不変性と稠密 coframe 恒等式。discriminant の局所化を使わない |
| CA,CB | `rank Kβ=3` の唯一の核線を運ぶと、両閉 β 制約に非零 `3/2` | 全被約 CA/CB を覆う proper 閉直線入射。全候補線が核内にある |
| T39,T40 | 軌道閉包にある Q_(8/9) が全域 graph 条件を満たさない | 全域 polynomial graph＝全被約 S61 成分、および PGL 不変閉性 |

CA/CB の閉入射については `AMBIENT_FULL_FIRSTJET_FIBERS_20261103_v63` と同 REVIEW
を確認した。固定線の像は全方程式を持つ閉 A16 であり、連結 parabolic 不変性から
`Sp4×^P A16⊂P3×S61` は閉となる。射影が proper で、核線の一意な rank3 開における
次元19から全19次元被約成分へ一致する。従って今回の不一致は単一の源 chart の失敗ではない。

T39,T40 では `Q51_UNIVERSAL_SECTION_REVIEW_20261101` と
`Q52_UNIVERSAL_SECTION_REVIEW_20261101` の閉 graph 同定を使う。
前者は全16変数での Jacobi 恒等式と既知滑らか点、後者は全域の一意な二次延長と
既知 T40 の稠密開から、各 graph を全被約成分と同定している。
物理的 Q_a の正規化における graph 残差は45座標中の一座標だけで

\[
 q-Q_{51}=\frac{9a-2}{2a^2},\qquad
 q-Q_{52}=\frac{9a+8}{2a^2}.
\]

a=8/9 は両方で非零。有限群作用
`diag(1,t,t²,t³,t⁴)_*P_eta / t⁵=P_(eta/t⁶)` は全150係数で検証済みである。
非零 eta は一軌道で、実多項式曲線の eta=0 極限が Q_(8/9) である。
もし P+ が一方の閉 PGL 不変成分に属せば、その極限も属して矛盾する。

P+∈Z を各既知閉成分から一つずつ除くことは、Z とその成分が相異なることの十分条件である。
Z が既知成分と交わらないという結論は不要であり、主張していない。
残る既知六 rank2 成分は rank≤2 という閉条件に全体が入り、P+ の実 quintic
`−16h⁵/81≠0` から Z と相異なる。従って既知57個に対する NEW25 の追加は正当である。

## 5. 独立した支持論の点検

例外幾何担当者が第2節と新実装・出力を独立に読み、閉枝の分割と次元評価を確認した。
f の u 最高係数は一次既約式 v+2w の非零倍なので、係数内容の非単元因子はこの式に限られる。
定数係数の v=−2w 制限が零でないため、その可能性が消える。
この内容の確認と非零 Sylvester 行列式を組み合わせることが必要であり、単一の特殊化だけで
三変数多項式の互いに素性を主張していない。二つの閉枝では b=0 を常に残し、b≠0 への
局所化に依存せず線形三平面への包含を得る。真正初期式への包含を既存の全350式検証に
依存させる区別も適切である。全旧有限証明書をこの点検で再実行したものではない。
