## vertexと四変数core

元座標は(a,b,c,u,v)。保存した十括弧ではbがb-row以外に出ないので、[b]は射影Poissonの二位以上の零点である。raw一成分の非零から射影rankを推論しない。

```

```

とおく。Π−E∧Rはb非依存のQ(a,c,u,v)+∂b∧Wとなる。

```

W_c=−432ac+96av+20uv
W_u=−288au−540c²+1440cv−420v²

```

## vertex移動と残るEuler gauge

vertex座標をx0=b+ell(a,c,u,v)に変えるとWはW+Q(ell,−)となる。さらにE∧(f∂b)を引くとWにf Ebaseが加わる。x3,x4-rowを零にする全条件は、同値に

```
W_u+Q(ell,u)+f u=0,
W_v−3W_c+Q(ell,v−3c)+f(v−3c)=0.
```

ellとfを全四変数一次式として係数比較すると、唯一解は

```
ell=−3c+2v,        f=144a+60u.
```

例えば第一式のc²,cv,v²係数からell_c=−3,ell_v=2、ac係数からell_a=0、残りからf_a=144,f_c=f_v=0,f_u=60、第二式からell_u=0を得る。二つの元多項式を全係数保持して20×8線形系として保存・検証する。

