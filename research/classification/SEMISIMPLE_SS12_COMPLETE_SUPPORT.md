# 固定 SS12 全源の次元と double_A の非包含

2026-11-07。`E_multiple_hyperplane` の親族候補を全源で判定する。
これは **double_A の E 帰属を与える結果ではない**。固定固有値比
`(-2,-1,1,2)` の全 affine 源を親とする経路を除外する。
別の固有値比、固有値を動かす族、他の既知成分への帰属は未解決のまま残る。

## 1. 全 affine 源と必要十分な七式

入力は `CLASSIFICATION_HYPERPLANE_QUARTIC_SEMISIMPLE_SOURCES_20261107.json`
の `full_semisimple_sources[11]`。全90係数に対する線形条件から得た九係数源であり、
定数・一次項を捨てた部分族ではない。座標 `(x,y,z,w)` で

```
Pxy=(n5+n7-1)xy,
Pxz=n0*y+(-n5+n8+1)xz,
Pxw=n1+n2*yz+(2-n7-n8)wx,
Pyz=n3+n4*wx+n5*yz,
Pyw=n6*z+n7*wy,
Pzw=n8*wz.
```

全四 Jacobi の全係数は、次の七式と定数係数線形包が等しい。

```
g1=n4(n7+n8-1),  g2=n2*n4,
g3=n1*n4-n3(n7+n8),  g4=n0(n7-1),
g5=n6(n5-n8),  g6=n2(2n5-1),
g7=n0*n6+n1(1-n5)-n2*n3.
```

従って以下の支持分解は Jacobi の必要条件だけの分解ではない。
runner は全四式を直接再構成し、七式との両向き定数行汎関数を保存する。
Pfaffian の階数条件、既約性条件は加えない。低階数や可約因子の補集合も含む。

## 2. 全支持を覆う28チャート

以下で列挙した自由係数以外は表示式で決まる。各チャートは高々三変数の開集合から
有理的に写され、非零条件及び分母は report の各 `charts` に全て保存される。
下記の分岐は各段階で零・非零の双方を含むので、局所化の補集合を落とさない。

まず `n0=n6=0` とする。

* `n4!=0` では `n2=0,n7+n8=1,n3=n1*n4`。
  `n1!=0` なら `n5=1`、自由係数は `(n1,n4,n8)`。
  `n1=0` なら `n3=0`、自由係数は `(n4,n5,n8)`。
* `n4=0,n2!=0` では `n5=1/2,n1=2*n2*n3`。
  `n3!=0` なら `n7=-n8`、自由係数は `(n2,n3,n8)`。
  `n3=0` なら `n1=0`、自由係数は `(n2,n7,n8)`。
* `n2=n4=0` では `n3(n7+n8)=n1(1-n5)=0`。
  `n1,n3` の四つの零・非零の場合に分けると、それぞれ
  `(n1,n3,n8)`、`(n1,n7,n8)`、`(n3,n5,n8)`、`(n5,n7,n8)` の三変数となる。

これで八チャートである。次に `n0!=0,n6=0` なら `n7=1` であり、
同じ `n4!=0`、`n4=0,n2!=0`、`n2=n4=0` の分岐を行う。
前者では `n8=0,n3=n1*n4,n1(1-n5)=0`、第二では
`n5=1/2,n1=2*n2*n3,n3(1+n8)=0`、最後は
`n3(1+n8)=n1(1-n5)=0` となる。それぞれ二、二、四チャート、合計八。
`n0` が新たに自由となる代わりに `n7=1` が固定されるので、各々依然三変数である。

反対の `n0=0,n6!=0` は、実座標変換 `(x,y,z,w)->(w,z,y,x)` と
tensor の符号反転による対合

```
n0 <-> n6,
n7 -> 1+n8-n5,
n8 -> n5+n7-1,
n1,n2,n3,n4,n5 は不変
```

で前の八チャートに一致する。対合の二乗が恒等であることと全六括弧の pushforward を
直接検証するので、この補集合に別の仮定はない。

最後に `n0*n6!=0` とする。`n7=1,n8=n5` であり、全分岐は次の四つ。

| 開・閉条件 | 決定される係数 | 自由係数 |
|---|---|---|
| `n4!=0` | `n2=n5=n8=0,n1=-n0*n6,n3=-n0*n6*n4` | `n0,n6,n4` |
| `n4=0,n2!=0` | `n5=n8=1/2,n3=0,n1=-2*n0*n6` | `n0,n6,n2` |
| `n2=n4=0,n3!=0` | `n5=n8=-1,n1=-n0*n6/2` | `n0,n6,n3` |
| `n2=n4=n3=0` | `n8=n5!=1,n1=-n0*n6/(1-n5)` | `n0,n6,n5` |

最後の `n5=1` は `g7=n0*n6!=0` で不可能である。
以上で `8+8+8+4=28` チャートが全支持を覆う。全写像を元の七式及び全四 Jacobi に
代入して零となることも直接検証した。従って固定全源の被約次元は高々3である。

## 3. 全 PGL 飽和像は高々23次元

五斉次座標 `(h,x,y,z,w)` の対角群 `T=(C*)^5/C*` は四次元であり、
affine `div(P)=diag(-2,-1,1,2)*(x,y,z,w)` の正規化を保つ。
従って全源を保つ。`PGL5 × source` の写像
`(g,p)->[g_*P(p)]` は `(g,p)->(g*t^-1,t_*p)` の四次元作用に不変であり、
第一因子の自由作用により全軌道が四次元である。
全源の各既約成分について像閉包の次元は従って `24+3-4<=23`。
チャートの像が T 不変である必要はない。各チャート閉包を含む全源の既約成分を取り、
連結群 T がその成分を保つことを用いる。

## 4. double_A は全固定 SS12 像閉包に入らない

既存 `CLASSIFICATION_NIL22_IMAGE_DOUBLE_A_KNOWN_FRONTIER_20261107.json` は
canonical `double_A` の実 projective PGL 軌道 `O` が23次元であることを、
全 Euler/GL/scale 行列の階数48から示す。
これは全六磁気源の稠密軌道であり、零不変量の補集合もその閉包に入る。
ここではこの既済の全行列証明書を入力とし、変更点を採らない。

全六磁気源は `N=x*partial_q1+y*partial_q2` を真の対称性として持つ。
runner は全六係数のまま `[N,P]=0` と `rank(N)=2,N^2=0` を直接確認した。
`dim PGL5=24,dim O=23` なので、この点の projective stabilizer Lie 代数は
ちょうど非零冪零行列 N の一次元直線である。

一方、SS12 全源は固有値 `(0,-2,-1,1,2)` の実非自明 C* 作用で不変である。
全単項式について重み恒等式を確認しており、単に cofactor を変形したとの推論ではない。
従って SS12 の任意の点の projective stabilizer は非零半単純元を含む。
一次元冪零 stabilizer と共役にはならないので、SS12 の実像は O と交わらない。

もし O が固定 SS12 飽和像の閉包に入れば、有限個の全源既約成分の一つの像閉包 Y が
O を含む。Y は PGL 不変、既約かつ次元高々23なので、`Y=closure(O)` となる。
軌道 O は Y の稠密開集合である。Chevalley による SS12 の実構成可能像は Y で稠密で
あるから O と交わり、上記に矛盾する。これで全固定 SS12 親族を除外できる。
特定 Laurent profile の不整合から全親族非包含へ飛んだ議論ではない。
