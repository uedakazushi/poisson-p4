# 階数3・接する二次曲面の原始枝：独立還元と全支持被覆

2026-11-07。Q=w+u^2 とし、次数2以下の逆二形式のうち

    α=Qdβ−dQ∧β,    β はアフィン一次,    Pf(α)=kQ^2, k≠0

で書ける原始枝を扱う。追加の二次原始形式を必要とする枝は、このノートの全点被覆には含めない。
Ω=dβ が退化する場合は不存在であり、非退化の場合は二つの一変数族へ還元できる。
その両方に実際の射影 Poisson pencil と SNC 構造への接続を与え、
原始枝の全支持を既知 MPS40 成分閉包の和で覆う。

## 1. 退化した Ω の排除

Ω=0 なら α は可分解なので Pf(α)=0 となる。rank Ω=2 と仮定し、
体積形式 vol によって i_X vol=Ω∧β と定める。X はアフィン場で、
その値は二次元空間 ker Ω に入る。また dβ=Ω から div X=0、
α の二乗から Pf(α)=−Q XQ なので XQ=−kQ となる。

一般にアフィン場 Y が YQ=λQ を満たすとき、その u,w 成分は

    Y_u=(λ/2)u+b,    Y_w=λw−2bu

となる。これは u^2、uv、uz、uw、u、v、z、w、定数の各係数の比較から従う。
U=(u,w)、R=(v,z) の順で X の線形部分を書くと

    L=[[A,0],[C,D]],    A=[[λ/2,0],[-2b,λ]],    λ=−k≠0.

A は可逆であるから rank L=2+rank D。一方 im L⊂ker Ω により rank L≤2 なので D=0。
従って tr L=3λ/2≠0 となり、div X=0 に矛盾する。よって Ω は非退化である。

## 2. 非退化の場合の二つの型

i_ZΩ=β と定義する。Ω は定数なので L_ZΩ=dβ=Ω。
また外積恒等式から Pf(α)=Pf(Ω)Q(Q−ZQ) であり、

    ZQ=λQ,    λ=1−k/Pf(Ω)≠1.

従って Z の u,w 成分は1節と同じ形を持つ。R=span(∂v,∂z) は Z の線形部分で保たれる。
二次元の Ω|R は非退化か零かのどちらかなので、次の二場合で尽くされる。

### Ω|R が非退化な型

U を固定する R の線形 shear で Ω を直交直和にし、射影スカラーと R の基底変換で
Ω=du∧dw+dv∧dz と正規化できる。L_ZΩ=Ω の各ブロックから

    λ=2/3,    C=0,    tr D=1

を得る。Q を保つアフィン変換 u↦u+s、w↦w−2su−s^2 により b を消せる。
D を trace 1 のまま一般の可逆・相異なる固有値の行列へ変形し、R の平行移動で定数項を消し、
R のシンプレクティック基底で対角化する。従って全ての点は、群飽和と閉包の意味で

    Z=(u/3, a v, (1−a)z, 2w/3)

という一変数族に還元される。対応する Poisson tensor は、非零全体スカラーを除き、
(uv,uz,uw,vz,vw,zw) の順で

    S_a=(3a hv, 3(1−a)hz, 3Q_h, Q_h, 6a uv, 6(1−a)uz),
    Q_h=hw+u^2

と書ける。Pf(S_a)=3Q_h^2。非対角 D や非可逆 D は、実際の trace 1 行列族の特殊化として保持する。

### Ω|R が零である Lagrange 型

U を固定する線形変換と R の shear で Ω=du∧dv+dw∧dz とできる。
U,R の順の行列式では

    D=I_2−A^T,    C=C^T,
    A=[[λ/2,0],[-2b,λ]].

λ を一般値へ変形し、b と R 方向の定数項を消す。対称行列 K による R↦R+KU は Ω を保ち、
C を C+KA+A^TK−K に移す。A が対角になった後、この写像の三係数は

    λ−1,    3λ/2−1,    2λ−1

である。従って一般 λ では C を消せる。除外した有限個の λ や非零定数項の点は、
Ω を固定し、λ,b,C,定数項を動かした実際の多項式 Poisson 族の閉包として保持する。
一般正規形は

    Z=(λu/2, (1−λ/2)v, (1−λ)z, λw),    λ≠1.

対応する Poisson tensor をスカラー倍して

    P_λ=(−2u^2+(2λ−2)hw, −λhu, 0,
         (4−4λ)uz−(2−λ)hv, 4λuw, 2hw+(2−2λ)u^2)

とする。Pf(P_λ)=4(λ−1)Q_h^2。

## 3. Lagrange 型全体の実際の SNC pencil

次の logcanonical tensor を取る。

    R_λ=(uv/2, −λuz/2, λuw/2, (λ/2−1)vz, −λvw/2, wz).

全 λ,t に対して Jac(P_λ+tR_λ)=0 が係数ごとの恒等式として成立する。
その Pfaffian は

    Pf(P_λ+tR_λ)
      =−(λ−1)(tuv−4Q_h)(twz+2Q_h)/2,
    Pf(R_λ)=−(λ−1)uvzw/2.

λ≠1 なら R_λ の射影退化因子は五つの独立な座標超平面 h u v z w であり、SNC である。
射影 pencil [sP_λ+tR_λ] は Poisson スキーム内の既約曲線で、P_λ と R_λ を含む。
この曲線を含む全空間既約成分は SNC locus と交わるので、既存 MPS40 定理により既知40成分の一つである。
従って全 λ≠1 の P_λ は既知閉包の和に入る。
2節の正規化・実変形と、この和の閉性・PGL5 不変性を合わせ、原始 Lagrange 型の全点が覆われる。

これは λ=3 の一標本を一般値へ推測したものではない。
有理関数体 QQ(λ) 上で logcanonical 係数の全線形互換条件を解き、
得られた式が実際には全 λ の多項式恒等式であることを直接確認した。

## 4. もう一方の型には射影 Poisson pencil を用いる

S_a に対し、同じ座標の任意の logcanonical tensor
R=Σ_(i<j)g_ij x_i x_j ∂i∧∂j との互換条件を QQ(a) 上で解くと、
係数空間は (0,0,0,1,0,0) の一次元 span に限られる。
この R の Pfaffian は零であり、この対角 ansatz では一般の S_a を SNC へ繋げられない。
そこで h を Casimir とする条件を pencil の第二項には課さず、次の同次二ベクトルを取る。

    (R_a)^(h,w)=−u^2,
    ((R_a)^(u,v),(R_a)^(u,z),(R_a)^(u,w),
     (R_a)^(v,z),(R_a)^(v,w),(R_a)^(z,w))
      =(a uv,(1−a)uz,uw,(2−2a)vz,(1−2a)vw,(2a−1)zw).

他の h を含む括弧は零である。全 a,t について

    E∧[R_a,R_a]=0,    E∧[S_a+tR_a,S_a+tR_a]=0

が成立する。アフィン lift の [R_a,R_a] 自体は非零であり、
ここでは全350係数の **射影** Jacobi 条件を検査している。
退化五次式は

    D(R_a)=u v z(hw+u^2).

pushforward の規約で g_ε=diag(1,ε^(−1),1,1,1) を作用させると、
六つの logcanonical 項は不変で、h,w 成分だけが −ε^2u^2 となる。
ε=0 の tensor 極限は logcanonical で、その退化式は h u v z w である。
六係数の反対称行列の Pfaffian は全 a で1なので、例外となる a はない。

R_a を含む任意の全空間既約成分は、連結群 PGL5 の作用で保たれるため、
この SNC 極限も含む。従って MPS40 のいずれかである。
実際の射影 pencil [sS_a+tR_a] を含む既約成分を選べば、S_a も既知成分に入る。
この包含と2節の実変形・閉性から、Ω|R が非退化な型の全点も覆われる。
3節と合わせ、原始枝全体の支持被覆が得られる。
