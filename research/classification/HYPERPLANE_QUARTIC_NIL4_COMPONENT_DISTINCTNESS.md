# regular nilpotent・単純H＋既約四次の22次元成分：既存89との相違

2026-11-07。課題AとE_reduced_nonnormal。新成分性の全周囲証明・独立検証を
入力とした相違の監査であり、このノートだけを理由に成分数を増やさない。
対象は純冪零型(4)、translation零、normalized scalar δ=−1/3の全源である。

## 1. 実代表と既約退化式

座標(h,x,y,z,w)、h-Casimir代表で六括弧を

    Pxy=36hw+6xz−8y², Pxz=6wx−10yz, Pxw=−10wy−z²,
    Pyz=6wy−9z², Pyw=−12wz, Pzw=−12w²

とする。実Pfaffianと退化五次式は

    F=9[(2wy−z²)²−48hw³],   D=hF.

Fはhについて原始一次式である。係数w³と定数項(2wy−z²)²は互いに素なので、
Gauss補題により複素数体上で既約。hもFを割らない。従ってDは被約で、
その既約因子次数分割は正確に1+4である。F≠0なので一般rank四。

全150係数・350式のJacobi微分rank102、実群・vertical・scalarのrank47から、
射影接次元は23、実PGL軌道次元は22。
真正な一本のnormalの二次項は微分像に入るが、全kernelによる補正曖昧さを除いても
三次項が全微分余核で非零となる。これは全空間の22次元成分を証明するための
別の支持証明書と独立確認を必要とする。単に接空間次元23から22成分とは推測しない。

## 2. 既存89成分との最弱の識別

`research/COMPONENTS.json` と `KNOWN_COMPONENT_AUDIT.md` の基準89成分に対する監査は次の通り。

* 40個のMPS成分は射影次元23、24、25である。対象の全空間成分が22次元と証明されれば、
  次元によりこれらと異なる。SNCの一点を持たないという観察だけに依存しない。
* 六つの一般rank二成分とは一般rankが異なる。
* その他、次元22でない成分とは次元が異なる。
* 既存の一般rank四・次元22・非MPS成分で、
  `R4_TWO_HYPERPLANES_CUBIC_22` 以外は全て非被約な一般退化因子を持つ。
  非被約五次式の集合はprojectiveな乗算写像による有限個の閉像の和である。
  各旧成分の全閉包もこの閉条件内に入るが、上のDは被約なので入らない。
* 残る `R4_TWO_HYPERPLANES_CUBIC_22` は、一般退化式が二つの一次式と三次式の積。
  その全閉包も `P(Sym¹)×P(Sym¹)×P(Sym³)` の積写像の閉像内にある。
  既約四次因子Fを持つD=hFはこの像に入らない。

最後の非被約22成分は具体的に、H+2Qのsmooth・rank3 mixed、3H+Q、Jordan4四成分、
nil31短鎖一成分・長鎖二成分、nil22/nil31の負重み三成分である。
catalogue上の十四個のrank四・次元22項を全て確認し、被約1+1+3型を唯一の別枝として保持した。

従って上記の**全周囲成分性が独立受理された場合**、この成分は基準89と全て相異なる。
下界を90、一般rank四を84へ更新してよい。全成分の上界又は全分類の完成は従わない。

## 3. 追加の幾何的な識別

同じ代表は平面Π=(w=z=0)に沿ってDが二重以上に消え、その法線二次項は
`36h y² w²` でrank一である。
Grassmannian Gr(3,5)上で `D∈I_Π²` と法線二次の判別式恒等零を課したprojective incidenceの像は閉じる。
SNC因子では特異曲面の一般点は二成分の横断交叉なので、法線二次はrank二。
三重交叉は次元一以下であり、平面の一般点を覆わない。
従ってこの閉条件を持つ対象の軌道閉包はSNC点を一つも含まない。
これは成分の幾何を説明する追加証明であり、上の次元・rank・因子次数による最弱の相違証明には不要。

## 4. 独立確認

`code/classification_quartic_component_distinctness_review.py` と
`reports/CLASSIFICATION_HYPERPLANE_QUARTIC_NIL4_DISTINCTNESS_REVIEW_20261107.json` で、
凍結した基準89台帳を読み直した。89件の全識別理由を個別に記録し、MPS40の次元、
rank四・次元22の全十四件とその十三非被約／唯一1+1+3という分岐を確認した。
台帳の各成分の元証明を全て再実行したのではなく、既存の成分性・次元・一般因子の
監査済み記録を入力として比較した。

標準libraryの独立疎多項式演算で、六括弧が別の全周囲独立検証の実witnessと
完全に同じこと、全十raw Jacobiの零、実Pf恒等式、平面法線二次項を確認した。
hの係数が−432w³、h定数項のw=0制限が9z⁴であることも確認し、Gauss論理を再検討した。
全周囲22次元の支持証明そのものは別のFraction独立証明書を受け入れた入力であり、
本相違checkerで再実行したものではない。

非被約五次の閉条件は、次数d=1,2に対するprojective写像
`(G,R)↦G²R, deg R=5−2d` の閉像の和として取れる。
rank二境界では退化式が零になるので、全空間閉包へ適用する際はこれらの閉像の
affine coneに零を含める。1+1+3型も同じく零を含む閉coneで扱う。
この補足により退化写像のprojective化がrank二点で未定義になる問題を避けている。
追加のGrassmannian incidenceによるSNC排除も独立読解で確認した。

全周囲成分証明と本相違証明を合わせれば、新成分を追加して下界90、一般rank四84と
数えてよい。全分類の完成又は成分数の上界を主張しない。
