# Poisson subvariety incidence (2026-11-10, v1)

This module studies Poisson extensions from smooth P3, quadric and cubic threefolds, and smooth (2,2) del Pezzo surfaces to P4. It is **not** a replacement for the 147-component classification manuscript.

- Japanese LuaLaTeX paper: [poisson_subvariety_incidence_ja.tex](../../papers/poisson_subvariety_incidence_ja.tex)
- Current research policy: [RESEARCH_POLICY.md](RESEARCH_POLICY.md)
- Notes and open problems: [NOTES.md](NOTES.md)
- Exact SymPy scripts: [generic rigidity](../../code/subvariety_incidence/verify_del_pezzo_rigidity.py) and [examples](../../code/subvariety_incidence/check_incidence_examples.py)
- Full v1 archive including the previously verified 11-page PDF, original script certificates and manifest: ChatGPT Library `/poisson-p4-incidence-20261110-v1(1).zip`; separate PDF `/poisson_subvariety_incidence_ja_20261110_v1.pdf`.

Main statements: unique rank-two ambient lift from a smooth cubic; generic reduced singleton extension for a smooth (2,2) del Pezzo/Poisson pair (not all pairs); incidence dimensions 36 and 28; transverse Poisson symmetry criterion for simple invariant hyperplanes; quadric rank-jump examples. Literature novelty remains unconfirmed.

To reproduce, install Python 3 with SymPy 1.14 and run the two scripts. The complete original v1 certificates and PDF are preserved in Library. Do not claim this module independently re-verifies the 147-component classification. Library binary redownload is not required.

The original classification manuscripts and certificates are unchanged.
