# Poisson structures on projective four-space

複素射影4空間のPoisson構造の完全分類を目指す研究リポジトリ。
**2026-11-01 · v37-s61：二平面型の自由階数65・非平坦な三枝交点・一般βに残る階数降下曲線。**
完全分類は未完了で、既知成分数の下界57は維持します。

非二元の標準型G=xzwは、**全ての十分一般な一次項上で、その軌道の全無限遠点を飽和除去**した。
普遍二次障害を一つの平方へ簡約し、消去minorの全因子を五つの十六次元層と既解決層で覆う。
別の非二元型G=z²w、zw²、特殊混合型、旗・二平面型の残る接続点は別に調べる。

二平面型の階数33/34点でも、完成環は三変数底上で自由階数65となる。
横断Hilbert関数は(1,8,22,34)、I⁴=0、0≠t、It=t²=0、t商は自由階数64。
さらにu4=0、u14=0、u49=0の三つの十六次元端点層を全一般βで除去した。
元の十七次元階数降下曲線の全点まで除いたとはしない。

最小型の八接続点では一般階数4,4,4,8,3,4,5,6を実在枝の長さ和で尽くし、tの冪零性を証明した。
内在的な頂点条件と有限jet特殊化により、対応する十六次元接続層の全一般βファイバーも除ける。
M0/M1のg6/g7全四孤立軸表示も、元134式の全Jacobian45を用いて全一般βで除去した。
正次元のtail・主曲線・自由基線の残る例外は別に保持する。

ABの正規化には次数三にも新しい生成元がなく、D3=B3は6691次元である。
原点の全次数生成性・正規性と、全S61の一般アフィン五点の尽くしは未決で、成分数の下界57を変えない。

一般一次項上の **未飽和無限遠の被約点を全モジュラー型にわたって尽くした**。
非冪零・正則冪零・冪零(2,2)・最小型開層のβ像を真の閉部分へ除外し、
残る全点を R0 と最小型 M0/M1 の有限正常形表へ帰着した。旧 Q45 分類を依存として保持する。
最小型の表は、実際の線形消去pivotを点検して見つかった四つの追加直線族を含む修正版である。
これは未飽和被約台の尽くしであり、全無限遠の飽和除去やアフィン五点の尽くしではない。

非二元型の二つの共鳴交点では、135式完成局所環が一変数冪級数環上自由階数4の
完全交叉で、被約台は通常二重点、冪零部分は平方零、t=0と証明した。
各交点stratumと最小型M0の孤立axis成分は十六次元でβを優越し、
それぞれの全一般βファイバーが飽和で除ける。正次元曲線族の他の端点は調査を続ける。

実際の T01 の零一次部分の被約台は既約十次元の AB であり、AB は **原点外で正規**。
一変数型の非零トレース軌道の埋込み次元・重複度は16・7、零トレース軌道では18・10となる。
proper incidence の全被約ファイバーだけからは正規性が従わない反例も保存した。
原点の正規性、スキーム論的T01零ファイバーの厚みは未決である。

最小型の一般二曲線の指定開部分は既証明の平方零完成局所環で記述される。
全135同次数斉次化のSp4同変性を用いるが、未検証の共鳴点への延長は行わない。

標準曲線が滑らかな全領域 Δ≠0 で、T01・T39・T40 は互いに交わらない。
三つの被約成分の合併は有限エタール・次数5となる。全 S61 のファイバーが
この五点だけであることや、その周囲の全局所環の被約性は未証明である。

Δ≠0でも非零モジュラー無限遠が残る反例は維持する。今回の除外は十分一般のβについてであり、
滑らかな標準曲線を持つ全βからの除外ではない。

T02 の一次像の既約定義式の次数は26以上と分かっているが、定義式そのものは未決である。

T01 の一般三次被覆を標準曲線 Cβ の Jacobian の非零二捩れと同定した。
Δ=(c4³−c6²)/1728 は幾何学的に既約被約な24次超曲面である。
次数9共変量 C9 の全域多項式性と、S61 座標による多項式 X の復元を証明したので、
**実際の T01 は Δ≠0 上で X³−27c4X−54c6=0 と同型**で、全域で有限エタール・次数3となる。
全 T01 の被約定義イデアルも、この三次式と明示的な45式を Δ で飽和して記述できる。

一方、T01→W は全域では有限でない。β=0 の被約ファイバーは AB であり、既約十次元である（旧 Q45 分類に依存）。
従来の有限な可換代数模型はその上では q=0 しか与えず、全トーリック境界を覆わない。
欠落する境界点への明示的な一パラメータ族を構成し、全134式とJacobi式を確認した。

楕円型二成分 T39=q(5,1)、T40=q(5,2) の被約 S61 閉包は、それぞれ
全一次部分空間 W=A16 上の明示的な二次多項式 graph である。従って両成分の
一般次数は1、射影 S61→W は全域で全射。表示の一般重複度は両族とも3000と決定した。
二 graph の被約交叉は五次元・次数24の旗円錐で、原点に長さ10の冪零部分を持つ。
T01 の三次被覆の幾何学的モノドロミーは S3 である。

一般 β について、既知五延長を含む有理的なアフィン三平面を構成した。その平面と
全134式との交叉は被約な長さ5で、関数体 K 上の代数は A_T×K×K と分解する。
**全ファイバーがこの三平面に含まれることは未証明**であり、一般有限性・尽くし・
特殊層・未知成分の不存在は完了していない。成分数の下界57は変更しない。

## 最短の再現手順

Python 3.11以上とvenvを用意し、リポジトリのルートで実行します。

```sh
bash scripts/setup.sh
.venv/bin/python scripts/doctor.py
.venv/bin/python scripts/verify.py --suite quick
.venv/bin/python scripts/verify.py --suite rank2
.venv/bin/python scripts/verify.py --suite integrity
```

Python依存は固定しています。日本語PDFの再ビルドにはLuaLaTeX、luatexja、HaranoAji等が
別途必要です。既存PDFは同梱されています。詳細は [setup文書](docs/CODEX_SETUP.md)。

## 保存と継続

作業の区切りと、長い作業ではおおむね30分ごとに、意味のある変更をmainへ保存・push
する方針です。GitHub Actionsは使用しません。保存のために毎回ユーザーへ確認しません。
`scripts/make_bundle.py` は再開に必要な資料をまとめた配布ZIPを生成します。
Library保存は、その機能が実行環境にある場合に許可済みの操作として行い、実際の
保存結果を記録します。リポジトリの設定だけでLibrary接続が追加されるわけではありません。

既存の強い結果の論文化を進めながら、未処理領域の尽くしを優先します。
このリポジトリにあることをもって査読済み・完全分類済みとは扱いません。
