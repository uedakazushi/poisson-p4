# Exact bounded nonsquare product work

This packet preserves work beyond the accepted marked-square and degree30
theorems. It does **not** prove all-core QQ product rank41, quartic coverage,
ambient removal of the remaining nonsquare locus, or absence of affine surfaces.

The original product matrix is41×84 on aFBC≠0. Known-unit elimination gives21
pivots; exact constant QQ row/column combinations give3 more. Scalar R3 ideals
then supply targets a and a³, with exact lifts of73 and3148 terms, respectively.
Thus26 unit pivots are justified, with a15×60 residual still unresolved.

The final residual has1,082,813 nonzero polynomial terms and489MiB (512,385,225 bytes) of coefficients.
Its SHA and exact byte count are in `report.json`; this large derived file is
kept in ignored work and omitted from the archive. It is regenerated by the
recorded native source from `after-witness.txt` and `controller-2-witness.txt`
(selected row12). The smaller inputs and exact witnesses are preserved.

`evidence.tar.gz` contains the archived-member paths and SHA values listed in
`report.json`, including input matrices, source builders, unit factors, Bezout
witnesses, native logs, and the two bounded QQ module attempts. The generic
J≠0 case14×46 exceeded120s; the J=0 two-parameter case12×44 exceeded90s.
The corner d=0,e=−2/3 has an exact24-pivot certificate.

The stable coordinate API is
`code/s61_binary_nonsquare_mod_ell_coordinates_20261103_v62.py`.
It supplies the actual six-light-variable quotient map by ell, including the
unchanged weight2 variable, unscaled four quadrics, and exact clearing factors.
This supports the independent66-column quartic strategy.

The reusable native source is
`code/polynomial_unit_span_pivots_20261103_v62.cpp`:

```sh
source /workspace/cloud-setup/activate.sh
g++ -O2 -std=c++17 code/polynomial_unit_span_pivots_20261103_v62.cpp \
  -o work/unit-span $(pkg-config --cflags --libs flint)
work/unit-span INPUT OUTPUT UNITS HAS_METADATA [transpose] [colclean] [WITNESS TARGET_ROW]
```

`INPUT` has header n,m,k and, when HAS_METADATA=1, k pivot labels plus n row
labels. Each polynomial is a term count followed by rational coefficient and
three exponents for a,e,d. `UNITS` lists nonconstant polynomials, one per line.
`WITNESS` has the column count followed by one polynomial per column in that
same format. TARGET_ROW is zero-based after the optional transpose. The source
verifies the exact resulting entry is a unit. It uses an invertible source
column replacement when one witness coefficient is a unit, otherwise adds a
column combination before the unit pivot. A partial pivot count is not a
full-rank certificate. Optional `colclean` was tested but did not improve this
product path and is off by default.

For an isolated replay, unpack into a new ignored directory and use new output
paths. Archived pilot M2 scripts and controller paths refer to their original
work directory; adjust those paths before executing them in a replay directory.
Do not rerun the large residual merely to inspect the scalar Bezout identity.

Macaulay2 1.24.11 supports the baseline GB and `//` matrix division used here.
Its experimental `Algorithm=>LinearAlgebra` failed even on a small QQ ideal
with an internal array-order error; this experimental acceleration is not used.
No environment setup needs to be repeated.
