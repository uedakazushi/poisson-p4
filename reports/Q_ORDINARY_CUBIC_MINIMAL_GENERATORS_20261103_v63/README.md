# Through3 初期イデアルの明示的な最小生成元

[真の三次初期証明書](../Q_ORDINARY_CUBIC_INITIAL_20261103_v63/)の別添。既存の証明書・ノートは変更していない。

57個の二次式を選んだ350行番号は親証明書のrecipeにある。三次式は次の17個の元の定数消去後の G_i で選べる（0始まり）。

- 元の重み12：168, 238
- 元の重み13：11, 12, 48, 98, 171, 234, 239, 241
- 元の重み14：13, 49, 101, 240, 242
- 元の重み15：14, 243

これにより、通常次数2・3の真の初期部分から生成される斉次イデアル J_(≤3) は、57二次式とこの17三次式の計74式で生成される。

証明ではGF(32003)上の全1995二次式変数倍を行簡約し、135候補 G_i を追加して独立な17 classを直接選んだ。親証明書でQQ上の対応する商の次元も17と厳密に計算済みなので、この17 classはQQ上でも基底である。さらに親証明書のQQ/GF rank一致とunit minorにより、V=Z_(32003)上の商は自由rank17であり、剰余体上で基底になるこの17 classはNakayamaによりV上でも基底となる。選択に使った有限体pivotも全て保存した。

これは全非斉次局所イデアルの生成元が74本という主張ではない。四次以上の初期生成元は未決である。次の次数を調べる際、1995個の変数倍二次式と17三次式の間の線形関係数は 1995+17−1911=101 となる。

`generators.json.gz` に全17個のQQ係数を保存した。解凍したファイルのSHA256は `report.json` の `evidence_sha256.generators_json` に一致する。親証明書の135式から同じ17式を選んでいる。

```sh
source /workspace/cloud-setup/activate.sh

```
