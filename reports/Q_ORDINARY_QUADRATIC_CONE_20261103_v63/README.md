# 通常の全二次障害：rank57 と QQ 上の13平面

保存済み35変数の有限局所モデルについて、u=a−2/9 と z0,…,z33 をすべて通常次数1とし、全350残差の総次数2以下をQQ上で抽出した。a のみに依存する逆元も定数項から2次まで正確に展開し、積が1になることを検査した。

## 証明書で確認した内容

- 全350式の定数項・一次項は零。
- 138行が非零二次式であり、QQ上の線形包の次元は57。
- 150個のテンソル係数の2jetから、5変数指数辞書の微分・積で独立に再構成した全350 physical Jacobiと一致し、divergence25係数も零。
- 350二次式の係数はZ_(32003)上にあり、QQの疎行消去に使った57 pivotはすべて32003-unit。選択した57原始行はZ_(32003)上でも全350二次式を生成する。
- 次の変数だけを自由にし、残り22変数を零にすると、全350二次式がQQ上で恒等的に零になる。

  `u,z3,z5,z8,z13,z14,z15,z16,z17,z24,z25,z26,z28`

従って通常の二次障害イデアルの零点集合はQQ上の13次元座標平面を閉部分スキームとして含み、C上でも次元13以上である。この二次障害だけから局所モデルの次元12以下を導くことはできない。全局所モデルに13次元成分が存在するという主張ではない。二次項が消去された組合せの高次初項や、さらに高次の障害が必要である。

二次式の各単項式を直接調べた座標平面検証は0.022秒。平方項のある20座標を除く15座標の全32768部分集合も検査し、最大次元の座標平面は上の13平面一つだけである。必要な次元下界は恒等消失の検証だけで成立する。

## 計算の限界

M2の完全GBは次数4で急増したため93秒で停止し、Singular slimgbも200秒で打ち切った。双方6GBの制約を課した。二次障害円錐の正確な次元・Hilbert級数・主成分分解は取得していない。全35変数の有限モデルの成分分解も未決である。18百万項の重み付き展開をこの抽出で使用していない。

将来GF(32003)上の二次円錐次元を得た場合、QQ上の上界に移すには、上記Z_(32003)係数から作る通常の斉次イデアルのProjを使い、射影的な族のファイバー次元の上半連続性を適用する必要がある。局所初期イデアルの剰余体への可換性を仮定してはならない。本記録の13次元下界はQQ上の直接証明であり、その移行を必要としない。
